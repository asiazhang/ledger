# ADR 0037: AI 标的搜索与幂等创建——投资迁移的 HTTP 前置能力

- 状态：已接受
- 日期：2026-08-30
- 作者：Ledger 项目
- 关联：issue #287；解除 ADR-0036 非目标「AI 导入不加建标的路由」；消费 ADR-0027（统一模糊搜索）、ADR-0028（商户即建先例）、ADR-0032（连接层写入口）；`source` 列归属与 ADR-0036（自建标的）协调；词汇表：投资域 Instrument / AI 导入域 AI API

## 背景

buy/sell 提交必须携带标的 id，但 AI API 面没有任何标的端点：AI 既查不到已有标的、也无法创建新标的，投资字段（标的、数量、单价、费用）是悬空契约，投资历史迁移整条走不通，导入知识只能对 buy/sell 保持沉默（写「支持」不诚实、写「不支持」不准确）。经 issue #287 两轮 grilling 定案：提供标的搜索与幂等创建两个端点 + 配套校验与教学，能力落地后解除文档沉默。

## 决策

1. **搜索端点（GET /api/v1/instruments）**：`query` 必填（空即 400，搜索式而非全量列表），`limit` 默认 20、上限 100，`market` / `type` 可选过滤；语义复用 ADR-0027 统一模糊搜索（内部走既有标的搜索接缝：词条 AND、子串 ∨ 拼音首字母、大小写不敏感，判定目标「代码 · 名称」label，按 symbol 排序），响应复用完整 Instrument 形状（items + total）。不为 AI 另造「前缀/子串」第二口径。
2. **创建端点（POST /api/v1/instruments）**：find-or-create 幂等（自然键（symbol, 类型）），命中静默复用返回既有 id——响应照账户/分类创建先例：201 + 裸 id 字符串，无 created 标记。`market` 缺省 unknown；报价币种可省，缺省按市场推导（沪深→人民币、港→港币、未知→人民币）——依据：标的币种不参与买卖账务（持仓批次成本币种 = 账户币种），仅影响行情/市值折算展示。
3. **无代码标的以名称充当代码**：AI 契约约定（源数据只有名称时 `symbol := name`），后端零特判；创建不做按名称二次匹配，防碎片靠「先搜后建」教学约定；AI 通道无就地升级为真实代码的入口，误建行走自建标的删除通道（ADR-0036）清理。
4. **创建类型不设白名单**：五类全开。自建标的的非股票白名单是 UI 侧政策（防用户手填信息被同步覆盖）；AI 面上同步按代码覆盖 stock 行属自愈（东财数据更权威），同码异类型（基金 000001 vs 平安银行 000001）由自然键分开、type 过滤消歧。AI 创建行来源标记 = 手动（非同步即手动），与自建标的同路。
5. **`source` 列由本决策的迁移先行落地**：只增合规（instruments 增列，存量回填同步），自建标的实施（代码未动）后到复用——投资迁移阻塞优先解除，两议题谁先实施谁带迁移。
6. **配套**：prepare 补「标的不存在」校验（400 中文信息，消除错 id 撞外键的 500，保证读回自纠）；标的写入不发参考失效信号（标的不属参考数据四表）；导入知识补 buy/sell 教学（标的解析三步法、行字段约束、纠错、对账）+ 关键词锁追加；openapi 补投资四字段描述（现为裸字段）。buy/sell 写入复用行为层投资域分派（prepare/apply），端点只补前置能力。

## 理由

1. **独立创建端点而非商户式内联**：商户 find-or-create 内联在交易写入路径（ADR-0028）胜在防孤儿；标的引用维度多（类型/市场/币种），内联需给 TransactionInput 加引用机制并扩展行为层编排。独立端点复用已测试的 upsert 接缝、错误归因清晰（标的问题在标的端点暴露）、改动面最小；孤儿行（创建成功而后续买出行校验失败）是轻微残留且有自建标的删除通道兜底。
2. **名称充代码而非 symbol 可空**：零 schema/模型改动，既有唯一约束与 upsert 免费提供幂等防碎；可空方案需动已发布表结构 + 部分唯一索引 + 输入/模型/前端连锁与两套自然键。代价（symbol 语义糊化、无升级通道）落在伤害面最小处：此类行以基金/债券等无行情来源标的为主，不参与行情同步。
3. **统一搜索口径**：全应用一个模糊搜索语义（ADR-0027）是既定规格，标的下拉已消费；另写口径即造出第二个口径（与金额口径收口同理）。
4. **照先例响应**：「沿用 AI API 既有形态」是 issue 级定案；created 标记无消费场景（幂等语义与账户创建一致）。

## 代价

1. 名称充代码行语义糊化：Instrument 词条「标的由显示代码与市场共同标识」加注迁移例外。
2. 名称行无法升级为真实代码（AI 通道无更新入口）；错行删除重建兜底（无引用时）。
3. 孤儿标的行可能残留（创建成功而后续买出行校验失败）；幂等重跑不放大，且有自建标的删除通道。
4. 无白名单下，AI 误填类型 + 代码可能造出与同步字典并存的同码异类型行——搜索两行并返、type 过滤可辨，碎片可控。

## 替代方案

- **商户式内联**（交易行带标的名字符串、后端两段式 find-or-create）：防孤儿最强但机制面大（TransactionInput 引用互斥 + 行为层编排扩展），且标的维度多于商户名，否决；若孤儿问题实质化可重议。
- **symbol 可空 +（类型, 名称）部分唯一索引**：语义最干净、可就地升级代码，但 schema/模型/前端连锁改动与双自然键维护，否决。
- **只搜不建**：无命中即失败该行、中断迁移流程，违背核心用户故事，否决。
- **AI 面专用搜索口径（前缀/子串）**：第二口径维护成本，否决。

## 影响

- 词汇表：投资域 Instrument 词条（幂等建行 / 标的搜索 / 迁移建行边界）、AI 导入域 AI API 词条（投资迁移链路）、CONTEXT-MAP 域间关系已随 grilling 更新。
- 测试面：api_server 集成测试（搜索命中/未命中/封顶/query 缺省 400、创建幂等、buy/sell 全链路、标的不存在 400）、投资域 BDD 迁移链路场景、导入知识关键词锁追加。
- ADR-0036 非目标「AI 导入不加建标的路由」自此解除；其 `source` 列需求由本决策的迁移先行承载。
