# ADR-0076: 应用更名「开源记账 / OpenLedger」——显示名与发布契约解耦，identifier 冻结

- 状态：已接受（实施待启动，grilling 定稿）
- 日期：2026-09-05
- 作者：Ledger 项目
- 关联：ADR-0049（i18n——双名按界面语言取用）；ADR-0066（跨平台发布——productName 即产物名与 Release 资产名）；ADR-0074（Android 发布——工程未生成，applicationId 届时从冻结 identifier 派生）；ADR-0018（主库文件名固定 `ledger.db`）；ADR-0007 / 0016（备份产物——受管备份前缀为识别依据）；AI 导入域 AIPrompt（「Ledger API」协议称谓）

## 背景

应用自始名为「Ledger」（productName、窗口标题「Ledger 账本」中英混排、标识符
`com.zhangheng.ledger`）。改名动机经 grilling 确认为二：英文命名空间撞名严重（Ledger
硬件钱包、ledger-cli 等在先且声量巨大），作为专有名不可搜索、不可传播；产品功能重仓
中文市场（A 股 / 港股行情同步、东财、场外基金），需要中文名。

候选筛选共九轮碰撞验证，事实结论：中文记账品类的常用字组合基本被占——算盘（同名
Rust 记账 CLI）、账房（云帐房 / 大账房 / 小账房财税 SaaS）、家账（家账本 / 易家账）、
壹本（一本记账 / 壹壹记账）、账柜（e账柜）、家财（家财宝 / 家底）、简账、小金库（同名
iOS）、一笔（一笔 / 一笔记账 / 一筆賬）、明账（账明）、松鼠 / 蜜蜂 / 鲨鱼等记账名宿，
及动物系仓鼠、锦鲤、卡皮巴拉（咔皮记账为商汤产品、巴拉记账包名即 capybara、
Capybara Budget 连 offline-first 定位都重合）全部有主；水獭、鲸头鹳等幸存者因品味否决。
结论是「朴素、直白、常用字、零撞名」四者不可兼得，必须放弃其一。

用户在知情下选定：中文名取品类词「开源记账」——名字即立场，接受不可独占；英文门面取
「OpenLedger」——明示接受与在营公司（openledger.com 嵌入式会计 API、openledger.xyz
AI 区块链）及多个同定位开源项目（openledger.cloud 本地 AI 个人财务等）撞名；接受理由
是项目非商业化，不参与商店搜索与品牌竞争，撞名代价可承受。

## 决策

### 1. 双名定案：中文「开源记账」、英文「OpenLedger」、tagline「开源、本地优先的个人记账应用」

- 中文名直接言明开源属性与品类，是「名字即立场」的明示选择；「开源记账」为品类词，
  独占性与搜索唯一性让位于直白。此前「双名不一致」的候选组合（中英各自直译不同词）
  随两名的字面对应而消除。
- **备选与否决**：OpenBookkeeping（字面直译，验证撞名最轻——仅一个 17 星同名 repo 与
  一家记账服务社，无公司无产品；因冗长落选，用户选择更简洁直接的 OpenLedger）；
  OpenBooks（验证不可用：GitHub 至少四个同名开源会计项目，另有在营计费软件同名）。
- 落选候选族记录在案、防止重启已否决方向：容器系（钱匣 / 账匣——品味否决）、
  动词系（落账——验证干净但未获青睐）、动物系（见背景，撞名与品味双重否决）。

### 2. 改名范围＝显示层；identifier 冻结

- 只改用户可见显示面：productName、窗口标题（zh / en 双名按 ADR-0049 取用）、i18n
  文案（关于页、备份文件过滤名、AI 提示词中的用户指引）、`index.html` 标题、侧栏标题、
  README、CI 产物名。
- **标识符 `com.zhangheng.ledger` 冻结，永不再改**：桌面数据目录由标识符派生，改即迁址；
  Android 工程（ADR-0074）尚未生成，applicationId 届时从现标识符派生——本次定案即
  「零成本窗口」的终局，此后不存在无痛改期。
- **备选与否决**：借 Android 工程未生成的窗口一并改标识符——数据目录换址、脚本面迁移，
  收益（标识符词根与新名一致）不抵代价，且内部词根本就不随品牌走（决策 3）。

### 3. 兼容契约保留「ledger」词根，内部命名与显示名永久解耦

- 不随改名变动：主库文件名 `ledger.db`（ADR-0018，备份压缩包内条目同名）；受管备份
  前缀 `ledger-backup-` / `ledger-auto-`（清理逻辑按前缀识别受管备份，改前缀使存量备份
  脱离管理）；AI 入口提示词的「Ledger API」标题与 API 称谓（对 AI 助手的协议文本）。
  Rust crate 名、package name、GitHub 仓库名等内部命名一律不动。
- 提示词正文中面向用户的应用操作指引（如「保持应用运行」）属用户可见文案，随显示名
  更新，其断言测试面同步。

## 后果

- 用户可见变更随实施记入 CHANGELOG `Unreleased`；schema、迁移、AI API 契约零改动，
  无发布边界问题。
- 搜索与传播面接受现状：`OpenLedger` 检索结果与上述公司 / 项目并存，社区传播依赖仓库
  与 README 自身的可发现性，不依赖名称独占。
- 显示名呈现面（窗口标题、侧栏、关于页、商店名）按界面语言取双名之一，杜绝「Ledger
  账本」式混排复活；存量在 i18n 之外硬编码显示名的位置随实施清理，新代码不得新增。
- 词汇表：参考数据与设置域新增「应用名称（App Name）」词条，收录双名、标识符冻结、
  契约词根解耦三条边界。
