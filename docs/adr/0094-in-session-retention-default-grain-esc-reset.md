# ADR-0094: 会话内保留升为瞬态选择的默认粒度——交易页筛选/分页保留与 ESC 复位通道

- 状态：已接受
- 日期：2026-09-09
- 作者：Ledger 项目
- 关联：spec issue #892（实现票 #893）；修订 ADR-0061（决策 2/4 的「逐票裁决」口径）；修订 ADR-0030（决策 1「组件状态是唯一事实源」的事实源归属、决策 2 的 URL 只读下钻让位规则）；先例 ADR-0061 落地 #427（报表页会话状态 store）；ADR-0035（弹层注册表）；ADR-0045（页码回退入口）；ADR-0070（搜索页豁免维持）；ADR-0088（系统返回语义不动）；词汇表：界面状态与交互域「会话内保留」（修订）「ESC 键语义」（修订）「TransactionFilter」（修订）

## 背景

ADR-0061 把「会话内保留」立为报表页的原则（离开再回来 = 回到离开时的样子，冷启动回默认，#427 以会话级 store 落地），但保留了「逐票裁决」的口径：其余瞬态是否纳入保留，由各自领域语义逐票决定。实际效果是默认粒度仍停在「每次进入回默认」——用户最常往返的交易页反而在切页后丢掉全部筛选与页码，从头再选一遍的代价最高。同时，保留态缺少主动清除通道：ESC 在无弹层时是无操作，用户没有「取消、回到默认」的一键手段。spec #892 经 grilling 定稿：把会话内保留升为全应用瞬态选择的默认粒度，交易页作为第二批落地，ESC 扩为两级语义。

## 决策

### 1. 原则升格：会话内保留是瞬态选择的默认粒度，豁免须显式决策

瞬态界面选择（筛选、分页、视图内位置）自本决策起默认按「会话内保留」粒度处理：同一应用会话内，离开视图再回来（侧栏切换、下钻跳转往返、路由回退）回到离开时的样子，数据按恢复的选择现拉；应用冷启动（跨启动）回默认口径。保留全程零写盘（不进 localStorage、不进 SQLite）、不写回 URL（ADR-0030）。这是对 ADR-0061 决策 2「各状态按其领域语义归位，不因本原则自动升级」与决策 4 逐票裁决口径的修订：**默认粒度从「每次进入回默认」翻转为「会话内保留」，豁免（维持每次进入回默认）从此须显式决策**；现行唯一豁免是搜索页（ADR-0070 维持——搜索词与筛选不持久化是搜索任务边界的一部分）。落地仍逐页推进：每页接入时对齐本原则，不再逐页重立原则性 ADR。

### 2. 交易页落地：TransactionFilter 全维筛选 + 分页住会话级 store（issue #893）

保留对象为 TransactionFilter 全维筛选（账户/商户/分类三态/单值类型/类型集合/日期边界）与分页（页码/页大小）。状态归宿从「组件状态是唯一事实源」（ADR-0030 决策 2 的事实源口径）改为**新建的交易页会话级 Pinia store 是过滤状态的唯一读写方**，解析防御与写路径内化其中（仿报表页会话状态 store 先例，#427/ADR-0061）；`useTransactionFilter` 工厂形态与对外接口不变，退为薄适配，视图保持薄接线。URL 参数表的运行时簿记（登记/结算/让位）是「单次进入」边界：随访次复位，URL 下钻参数在场即重新消费——**URL 永远赢**（显式跳转意图覆盖保留态对应维度，无参数才恢复保留态），让位守卫收窄为单次进入内的时序守卫，不抗跨访问的旧手动状态。

> 注（2026-09-13 落地，issue #1192）：决策 1 的默认粒度在投资页按同形承接——新建投资页会话级 Pinia store 是持仓页签筛选三维（搜索/账户过滤/排序）与页码、走势页签选中标的（模式/预设区间/单标的）以及当前页签的唯一读写方；页签内容仍经 `display-directive` 卸载重挂（决策 5 对 KeepAlive 的否决不变），保留由状态提升承担。持仓页签的「三维过滤闭集全瞬态」（spec #898/#902 的显式豁免）随本注记撤回。ESC 复位出口复用决策 4 的既有注册点（不新增缝），复位 = 页签回默认「盈亏」、持仓筛选三维清零 + 翻页归零、走势回默认组合曲线。

### 3. 页码恢复钳制走既有回退出口

恢复的页码超出当前数据有效范围（请求返回空页而库中尚有数据且非第一页）时，逐页走 ADR-0045 页码回退入口（「回退不归零 + 版本 bump」的既有出口）回落到有效范围，不新增第二出口、视图不直写页码、不渲染空页。

> 注（2026-09-13 落地，issue #1192）：本决策原述以**服务端分页**为形态（「请求返回空页」是它的越界信号）。投资页持仓页签是**内存切片分页**（词条「客户端切片分页」）：行集一次全量拉取、切片在本地，越界的观察面不是空页响应而是派生行集的有效页数（`ceil(行数 / 页大小)`），且保留态与展示同在进程内、不涉「版本 bump 重拉」。同形承接为：读保留态页码时按有效页数回落并**写回保留态本身**（等价于「回退到有效范围」，不是只钳展示值）——只钳展示会让陈旧页码在行集回增后重新生效、凭空跳页，与「回到离开时的样子」冲突。出口仍只有一处（模块对账出口），视图不直写页码；无第二出口、不渲染空页的边界不变。

### 4. ESC 两级语义：无弹层时复位当前视图的保留状态

ESC 的唯一实现点仍在窗口行为守卫（issue #154 的既有拦截出处）：有弹层时维持弹层库默认关闭行为（关最上层弹层，不叠加动作）；无弹层时调用**当前视图注册的复位回调**。无弹层判定复用弹层注册表（ADR-0035），不做 DOM 推断。复位回调注册点是本功能的**唯一新缝**：仿弹层注册表的声明式上报形态——持有保留态的视图挂载时注册、作用域销毁时自动撤销（跨断点换档卸载不滞留注册态，导航抽屉先例同款）；注册表不持业务语义，只存「当前视图的复位回调」一个槽位。复位语义是**清除保留态本身**（复位后离开再回来 = 默认），走模块既有复位出口（清全部过滤 + 翻页归零 + 版本 bump 照常重拉）；无保留状态的视图不注册，天然无操作。

**ESC 是「取消」**：与「会话内保留」的被动保留相对，ESC 复位是保留态唯一的主动清除通道——按 ESC 后离开再回来，回到的是默认而非「上次选择」。

### 5. 边界澄清

- **不做焦点判定特例**：ESC 拦截既有口径无条件（可编辑元素无豁免，与退出全屏禁令同源）；当前无「无弹层 + 可编辑焦点」与复位冲突的真实场景，出现时再议。
- **触控轴无 ESC**：移动档暂无复位通道；系统返回语义不动（关弹层/路由回退，ADR-0088），返回 ≠ 清空。
- **refresh 语义不变**：记一笔提交等外部数据变化的刷新仍是「重拉 + 翻回第一页、不动筛选」，保留态不因正常记账动作被打断。

## 备选否决

- **跨启动持久化筛选（进 localStorage / ViewState）**：筛选是临时浏览位置，跨启动记忆正是 ViewState「不做过度记忆」边界禁止的形态；冷启动回默认无筛选态是刻意的默认口径（打开应用 = 全量账本视图）。且跨启动持久化会让 ESC 复位从「便利」变为「必需的清除手段」——状态持久到用户自己都嫌烦时才需要专门清除，说明已越过心智负担线；会话内粒度下 ESC 复位是低频便利，语义成立。
- **独立复位按钮（每页一个「重置」）**：与清除筛选按钮职责重叠（后者已是「回默认态」出口），多一个常驻控件只增加视觉负担；ESC 是键盘用户的一键「取消」，语义是复位而非新入口。
- **系统返回键兼任复位（移动档）**：返回手势的心智是「回到上一处」而非「清空条件」，兼任会让返回意外丢状态，与 ADR-0088 系统返回语义冲突；真机痛点出现再议。
- **KeepAlive（离开不卸载组件实例）**：ADR-0061 已否决（数据陈旧、内存常驻、生命周期双轨分叉），状态提升到会话生命周期即可，「保留」自然成立。
- **ESC 复位做成全局路由层逻辑（按路由名分派）**：路由表持业务复位语义会散布第二处按键监听与每路由一张复位清单；注册表把「谁有保留态、怎么复位」留给视图声明，守卫只消费，语义全仓一个出处。

## 后果

- **文档口径统一**：ADR-0061 增补修订记录（决策 2/4 的逐票裁决口径由本决策取代）；词汇表「会话内保留」「ESC 键语义」「TransactionFilter」三词条修订；ADR-0030 增补修订注记（事实源归属与 URL 永远赢）。
- **行为面**：交易页筛选/分页在会话内跨导航保留（#893 落地），搜索页维持豁免；ESC 在交易页复位保留态，其余视图接入复位随各自落地票推进（注册点已备，不再新增缝）；词汇表落地清单随接入状态标注，不提前宣称行为。
- **测试锚点沿报表页先例**：同会话卸载重挂恢复 / 新 pinia 冷启动回默认 / 零 localStorage 写入三锚点，另锚 URL 永远赢与页码钳制（Vitest，不加 e2e BDD，跟随 #427 先例）。
