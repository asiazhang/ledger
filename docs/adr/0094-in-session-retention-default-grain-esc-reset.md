# ADR-0094: 会话内保留升为瞬态选择默认粒度，ESC 复位语义落地

- 状态：已接受
- 日期：2026-09-09
- 作者：Ledger 项目
- 关联：修订 ADR-0061（保留粒度由逐票裁决改为默认纳入）；维持 ADR-0070（搜索页豁免）、ADR-0030（URL 只读不写回）；词汇表：界面状态与交互域「会话内保留」「ESC 键语义」「TransactionFilter」

## 背景

ADR-0061 立了「会话内保留」原则（离开视图再回来 = 回到离开时的样子，冷启动回默认，零写盘），但保留粒度取「逐票裁决、不因原则自动升级」：报表页已落地（期间、图内下钻、TopN），交易页筛选仍每次进入回默认。实践中「逐票裁决」执行为普遍不落地——用户在侧栏几大类间切换，交易页筛选、分页全部丢失，每个页面都要重新选一遍；而「回到离开时的样子」才是瞬态选择的自然预期。本次把原则反转：会话内保留升为瞬态选择的**默认粒度**，并为其补上显式清除通道——ESC 复位（无弹层时 ESC 当前为无操作，语义空心）。

## 决策

### 1. 原则反转：会话内保留是瞬态选择的默认粒度

凡视图的瞬态选择（筛选、分页、页签、下钻位置等），默认纳入会话内保留；未纳入属临时实现态（随页面逐页接入）或显式豁免（豁免须记录）。ADR-0061 决策 2 的「各状态按其领域语义归位，不因本原则自动升级」与决策 4 的「逐票裁决」口径据此修订；该原则其余部分不变：保留的是选择不是数据、零写盘、不写回 URL、冷启动回默认。首个显式豁免维持：搜索页（ADR-0070，任务型流程每次从零开始）。

### 2. 交易页筛选与分页纳入保留（第二批落地）

TransactionFilter 全维筛选（账户/商户/分类/类型/类型集合/日期边界）与分页（页码/页大小）会话内保留，冷启动回默认。恢复时页码钳制到当前数据的有效范围（离开期间数据变少不产生空页）。与 URL 下钻的关系：**URL 参数在场永远赢**——带参跳转是显式下钻意图，覆盖保留态的对应维度；无参数才恢复保留态。「让位」守卫随之收窄为**单次进入内的时序守卫**（防参考数据未就绪挂起补判期间的手动改动竞态），不抗跨访问的旧手动状态——旧状态就是保留态本身。落地前过渡期行为不变（每次进入回默认），随实施票切换。

### 3. ESC 复位语义（修订「ESC 键语义」）

ESC 的职责扩为两级，一次按键只做一件事：

- **有弹层时**：关闭最上层弹层（现行为不变，弹层库默认行为）。
- **无弹层时**：复位当前视图的会话内保留状态回默认态（走各模块既有复位出口，照常触发重拉）；无保留状态的视图无操作（维持原「无弹层时无操作」）。

**复位即清除保留态本身**：按 ESC 后离开再回来，回到的是默认而非「上次选择」——ESC 是「取消」，与「会话内保留」的被动保留相对，是保留态唯一的主动清除通道。触控轴无 ESC，移动档暂无复位通道（系统返回语义不动，见备选否决 3）。

## 备选否决

- **跨启动持久化（筛选进 ViewState/localStorage）**：推翻「不做过度记忆」边界——筛选是临时浏览配置，跨启动记忆正是该边界禁止的形态；且 Esc 复位将从「便利」变为「必需的清除手段」，状态持久到用户自己都嫌烦时才需要专门清除，说明已越过心智负担线。会话内粒度下 Esc 复位是低频便利，语义成立。
- **独立复位按钮（不动 ESC）**：为低频动作新增常驻控件，且 ESC「无弹层时无操作」的语义空心化保留；「取消 = Esc」的肌肉记忆天然对齐，无需学习。
- **系统返回兼任移动档复位**：系统返回已有闭集语义（关最上层弹层 → 路由回退 → 栈底交还系统）；兼任复位把「返回」与「清空」两意图混入一键，路由栈底判定多一层拦截，得不偿失。移动档复位通道留真机痛点后再议。

## 后果

- **词汇表修订**（界面状态与交互域）：「会话内保留」默认粒度反转 + 落地清单更新、「ESC 键语义」扩为两级、「TransactionFilter」保留与 URL 永远赢、让位收窄。
- **ADR-0061 增修订记录**：决策 2/4 修订，其余（保留语义对象、零写盘、备选取舍）不变。
- **逐页接入无需再立 ADR**：原则反转后，其余页面（定时计划状态过滤、投资页签与分页、组内收纳「更多」页签等）按默认粒度随触碰逐页接入；新增显式豁免才需要新决策。
- **过渡期诚实**：交易页等未接入页面在落地前维持「每次进入回默认」，词汇表落地清单标注接入状态，不提前宣称行为。
