# ADR-0061: 会话内保留——界面瞬态选择的默认保留粒度原则

- 状态：已接受（保留粒度已由 ADR-0094 / spec #892 从「逐票裁决」升格为默认粒度；正文已按现行态收敛）
- 日期：2026-09-03（现行态收敛：2026-09-09）
- 作者：Ledger 项目
- 关联：spec #428 / #427（报表页首个落地）；修订 ADR-0057（报表页期间冷启动回当年、会话内保留）；ADR-0030（URL 只读不写回）；ADR-0063（ViewState 跨启动持久化边界）；ADR-0070（搜索页显式豁免）；ADR-0094（升格为瞬态选择默认粒度 + ESC 复位通道）；词汇表：界面状态与交互域「会话内保留」「ViewState」「ESC 键语义」

## 背景

`ViewState` 的「不做过度记忆」边界早期被执行为「不持久化 = 每次进入即回默认」，导致用户在报表页下钻跳到交易明细再返回时，期间与下钻位置全部归零。需要把「不做过度记忆」精确界定为禁止**跨启动**记忆，并在应用同一次运行会话内建立统一的保留粒度原则。

## 决策

### 1. 会话内保留语义：离开再回来回到离开时的样子，冷启动回默认

- 同一应用会话（进程一次运行）内离开再返回视图，用户的瞬态选择（筛选、期间、分页、下钻位置等）自动恢复；数据照常按恢复的选择**现拉**（不缓存旧数据，离开期间新记的账进入即反映）。
- 应用冷启动（跨启动）不保留，全部回到各自默认口径；全程零写盘（不入 `localStorage` / SQLite）、不写回 URL（ADR-0030）。

### 2. 三层保留粒度光谱与默认粒度（ADR-0094 升格）

`ViewState` 跨启动持久化（上次视图、侧栏折叠、侧栏组内顺序等）保持不动；界面状态的保留光谱收口为三层：
1. **跨启动持久**：仅限 `ViewState` 明确登记项；
2. **会话内保留（瞬态选择的默认粒度，ADR-0094）**：所有视图的瞬态选择默认按本原则在会话内保留、冷启动回默认，并提供无弹层 ESC 复位作为保留态显式清除通道；
3. **每次进入回默认（显式豁免）**：维持「每次进入回默认」必须有显式决策依据（现行代表豁免：搜索页 ADR-0070）。

### 3. 保留的是选择状态，不是组件实例或数据快照

状态提升至会话级 Pinia store，组件装卸如常；不保留组件实例、不缓存结果数据。报表页（#427，同时修订 ADR-0057 消费形态二）为首个落地，交易页筛选/分页（ADR-0094）与其余视图按本原则逐页对齐。

## 备选与否决

- **Vue `KeepAlive`（保留组件实例）**：导致数据陈旧需额外失效补丁、内存常驻增长、生命周期钩子双轨分叉，否决。
- **把瞬态写回 URL query**：推翻 ADR-0030「URL 只读不写回」且跨刷新语义超出「会话内」，否决。
- **`sessionStorage`**：在内存与 `localStorage` 外引入第三通道，WebView 刷新边界模糊且零增量收益，否决。
- **跨启动写入 `localStorage`**：违背 `ViewState`「不做过度记忆」边界，冷启动应回到默认视角，否决。

## 后果

- 报表页、交易页等瞬态选择离开往返不再归零，冷启动照常干净回默认、零磁盘写入。
- 新增视图瞬态默认遵循会话内保留；若需每次进入归零（如搜索页），须显式记录豁免理由。
