# ADR-0061: 会话内保留——界面瞬态选择的会话粒度保留原则

- 状态：已接受
- 日期：2026-09-03
- 作者：Ledger 项目
- 关联：spec issue #428（父 #426）；行为先行落地 #427（报表页会话状态 store）；修订 ADR-0057（消费形态二默认语义）；ADR-0055（ViewState 上次视图持久化粒度）；ADR-0030（URL 只读不写回）；词汇表：界面状态与交互域「会话内保留」（新增）「ViewState」「时间范围快捷选择」「分类下钻」
- 编号注：spec #428 立项时本决策按当时的下一空闲号写作「ADR-0059」；立项后 0059（模型域目录归位，#419）与 0060（后端易 panic 构造门禁，#432）先行落地占用，按编号唯一顺延为 0061，内容与语义不变。

## 背景

ViewState 的「不做过度记忆」边界（不持久化筛选条件、滚动位置、列宽等）在实践中被执行为「不持久化 = 每次进入即回默认」：报表页每次进入都回「当年」，图内下钻位置跨导航即丢失。报表页接入时间范围快捷选择与分类下钻后（ADR-0057），这个口径的实际代价显形：用户在分类构成图下钻、跳到交易列表明细、再返回报表页——期间与下钻位置全部归零，被迫从「当年」重新选起。#427 以会话级状态 store 落地了报表页「离开再回来回到离开时的样子」，验证了行为形态；本 ADR 把它写成通用原则「会话内保留」，并细化「不做过度记忆」的边界——它禁止的是**跨启动**的记忆，不是同一会话内的位置保留。

## 决策

### 1. 原则成文：会话内离开再回来 = 回到离开时的样子

同一应用会话内（应用进程的一次运行），离开一个视图再回来——不论经侧栏切换、下钻跳转往返还是回退——视图回到离开时的样子：用户的瞬态选择（期间、下钻位置等）恢复，数据照常按恢复的选择现拉（不是缓存快照，离开期间新记的账进入即反映）。应用冷启动（跨启动）不保留，回到各瞬态的默认口径（如报表页「当年」）。保留全程不写盘（不进 localStorage、不进 SQLite）、不写回 URL（URL 只读不写回，ADR-0030）。

### 2. ViewState 边界是细化不是推翻

ViewState 持久化的三样（上次视图、侧栏折叠、侧栏组内顺序）跨启动保持不变；「不做过度记忆」的禁止对象自此明确为**跨启动的记忆**。会话内保留补上「同一会话内」的保留粒度：瞬态选择从「每次进入即回默认」细化为「会话内回到离开时的样子、冷启动回默认」，依旧零写盘。两原则合起来是一条保留粒度光谱：跨启动持久（ViewState）→ 会话内保留（本 ADR）→ 每次进入即默认（未纳入保留的瞬态，如交易页筛选——各状态按其领域语义归位，不因本原则自动升级）。

### 3. 保留的是选择，不是组件实例或数据

「保留」的语义对象是用户的**选择位置**。数据永远现拉（与「列表永不被静默换数据」的快照语义不冲突——恢复的是区间，区间内的数据以当前查询结果为准）；组件实例不必存活（状态提升到会话生命周期即可，视图装卸如常）。首个落地是报表页期间选择与图内下钻位置（#427：会话级 store 内化同值守卫与期间切换复位下钻，视图只接线）；后续视图的同类瞬态若要纳入保留，按本原则对齐即可，不逐个立 ADR。

### 4. 修订 ADR-0057 消费形态二

「每次进入回当年」修订为「冷启动回当年、会话内保留离开时的期间」；修订注记与修订记录见 ADR-0057。其余决策（闭集差异、快照语义、年份下拉退役、from/to 参数形状）不受影响。

## 备选否决

- **KeepAlive（离开不卸载组件实例）**：保留组件实例的代价是三重的——数据陈旧（离开期间的新账要靠额外失效补丁才可见，与「回来即见新账」背道而驰）、内存随视图数常驻增长、生命周期副作用（onMounted 语义被架空，激活/停用钩子双轨分叉）。保留「状态」比保留「实例」便宜且语义干净：视图装卸如常，状态提升到会话生命周期，「保留」自然成立。
- **URL 写回（期间/下钻写进 query）**：直接推翻「URL 只读不写回」既定决策（ADR-0030，#96 决策 3/4），动面大——全部下钻维度的写回语义、刷新与分享的行为都要重定义；且 URL 的存活期跨刷新，实质是比「会话内」更宽的持久化，超出本原则的目标形态。
- **sessionStorage（会话级存储通道）**：为「不写盘」的状态引入第三条存储通道（localStorage、URL 之外），而收益为零——状态本可随进程存活于内存；且「跨刷新保留、跨启动不保留」的语义在 WebView 里模糊（刷新算不算新会话，取决于实现细节而非用户心智）。内存存活期天然就是「会话」的准确边界，无需再造。
- **跨启动持久化（进 localStorage / ViewState）**：期间选择与下钻位置是临时浏览位置，跨启动记忆正是 ViewState「不做过度记忆」边界禁止的形态；冷启动回「当年」也是刻意的默认口径（报表的默认问题是「今年花得怎样」）。

## 后果

- **文档口径统一**：词汇表新增「会话内保留」词条；「时间范围快捷选择」「分类下钻」「ViewState」三词条同步；「每次进入回当年」「下钻位置跨导航丢失」旧口径作废。
- **ADR-0057 消费形态二语义修订**：见其修订记录；行为已由 #427 先行落地并有测试锚定（同会话卸载重挂恢复、新会话冷启动回默认、全程零 localStorage 写入）。
- **保留 ≠ 缓存**：回来必现拉，界面不展示离开时的旧数据；「列表永不被静默换数据」不受影响。
- **后续零增量决策**：原则先行，同类瞬态（其余视图的筛选、滚动位置等）是否纳入保留由各自领域语义逐票裁决，纳入时对齐本原则即可。
