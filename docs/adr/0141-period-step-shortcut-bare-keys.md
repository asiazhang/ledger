# ADR-0141: 周期步进快捷键——裸键 `,` 上一个周期 / `.` 下一个周期（交易页接入）

- 状态：已接受
- 日期：2026-10-02
- 作者：Ledger 项目
- 关联：与 ViewShortcut（ADR-0065）、CreateShortcut（ADR-0135 决策 5）、翻页快捷键（ADR-0140）同族的第四个快捷键词条；被步进对象是时间范围快捷选择（ADR-0057 决策 5，受控共享组件）；抑制闸门沿 Overlay Suppression（ADR-0035）与输入轴（ADR-0088）；词汇表：界面状态与交互域「周期步进快捷键」（issue #1904）

## 背景

时间范围快捷选择（ADR-0057 决策 5）的期间步进器以 `<` 期间标签 `>` 三件常驻呈现，用户可以用鼠标点击步进到上一个/下一个自然周期。翻页快捷键（ADR-0140）落地后，键盘流用户在交易页浏览相邻时间周期时仍需移手找步进箭头——时间维度与页码维度的键盘可达性出现落差。

键位选择的前提约束（ADR-0140 背景已立）：主修饰键数字带被 ViewShortcut 封闭占用（ADR-0065）；方向键与 PageUp/PageDown 携带浏览器默认滚动语义；组合键被 CreateShortcut 家族先例排除。裸键占用现状：`[` / `]`（翻页）、`a` / `z` / `i`（记一笔）、`⌘1..9` / `` ⌘` `` / `⌘0` / `⌘,`（视图）。

实现侧的前提约束：周期步进不是「视图持有的状态」——游标（从当前区间反推的自然周期）、数据期间边界（钳制输入）与步进换算全部内化在共享受控组件内部，组件未暴露步进入口；交易页侧只有日期区间的 v-model 桥接。接缝怎么开是本决策的实质内容。

## 决策

### 1. 裸键形态：`,` 上一个周期 / `.` 下一个周期

沿 CreateShortcut 既定纪律——组合键让给系统与视图快捷键的肌肉记忆，快捷键只走无修饰键裸键。`,` `.` 恰是步进箭头图标 `<` `>` 同一物理键位的无 Shift 形态，方向空间映射与按钮图标逐键对齐；仓库内裸键零占用（与 ViewShortcut 的 `⌘,` 设置键同键不同修饰，裸键匹配本就拒绝一切修饰键）。

### 2. 语义等同点击步进器，不加特判

步进换算、数据期间边界钳制、越界幂等与快照写回全在组件内单点——快捷键经组件暴露的步进入口走同一 `onStepPeriod` 出口，与点击箭头零分叉。「全部」无游标与边界末端越界幂等无操作，不提示、不抖动。不为快捷键另设步进逻辑：游标不落状态（词汇表「周期派生」已立），快捷键只是它的又一个触发面。

### 3. 接缝取「组件暴露步进入口」，不抽共享 composable

共享受控组件以 `defineExpose` 暴露 `stepPrev` / `stepNext`，消费视图持组件引用接线。只暴露步进动作、不暴露可达性（`canStepPrev` / `canStepNext`）：可达性守卫已在 `onStepPeriod` 内（点击路径同款），暴露给调用方即成死代码。

不把「周期游标 + 数据期间边界」抽成共享 composable：该逻辑虽是组件内部职责，但抽离要动报表页、搜索页与投资明细页签三个消费方，属范围外重构——本票按「组件暴露一个入口」收口，他页接入时复用同一入口与同一快捷键模块，组件改造不再需要。

### 4. 抑制闸门与监听面抽 `useBareKeyShortcuts` 共用内核

翻页与周期步进两族快捷键同形，只有「键位 ⇄ 语义」的纯映射不同。共用内核独占抑制三闸门与监听面装配（可编辑焦点抑制、弹层抑制、触控轴不绑与换轴实时拆装、卸载清理），键位闭集与语义留在各自模块（单一事实源不合并）——`usePaginationShortcuts` 对外 API 不变，`useTimePeriodShortcuts` 为其同构兄弟。

记一笔快捷键不入内核：其可用性闸门要求「命中但不可用时不 preventDefault」（ADR-0135 决策 5），与内核「命中即 preventDefault」语义冲突，自持闸门。

### 5. 键位提示在步进器旁弱化小字，仅指针轴渲染，由消费视图按需开启

入口可见处标注键位（与 ViewShortcut 键位带、CreateShortcut 下拉标注、翻页快捷键同一哲学）；文案随界面语言；触控轴不绑监听、不渲染提示（输入轴 ADR-0088）。提示由消费视图经组件可选属性传入键位闭集，缺省不渲染——组件其他消费方渲染与行为零变化。

### 6. 概念按共享交互立项，本次只接交易页

词条以「时间范围快捷选择可消费的共享交互」立项，不绑定交易页；报表页、搜索页与投资明细页签同为时间范围快捷选择的消费方，按需后续接入——接入成本是传同一键位属性 + 接同一快捷键模块，组件已就位。本票不扩范围。

## 备选方案与否决理由

- **`-` / `=`**：键位位置直觉尚可，但缩放语义与「步进一个周期」不是同一心智模型（用户会问"缩放什么"）——弃。
- **`<` / `>`（即 Shift + `,` / `.`）**：与步进按钮图标逐字一致，但带 Shift 修饰，违反裸键家族纪律（ADR-0140 决策 1）——弃。
- **方向键 `←` / `→`**：最直觉，但浏览器默认语义是滚动页面，且组件级按键面存在既有消费；ADR-0140 已就同一对键否决过一次，不因换维度翻案——弃。
- **抽「周期游标 + 数据期间边界」共享 composable**：内部实现更干净，但要动三个他页消费方（报表页 / 搜索页 / 投资明细页签），属范围外重构——本次不做，按需另立票。
- **视图侧自行派生游标与边界**（复用期间数学纯函数 + 二次拉取数据期间边界）：重复实现即分叉风险（钳制口径有两处），且边界二次拉取引入两个订阅与一致性面——弃。

## 后果

- **纯前端交互改动**：schema / API / 命令零变化；不新增持久化状态（游标仍不落状态，快捷键不改变这一点）。
- **共享受控组件新增一个可选属性**：缺省不渲染，三个他页消费方渲染与行为零变化（组件测试锚定）。
- **组件暴露步进入口是周期步进快捷键的唯一缝**：删除该暴露面、或删除消费视图的接线调用，视图用例即变红（负向判据，ADR-0087）。
- **抑制三闸门照常**：快捷键失效先修弹层判定，不加组合键双轨（家族纪律）。
- **键位发布即成肌肉记忆**：键位闭集随词条定档，与 ViewShortcut 键位带同等稳定性对待。
- **词汇表修订随本决策落地**（界面状态与交互域）：新增「周期步进快捷键」，同步 `CONTEXT-MAP.md` 条目主题。
