# ADR 0135: 投资交易迁入投资页「明细」页签——主交易列表收窄为通用 kind，创建入口随迁

- 状态：已接受（决策入档；实现随实施票落地）。**修订（2026-09-24）**：决策 3 的「筛选四维」手动形态被产品裁决修订——标的维度降级为仅 URL 下钻只读入口、明细页签呈现面与主列表对齐，见文末修订注记。
- 日期：2026-09-24
- 作者：Ledger 项目
- 关联：ADR-0107（持仓下钻与交易页标的维度，本次修订其决策 3/4）、ADR-0116（功能开关，本次修订其决策 4 的入口示例）、ADR-0038/0099/0106/0109（投资 kind 闭集）、ADR-0096（出资账户）、ADR-0008（服务端分页形态）、ADR-0094（会话内保留与 ESC 复位）、ADR-0088（窗口分级）；词汇表：投资域「投资明细页签」（新）、核心交易域「Transaction」列表呈现边界与「InvolvingAccount」、界面状态与交互域「TransactionFilter」类型维度与标的维度、「持仓下钻」「来源列」

## 背景

主交易列表混排通用 kind（income/expense/transfer/refund）与投资 kind（buy/sell/convert/split/dividend）：投资行挤在通用行形态里——convert 金额列只能显示转出金额、split 金额恒「-」、标的信息只在来源列露出，投资专属字段（数量、单价、手续费、两腿）无处安放。投资页已有概览/盈亏/持仓/标的/走势五签，唯独没有「交易」本身：盈亏页的逐匹配明细已按 ADR-0107 退役，逐笔投资交易目前只在主列表以通用形态可见，买入/卖出的创建与编辑入口也都长在交易页（记一笔家族与行操作弹窗族）。

产品动机：投资明细做投资专属的展示优化，并把投资相关动作（看、记、改）收拢到投资页——每个模块在概念与使用上统一。

## 决策

1. **迁移闭集 = 五种投资 kind 整体迁出主交易列表**，呈现面为投资页新增「明细」页签（术语：投资明细页签，归投资域词汇表）。库级聚合口径一律不动——报表、预算、余额、净资产、数据期间边界全部读库不读列表，分红仍计收入净额。
2. **排除机制走前端显式 kind 集合**：主列表每次请求显式携带四通用 kind（含默认态），`list_transactions` 的 IPC 与 HTTP 契约零改动、无 BREAKING；主列表类型下拉收窄为四通用 kind。账户过滤维度不动——账户名下钻与手动过滤同见四通用 kind（维度正交，不为账户入口开例外）。
3. **明细页签数据面**：投资域新增列表读命令，行投影携带投资字段（标的、数量、单价、手续费、convert 两腿、split 带符号份额增量、dividend 现金腿与到账账户），按 kind 分形态呈现；无界流水走服务端 offset 分页（ADR-0008），排序与主列表同构（date 倒序）。筛选四维：账户 / 标的 / 类型（投资 kind 子集多选）/ 日期——无分类与商户维（投资 kind 编排入口即拒绝携带）。筛选与页码随会话内保留默认粒度入投资页会话 store（ADR-0094），ESC 复位 = 页签回概览 + 清明细筛选、翻页归零。
4. **操作同权**：编辑 buy/sell（买卖明细回填）、convert/split/dividend 只读详情、软删与行菜单在明细页签全量可用——弹窗族组件复用、意图在投资页重接线；交易页弹窗族瘦身不删组件。
5. **创建入口随迁（产品裁决）**：买入/卖出的记一笔入口落明细页签头部；交易页可创建闭集收窄为支出/收入/转账（创建类型映射、桌面下拉与移动 FAB 同源收窄）；交易页裸键 `b`/`s` 退役、投资页不设裸键。
6. **持仓下钻迁址**：持仓页签标的列跳转改落 `/investments?tab=detail&account=&instrument=`（URL 只读不写回、参数在场永远赢、一次性消费，与既有下钻同纪律）；交易页 `?instrument=` 标的维度随 ADR-0107 决策 3 一并退役（契约字段冻结并存，比照 ADR-0057 遗留参数先例）。已清仓标的的卖出流水在明细页签重获入口（按标的筛、不带账户）——ADR-0107 修订注记显式接受的「清仓标的无入口」代价就此归还。
7. **交易搜索零改动**：`search_transactions` 保持全域、无 kind 过滤；来源列链接不动。主列表来源列的「标的」来源行随行消失，搜索结果中照常可见。
8. **移动档**：明细页签按投资页轻适配先例处理——表格 + 横向滚动（scroll-x），列形态遵守表格列形态规范；不做卡片列表双渲染。

## 理由

- 模块统一是产品裁决：投资的看/记/改集中一处，投资行不再挤通用形态，交易页回归「日常收支动线」定位。
- 排除走前端显式集合是发布边界最窄的路径：`list_transactions` 有 IPC 与 HTTP API 双消费面（后者已入 OpenAPI 文档），动后端默认语义即双面 BREAKING；显式集合方案契约零改动。
- 下钻落点随数据走：`?instrument=` 在不再含投资行的列表里必然落空，迁址是 ADR-0107 的自然修订而非新机制。
- 搜索是定位必需的检索面（ADR-0116 决策 4 的引用放行原则），保持全域覆盖与其一致；账户维度保持正交则行集口径不随入口漂移。

## 代价

- 银行账户视角的流水不再完整：经出资账户直扣的 buy/sell、分红到账不在主列表与账户下钻出现，需到明细页签按账户筛——显式接受，以明细页签账户筛选兜底。
- 报表中的分红收入与主列表可见行失去一一对应（分红行只在投资页可见）。
- 「记一笔」的通用入口不再覆盖买卖：从交易页动线记买入/卖出的老习惯需要迁移。

## 替代方案

- **部分迁移（分红留在主列表）**：同一闭集两处呈现、两套展示逻辑，违背口径单一——否决。
- **后端加排除参数或改列表默认语义**：IPC + HTTP 双面 BREAKING，收益为零——否决。
- **账户维度例外（带账户过滤时放开投资 kind）**：同一列表行集随入口漂移，手动与下钻共用的维度语义分叉——否决。
- **创建入口留在交易页**：显示面与动作面割裂，产品裁决模块统一优先——否决。
- **裸键 b/s 随迁投资页**：买卖低频，且走势/盈亏等页签语境下弹记账弹窗突兀——否决。
- **明细页签移动档做卡片列表双渲染**：分析型浏览面非记账主面，横滚可接受，重做一套卡片收益不足——否决。

## 影响

- 契约：零 BREAKING；唯一新增为投资域列表读命令（只增）；退役的标的维度字段冻结并存（ADR-0057 先例）。
- 词汇表同步（随本 ADR 入档）：核心交易域 Transaction「列表呈现边界」与 InvolvingAccount 用途注记；投资域新增「投资明细页签」词条、Investment 词条补创建入口落点；界面状态与交互域 TransactionFilter 类型维度收窄与标的维度退役、持仓下钻落点改址、来源列注记、CreateShortcut 与记一笔悬浮按钮注记、会话内保留落地清单追加；CONTEXT-MAP 投资域条目主题追加。
- 实施拆票建议：① 后端投资交易列表命令 + 行投影；② 明细页签（列表/筛选/弹窗重接线/创建入口/轻适配）；③ 下钻迁址 + 主列表收窄（显式 kind 集合、类型下拉、裸键退役）。

## 修订注记（产品裁决，2026-09-24）：标的筛选降级为下钻只读入口，明细页签呈现面对齐主列表（#1807）

明细页签手动标的控件被裁决为多余——持仓下钻与深链才是标的维度的真实入口，手动远程搜索下拉只添噪音。随裁决修订决策 3：

- **决策 3 修订为**：手动筛选三维 = 账户 / 类型（投资 kind 子集多选）/ 日期；**标的维度仅作 URL 下钻只读入口**（`?tab=detail&instrument=`，无手动控件，比照主列表分类维度形态）——深链一次性消费、会话内保留与 ESC 复位口径不变，持仓下钻落点（决策 6）与已清仓标的卖出流水入口零破坏；后端 `list_investment_transactions` 的 `instrument_id` 参数照常消费、契约不动。
- **呈现面对齐主列表（决策 3 的呈现细化，非口径变更）**：日期维度由裸日期区间选择器换「时间范围快捷选择」全闭集形态（五芯片含「全部」＋期间步进器＋期间直达面板，钳制于数据期间边界）；金额列消费语义色（kindSemanticColor）、类型列消费标签色（KIND_TAG_TYPE），与主列表同源同件；补「清除筛选」按钮（清明细筛选 + 翻页归零，不切页签、不动页大小；ESC 复位仍为页签回概览 + 清明细筛选）。
- **决策 1/2/4–8 与会话保留、ESC 复位裁决不变**；移动档仍为表格 + 横滚（决策 8）。
- **文档同步**：投资域「投资明细页签」词条（手动筛选三维 + 标的仅下钻入口、着色同源）、界面域「时间范围快捷选择」消费形态追加明细页签，随本次落地。
