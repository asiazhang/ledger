# ADR 索引

收录标准（三问，缺一不立）：**难以逆转**（改主意的代价大）、**事后会困惑**（不看记录无法理解为什么这么做）、**真实取舍**（存在货真价实的备选项）。

纯实现注记、UI 微调、已被翻案且被后续 ADR 完整转述的决策不立 ADR。交叉引用了已删除编号的，见文末「已删除」清单。

## 现行 ADR

### 数据模型与核心口径
- 0001 — 定时交易采用独立 ScheduledTransaction + Occurrence 模型（计划与已发生交易分离）
- 0003 — 定时计划核心表 + 扩展表（现行五表结构）
- 0011 — kind→度量矩阵与 raw/native 金额分离，收口 transaction 领域模块（全库金额口径唯一真源）
- 0013 — 交易类型行为收敛分派 + investment 出口收窄为 prepare/apply/revert（kind 行为单点、三件套出口；部分被 0033/0097 修订）
- 0019 — 价格历史化：K 线回填 + 周粒度采样，MarketPrice 收缩为现价缓存
- 0020 — 首页净资产 = 非投资账户余额 + 持仓市值（防重复计算）
- 0026 — 余额调整采用黑洞转账机制
- 0028 — 交易对手方统一为商户 Merchant（breaking，推翻 0024 一个决策点）
- 0029 — 预算永久滚动（start_date 为冻结残留）
- 0038 — 场外基金一等标的：复用 buy/sell，价格刻度就地改万分位（BREAKING）
- 0048 — 财务自由度口径：可投资资产 × 3% ÷ 年度预算总额
- 0052 — 预算彼此独立：父子并存不扣减不互斥（双计是有意的）
- 0053 — 个人间借贷复用转账与债权/债务账户，不新增 kind
- 0067 — 余额与净资产持久化缓存：写路径同事务整体重算 + 读探针指纹自愈（推翻 ADR-0019「个人规模收益趋零」前提）
- 0089 — 多账本立项：一库 = 一本账，多库文件经引导层实现，schema 永不加账本维度（显式修订 0018 后果条款）
- 0092 — transfer 放开携带商户：借贷转账可关联商户（修订 0053 决策 2 的商户部分）
- 0096 — buy/sell 增设出资账户：直扣买卖的资金流归因（关联 0038/0067）
- 0099 — 基金转换（convert）：第 9 种 kind（一笔一行两腿、六度量系数全 0）、转入成本按转出批次结转、转出消耗表承载回退依据；schema 就地修改 V001/V002（1.0 前 BREAKING，存量库须重建库；spec #973）
- 0106 — 份额调整（split）：激活已声明 kind——单标的非现金份额变动（折算/结转/送股为 +、缩股为 −）、批次成本按比例重述（尾差归末批次）、批次重述审计表承载精确回退；零 CHECK 改动、零 BREAKING；无现金腿 kind 界面只读化（AI 记账为写入主面；修订 0099 决策 1/7/8；spec #1045、#1048）
- 0109 — 现金分红（dividend）：激活已声明 kind——归属标的的现金收入（现金腿入任意在用账户）、不计入成本法；累计收益扩为「未实现 + 已实现 + 累计分红」三腿；零 schema 改动；有现金腿 kind 同样界面只读（AI 记账为写入主面；#1078）
