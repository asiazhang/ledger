# ADR-0129: 盈亏页的新口径「已实现收益」——按年/按账户表并列合成已实现盈亏与现金分红

- 状态：已接受（grilling 定稿，2026-09-19）
- 日期：2026-09-19
- 作者：Ledger 项目
- 关联：#1533（本票）；ADR-0107（盈亏页组成、按币种分组、两表收敛）；ADR-0109（现金分红为累计收益第三腿、分红不摊薄成本）；ADR-0126（价格恒定标的，与货基收益的落账形态相邻）；词汇表：投资域「已实现收益（RealizedGain）」（新）、「已实现盈亏（RealizedPnl）」、「累计收益（CumulativePnl）」、「现金分红（Dividend）」

## 背景

盈亏页「按年」表（读投影 `realized_pnl_summary` 的按年行）只汇总卖出匹配（security_lot_sales）的逐匹配已实现盈亏，不含现金分红（dividend，ADR-0109 决策 2 立起的累计收益第三腿）。列名「已实现盈亏」在页面语境里读起来像「这一年赚了多少」，于是有两处事实错误：已经到手的现金分红不显示为收益；只有分红、没有卖出的年份整年不出现——真实账本「老婆的且慢」2019 年（已实现 0.00、现金分红 8,365.36）在按年表里没有行。同源的按账户表同病：只有分红的账户整行不出现。

累计收益（未实现 + 已实现 + 累计分红）回答的是持仓口径，与「这一年到手多少」不是同一个问题，且本页不展示未实现腿；完整年度收益（Δ未实现 + 已实现 + 分红）需要年内时点市值，而价格历史只覆盖近两年、早期年份无点、不可算。本页缺的是一个「只含已实现与已到手」的年度口径。

## 决策

1. **按年表与按账户表各增一列「已实现收益」，单元内以副行拆出两腿**（呈现形态经原型裁决，2026-09-19）：主值 = 已实现盈亏 + 该年 / 该账户的 dividend 行金额；副行 = 「已实现盈亏 X · 现金分红 Y」。原独立成列的「已实现盈亏」不再单独占列，其口径仍逐位不变（FIFO 卖出匹配、不含分红），只是展示落点从独立列移进同一单元格的副行；行集从「只有卖出年份才出现」扩为「有卖出或有分红的年份都出现」。
2. **新词汇表词条「已实现收益（RealizedGain）」**，写明三层阶梯：已实现盈亏 ⊂ 已实现收益 ⊂ 累计收益；并写明不含浮动盈亏是外部约束（价格历史只覆盖近两年）而非遗漏。
3. **分红腿与已实现腿同源同过滤**：归年取交易行日期、按账户表按账户聚合、币种分组取交易行币种；账户 / 标的筛选对两腿同源；软删账户与软删流水排除、隐藏账户计入（与累计收益三腿同口径）。
4. **合成在域内完成**：两腿与合计由投资域同一段读投影算出（按年行与按账户行各带分红腿与合计），前端只做格式化与呈现。命令名与结果类型名不改——`realized_pnl_summary` 现在承载两条腿是名字滞后，改名要动命令注册表、前端调用面与全部测试，收益不足，作为已接受债务记账。总数与按标的行的读投影维持已实现盈亏专义、不扩分红（前者是「已实现盈亏」的总数，后者已无 UI 消费方）。
5. **红利再投（DRIP）的分红腿计入**：不区分「非再投分红」与「再投分红」，与累计收益第三腿一致；不引入「同日同账户同额买入」的配对启发式。
6. **口径说明在场，且只挂一处**：「已实现收益」列头挂一条口径说明，写明两腿口径、不含浮动盈亏及其原因（价格历史只覆盖近两年），并覆盖分红腿两个易误解处（含红利再投的分红腿、含迁移来源的货基按年收益）。副行不再挂第二个入口——拆解项就写在数字旁边，多加一个图标只是噪声。

## 理由

- **并列合成、不重定义**：把分红并进已实现盈亏的定义必须摊薄成本，会同时改写持仓收益、转换结转成本与份额调整重述三条链路（ADR-0109 决策 2）；并列一列零风险，且两列之差本身就回答了「分红有没有算进来」。
- **单列主值 + 副行拆解**：原型实测（1360px 窗口、两块卡并排）四列放不下、按账户表要横向滚动；把「拆解项」与「结果」摆成同权重的四列，也看不出哪个是这一年真正到手的数。主值一个数、副行写清怎么来的，密度与可读性都更好。
- **口径归域、前端零算术**：仓库纪律是金额口径归域（三腿相加在域内读投影、收益率在后端算），前端只格式化；合计与两腿出自同一段查询，口径说明与数字不会各说各话。
- **两表同改**：按账户表与按年表同源同病、同页并排，只修一张会立刻显得另一张漏算。
- **含 DRIP 是为了与累计收益逐位一致**：本页「已实现收益」与持仓页「累计收益」之差应当只有未实现腿，不该再叠一层「是否再投」的口径差。
- **不含浮动盈亏是外部约束**：早期年份没有价格历史，这点必须写进文档，否则后来者会把它当作遗漏来「补全」。

## 代价

- 投资域同时存在三个近邻词（已实现盈亏 / 已实现收益 / 累计收益），词义分工靠词汇表与每列的常驻说明撑住——这是把「这一年赚了多少」讲清楚必须付的命名成本。
- 读投影契约只增不改地多两个字段；命令名与结果类型名从「只装已实现盈亏」变成「装两条腿」，名字滞后记为已接受债务。
- 「已实现盈亏」不再独立成列，习惯按列读该数的人要多读一行副行——这是换列数的代价。
- DRIP 年份的合计会包含那笔未落袋现金（再投的分红腿），只体现在未实现腿的抵消不在本页可见。
- 迁移来源的货基按年收益归属自建标的，按年表会出现归属标的是自建标的的分红行——这是源侧口径的映像，本页不做识别或过滤。

## 替代方案（防重提）

- **把 dividend 并进已实现盈亏的定义（摊薄成本）**：ADR-0109 决策 2 已否决——会连带改写持仓收益、转换结转成本与份额调整重述三条链路。否决。
- **本页升级为「含未实现变动的完整年度收益」**：需年内时点市值，价格历史只覆盖近两年、2019~2023 无点，早期年份不可算；要做得先立「价格历史回填」票。否决。
- **只加「现金分红」列、不给合计列**：用户还得自己做加法，「这一年赚了多少」仍无答案。否决。
- **合计列由前端相加**：把金额口径留在展示层，与「金额口径归域、前端只格式化」的纪律相悖。否决。
- **排除红利再投的分红腿**：需要配对启发式（同日同账户同额买入），跨设备 / 跨币种 / 部分再投必然漏配，且与累计收益第三腿形成第二套口径。否决。
- **本页直接展示累计收益**：与持仓页签合计重复，且本页没有未实现腿所需的持仓与价格上下文。否决。
- **「现金分红」与「已实现收益合计」各自独立成列（并列四列）**：原型实测在 1360px 双卡并排下四列放不下、要横向滚动，且拆解项与结果同权重、看不出哪个是到手总数。否决。
- **顺带恢复逐笔卖出明细或分红明细**：逐匹配明细已随 ADR-0107 退役，翻案须另立票。否决。

## 影响

- 词汇表：投资域新增「已实现收益（RealizedGain）」；「已实现盈亏（RealizedPnl）」「累计收益（CumulativePnl）」「现金分红（Dividend）」三条各补边界句；CONTEXT-MAP.md 分域一览同步。
- 契约：按年行与按账户行各增分红腿与合计（只增不改，无 BREAKING）；前端类型、i18n（一个列名 + 副行标签 + 一条口径说明，中英双份，概念键入投资域闭集）与测试同步。
- 验收：真实账本「老婆的且慢」按年表出现 2019 行（已实现 0.00 / 现金分红 8,365.36 / 合计 8,365.36），2021 年已实现 6,225.79 逐位不变；无分红账本读数逐位一致；分红腿随账户 / 标的筛选收窄。
