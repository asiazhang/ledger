# ADR-0122: 现价刷新与价格历史解耦——历史回填改后台自动补全

- 状态：已接受（正文已按 ADR-0126、ADR-0130 与 #1534/#1539/#1571/#1674/#1906 现行态收敛）
- 日期：2026-09-15（现行态收敛：2026-10-07）
- 作者：Ledger 项目
- 关联：推翻 ADR-0019「采集单通道」口径；ADR-0038（基金净值水位与首刷）；ADR-0095（标的级同步进度，页级明细已退役）；ADR-0112 决策 5（后台启动接线形态）；ADR-0120（网络等待不进连接锁）；ADR-0121（批量取数面与进程唯一限速器）；ADR-0126（价格恒定标的退出采集）；ADR-0130（新浪/腾讯单请求历史面）；#1534 / #1539 / #1571 / #1674 / #1906；词汇表：投资域「价格历史后台补全」「PriceHistory」「InstrumentInfoSync」

## 背景

ADR-0019 原定「K 线回填同时兼刷现价」单通道，导致每次同步都要为全库标的反复判定首刷；ADR-0121 将日常现价刷新压至常数级批量请求后，逐标的请求只剩补历史一个理由。同时，逐周点自动提交在中断或部分页被拦截时会留下「半根历史」，使「磁盘有行即已首刷」的判据永久失真。

## 决策

### 1. 现价与历史解耦；当周采样点由现价刷新直接落库

- 日常刷新（手动按钮与每日自动）仅刷现价并经批量取数面直接落**当周采样点**（ADR-0121），不再触发逐只历史回填。
- 逐标的采集下沉至后台自动补全，仅服务三类缺口：**首刷**（无任何历史序列）、**缺周点补齐**（水位落后当前周超过一周）与**覆盖不足深回填**（#1534 / #1906：基金或股票/场内标的的最早历史周点晚于其首笔持仓流水日所在周）。
- 采集车道统一走单请求整段历史（场内走腾讯周 K，#1906；场外基金走新浪全历史，ADR-0130；原场内日 K 与分页翻页通道已退役）。
- **适用边界**：本 ADR 仅辖**非恒定标的价格历史**——**价格恒定标的**（如货基，ADR-0126）完全退出采集、不落历史行与当周点；**汇率序列**（ADR-0019 / #1539）独立走 ECB 采集与设置页手动同步，不受本 ADR「无用户入口」约束。

### 2. 后台自动触发、静默纯计数、走势空态三态化

- **无用户入口**：应用启动后延迟触发一次，此后每个自然日窗口自动运行直至队列清空；「同步标的信息」按钮只刷现价。
- **静默可见**：仅展示标的级完成计数 `{ done, total }`（与 ADR-0095 同源；原基金首刷页级明细随分页通道删除于 #1571 整体退役），不占全局忙碌条、不阻断任何操作，终态静默收起。
- **走势空态三态化**：按补全状态呈现「补全中（带计数）」「补全失败待重试」「无数据」，避免指向无响应按钮。

### 3. 额度让路与在途槽位分离

- 后台补全与全部前台请求共享进程唯一全局限速器（ADR-0121），前台请求在途时后台主动让路——前台包含手动同步与手动按代码查询（#1674 补全）。
- 后台补全**不占用**「用户动作在途唯一」的前台槽位，前台操作永不被后台任务拒绝。

### 4. 派生事实续做 + 单只一事务原子提交

- **不建持久化任务表**：补全队列直接由「有价格通道且历史不完整/覆盖不足」派生，排队顺序**持仓优先**（覆盖库内全部非恒定有通道标的，含已清仓，#827）；应用退出即硬停，下次启动自然续做。
- **单只原子**：单只标的整段历史回填在**单一事务**内提交（全成或全不成），中断或源异常不留半根历史，保证「有完整历史」与磁盘事实等价；窗口内全部周点已入库且同值时零落库，零写入不置脏不广播。
- **显式接受的长期行为**：若外部源确实无更早于首笔持仓周的历史数据，该标的会在每窗口重进队发一次请求且零写入——请求量有界（受影响标的数 × 每轮一次）且一旦源补齐数据即自动自愈退队。

## 备选与否决

- **维持现价与历史耦合 / 每日全库逐只增量**：把已压至秒级的日常刷新退回分钟级，否决。
- **新增「补齐历史」用户按钮或插队机制 / 占用全局忙碌条**：为一次性数分钟后台过程引入机制税与界面干扰，否决。
- **建持久任务队列或断点表**：制造第二份真相，派生事实已天然自愈，否决。
- **打开走势图时按需回填 / 退出时阻塞等待补全完成**：分别拖垮组合走势首开体验与退出响应，否决。

## 后果

- 首次同步后现价立即可用，历史走势在数分钟内由后台静默补齐；启动接线归壳层后台服务单点守门，单只原子与前台槽位隔离由对应测试锁定。
- 首次启动后的短暂过渡期内组合走势仅呈现已补齐标的，由三态空态与计数解释。
