# ADR-0038: 场外基金一等标的——复用 Instrument 与 buy/sell，净值入价格线，价格刻度万分位

- 状态：已接受（正文已按 #300–#303、#1059/#1062、#1194、#1534 与 ADR-0109/0126/0130 现行态收敛）
- 日期：2026-08-30（现行态收敛：2026-09-21）
- 作者：Ledger 项目
- 关联：扩展 ADR-0019（价格历史覆盖面）；ADR-0036（自建标的边界）；AI 侧配套 ADR-0039；ADR-0095（同步进度不做取消）；ADR-0109（现金分红 `dividend` kind）；ADR-0122（现价与历史解耦）；ADR-0126（货币基金归价格恒定标的）；ADR-0130（净值与查询换源新浪/证监会，东财退役）；词汇表：投资域 Instrument / MarketPrice / PriceHistory / 价格刻度 / 价格恒定标的 / 红利再投

## 背景

`Instrument` 类型闭集虽含 `fund`，但早期场外基金无行情通道、无法进净值与走势管线。要让国内场外公募基金（人民币份额）成为一等标的，需解决三道核心取舍：净值 4 位小数 vs 价格列整数「分」刻度；申赎语义 vs `buy`/`sell`；以及创建入口、市场字段与净值同步通道的边界。

## 决策

1. **复用 `Instrument`，零枚举改动；市场恒 `unknown`**
   - 类型 `fund`、市场恒 `unknown`（6 位基金代码无交易所概念且无前缀规律）；`UNIQUE(symbol, instrument_type)` 与股票自然隔离。
   - **唯一创建入口与市场守卫（#1194）**：ADR-0036 自建白名单收窄为债券/ETF/其他后，基金只能经按代码查询回填入口创建（AI 侧走 ADR-0039 增强创建）；字典来源标记 = 手动（仅作删除准入消费，不作价格来源展示）。任意通道（HTTP 创建、IPC 创建、同步重放）携带非 `unknown` 市场均显式拒绝（`instrument.fund-market-forbidden`），缺省时由核心创建归一为 `unknown`；不做存量回填（历史错行下次缺省 upsert 自愈，旧非法 op 重放落挂起队列）。
   - **范围与货币基金（ADR-0126）**：覆盖场外申赎式公募基金（含 QDII 人民币份额，ETF 走股票通道）；货币基金允许建档，但归**价格恒定标的**（单位价格恒 1.0000，退出每日刷新与历史采集，读侧按常量取值、不落历史行，单向判定自数据源自报口径——防把万份收益误录成单位净值导致市值少计）。

2. **申赎复用 `buy`/`sell`；分红归 `dividend`（ADR-0109）**
   - 申购 = `buy`、赎回 = `sell`（数量 = 确认份额、手续费 = 申赎费），直接复用持仓、FIFO 卖出匹配、盈亏与走势整条管线。
   - 录入按确认后结果：金额与确认份额为权威输入（从确认单抄写），单价由其反算；不做未知价与 T+1 在途状态。
   - 现金分红由 ADR-0109 激活的 `dividend` kind 承载；红利再投以「现金分红入投资账户 + 0 手续费买入自投资账户出资」两笔在账户内自相抵表达（原「分红不做专门承载」与黑洞过渡形态已退役）。

3. **单位净值即价格，价格刻度就地重定义为万分之一元（BREAKING）**
   - 非恒定场外基金的单位净值直接落 `market_prices`（现价缓存，含净值日期 `nav_date`）与 `price_history`（周粒度序列），沿用「价格」统一账务语义。
   - `price_cents` 列名保留、刻度从 0.01 元就地重定义为 **0.0001 元**，覆盖四列：`market_prices.price_cents`、`price_history.price_cents`、`security_transactions.price_cents`、`security_lots.cost_per_unit_cents`。
   - V002（含 `market_prices.nav_date` 就地增列，#301）/ V010 按已发布迁移两级 BREAKING 标记处理；**不提供存量库自动兼容或 ×100 迁移脚本**（#300 裁定：无可靠版本嗅探点，存量库由维护者自行重建缓存或账本）。

4. **净值采集通道与回填窗口（ADR-0121 / 0122 / 0130 / #1534）**
   - 6 位纯数字基金代码进入场外基金净值分区（依赖入口收口保证不会误拉自编 6 位代码；名称充代码等非 6 位行跳过）。
   - 日常现价与当周采样点走批量取数面，历史回填解耦至后台自动补全（ADR-0121 / ADR-0122）；数据源已于 ADR-0130 替换为新浪批量/单只全历史面与证监会基金电子披露权威兜底（东财 `lsjz` 与详情页数据文件退役）。
   - **首刷与回填深度**：首刷判据为「磁盘 `price_history` 无行」（#1059，不以现价缓存 `nav_date` 有无判定，避免建档写现价后首刷静默落空）；单只全历史单请求拉回后本地裁剪，窗口覆盖至**该基金首笔持仓流水日所在周**（`buy`/`sell`/`convert`/`split` 任一腿命中；无持仓流水维持近两年，#1534）；现价缓存 `nav_date` 仅作已有历史后的增量水位；零实际写入不广播价格失效信号（ADR-0031）。

## 理由

- 复用 `buy`/`sell` 与既有持仓管线零复制成本，避免新 kind 贯穿 Amount 矩阵、写入协议与全部报表。
- 万分位刻度是整数分纪律向 4 位小数净值的延伸——按分舍入会引入最高约 0.5% 的市值噪声；就地重定义刻度避免加列重建视图与双列语义并存。
- 货基单向归入恒定价格标的，既规避万份收益与单位净值混用事故，也避免批量面缺席导致的每日无效逐只请求。

## 否决与已退役方案

- **新增申赎 kind 或基金独立持仓表**：贯穿全链路且无记账语义收益，否决。
- **加万分位新列 + 双列共存**：视图与读写双口径换算复杂度高于 BREAKING 就地改刻度，否决。
- **按分舍入价格 / 仅基金行隐式按万分位解释**：前者破坏精度纪律，后者制造隐式双刻度，否决。
- **在途/确认中状态、基金全量字典同步**：复杂度高、收益低（2 万+只字典按需建档即可），否决。
- **东财 `lsjz` 逐页回填（25 页/只）与东财全历史通道**：先因单只 50s 耗时被单请求全历史取代（#1062），后随 ADR-0130 换源整体退役。
- **货基写入 1.0000 平坦周序列（#1342 过渡态）**：被 ADR-0126 常量读侧合成取代，不再每日请求与落虚拟行。

## 后果

- `price_cents` 列名沿用而真实刻度为万分之一元，依赖词汇表「价格刻度」与读取层单点换算维持认知一致。
- T 日净值 T+1 公布且录入要求确认份额，当日申赎需确认后补录（不做盘中估值）。
- 存量库跨 BREAKING 边界升级需维护者自行处置，不提供一次性自动转换工具。
