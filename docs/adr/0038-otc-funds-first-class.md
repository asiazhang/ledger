# ADR 0038: 场外基金一等标的——复用 Instrument 与 buy/sell，净值入价格线，价格刻度万分位

- 状态：已接受（正文收束为现行态——货基口径、分红承载与数据源均以现行裁决为准，沿革见演进脉络）
- 日期：2026-08-30（现行态收束：2026-11-20）
- 作者：Ledger 项目
- 关联：ADR-0019（价格通道覆盖面扩展）、ADR-0036（自建标的，fund 唯一创建入口的来源约束）、ADR-0039（AI 侧按代码创建配套）、ADR-0095（标的信息同步——取消不做）、ADR-0109（现金分红 kind 激活）、ADR-0122（后台补全「覆盖不足」判据）、ADR-0126（价格恒定标的——货基归属）、ADR-0130（数据源策略——东财退役换新浪/证监会）；词汇表：投资域 Instrument / MarketPrice / PriceHistory / 价格刻度 / HoldingPriceSync / 价格失效信号 / Investment

## 背景

Instrument 类型闭集虽含「基金」，但基金曾是无行情来源的二等标的：手动盲建、无价格通道、增量同步跳过。需求是让国内场外公募基金（支付宝/天天基金渠道的申赎式基金，人民币份额）成为一等标的：有净值行情、有申赎记录、进持仓/盈亏/走势/净资产。三道坎：净值 4 位小数 vs 价格列「分」刻度；申赎语义 vs buy/sell kind；发布冻结 vs 刻度修改。经 grilling 定案如下。

## 决策（现行）

1. **复用 Instrument，零枚举改动**：类型 fund、市场恒 unknown——场外基金没有交易所市场概念，基金代码（6 位）无市场前缀规律，纯字典键；`UNIQUE(symbol, instrument_type)` 与股票代码天然隔离。fund 唯一创建入口 = **按代码即拉**（详情回填名称/类型/最新净值，自建白名单缩为债券/ETF/其他后 fund 自由文本入口已封死）；fund 行携带非 unknown 市场被**显式拒绝**（`instrument.fund-market-forbidden` 码化 400，守卫覆盖创建入口先拒 + 写入协议兜底，缺省市场在核心创建函数归一）——修复前的错误输入不自动回填，旧 Create op 重放被拒按 ADR-0091 落挂起队列（不丢数据、不阻塞同批）。全量标同步退役后「来源标记」的唯一功能消费是删除准入，称**字典来源**，不进用户可见列表。
2. **申赎复用 buy/sell，不新增 kind**：申购 = buy、赎回 = sell（数量 = 确认份额、单价 = 成交日净值、手续费 = 申购/赎回费），时点持仓推算、卖出 FIFO 匹配、盈亏页、走势全部自动工作。录入按确认后结果：忽略未知价与 T+1 在途，金额与确认份额为权威输入、单价由其反算；不做在途/确认中状态。范围边界：仅场外申赎式公募；ETF 已有股票通道不重复；货币基金可建（归属见决策 3 的恒定价格例外）。
3. **单位净值即价格**：净值入 MarketPrice + PriceHistory 既有承载线（现价 = 最新公布单位净值并记录净值日期），市值/未实现盈亏/组合走势/净资产折算自动纳入；沿用「价格」称谓，组合走势不称「净值走势」。**货基是唯一例外**：归价格恒定标的（ADR-0126）——现价恒 1.0000、退出采集链路、读侧按常量取值，万份收益不作价格收录。
4. **价格刻度就地重定义为万分之一元**：`price_cents` 列名保留，刻度从「分」改 0.0001 元，波及四列（market_prices / price_history / security_transactions / security_lots 的 price 列）；V002/V010 就地修改、nav_date 列亦就地增列进 V002，按约定两级 BREAKING 标记（迁移文件头注记 + CHANGELOG BREAKING 条目）。
5. **存量库不兼容，处置义务移交维护者**：无可靠嗅探点区分新旧刻度库，不做自动修复与一次性 ×100 工具；存量库直接升级后价格按 100 倍错读，可重建价格缓存零损失、确定性记录可按需手工 ×100 或重建账本，由维护者自行权衡。
6. **净值同步并入 HoldingPriceSync 分区（fund 分区）**，通道随 ADR-0130 换源：批量最新净值走新浪 `f_` 批量面、单只全历史走新浪全历史面、权威兜底为证监会基金电子披露（东财 lsjz 与详情页数据文件通道退役）。**首刷深回填优先单请求全量通道**（一次请求/只取整只历史、本地裁剪窗口，失败/无点 fail-closed 回退分页通道）；**首刷窗口 = 覆盖到该基金首笔持仓流水日所在周**（无持仓流水维持近两年），AOD 后台补全有「覆盖不足」判据让存量基金自然补齐；**日常增量走分页通道、以现价缓存的净值日期为水位**，水位只服务已有历史序列的增量（首刷判据 = 磁盘上没有任何历史序列，不是「现价缓存无净值日期」）；pageSize 服务端硬上限 20。空响应（报文异常）与「窗口内无新净值」分开处置：前者计入跳过并警告，正常空窗计入成功。货基判定取数据源自报口径且**单向**（缺信号不得反推为非货基）；「已是最新」零写入不广播（ADR-0031 同义）。进度复用、**取消不做**（ADR-0095）。
7. **基金分红走 ADR-0109 的 dividend kind**：现金分红激活为第 8 种 kind（现金腿入任意在用账户）；红利再投 = 两笔组合——现金分红到账投资账户 + 0 手续费买入自投资账户出资（黑洞形态已废止）。

## 理由

- 复用整条持仓管线（Holding / `v_holdings` / InvestedInstrument / 时点持仓 / 净资产）是最大赢家：基金申赎与股票买卖在账务上同构（数量 × 单价 ± 手续费 = 金额），kind 层面区分基金/股票无记账价值；新 kind 要贯穿 Amount 矩阵、行为层、推算模块，无对应语义收益。
- 净值满足价格的账务定义「一单位标的值多少钱」；与手动报价同一哲学（统一为价格，不引入第二语义）。
- 金额权威使成本与已实现盈亏全程锚定整分金额、零误差；万分位刻度保真市值展示（按分舍入会引入最高约 0.5% 的市值噪声，污染持仓/净资产/走势三处消费方）——金额整数分纪律的延伸。
- 水位把增量同步成本从 O(11 请求/只) 压到 O(1/只)；首刷单请求通道把每只 ≈50s 压到 ≈2s。
- 就地改刻度优于加列：加列需视图重建 + 双列语义并存 + 读写两处换算；就地改在「存量库分叉被接受 + BREAKING 标记」的既有发布约定内成本最低、语义最干净。

## 否决方案与代价

**否决方案（防重提）**：新 kind（purchase/redeem，贯穿全链路无语义收益）；基金独立表 + 独立持仓管线（复制持仓/盈亏/折算/走势）；加分位列 + `v_holdings` 重建（双列并存语义不诚实）；`price_cents` 按类型解释刻度（列名说谎）；接受按分舍入（0.5% 噪声不值得）；做在途/确认中状态（挂起-转正生命周期复杂度高，「份额必填」消解）；基金全量同步（2 万+只无批量价值）；~~支持货币基金~~（初版否决，后按代码行为修正为承认可建并归恒定价格口径）。

**代价**：`price_cents` 名不副实（列注释与词汇表钉住真实刻度）；存量库一次性人工处置未做前价格 100 倍错乱；首刷深回填单请求通道依赖新浪未公开承诺的数据文件形态（解析层严格校验 + fail-closed 回退分页兜底）；盘中估值不可见，T 日净值 T+1 公布需补录。
