# ADR 0084: 统一测试数据库工厂与共享断言库——深模块收敛、白名单守门、固定时刻显式化

- 状态：已接受（grilling 定稿，2026-09-07 两轮；迁移收官见文末「迁移状态」段；修订：「独立测试 crate」否决前提被 ADR-0112 修订——workspace 下 dev-dependency 环可解，决策 2 其余判定与工厂接口形态不变，见文末 #1111 修订注记）
- 日期：2026-09-07
- 作者：Ledger 项目
- 关联：spec #728（本文档票）；前身 #250（合并共识在案，本决策为其落地）；前端同构先例 #725/#726（参考数据桩深模块收敛 + `check-test-stubs.ts` 守门）；ADR-0056（白名单守门哲学、测试豁免约定、结构守门）；ADR-0067（余额缓存——共享对拍断言是其测试保障面）；ADR-0083（守门脚本 Bun 运行时）

## 背景

测试架构评审（2026-09-06，spec #728）量化了后端测试建库与种子知识的散落：建库样板（`open_in_memory` + `init_db` 两行序）逐字重复 15 处；建账户助手 4 种参数形状 + 4 个异名共 8 种变体；直接写账户表的夹具裸 SQL 31 处；固定时刻字面量约 166 处；投资铺垫（账户+标的+汇率）在 API 集成层成段复制 6 处；「缓存回填==实时计算」对拍断言（ADR-0067 的关键不变式）在 transaction 域与 db 域测试里各维护一份；同一目录存在绕开本域共享辅助、重抄同体样板的文件。七个域级测试辅助文件合计 652 行，头部注释各自声明「仅限本目录、跨模块合并见 issue #250」。

grilling（2026-09-07，两轮）逐项复核评审数字与当前工作树一致（时刻戳现值 168 行/52 文件；其中同一默认时刻 `2026-01-01T00:00:00Z` 占绝对多数，其余为表达时间推进的域时刻），并确认以下决策。

## 决策

### 1. 深模块方向与准入规则

建统一的测试数据库工厂 + 共享断言库：打开（吸收建库样板）、种子（吸收实体列清单与组合铺垫）、断言（吸收不变式对拍）一个入口完成。各域测试辅助文件保留为「按域种子」的薄皮，装域特有编排（订阅/分期计划创建、occurrence 读取器等），长期存在不删除。

**准入规则**：工厂只收跨 ≥2 域重复的夹具；单域特有的种子与读取器留域薄皮。这是深模块防腐化的判定依据——工厂不长成大杂烩，守门豁免清单即此规则的机器面。

### 2. 住址与可见性

工厂落根包 `test_support/`（打开/种子/断言子模块），与既有 `test_utils.rs` 并列、职责正交（追踪捕获/假发射器不并入）；可见性跟随其先例 `pub mod` + `#[doc(hidden)]`——外部集成测试（`tests/api_server/`）看不到 `#[cfg(test)]` 模块，这是仓库已验证的共享机制，代价（测试面进产品 lib 导出）先例已接受。独立测试 crate 否决：单 crate 无 workspace，工厂需调用 `init_db` 等主 crate 接口，自依赖循环不可解。结构守门白名单追加 `test_support` 并验证其对壳层零依赖（依赖域与基础设施合法，ADR-0056 方向约束）。

### 3. 接口形态：&Connection 自由函数集

`open() -> Connection` 零配置项（内存库 + 迁移就是建库的全部现状；文件库/加密是 BDD 场景，不入本工厂）；种子 `seed_*(&conn, …) -> 实体 id`；断言 `assert_*(&conn, …)`。不引入包装类型与 builder 链——现状 15 处样板、全部域助手、API 集成 `ApiState` 注入都以 `&Connection` 流转，包装类型让每个调用点改两遍。深模块的第一版就该没有配置。

### 4. 建账户签名归一

`seed_account` 单一全位置签名 `(conn, id, name, kind, currency, initial_balance_cents)`（现存最全形状），`id` 仍由调用方指定（外键引用显式）。options struct + `Default` 否决：`..Default::default()` 把关键字段藏进默认值，测试失去显式性；账户列集随已发布 schema 冻结，参数增长风险低。异名处置：`setup_investment_account`（transaction 域两份逐字重复）与 `seed_investment_account`（API 集成）由工厂投资铺垫组合种子取代；e2e 步骤内异名不动（out of scope）。

### 5. 固定时刻：命名常量 + 簿记戳内部发放

字面量两类分治：**夹具簿记戳**（账户/标的/汇率的 created_at/updated_at，同一默认时刻 `2026-01-01T00:00:00Z` 占绝对多数）由工厂命名常量（`FIXED_NOW`）在种子内部发放，调用点消失；**域时刻**（汇率/价格序列点、预算窗口、定时触发点）是测试的行为输入，不吸收——需要时间推进的种子参数显式收时刻，默认值引用常量。递增发放否决：调用点零参数但先后关系隐式化，读者无法从调用点看出时序。守门只禁默认时刻字面量出现在工厂之外（域时刻字面量合法）。

### 6. 共享断言库成员

本 spec 收两件：余额缓存「回填==实时」对拍（`assert_balance_cache_matches_realtime`，transaction/db 两域旧断言删除归一，ADR-0067 的测试保障收归唯一维护点）+ 通用行读取器（既有白盒读约定是有意旁路，本决策只共享读取体、不推翻约定）。金额矩阵双算对拍（reports/budget/accounts 三域域内实现）**不**一并收编，留后续票：评审仅列其为模式先例，无双维护痛点证据；本 spec 迁移面已到 review 可机械核对上限。

### 7. 迁移节奏：工厂先行 + 按域渐进

先落工厂 + 断言库（不动任何既有调用，全量测试保持绿）；随后按域渐进迁移，一域一 PR：薄皮体内改调工厂、调用点改用归一签名（薄皮转发可作域内中间态，签名归一在域迁移时完成）；API 集成 `build_test_app` 内部接工厂打开入口，投资铺垫三段复制改组合种子。e2e 层不动（夹具统一另立 spec）。纪律沿 ADR-0056 先例：改动可机械核对、每步质量门槛全绿。

### 8. 白名单守门

`check.sh` 新增 Rust 测试守门（文本级扫描，运行时遵循 ADR-0083）：测试代码直连建库样板（`open_in_memory`/`init_db` 于工厂与 db 域之外）、夹具表裸 SQL（`INSERT INTO accounts` 等于工厂与域薄皮之外）、默认时刻字面量（`FIXED_NOW` 值于工厂之外）命中即红。白名单起步、随按域迁移清零，清零后转纯禁令——「白名单即规格」（ADR-0056 哲学），前端同构问题（散落桩）已由 `check-test-stubs.ts` 验证「深模块收敛 + 守门防回潮」在本仓有效。具体命中模式清单与脚本归属（新脚本或并入既有）实施票定。

## 备选与否决

- **仅去重不建统一入口**（#250 原设想）：逐份 diff、保留「本质差异」——8 种签名证明差异多为偶然漂移；不打平接口则跨域读者仍要分辨 N 个入口，时刻戳与样板噪音原样保留。
- **独立测试 crate**：见决策 2，自依赖循环。
- **包装类型 + builder 链**：见决策 3，与现状 `&Connection` 惯例全冲突，迁移摩擦翻倍。
- **options struct 种子签名**：见决策 4，`Default` 藏关键字段、损显式性。
- **时刻递增发放**：见决策 5，时序隐式化。
- **不加守门靠评审**：回潮无机器信号——样板积到 15 处无人拦即是回潮率的直接证据。

## 影响

- 迁移完成后：建库样板 15 处归一、簿记时刻戳清零、账户签名单一、投资铺垫一行建成、对拍断言唯一维护点；20+ 测试文件调用点按域逐步改写（期间新旧共存、守门白名单递减）。
- 产品 lib 导出面新增 `doc(hidden)` 测试模块（先例已接受的代价）；`check.sh` 增一环；结构守门白名单追加 `test_support`。
- schema、迁移文件、IPC/HTTP 契约零变化；「已发布契约只增不改」不受影响。
- 实施票待定项：种子函数完整清单、守门命中模式与脚本归属、按域迁移的 PR 切分顺序。

按域渐进迁移已收官，守门转纯禁令：白名单机制随 #758 移除，扫描范围内命中即红（fail loud 语义不变）。两条边界仍有效：①「缺表」场景经工厂库 `DROP TABLE` 模拟，迁移后文件库落盘经 `VACUUM INTO`（工厂无「未迁移库」形态，同决策 3）；② `tests/e2e` 不在工厂辖域（BDD 与工厂分层互斥，ADR-0086），#764 落地时恢复该目录的守门覆盖。共享断言是测试域对拍的唯一维护点；ledger-perf 第三份同名断言经 #776 裁决定案（不归一，分工留痕于该函数注释）。

## 修订注记（#956，2026-09-10）：通道线格式替身与测试专用域间边

多端同步的「构造合法通道段 + 归并 manifest」曾与 BDD 步骤层各手工复制一份，收归 `test_support::channel::publish_raw_segment`（决策 1 准入：≥2 层同体消费）。

- **共享物是「通道线格式契约」（字节级成帧），不是建库/种子/默认值集**：ADR-0086 决策 9 的分层互斥不破，与 WebDAV 协议替身同待遇；词汇表锚定「通道线格式替身」。
- **测试专用域间边 `test_support → sync_engine` 登记**：按 ADR-0071「域间横向边显式化、逐条留痕」口径，该边由测试豁免路径消费、不进产品依赖图；与既有 `test_support → accounts` 同性质。域间边机器不可达，靠评审与 ADR 登记兜底（如实登记，非守门缺口误判）。
- **守门新增规则 4**：测试代码禁手工构造通道段/清单与自建摘要（`test_support` 本体豁免；作用域限定防误伤无关摘要用法）。
- **成因留痕**：两份夹具把尺寸/摘要算在 payload 上、产品算在封套输出上，明文模式二者恰等而长期掩盖；原票「摘要口径漂移致测试静默变绿」的风险陈述不成立（拉取侧校验下载字节，换算法会直接打红），真实风险是同一隐式假设被写了两遍。

## 修订注记（#1111 / ADR-0112，2026-09-13）：「独立测试 crate」否决前提已变——workspace 下 dev-dependency 环可解

决策 2 否决独立测试 crate 的理由（单 crate 无 workspace、自依赖循环不可解）随 workspace 落地失效：dev-dependency 环是 Cargo 允许的测试专用边——测试目标与生产依赖图分离，不构成生产环（ADR-0112 决策 5），先例已实证（基础设施 crate 域单测经 `[dev-dependencies]` 消费根包的测试工厂与共享断言，结构守门的依赖方向核对只辖生产依赖）。

落点判定不变的部分：工厂仍是跨域深模块（决策 1 准入规则）、接口仍是 `&Connection` 自由函数集（决策 3）。落点判定随结构演进的部分：域目录尚在根包时工厂留 `test_support/`（环无必要）；业务域逐域拆出后按 spec #1086 以**独立测试支持 crate** 供各域 dev-dependency 引用——届时「独立测试 crate」从否决项变为目标形态，`#[doc(hidden)]` 机制随之迁入（生产 lib 导出面同步瘦身）。

环非默认必选：负向用例可能被环击穿时以「测试不随迁」替代（协议 crate 先例：compile_fail 负向用例要求根包不可见，取环会击穿之；理由留痕于相关 Cargo.toml）。

## 修订注记（#1107，2026-09-13）：DeviceId 单测随多端同步域迁入

上条「DeviceId 单测留根包」的落点随域拆分变更：多端同步域拆为 `ledger-sync-engine`，其 `[dev-dependencies]` 测试环只进该域 crate 的测试目标，协议 crate 仍无环、compile_fail 负向用例继续由 workspace doc 测试守卫。同票 `channel::sha256_hex` 随跨 crate 消费再放宽为 `#[doc(hidden)] pub`（#956 的第二次放宽），产品消费者仍只有通道模块。

## 修订注记（#1433，2026-09-17）：源码扫描掩码器具上收 `test_support::scan`

源码扫描守门的词法掩码与花括号配对曾三处同型（Rust 侧两处 + TS 守门脚本一处）。Rust 侧上收为 `test_support::scan` 单一维护点（注释/字符串字面量等长掩码原语 + 掩码文本花括号配对原语），四处手写花括号配对同型随同一原语归一；消费面为壳层信号/连接槽/同步触发/行情接缝守门与 market-sync 车道守门（经既有 dev-dependency 环，无新依赖边）。

- **双源登记**：与 TS 侧掩码是同一词法规则的两个运行时载体（守门脚本跑 Bun、Rust 测试跑 cargo，单份实现不可共享），规则改动必须两侧同步；共享语料夹具被双侧测试消费，任一侧单独改规则即红。
- **准入与可见性**：沿决策 1 放宽面先例（#956 同款）与决策 2。
- **已知双源边界（如实化）**：多级 `#` 原始串与 `'\u{…}'` 转义两侧一致地不按字面量识别（旧注释声称支持、与实现不符，本票改为如实描述）；非 ASCII 标识符紧邻原始串等病态形态 TS 侧按近似处理；`keepLiterals` 扩展形态 TS 侧独有，扩展属规则改动、须两侧同步。掩码原始串前缀判定的下溢 panic（被扫文本以原始串起始即触发）随本票独立修复更正，语料锁定该路径。

## 修订注记（#1514，2026-09-18）：`open()` 建库形态改模板还原 + 确定性等待可注入

测试执行提速续作，两处落点都不改本 ADR 的接口判定：

- **建库不再逐用例重放迁移链**：进程内首次调用固化迁移后 schema 与默认种子，其后每次 `open()` 经序列化还原一份全新独立内存库。实测逐次建库 31ms/次 → 约 40µs/次；整套 lib 测试单线程 116.5s → 104.3s、12 线程墙钟 16.9s → 14.3s。**独立性不变**——模板是迁移产物的只读快照，还原所得互不干扰、与逐次 init_db 等价；建库仍是基础设施职责，工厂仍是唯一入口，连接级设置经收尾单点重新施加、不进序列化产物。
- **确定性真实等待改为可注入**：多端同步调度侧轮次连接源的取锁等待上限改为字段（产品默认不变），「拿不到锁即放弃本轮」同一断言面实等 10.1s → 0.18s；备份侧新增参数化形态、原常量形态保留为薄转发，回潮哨兵判定面不变。

本注记只记机制变更与实测数据；决策 1–8 的判定与守门规则不变。

## 修订注记（#1645，2026-09-21）：测试暂存目录 guard 收编 `test_support::scratch`

真临时目录夹具「只建不删」散在 5 个编译单元约 70 处（本机 /tmp 实测残留 1.3 万项 / 11.2GB），收编为 `test_support::scratch`：`ScratchDir` / `ScratchFile` 构造即建 `ledger-test-` 前缀暂存目录，drop（含 panic unwind）整棵删除；手写清理收尾与建目录样板随迁移退役。e2e 场景 guard 登记进场景组（每 scenario 重建即清理）；集成测试夹具把 guard 交调用方持到用例结束。

- **准入与可见性**：沿决策 1 放宽面先例（#956/#1433 同款）与决策 2；各消费域经既有 dev-dependency 环消费，无新依赖边、无白名单改动；词汇表锚定「测试暂存目录」。
- **不收编面（如实登记）**：进程级 `$HOME` 夹具保持现状（目录进程存活期不能删，属验收豁免类；后随 #1989 收编退役）；产品代码路径的临时文件不属测试器具；SIGKILL 下 guard 不执行，残留从「每次全量堆积」降为「异常终止偶发」。

## 修订注记（#1699，2026-09-22）：读快照探针收编 `test_support::snapshot_probe` + 文件库建库 `open_file`

多语句读闭包的快照一致性修复（rollback journal 下语句间无快照隔离，写提交落在两语句之间即同屏口径自相矛盾）需要「写提交恰落在两语句之间」的确定性注入现场：探针在 reader 连接注册 trace 回调，目标语句开始前于**另一条连接**原子提交注入写——红（无修复）= 注入提交、口径断言必红；绿（修复后）= 读事务持锁挡住注入、口径仍自洽。七处探针测试跨交易 / 投资 / 壳层三个编译单元同体消费。

- **准入与可见性**：沿决策 1（≥2 域同体消费）与决策 2；配套 `open_file(db_dir)` 是文件库建库入口——内存库按连接隔离、第二连接是另一个空库，双连接现场必须文件库；建库接线知识收单点，决策 3 的零配置接口形态与既有调用点不变；词汇表锚定「读快照探针」。
- **单槽与传态边界（如实登记）**：trace 回调是单槽，探针注册顶掉建连收尾安装的耗时 hook——仅测试连接、仅用例存活期，perf 日志缺席无行为影响；回调只收裸函数指针，状态经线程局部传递。
- **守门不触（如实登记）**：注入写经既有事务原语、注入载荷簿记戳引 `FIXED_NOW` 常量、目标表不在夹具裸 SQL 禁用表集，既有守门均不触。

## 修订注记（#1702，2026-09-22）：同根因残留候选取舍，探针消费面扩围

同根因残留候选 triage：收益率、组合走势（读数↔汇率折算）、仪表盘净资产三腿、实物资产折算、定时计划与订阅花费、保单统计九个新读闭包修复——探针测试新增九处，消费面自三个编译单元扩至七个（新增仪表盘、实物资产、定时、保单四 crate 的 dev-dependency 测试环）。仪表盘接线的设计裁决：**读闭包收进读事务、回填写留在事务外**——指纹标签自证失效（回填后被并发写超越即失配重算，竞态最多浪费一次重算），而读事务内升级写有 BUSY 面。判定不修候选的审计结论随 #1702 交付报告留痕，不改变本 ADR 契约。

## 修订注记（#1868，2026-09-28）：文件库测试模板 `open_file_scratch`

ADR-0139 决策 2 的实施前置：跨库（main + ATTACH 的 sync.db）事务的集合级原子性断言必须用文件库——main 为内存库时 SQLite 对多库事务不提供集合级原子保证，内存库测不出真实语义。文件库模板由此收编 `open_file_scratch`：暂存目录经 `ScratchDir` 发放、guard 交调用方持到用例结束（#1645 契约），全量迁移与建库接线沿 `open_file` 同两处单点；决策 3 的接口形态不动（自由函数 + `&Connection`，唯一差异是返回多一个目录 guard）。

- **准入与可见性**：工厂本体成员（决策 1/2），无新依赖边、无守门改动；词汇表锚定「文件库测试模板」。
- **行为等价判据**：首个闭环行为测试改内存 / 文件库双形态矩阵（同一场景体两形态等价绿）；工厂自测另钉直接等值断言（user_version 与默认种子两形态相等）与 drop 后整树清理。
- **已知边界（如实登记）**：文件库模板逐用例重放迁移链——序列化快照不适用于文件库（跨库原子性要求真落盘），建库成本回到毫秒级；跨库原子性断言由拆库切换票消费本形态落地。

## 修订注记（#1896，2026-09-29）：op 写失败注入收编 + 拆库票审查的重复单点化

拆库切换票 code-review 标准轴发现的重复形状（按「既有技术债立单」纪律立票）按归属单点化：

## 修订注记（#1989，2026-10-31）：进程级现场隔离收编 `test_support::isolate_home`——`$HOME` 单根重定向挡不住 XDG

实施期间发现：本机设置了 `XDG_DATA_HOME` 时，各测试二进制自持的 `$HOME` 夹具只重定向单根——mock runtime 的应用数据目录解析优先走 XDG，集成测试的备份/恢复与默认数据目录写入因此落在真实用户根（相关测试在现场环境稳定红）。六处同体副本收编 `test_support::isolate_home`：`$HOME` + XDG 数据/配置三根一齐重定向进 `ledger-test-home-` 前缀隔离目录，`Once` 语义每测试二进制恰有一次写入。#1645 不收编面登记的「进程级 `$HOME` 夹具保持现状」随本收编退役——收编动机正是该夹具被证实有隔离缺口且六副本已漂移（隔离根仍不随用例删除，不属暂存目录管辖）。

- **准入与可见性**：决策 1（≥2 编译单元同体消费，六处副本）+ 决策 2（`pub mod` 工厂内私有模块 + 顶层再导出，与 `ScratchDir` 同面）；无新依赖边、无守门改动。
- **删除即变红**：契约测试先毒化 XDG 两根再调夹具，断言 mock 应用数据/配置目录解析（事故同一条路径）落进隔离根；删除夹具内任一 XDG 写入即红。已知边界：macOS 不消费 XDG 变量，对「未重定向 XDG」回归不敏感（事故仅 Linux 形态）。
- **迁移为纯机械替换**，全量测试在预置 XDG 变量的环境保持绿；词汇表锚定「进程级现场隔离」。
