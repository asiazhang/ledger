# ADR 0086: BDD e2e 步骤共享层加深——步骤输入工厂、步骤动词走公开写入口、world 快照按域分组

- 状态：已接受（grilling 定稿，2026-09-07 两轮）
- 日期：2026-09-07
- 作者：Ledger 项目
- 关联：spec #729（本文档票，测试架构评审 2026-09-06 姊妹 spec #728–#732 之一）；ADR-0084（统一测试数据库工厂——分层相邻互不消费，其决策 7 明言「e2e 层不动、夹具统一另立 spec」即本票）；ADR-0085（前端 invoke 测试接缝——测试基础设施域的姊妹决策）；ADR-0073（壳层写仪式收敛——例外白名单纪律同构）；ADR-0067（余额缓存——「存在账户」旁路的历史成因）；ADR-0033（行为层三编排入口——交易写入的公开接缝）

## 背景

BDD 层 feature 文件健康（408 场景、步骤短语高度复用），但步骤实现层复制粘贴严重：17 字段交易输入字面量 53 处/19 文件（约 1,000 行）、计划输入字面量 12 处；支撑 647 个步骤函数的共享层仅 133 行。「存在账户」前置（131 场景引用）以裸 SQL 插入绕开公开创建入口（ADR-0067 落地前的历史产物），同一造账户行为并存两条接缝。world 快照 67 字段按 issue 线性生长无分组，且是近 4 个月全仓改动最热文件（×57）。

grilling（2026-09-07）对评审证据修正两处（以代码为准）：

1. 「手工补一行余额缓存」失真——现状旁路是裸 SQL INSERT 后**调用**余额刷新函数（与 ADR-0067 写路径同款）；真实缺口在绕过公开创建入口的校验与不变量（名字唯一、类型合法），以及自带预置 id 计数器。
2. 「查询助手 ×26 散布」前提失真——全量交易读取已在共享层唯一定义，26 处是调用不是复制；真正散布的是文件级步骤（备份/加密/数据位置）的内联 COUNT/SELECT。

旁路普查（grilling 实测）：步骤层裸 SQL 约 30 处/13 文件，远超 spec 原点名的账户/商户/计划三类——账户 ×6、交易直插 ×5、标的 ×5、汇率 ×3、行情与价格历史 ×3、分类 ×2、预算 ×2、期次状态回写 ×1、持仓时间戳回溯 ×1、批量软删 ×1 等。

## 决策

1. **两层结构：步骤输入工厂（L1）+ 步骤动词（L2）**。L1 纯函数、无 world 依赖、可独立单测；L2 动词完成名称注册表解析 → L1 构造 → 经域层公开函数写入 → 结果注册回 world；步骤函数薄化为文本解析。术语「步骤动词」统摄前置（Given）与动作（When）两种使用形态，取代 spec 原窄称「前置动词」。词汇落 `docs/contexts/CONTEXT-testing.md`（测试基础设施域）。
2. **工厂签名：位置参数热点字段 + 结构体更新覆盖**。金额/账户/日期等热点作位置参数，其余取合法且语义中性的默认值，冷字段经结构体更新语法覆盖——与物品域构造助手、域内测试工厂两先例同形，零新机制。交易按 kind 各设构造函数、计划按三形态各设构造函数：per-kind 合法字段集差异大（转账要两端账户、退款要原交易），单工厂把 per-kind 矩阵知识摊回调用点。
3. **前置走公开写入口**：凡公开入口存在的实体创建与状态变更，测试一律经域层/行为层公开函数完成（与 IPC 命令体同款调用；测试无应用运行时，不经壳层）。业务不变量（含余额缓存行等派生数据维护）由产品代码保证。撞上域不变量的既有场景数据默认改数据并记录；确需「不合法状态」作被测前提的场景保留直置并登记例外，不静默放松产品校验。
4. **旁路归零 + 例外白名单**：有公开入口的旁路（账户、分类、预算、标的等）全部收敛；公开入口不存在且场景本身依赖「库内状态直置」的旁路（期次状态回写、持仓时间戳回溯、市场数据历史行、批量软删态等）逐个登记动机，比照 ADR-0073 例外白名单纪律——「例外显式登记在案，防止被无意复制」。
5. **预置 id 消亡**：公开创建入口返回生成 id，实体引用一律经名称注册表解析；id 计数器与各创建助手的 id 形参删除（普查证实无场景依赖 id 字面值）。与 ADR-0084 账户种子「调用方指定 id」的分层差异显式声明：域内测试无注册表概念、外键显式是其显式性；e2e 以名称为场景词汇，生成 id + 注册表解析。
6. **world 快照七分组，本体收缩**：快照按消费域聚合为交易 / 计划 / 资产（投资+实物资产，净资产同腿）/ 物品 / 保单 / 报表（跨域消费端聚合）/ 引导（备份+数据位置+加密+启动失败）七组，各自持有快照与断言辅助；本体只留数据库连接、四名称注册表、跨域错误断言状态与冻结时钟。分组内读取辅助做分组方法，纯连接查询保持自由函数；既有连接借用宏机制不动。新快照必须归入既有分组，回退本体平铺即回潮。组数上限「一屏记得住」，不为对齐产品域数量裂分。
7. **查询助手收编面修正**：全量交易读取助手已唯一定义，维持稳定不动（错误断言助手同理）；收编对象改为文件级步骤内联 SQL 的重复形状，提取为共享助手，体量小、并入迁移票，不立独立大票。
8. **验收口径精确化（比照 ADR-0073 决策 7）**：feature 文件零改 + 场景断言语义零改；world 访问形态改造与动词签名适配不算违约；等价判据为 BDD 全量保持绿。
9. **与姊妹 spec 分层互斥**：ADR-0084 工厂（域内/API 集成层）与本决策（BDD 步骤层）互不消费、互不共享默认值集——一次默认值调整不得同时打红两层；只共享「默认+覆盖」模式哲学。

## 备选与否决

- **builder 链式覆盖**（`.with_note()` 形态）：新机制，53 个调用点未必需要；位置参数 + 结构体更新是语言原生免费逃生舱。
- **单一 `transaction_input(kind)` 工厂**：per-kind 矩阵知识摊回每个调用点，与产品侧「矩阵收口一处」同构的理由在测试层同样成立。
- **工厂连带写入的单层形态**：造输入与写仪式耦合，错误断言路径（只需构造不需写入）复用打架。
- **公开入口加「指定 id」测试后门**：产品接缝为测试开口，违背收敛初衷。
- **world 与 CONTEXT-MAP 产品域一一对应（8–11 组）**：组数超一屏记忆；物品/保单并入资产组违背「找某域状态只看一处」。
- **测试专用包装写入口**：新造一条接缝，正是本票要消灭的形态。
- **与 ADR-0084 工厂共享种子/默认值集**：默认值漂移会同时打红两层测试——正是本票要消灭的噪音形态。

## 影响

- 迁移完成后：53 + 12 处字面量收敛为工厂调用（字段变更只改工厂一处，19 个步骤文件不再机械跟改）；有公开入口的旁路归零、例外显式登记在案；world 字段访问一次机械改写，新增快照有明确归属分组；新场景步骤实现 = 动词调用 + 字段覆盖，AFK agent 可循既定形态。
- feature 文件、产品代码、schema、IPC/HTTP 契约零变化；「已发布契约只增不改」不受影响。
- e2e 前置走公开入口后单场景略慢（校验 + 余额重算），全量时长可感知但不敏感。
- 与 ADR-0084 守门衔接：其「夹具表裸 SQL」白名单中的 e2e 条目随本 spec 迁移递减清零。
- 词汇落测试基础设施域（`CONTEXT-testing.md` 新增测试世界、步骤输入工厂、步骤动词、快照分组、公开写入口（测试侧）五条）。
- 落地：spec #729 及其子 ticket（拆分见 issue 正文）。
