# ADR-0073: 壳层写路径仪式收敛——统一写入口 `write_entry` + 身份单点声明（声明表派生消亡）

- 状态：已接受（实施待启动，三批迁移，spec #523）
- 日期：2026-09-04
- 作者：Ledger 项目
- 关联：spec #523（grilling 定稿）；ADR-0069（`run_db` 先例，本入口组合之而非替代）；ADR-0044（信号映射单点不变，决策 1/3 的壳侧发射与声明表形态由本 ADR 修订）；ADR-0032（置脏豁免单点不变）；ADR-0033（域层写路径接缝不动）；ADR-0047（命令注册扫描面不变）；ADR-0056（壳层职责与基础设施白名单，白名单追加一行）；ADR-0009 / ADR-0068（SQL 归因与性能门禁，日志形态零变化）

## 背景

ADR-0069 统一了执行线程，但写命令的仪式仍逐处重复：克隆连接句柄 → `run_db` 进阻塞线程池 →
`db::write`（锁失败映射、事务、提交点置脏）→ 发信号，六行样板在全部命令壳与 HTTP handlers
中出现五十余处。更实质的是写操作身份双声明：每个写命令在命令体内 `emit_for(op)` 一份、壳旁
手写声明表（IPC `IPC_COMMAND_WRITE_OPS` 158 行 94 条目 + HTTP `HTTP_ENDPOINT_WRITE_OPS`
32 行 18 条目）再一份，两份靠交叉核对测试（`signals_cross_check` 五条）事后对齐——「新增写
命令忘了声明身份」要等测试跑红才被发现，且每加一个命令都要记得同步两张表。本决策把仪式收敛
进一处实现，身份成为参数随闭包流动，声明表从「手工维护的第二份事实」降级为源码扫描的派生物。

## 决策

1. **统一写入口 `write_entry`：连接句柄、发射器、写操作身份、业务闭包进，其余内化**。落点为
   `db/` 的兄弟基础设施模块（`write_entry.rs`，与 `signals.rs`/`events.rs` 并列，ADR-0056
   守门白名单追加一行）——组合器自身无连接机制知识，`db/` 保持「纯连接机制」的目录叙事，
   「连接层接缝」指接缝位置而非文件住址。入口内部按序组合：`run_db`（执行线程与 span 传播
   照旧，ADR-0069 决策 3）→ `db::write`（锁失败映射、事务、提交点置脏，ADR-0032 豁免单点
   不动）→ `signals_for`（映射单点，穷尽 match 仍是身份合法性的唯一裁决者）→ 发射（语义
   锚定不变：事务提交成功后发射，发射失败不影响写结果）。闭包业务错误原样传播、闭包 panic
   归一化（JoinError → 通用错误）与 ADR-0069 先例同形。
2. **结果证据经 `Outcome<T>` 包装随闭包返回必达**：`Silent(T)`（零证据）/ `Evidenced(T,
   WriteEvidence)`。`signals_for` 的条件一半（价格写入数、黑洞即建、商户即建）依赖闭包结果，
   而证据只能从返回值来——单形态包装让证据必达，「条件信号身份误用静默入口」的漂移被类型
   消灭。零证据命令的代价是一个 `Silent` 构造器。
3. **发射器参数归一 `Option<AppHandle>`**：IPC 壳透传 `Some(app)`，HTTP 壳从 `EmitterSlot`
   解包；`None` 跳过发射正是两侧共有的既有测试态语义。「走 `db::write` 但映射为零信号」的
   写命令恢复 `app` 参数并统一传 `Some(app)`——生产代码不借用测试态语义；`signals_for`
   返回空集时发射循环自然零次，行为与今日逐字节相同，且未来给零信号身份补信号时天然生效。
4. **span 归因名保留 `&'static str` 参数**：IPC 传命令名字面量、HTTP 传 `"METHOD /path"`
   端点键，SQL 日志输出逐字节不变（ADR-0009 消费方与 ADR-0068 门禁语境零感知）。身份与
   归因串的理论漂移是纯展示层问题，由决策 5 的扫描守门顺带核对（IPC 侧归因串 == 身份派生名）。
5. **声明表派生消亡 + 源码扫描守门**：两张手写表删除。交叉核对测试改形为测试期源码扫描
   （不扩 build.rs——声明表的唯一消费方就是交叉核对测试，函数体扫描不必抬到编译期）：
   - 从命令 / handler 函数体扫描 `write_entry` 调用点，提取（声明壳, 身份）派生表，
     「每个被映射身份至少被一壳声明」（抓孤儿身份）与「单壳至多一身份」两条守门原样保留；
   - 新增反向守门：命令体内出现 `db::write` / 发射调用而无 `write_entry` 即红，兜住
     「绕开入口写库」的回归——这是「读命令不再有成文 `None` 登记」的补偿性保证；
   - 不经 `db::write` 的声明写命令进显式例外白名单，逐个附动机注释（文件级备份三命令、
     settings KV 两命令、data_location 引导指针两命令、`set_auto_execution_enabled`
     进程标志、`audit_balance_cache` / `repair_note_pinyin` 直连锁内维护、
     `sync_instruments` 分离线程自发射——先例：ADR-0069 六命令清单、ADR-0033 例外登记纪律）；
   - 信号知识本身的守门不降级：`signals_for` 穷尽 match（编译期）+ 每身份一条直测断言
     （含零信号显式断言）全部保留。
6. **覆盖面 = 壳层专用，入口零豁免概念**。53 个 IPC 声明写命令与 9 个 HTTP 写端点中呈
   「`run_db` + `db::write` + 发射」形状的全部迁入；域层写路径（行为层三入口、批量导入
   batch、余额调整事务壳、定时引擎、AI 导入）不纳入——它们没有身份与信号职责，接缝契约
   （ADR-0033）零改动。入口不设 bypass-dirty 参数：settings 写命令照走入口（映射表中
   settings 域本是显式行），置脏豁免仍由 `db::write`/settings.rs 内层单点裁决；Restore
   路径不经本入口、保留现状。读侧不跟进：读命令剩余仪式约两行且无身份/信号维度，待真出现
   第四件读后横切事项再议。
7. **迁移三批，每批「既有测试断言零改全绿」后合并**：①入口落地（新模块 + `Outcome` +
   单测：闭包执行、错误传播、panic 归一化、信号发射与身份传递，纯增量零迁移）；②IPC 批
   迁移 + 交叉核对改形（IPC 表消亡、扫描守门上线、例外白名单登记；过渡态 HTTP 仍手写表，
   扫描对 HTTP 侧暂读旧表）；③HTTP 批迁移（HTTP 表消亡，扫描覆盖两壳）。等价性验收口径：
   BDD e2e 与 API 集成测试**断言**零改全绿；零信号命令恢复 `app` 参数导致的 BDD 直调点
   **签名适配**（补实参）不算断言变化，验收时不与「测试世界零改造」承诺混淆。

## 否决（防重复提案）

- **双入口（`write_entry` / `write_entry_with_evidence`）**：零证据命令仪式最少，但出现
  两条模仿形状，且条件信号身份误用静默入口会少发信号——撞在信号正确性命门上，另立小清单
  守门是补丁叠补丁。
- **提取器参数（`|&T| -> WriteEvidence`）**：把仪式从调用体挪进参数列表，没省；恒返
  `None` 的 lambda 是新样板。
- **收窄保留手写表（只删 `None` 行）**：保留一张纯派生可得的表，第二份事实依旧。
- **build.rs 编译期声明扫描**：函数体扫描的脆弱形态抬到编译期无增益，消费方只有测试。
- **发射器 trait（`AppHandle` 与 `EmitterSlot` 各 impl 一套）**：为「透传省一行解包」
  引入新机制，接口宽度不划算。
- **span 名从 `WriteOp` 派生**：省一个参数的代价是 HTTP 归因形态变化（端点键 → 身份名），
  违反本决策的等价性纪律。
- **域层纳入 / 读侧统一入口 / 入口豁免参数**：见决策 6——身份与信号对域层无意义；读侧
  无收敛对象；豁免参数把「什么算数据变化」撕成两处。
- **命名约定派生身份（命令名 → `WriteOp` 自动映射）**：身份是跨壳共享的语义概念（两壳
  命令面不对称、HTTP 无命令名），字符串约定正是 ADR-0044 否决字符串键的翻版。

## 代价

1. 零证据写闭包多一个 `Silent` 构造器（约五十处）——「证据必达」的保证价。
2. 零信号写命令恢复 `app` 参数（约十处），BDD 直调点编译级适配。
3. 读命令不再有成文清单——「这是读命令」靠反向扫描守门保证而非登记。
4. 基础设施守门白名单追加一行（`write_entry.rs`）。
5. `audit_balance_cache` 维护缓存行是否算账本数据变化的置脏口径，为已知开放点，白名单
   登记、不在本票裁决。

## 后果

- 新增写命令只剩：域函数 + 壳层一行 `write_entry`（身份作参数）+ TS 调用面——「忘了同步
  声明表」这类返工从流程中消失，漏接线在扫描守门即红。
- 事务规则的调整（锁、事务、置脏、信号时序）天然覆盖全部写命令；壳层文件业务闭包之外的
  内容趋近于零，ADR-0056「壳层无业务语义」的承诺肉眼可验。
- 两张手写声明表（约 190 行）消亡为扫描派生物；信号映射单点（ADR-0044）与置脏豁免单点
  （ADR-0032）地位不变。
