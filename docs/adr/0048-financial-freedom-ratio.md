# ADR-0048: 财务自由度口径——可投资资产 × 3% ÷ 年度预算总额

- 状态：已接受
- 日期：2026-08-31
- 作者：Ledger 项目
- 关联：issue #341（spec）、#343（口径命令 + 文档先行）、#344（概览页卡片）；术语锚点见投资域词汇表 InvestableAssets / FinancialFreedom、预算域词汇表 AnnualBudgetTotal

## 背景

概览页已有净资产、本月收支、投资市值与预算进度，但都是孤立数字；用户缺一个指标回答那个终极问题：「我现在攒下的可投资资产，离『不动本金、靠收益覆盖开销』还有多远？」把资产与年度支出水平放到同一刻度上，需要一次口径定案：分子算什么、分母算什么、提取率取多少、算不出时怎么表现。本 ADR 沉淀这四个取舍的 why；#343 落地只读聚合命令（实时计算不落库）与 BDD 钉口径，#344 承接展示层卡片。

## 决策

1. **提取率取保守的 3%，不是教科书 4%**：4% 法则是特定市场历史回测的经验值，直接照搬对保守型用户过于激进；3% 意味着同样的资产被允许提取的年度金额更少，达标线更扎实、留足安全边际。提取率是常量、后端单点收口，不开放用户配置——要改就是改代码 + 修订本 ADR，避免「人人一套口径」后指标不可比。自由度公式 = 可投资资产 × 3% ÷ 年度预算总额 × 100%，≥100% 即财务自由；覆盖年数 = 可投资资产 ÷ 年度预算总额，与自由度是同一刻度的两种表述（「每年能提多少」与「能躺几年」）。百分比与覆盖年数均保留一位小数。
2. **分子 = 可投资资产：Σ 持仓市值 + Σ 投资账户余额**，均折算 DefaultCurrency，排除隐藏账户（含黑洞账户）与负债。投资账户余额计入而净资产（ADR-0020）不计入，两者并存不冲突：净资产排除投资账户余额，是防止其价值与持仓市值重复计入同一笔资产；可投资资产计入，是因为账户里未投入的现金不被持仓市值体现，漏算会低估真正能产生被动收益的资产。生活现金/储蓄/电子钱包账户不计入（计入会虚增自由度）；负债既不计入也不抵扣（指标聚焦资产侧，口径简单可解释）。从未录价的持仓按空值语义跳过（同净资产），缺汇率让错误上抛，不静默返回缺料的数字。
3. **分母 = 年度预算总额：Σ 月度预算 × 12 + Σ 年度预算**（全部未删除预算；无窗口、不滚动），不回退实际支出。三个候选口径中：仅年度预算会漏掉只设月度预算的大多数用户，月度 × 12 是**节奏年化**，让只设月预算也得到完整的年度支出水平；实际支出口径被明确排除——指标要回答的是「计划中的开销节奏够不够被动收益覆盖」，被单月挥霍冲击的实际支出既惩罚节俭者、也奖励挥霍者；且本口径与预算域 BudgetProgress 的滚动窗口语义显式划界（Progress 看当前自然周期窗口，本口径不看任何时间窗，预算一存在即按周期粒度年化）。预算金额本身即默认币种单币种口径，与折算后的分子同币种可直接相除。
4. **零分母照常返回零值，占位引导归展示层**：未设任何预算时分母为零，命令照常返回（自由度与覆盖年数为 0），不做「隐藏功能」「报错」「回退实际支出」三种替代——隐藏让功能不可发现，报错把正常的新手态当故障，回退则违反决策 3；「设置预算后解锁」的引导（点击跳预算页）是展示层职责，口径层保持单一分母。
5. **指标实时计算不落库**：买卖投资、录入报价、编辑预算后即时反映，不存在会过期的快照；阶段标签（积累期 / 接近自由 / 财务自由）与阈值归界面层派生——阈值是文案而非口径，后端只输出百分比本身。

## 理由

- **为什么分子口径与净资产分开成对词条**：两个合计数字只在一处不同（投资账户余额计不计入），合并成一个带开关的口径会引入「哪个是对的」的歧义；分成 InvestableAssets 与 NetWorth 两个术语，各自回答不同的问题（「能钱生钱的有多少」vs「全部家当有多少」），消费者按问题选口径。
- **为什么分母不设时间窗**：年度支出水平是「节奏」概念——月预算 5 千意味着每年 6 万的心智开销水平，与今天处在哪个月无关；一旦引入窗口（如「近 12 个月的预算」）就要回答窗口边界的预算增删怎么算，复杂度不成比例。
- **为什么阶段标签不在后端**：<30% 积累期 / 30–100% 接近自由 / ≥100% 财务自由的分档是展示文案，未来调阈值不应触碰后端命令契约。

## 代价

1. 3% 常量意味着指标偏保守，激进用户会认为达标线过高；这是刻意取舍，调整入口 = 修订本 ADR + 改常量一处。
2. 分母不回退实际支出：未设预算的用户看到的是引导占位而非数字，首次使用价值后置；换取指标语义稳定（计划节奏，不随波动漂移）。
3. 投资账户余额计入分子，使「刚转入大额现金待投」的瞬时状态抬高自由度；接受——待投现金本就是可投资资产，口径不猜测资金意图。
