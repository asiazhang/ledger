# ADR-0140: 翻页快捷键——裸键 `[` 上一页 / `]` 下一页（交易页首批接入）

- 状态：已接受
- 日期：2026-10-02
- 作者：Ledger 项目
- 关联：与 ViewShortcut（ADR-0065）、CreateShortcut（裸键家族先例，b/s 退役见 ADR-0135 决策 5）同族的第三个快捷键词条；抑制闸门沿 Overlay Suppression（ADR-0035）与输入轴（ADR-0088）；词汇表：界面状态与交互域「翻页快捷键」

## 背景

交易页走服务端分页（ADR-0008），翻页唯一入口是分页条点击——桌面表格内置分页与移动档分页条共用同一翻页出口。键盘流用户浏览长列表时手不离键盘，但翻一页必须移手找分页条；上/下页缺一对快捷键。

键位选择的前提约束：主修饰键数字带已被 ViewShortcut 封闭占用（ADR-0065），方向键与 PageUp/PageDown 携带浏览器默认滚动语义，组合键被家族先例排除（见决策 1）。

## 决策

### 1. 裸键形态：`[` 上一页 / `]` 下一页

沿 CreateShortcut 既定纪律——组合键让给系统与视图快捷键的肌肉记忆，快捷键只走无修饰键裸键。`[` / `]` 物理相邻、左右位置与「上一页/下一页」方向空间映射直觉一致，仓库内零占用（与 ⌘, 设置键同键不同修饰、机制无冲突，裸键匹配本就拒绝一切修饰键）。

### 2. 语义等同点击分页条，不加特判

以最新页码状态为基准步进一页，写入走既有翻页出口，两档（桌面表格内置分页 / 移动档分页条）零分叉；首/末页越界幂等无操作，不提示、不抖动。不为快捷键另设步进逻辑——页码是会话保留状态，快捷键只是它的又一个触发面。

### 3. 键位提示在分页条旁弱化小字，仅指针轴渲染

入口可见处标注键位（与 ViewShortcut 键位带、CreateShortcut 下拉标注同一哲学）；文案随界面语言；触控轴不绑监听、不渲染提示（输入轴 ADR-0088）。

### 4. 概念按共享交互立项，本次只接交易页

词条以「服务端分页列表可消费的共享交互」立项，不绑定交易页；搜索页同为服务端分页、交互同构，按需后续接入，本票不扩范围。

## 备选方案与否决理由

- **方向键 ←/→**：最直觉，但浏览器默认语义是滚动页面，且表格行、下拉、日历面板等组件级按键面存在既有消费，冲突面最大——弃。
- **PageUp/PageDown**：系统惯例同样是滚动页面，preventDefault 即破坏滚动预期——弃。
- **`,` / `.`（Gmail older/newer 惯例）**：位置直觉与 `[`/`]` 等价，但 Gmail 惯例对目标用户认知度弱；打字热区相邻键，裸浏览时误按面略大——弃。
- **`n` / `p`（next/previous 字母助记）**：助记成立但两键物理不相邻，无位置映射——弃。
- **组合键（⌘←/⌘→ 等）**：违反「组合键让给系统与视图快捷键」家族先例（CreateShortcut 2025-08 决策）——弃。

## 后果

- **纯前端交互改动**：schema / API / 命令零变化；不新增持久化状态（页码本就住交易页会话 store，ADR-0094）。
- **抑制三闸门照常**：焦点在可编辑元素抑制、弹层打开抑制（ADR-0035）、触控轴不绑不提示（ADR-0088）——快捷键失效先修弹层判定，不加组合键双轨（家族纪律）。
- **键位发布即成肌肉记忆**：改键位伤用户，键位闭集随词条定档，与 ViewShortcut 键位带同等稳定性对待。
- **词汇表修订随本决策落地**（界面状态与交互域）：新增「翻页快捷键」，同步 `CONTEXT-MAP.md` 条目主题。
