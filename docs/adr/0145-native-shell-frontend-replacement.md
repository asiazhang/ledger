# ADR 0145: 前端替换为 NSH 原生壳——Web 前端整体退役、双壳并存逐视图迁移

- 状态：已接受并已实施完毕（一体切轨 #2083 落地、逐视图迁移 26/26、Web 参照前端终局退役 ADR-0148；正文收束为终局态，沿革见演进脉络）
- 日期：2026-11-04（终局态收束：2026-11-20）
- 作者：Ledger 项目
- 关联：ADR-0112（workspace crate 拆分——壳→域合法直呼，本决策的护城河）、ADR-0118（ui-kit `App*` 封装族）、ADR-0047（命令层随旧壳退役）、ADR-0087（测试三层权威——BDD 退役的基准）、ADR-0124（自动更新——随 NSH 内置更新器重建，见决策 7 与修订注记）、ADR-0143 / ADR-0148（浏览器开发模式与 Web 前端退役）、ADR-0080 / ADR-0054（壳层机制随旧壳消失）、ADR-0088（交互语义保真基准）、#2010 / #2012（Linux 迟滞诊断）；词汇表：应用壳域「原生壳」（「双壳并存期」「Web 参照前端」已随终局退役成墓碑词条）
- 来源：grill-with-docs 五轮裁决（2026-11-04）

## 背景

前产品为 Tauri 2 + Vue 3 + naive-ui，Linux 端渲染宿主是 WebKitGTK。**硬伤清单**（本决策的动机，也是新壳上线时的验收判据）：

1. WebKitGTK DMA-BUF 渲染器在 Hyprland/Wayland 不可用，回退渲染路径自带性能税——上游行为，应用层无解。
2. 同量级 UI 工作 Linux 端迟滞远高于 macOS：#2010 实测 50 行交易列表翻页 Linux 数百 ms、macOS 无感；修复只能压工作量，平台天花板不动。
3. 输入延迟、常驻内存、渲染缺陷（闪烁、字体、fractional scaling 模糊）等长期切肤之痛。
4. WebKitGTK 上游回归频繁、响应慢，版本随发行版传导。

迁移面盘点（决策时点）：前端约 11.4 万行（19 个 pnpm 子包）、155 条 IPC 命令、456 个 BDD 场景、18 个视图；近期仓库投资均在加码 Web 栈（ADR-0143 / ADR-0118 / ADR-0128）——本决策显式推翻该方向的延续预期。

选型为 Native Shell（NSH，longbridge/nsh）：Rust-first 跨平台 UI 框架，Linux 用 GTK4 原生控件（绕开 WebKitGTK）、Rust 模式无 JS VM、可作为库嵌入既有 workspace 直调域代码、Apache-2.0。成色已知：开源约三周、0.x 节奏连续 breaking、单一公司主导、组件缺日期选择器与下拉选择、Linux 端 bug 反馈偏多。

## 决策（终局态）

1. **替换与重写**：UI 以 NSH **Rust 模式**（无 QuickJS VM）重写为唯一产品形态，产品平台收缩为 **Linux 桌面**（macOS / Windows / Android 移出目标面）；Web 前端（Vue / naive-ui / pnpm workspace 全家）整体退役——中间曾降格「Web 参照前端」作布局对照物，随布局对齐收口完结终局退役（ADR-0148）。
2. **赌注成色与护城河**：NSH 极早期是明牌赌注，接受依据＝域层与壳层已解耦（ADR-0112 分层），壳可弃换而域 crate 不动；license Apache-2.0 已核实。不设预先弃船判据，以逐视图迁移的自然止损代替；nsh-core 锁版本跟随升级是常态税。
3. **双壳并存期（已终局）**：Tauri 旧壳曾是唯一发版产品、新壳逐视图迁移；自功能冻结点（主路径三视图迁移完成）起新功能只进原生壳；终局以**一体切轨**收束——旧壳、IPC 命令层与 Web 基建一体退役，`crates/nsh` 升为 workspace 根包（`nsh-app`），NSH 升唯一产品。UI 保真口径＝**布局靠拢 web 版、控件形态 GTK 原生、交互语义不变**（快捷键、页签状态保留、弹层关闭语义、Overlay Suppression、输入轴与系统返回语义逐项保真）；布局对照物退役后，布局对齐结论已固化在视图实现中。
4. **IPC 命令层退役**：新壳与域 crate 同进程，UI 直调域服务，不经命令序列化边界；155 条命令清单降级为迁移核对表；命令注册扫描器与 TS 调用面校验、emit 非阻塞（ADR-0054）与 WebView 事件桥等壳层接缝随之消失。TS 侧 formatAmount / i18n / 单元格预计算等展示逻辑在 Rust 侧重生（金额与折算口径仍以核心域为唯一真源）。
5. **ui-kit 封装族重实现**：`App*` 封装族（日期选择器、下拉、树选择、拼音可搜下拉、模态 / 抽屉 / popconfirm、弹层注册表）在 NSH 基元上重实现，含 NSH 缺失的日期选择器与下拉选择；bar 图自绘。视图层不直连 NSH 缺件——ADR-0118 的封装纪律在原生壳延续。
6. **测试策略**：BDD e2e（456 场景）随旧壳退役、不移植；新壳验收＝域层 API 集成测试（既有权威层，ADR-0087）＋ NSH headless 组件测试（测试钩子能力经 #2016 调查确认）；域单测不受壳更换影响。
7. **打包与更新器**：发版走 nsh package 打包形态（内置更新器的硬前提，packaging 模板与发布流程随票恢复）；自动更新随 **NSH 内置签名更新器**重建——Ed25519 新密钥对（nsh keygen，清单分离签名、公钥烧入应用配置、context 防挪用），ADR-0124 交互语义（全询问式、启动延迟静默检查＋设置页手动检查、已提醒版本记忆、单 stable 通道）沿袭不变；更新前备份走 backup crate 既有接缝。
8. **立桩靶标**：首个迁移视图＝交易列表页——#2010 的战场（50 行大表格、单元格预计算、翻页与周期步进快捷键、行右键菜单、中文 IME 输入）；立桩验收＝硬伤清单各项在新壳可感知消失。已交付。

## 理由

- 硬伤在平台层（WebKitGTK 上游）：应用侧修复只能压工作量，天花板不动；DMA-BUF workaround 是拿「能跑」换「更慢」，证明无解路径已穷尽。
- NSH 的库嵌入故事与既有架构完全对口：壳→域合法依赖直呼（ADR-0112）正是本赌注的护城河——UI 壳可弃换，域语义与数据零改动。
- ui-kit `App*` 封装族（ADR-0118）让组件缺口落在单点层：重写约十个封装件而非改十八个视图。
- 全平台单栈原生避免「Linux 原生 + 其余 Tauri」的双 UI 长期双维护。

## 否决方案

- **保留 Web 前端、换 Chromium 内嵌壳**（Electron / CEF 式）：引入捆绑 Chromium 的内存与体积税，未兑现「原生」动机，否决。
- **双壳长期并存**（Linux 原生 + 其他平台 Tauri）：两套 UI 双维护税高于性能税，否决。
- **观望 NSH 半年再动**：方向相反——立桩即开始，赌注止损由逐视图迁移自然承担，否决。
- **修复 WebKitGTK / 换 wry 渲染后端**：上游行为，应用层无解路径已在 #2010 与 DMA-BUF workaround 中穷尽。
- **NSH TSX 模式渐进迁移**（QuickJS + 热更新）：换了壳却保留 JS 运行时税，UI 逻辑无法直调域 crate，否决。

## 代价与边界

- 11.4 万行前端与全部 Web 基建终局退役：pnpm workspace、Vitest 前端逻辑测试、BDD e2e、浏览器开发模式、命令注册扫描、vanilla-extract 样式方案——旅程级回归网随旧壳消失，新壳时代依赖域层集成测试＋NSH 侧自动化。
- NSH 0.x 连续 breaking：锁版本跟随升级是常态税；日期选择器、下拉、bar 图自研自维护。
- 双壳并存期曾付出域接缝两侧同步与人工平价核对税，随终局切轨消失。
- 加密面曾是切轨遗留偏差，已随 #2088 收敛（密文库启动落锁定视图、解锁 / 忘口令重置 / 加密卡写面全量平价）。
