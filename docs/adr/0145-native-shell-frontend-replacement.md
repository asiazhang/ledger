# ADR 0145: 前端替换为 NSH 原生壳——Web 前端整体退役、双壳并存逐视图迁移

- 状态：已接受（决策入档；实现随迁移票系列落地）
- 日期：2026-11-04
- 作者：Ledger 项目
- 关联：ADR-0112（workspace crate 拆分——新 bin crate 与壳→域合法直呼，本决策的护城河）、ADR-0118（ui-kit `App*` 封装族——组件缺口的单点落点）、ADR-0047（命令注册单一来源——命令层随旧壳退役）、ADR-0087（测试三层权威——BDD 退役的基准）、ADR-0124（自动更新——随旧壳下线）、ADR-0143（浏览器开发模式——随 Web 前端退役）、ADR-0080（原位重引导与 WebView 重载——壳层机制随旧壳退役）、ADR-0054（emit 非阻塞——接缝问题随命令层消失）、ADR-0088（移动端 UI 适配——交互语义保真基准之一）、#2010 / #2012（Linux 迟滞诊断与渲染守门）；词汇表：应用壳域「原生壳」「双壳并存期」（随本 ADR 入档）
- 来源：grill-with-docs 五轮裁决（2026-11-04）

## 背景

现产品为 Tauri 2 + Vue 3 + naive-ui，Linux 端渲染宿主是 WebKitGTK。**硬伤清单**（本决策的动机，也是新壳上线时的验收判据）：

1. WebKitGTK DMA-BUF 渲染器在本机（Hyprland/Wayland）不可用，应用必须以禁用环境变量启动才能正常渲染，回退的渲染路径自带性能税——上游行为，应用层无解。
2. 同量级 UI 工作 Linux 端迟滞远高于 macOS：#2010 实测 50 行交易列表翻页 Linux 数百 ms、macOS 无感；修复靠单元格预计算与组件瘦身把渲染工作量压到平台消化得动的水平，平台天花板并未消失。
3. 输入延迟、常驻内存、渲染缺陷（闪烁、字体、fractional scaling 模糊）等长期切肤之痛（多为未立票的自证体验）。
4. WebKitGTK 上游回归频繁、响应慢，版本随发行版传导（基础设施事件桥中已有 WebKit URL 时序 workaround）。

迁移面盘点：前端约 11.4 万行（19 个 pnpm 子包）、155 条 IPC 命令、456 个 BDD 场景、18 个视图；选择类控件全数经 ui-kit `App*` 封装族消费、视图不直连；图表仅 line（走势）与 bar（报表）两类。近期仓库投资均在加码 Web 栈（ADR-0143 / ADR-0118 / ADR-0128）——本决策显式推翻该方向的延续预期。

选型为 Native Shell（NSH，longbridge/nsh）：Rust-first 跨平台 UI 框架，Linux 用 GTK4 原生控件（绕开 WebKitGTK）、Rust 模式无 JS VM、可作为库嵌入既有 workspace 直调域代码、Apache-2.0。成色已知：开源约三周、0.x 节奏连续两个版本带 breaking、单一公司主导、组件库缺日期选择器与下拉选择、plot 仅 line/area、Linux 打包产物仅目录 tar.gz、社区反馈 Linux 端 bug 偏多。

## 决策

### 1. 替换与重写

Web 前端（Vue / naive-ui / pnpm workspace 全家）整体退役，UI 以 NSH **Rust 模式**（无 QuickJS VM）重写；平台目标不收缩（macOS / Windows / Linux / Android 全平台）。动机是硬伤清单而非工作量权衡——明知 11.4 万行重写仍换。

### 2. 赌注成色与护城河

NSH 极早期是明牌赌注，接受依据＝域层与壳层已解耦（ADR-0112 分层），壳可弃换而域 crate 不动；license Apache-2.0 已核实。不设预先弃船判据，以逐视图迁移的自然止损代替。

### 3. 双壳并存期

workspace 新增 NSH 应用 bin crate（结构守门白名单为其开门），依赖方向沿用壳→域合法直呼；**Tauri 壳保持唯一对外发版产品**，直至新壳逐平台达到平价才切换发布轨道。UI 保真取「原生观感、交互语义不变」：快捷键、页签状态保留、弹层关闭语义、Overlay Suppression、输入轴与系统返回语义（ADR-0088）等行为逐项保真，观感从平台控件、不复刻 naive-ui。

### 4. IPC 命令层退役

新壳与域 crate 同进程，UI 直调域服务，不经命令序列化边界；155 条命令清单降级为**迁移核对表**（逐命令确认消费方已搬家）；命令注册扫描器与 TS 调用面校验随旧壳退役。emit 非阻塞（ADR-0054）、WebView 事件桥等壳层接缝问题随之消失。TS 侧 formatAmount / i18n / 单元格预计算等展示逻辑在 Rust 侧重生（金额与折算口径仍以核心域为唯一真源）。

### 5. ui-kit 封装族重实现

`App*` 封装族（日期选择器、下拉、树选择、拼音可搜下拉、模态 / 抽屉 / popconfirm、overlayRegistry）在 NSH 基元上重实现，含 NSH 缺失的日期选择器与下拉选择；bar 图自绘。视图层不直连 NSH 缺件——ADR-0118 的封装纪律在原生壳延续。

### 6. 测试策略

BDD e2e（456 场景）随旧壳退役、不做 1:1 移植：迁移期继续对旧壳跑（它仍是产品），场景清单转为平价核对表；新壳验收＝域层 API 集成测试（既有权威层，ADR-0087）＋ NSH 测试钩子能力另查（立桩票前置项）；域单测不受壳更换影响。

### 7. 打包与更新器

Linux 打包自建（AppImage / deb 工具链接入既有 CI 矩阵），macOS / Windows / APK 产物在切轨票另立；**自动更新（ADR-0124）随旧壳退役下线**（个人应用，手动更新即可，后续想要再立票自建）；浏览器开发模式与替身后端（ADR-0143）随 Web 前端退役。

### 8. 立桩靶标

首个迁移视图＝交易列表页——#2010 的战场：50 行大表格、单元格预计算、翻页与周期步进快捷键、行右键菜单、中文 IME 输入。立桩验收＝硬伤清单各项在新壳可感知消失＋表格操作无迟滞＋中文 IME 可用。

## 理由

- 硬伤在平台层（WebKitGTK 上游）：应用侧修复只能压工作量，天花板不动；DMA-BUF workaround 是拿「能跑」换「更慢」，证明无解路径已穷尽。
- NSH 的库嵌入故事与既有架构完全对口：壳→域合法依赖直呼（ADR-0112）正是本赌注的护城河——UI 壳可弃换，域语义与数据零改动。
- ui-kit `App*` 封装族（ADR-0118）让组件缺口落在单点层：重写约十个封装件而非改十八个视图。
- 全平台单栈原生避免「Linux 原生 + 其余 Tauri」的双 UI 长期双维护。

## 代价

- 11.4 万行前端与全部 Web 基建终局退役：pnpm workspace、Vitest 前端逻辑测试、BDD e2e、浏览器开发模式、命令注册扫描、vanilla-extract 样式方案。
- 双壳并存期域接缝两侧同步：新增域读写能力时两壳消费方都要接线，命令核对表兜住遗漏；UI 行为语义跨栈保真无自动防护，靠平价核对表人工对齐。
- NSH 0.x 连续 breaking：锁版本跟随升级是常态税；日期选择器、下拉、bar 图自研自维护。
- 打包、更新器、窗口管理、文件对话框等壳层能力全部自建或另选。
- 456 场景的旅程级回归网随旧壳消失，新壳时代依赖域层集成测试＋NSH 侧自动化（能力待证）。

## 替代方案

- **保留 Web 前端、换 Chromium 内嵌壳**（Electron / CEF 式）：消灭 WebKitGTK 硬伤但引入捆绑 Chromium 的内存与体积税，且未兑现「原生」动机，否决。
- **双壳长期并存**（Linux 原生 + 其他平台 Tauri）：两套 UI 双维护税高于性能税，否决。
- **观望 NSH 半年再动**：方向相反——立桩即开始，赌注止损由逐视图迁移自然承担，不靠等待。
- **修复 WebKitGTK / 换 wry 渲染后端**：上游行为，应用层无解路径已在 #2010 与 DMA-BUF workaround 中穷尽。
- **NSH TSX 模式渐进迁移**（QuickJS + 热更新）：换了壳却保留 JS 运行时税，且 UI 逻辑无法直调域 crate，否决；TSX 仅容许当立桩期速写板。

## 影响

- 词汇表新增应用壳域（CONTEXT-app-shell.md）：「原生壳」「双壳并存期」；地图挂载。
- 实施拆票建议：①立桩票——交易列表页＋`App*` 封装族首批件＋IME / 大表格验证，前置含 NSH 测试钩子能力调查 → ②逐视图迁移票系列——按命令核对表与场景核对表推进 → ③切轨票——逐平台发布轨道切换＋旧壳与 Web 基建退役清单。
- AGENTS.md「前端与入口」段与 CONTEXT-MAP 结构约定在切轨时改写；双壳并存期内两壳规则并存，以本 ADR 为准绳。
- 发布边界：本决策纯文档，无 schema / 契约变更；旧壳发版轨道不变。

## 修订注记（grill-with-docs 拆票②裁决，2026-11-07）：双壳并存纪律增设功能冻结点

决策 3 与「代价」段的并存期纪律修订：域接缝「两壳消费方同步接线」不是全程义务，自**功能冻结点**起废止。冻结点＝新壳覆盖日常主路径三视图（交易列表〔立桩已交付〕、交易表单族、概览）全部迁移完成，客观可判、不另设评估仪式；冻结点前两壳同步照旧（命令核对表兜住遗漏），冻结点后**新功能只进原生壳**，旧壳仅修数据正确性缺陷（用户可见数据错误、安全风险），不再为旧壳接线新域能力。配套裁定：迁移期日常主力壳在交易列表＋表单迁完后切至原生壳（真实使用是平价验证的最快路径），旧壳退居补漏。动机：唯一用户场景下双写税无对外发布价值，迁移带宽应尽早全部让给切轨。
