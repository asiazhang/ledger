# ADR-0121: 行情日常刷新改走批量取数面——逐标的通道留作降级、自适应全局唯一限速

- 状态：已接受（决策 6「不做多源」已被 ADR-0130 取代，其余批量取数、降级契约与自适应限速形状完整保留；正文已按 #1374/#1376、ADR-0130 与 #1674 现行态收敛）
- 日期：2026-09-15（现行态收敛：2026-09-22）
- 作者：Ledger 项目
- 关联：ADR-0015 / ADR-0019（同步职责与价格历史化）；ADR-0038（场外基金净值通道）；ADR-0081（按代码查询主干道）；ADR-0095（同步进度分母）；ADR-0103（行情接入接缝）；ADR-0120（网络等待不进连接锁）；ADR-0122（现价与历史解耦）；ADR-0130（按链路分工选源：腾讯/新浪/证监会/ECB，取代本 ADR 原「不做多源」条款）；#1374 / #1376 / #1674；词汇表：投资域「行情批量取数」「InstrumentInfoSync」「价格通道」

## 背景

早期「同步标的信息」按标的数线性发请求（233 只标的 ≈ 456 次请求、固定 2 秒限速需约 15 分钟），而数据源实际支持批量报价/净值取数面且限速写死浪费额度。日常现价与历史回填解耦后（ADR-0122），将日常刷新改走批量取数面可把请求量压至常数级。

## 决策

### 1. 日常现价刷新改走批量取数面（当周采样点同步落库）

- 标的现价刷新以批量取数面为主（请求量从 O(N) 降为常数级；场内批量报价批大小 300），同时直接落现价缓存与当周采样点（ADR-0122 决策 2）。
- 逐标的通道保留为兜底，仅承接三类情形：首刷（无历史序列）、缺周点补齐、批量面未覆盖的按条缺口（及批量面降级时）。
- 数据源成员随 ADR-0130 替换为按链路分工选源（场内腾讯、场外基金新浪、权威兜底证监会，东方财富整体移除），本 ADR 确立的「批量为主 + 逐标降级」形状不变。

### 2. 批量取数面不是价格来源

价格来源仍由价格通道闭集单点判定，批量取数只决定刷新使用几次请求，不改变标的列表的「价格来源」语义。

### 3. 降级契约：fail-closed + 同步内熔断 + 跨同步记忆 + 缺口不熔断

- **fail-closed 回退**：批量取数失败或遇疑似风控报文时一律回退逐标的通道，不静默丢数据。
- **同步内熔断**：一次同步内任一批量面失败，本次剩余标的直接走逐标的通道，避免每只都重复撞批量再回退。
- **跨同步记忆**：进程内单例 `BulkFetchCircuit`（不落库）连续失败 3 次后停用批量面 30 分钟，到期放行一次半开试探，试探失败重新计时。
- **按条缺口不触发熔断**：新成立、清盘或批量面天然未覆盖的标的退回逐标的补齐，归为「缺口」而非「失败」，日志与统计分开记录。

### 4. 降级对用户可见

回退到逐标的通道时，响应携带 `bulk_degraded` 标志，前端经 `SyncDegradedNotice` 显式展示警示文案（「已降级、本次较慢」，随下一次同步开始收起，不残留于失败终态），避免不可解释的耗时波动。

### 5. 全局限速自适应且进程唯一（#1674）

- 限速器采用自适应策略：基线 1s，遇限流（429）或疑似风控页翻倍降速（封顶 8s）并进入冷却，此后每次成功回升 10% 至不低于基线。
- **进程唯一实例收口（#1674）**：生产面限速器构造编译期收口为唯一共享单例，手动按代码查询（股票/基金）与后台车道共用同一额度并受前台守卫纪律约束（后台在手动查询在途时让路，ADR-0122）。

## 备选与否决

- **并发提速**：单源额度是硬天花板，并发只会把排队变成封禁，否决。
- **完全移除逐标的通道**：批量面存在天然覆盖缺口，且批量面失效会导致全库无价，否决。
- **写死固定 2 秒节流 / 降级不提示用户 / 引入取数面 trait 注册表**：分别导致额度浪费、不可解释的慢反馈与无多态消费点的机制税，均否决。
- **原决策 6「维持东方财富单一数据源、不做多源」**：在东财风控受阻后已被 ADR-0130 取代为按链路分工选源，本条款退役。

## 后果

- 日常现价刷新从分钟级降为秒级完成（不承诺绝对耗时，受外部源网络决定）。
- 降级接线与界面降级提示由负向/存在性测试守门，确保批量失败时回退与提示不被静默破坏。
- 所有前台手动查询与后台同步共享单点限速队列，避免多实例绕过节流触发风控。
