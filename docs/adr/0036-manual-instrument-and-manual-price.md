# ADR 0036: 自建标的与手动报价——无行情来源标的的字典与价格通道

- 状态：已接受
- 日期：2026-08-30
- 作者：Ledger 项目
- 关联：投资域词汇表 自建标的 / 手动报价 词条；扩展 ADR-0031 的信号生产者清单；延续 ADR-0015 职责切分与 ADR-0019 价格历史化

## 背景

用户需要在投资中记录无任何行情数据源的标的：且慢基金投顾组合「稳稳地幸福」（按组合份额申赎，平台公布单位净值）、华为虚拟股票（非上市，年报公布每股公允价，每年分红）。现状是三重缺口：标的字典虽留有手动创建命令（基金/债券类），但 UI 无任何创建入口；无价格来源的标的市场价值为空——`v_holdings` 左连现价缓存后市值为 NULL，净资产按空值语义跳过，价格历史与组合走势明确仅覆盖股票类；手动写价命令作为后端半成品存在（`source` 可传 manual），但不接 UI、不沉淀历史、不发失效信号。

## 决策

1. **手动报价（ManualPrice）**：用户按「日期 + 价格」单点录入，一条通道两个落点——现价缓存 upsert + PriceHistory 周采样幂等覆盖（同周后写覆盖先写，与同步同规则，复用既有价格历史表，不立第二承载）。实际写入（任一落点）即发 `ledger:prices-changed`。现价维持 MarketPrice 既有定义「PriceHistory 最新一条的即时映像」：回填早于最新点的旧价只沉淀历史、不改变现价——此规则是既有定义的推论，非新发明。
2. **自建标的（ManualInstrument）**：字典条目持久化来源 `source`（同步 / 手动），对 `instruments` 只增一列（该表已随 v0.3.0 发布，只增不改合规）；存量行全部回填为同步（UI 从无创建入口，现存字典均出自同步）。标的列表「来源」标记由此直出。
3. **手动创建入口类型白名单 = 非股票四类**（基金/债券/ETF/其他），使手动字典与 InstrumentSync（仅修 stock 类字典）正交。事实依据：全量同步按裸代码匹配 `type='stock'` 行后覆盖名称/市场并刷价——放开股票类则同代码自建标的被东财静默覆盖；而东财对非 stock 类会另插同代码 stock 行造成重复标的。白名单让两类字典永不相交。创建语义：名称必填（自建标的主身份是名称，如「稳稳地幸福」）、代码自由文本、市场未知、币种可选；同（代码，类型）已存在则复用该标的并更新名称（沿用既有 upsert 语义）。
4. **不扩展类型闭集**：组合记「基金」、虚拟股记「其他」；且慢单位净值、华为每股公允价统一映射为标的价格（市值 = 数量 × 价格），不引入「净值」术语。类型闭集在已发布迁移中是 CHECK 约束，扩展须重建表且无真实消费差异。
5. **自建标的可删除**：仅来源为手动且无任何 buy/sell 流水引用（`security_transactions` 无行）的自建标的可物理删除，守卫前置检查、有引用拒删。不引入软删列——标的字典查询面不被污染；同步标的不可删（填错由全量同步修正），自建标的填错是常态而非例外。
6. **非目标**：dividend/split kind 维持写入层显式拒绝，华为虚拟股分红以普通 `income` 流水入银行卡 + 挂分类承载；组合不拆底层基金（用户交易的对象是组合份额，平台代客调仓不产生现金流、不入账）；AI 导入不加建标的路由（AI 买入/卖出仍只能引用已有标的）；不做批量价格回填（单点「日期 + 价格」已覆盖华为年度净值与且慢逐点回填场景）。

## 理由

1. **手动报价是第一公民，自建标记是轻量配套**。真正的缺口是「无数据源标的价格无处可来」（市值/盈亏/净资产/走势四消费方全部落空），而不是「标的建不出来」；先解决价格通道，字典来源只是让用户分得清谁管修正。
2. **来源持久化而非派生**。「市场未知 ⟺ 自建」当前恰好等价，但那是同步从不产生未知市场的巧合——同步语义一变即碎；持久化列与现价缓存的 `source` 对称，诚实建模且回填无歧义。
3. **类型白名单是 ADR-0015 职责切分的自然延伸**：字典的股票半边归全量同步修、非股票半边归手动建，两边永不需要抢同一行。
4. **价格单承载**：手动报价复用 PriceHistory 与周幂等语义，现价/走势消费方零改动接入；另立手动价格表必然产生双口径漂移（ADR-0019 单通道哲学的反面教材）。

## 代价

1. 增量同步对自建标的永远计入「跳过 M 只」，用户可能误读为出错——语义上正确（同步只管东财行情），必要时 UI 文案区分来源。
2. 手动价格无数据源背书，市值/走势质量取决于录入纪律；低频录入（华为一年一点）曲线稀疏，属预期而非缺陷。
3. 一列 + 三入口（创建、录价、删除）的后端与 UI 改动面，比「只加个标的」的表面理解要宽。

## 替代方案

- **市场未知派生自建标记**：零 schema，但语义脆弱（见理由 2），否决。
- **独立手动价格表**：双承载必漂移，消费方 UNION 两源，否决。
- **新增「组合」「虚拟股」类型值**：动已发布 CHECK 须重建表，且与基金/其他无真实行为差异，否决。
- **本期激活 dividend kind**：分红计入已实现盈亏的口径牵连远超本需求，普通收入流水足以承载现金流事实，否决。

## 影响

- 词汇表：投资域新增「自建标的」「手动报价」词条；Instrument 补来源边界；PriceHistory / PortfolioValueTrend 覆盖面从「股票类」修订为「有价格写入通道」；价格失效信号生产者两处 → 三处。**ADR-0031 决策 2「生产者 = 两个同步命令」自此读作「两个同步命令 + 手动报价」**——扩展而非推翻，信号形状、零变化不广播、消费方自选订阅均不变。
- Schema：`instruments` 增 `source` 列（只增合规）；无其他表变更，价格历史表复用。模型文档 Migration 索引随实现新增迁移时补行。
