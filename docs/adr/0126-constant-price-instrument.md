# ADR-0126: 价格恒定标的——恒定是价格口径不是采集对象（货基为首个成员）

- 状态：已接受（grilling 定稿，2026-09-17；实现随实施票落地）
- 日期：2026-09-17
- 作者：Ledger 项目
- 关联：ADR-0038 决策 3/6（单位净值即价格、净值日期兼任水位——本裁决为其中「恒定净值」的一类划出例外）；ADR-0121（行情批量取数面——货基不在其结构覆盖内）；ADR-0122（历史覆盖面、补全队列判据与当周采样点来源）；ADR-0019（价格历史化）；词汇表：投资域 价格恒定标的 / 价格通道 / PriceHistory / Instrument / InstrumentInfoSync / 价格历史后台补全 / 价格过期提示 / MarketPrice

## 背景

货基的单位净值恒 1.0000（收益以份额结转体现，ADR-0038 修订 / issue #1342），因此它的价格历史序列是一条全等的水平线：近两年周采样约 104 行，每一行都是同一个已知常量。

与此同时，现价刷新的批量取数面（ADR-0121）**在结构上不覆盖货基**：场外基金净值排行面实测（2026-09-17）返回 20,349 行，类别桶为指数 / 股票 / 混合 / 债券 / QDII / FOF，**没有货币型**；余额宝（000198）等 12 个已知货基代码一只不在其中（货基排行在数据源是另一条榜）。于是每只货基每天落进「批量面未覆盖」的降级分支：发一次逐只短窗请求，只为确认「净值还是 1.0000」，并被计入批量面缺口统计——同步日志里的「缺口」因此永久含货基，真正的缺口被淹没。

而`price_history` 的行又被当成两份不同的事实使用：「有没有历史行」是首刷判据、补全队列缺口与走势空态三处的判据，「行的值」是组合走势与收益率（MoneyWeightedReturn）边界市值的价格来源。两件事叠加的结果是：一个已知常量既被当成每天要去问的价格，又被当成必须落盘才能被消费的数据。二者都不是它的本性。

## 决策

1. **恒定是价格通道的一个分区成员，不是通道上的正交标记**：价格通道闭集自四值（行情 / 净值 / 手动报价 / 无来源）扩为五值，新增**恒定价格**——没人给它写价，取值由本地常量给出。恒定改变的是「谁给它写价」这个问题的答案（答案是：没有人），因此它是分区成员，不是与通道叠加的属性。
2. **判定单点的输入多一枚持久化事实**：价格通道素来是纯派生事实（类型 × 市场 × 代码，不落库）。恒定无法由这三者推导（6 位代码的场外基金今天一律归净值通道），因此标的行携带**恒定单位价格**，进入恒定价格通道当且仅当该列有值；货基的值 = 1.0000。这是本裁决唯一新增的持久事实。
3. **标记写入单向、收敛到单点**：事实来源仍是数据源自报口径（搜索索引的类型码、历史净值接口的收益披露声明或类型码、详情页数据文件「缺单位净值序列而有万份收益序列」三处任一）。写入只允许「未标记 → 标记」，响应缺信号时**不清空**——已终止基金等形态天然缺省，缺信号 ≠ 不是恒定标的。建档、首刷、日常刷新任一次确认即回填；不做一次性存量回填（货基本来就每天走逐只路径，确认并打标后即自然收敛）。
4. **采集侧全豁免**：恒定标的不进首刷队列、不进每日逐只刷新、不落当周采样点；批量面的「未覆盖」不再把货基计为缺口。为一个已知常量发请求收益为零，代价是永久请求与失真的缺口统计。
5. **现价缓存保留一条、但不再更新**：净资产、持仓市值与可投资资产走的是现价缓存而非历史表，建档（或首刷）时落一条 1.0000 即可，四个消费面零改动；净值日期列对恒定标的显示为空——水位语义对它不适用。
6. **读侧按常量取值，库里不落虚拟行**：一条价格取值接缝——恒定标的在**响应内**按区间周键合成，非恒定标的读 PriceHistory；单标的走势、组合走势（市值 = 时点份额 × 常量）与收益率边界市值三处共用。落虚拟行等于换个地方写同一批平坦行，「豁免采集」的承诺在本条兑现。
7. **价格过期提示整体豁免恒定标的**（含「持仓缺现价」一档）：它的水位语义不适用，同步既修不了它也不需要修它；计数面与提示文案同进同退（既有措辞纪律）。
8. **展示收口**：走势面板对恒定标的一句解释（单位净值恒 1.0000、收益以份额结转体现）；不新增万份收益 / 七日年化曲线——那是第二个价格口径，与「份额已含结转收益」冲突。

## 否决

- **维持现状（继续采平坦序列）**：把已知常量当成每天要问的价格，收益为零，且让「批量面缺口」统计永久失真。
- **正交标记（通道不变 + 一枚标记，判据按两维分派）**：恒定不是通道的叠加属性（不存在既是行情通道又是恒定价格的标的），两维分派让每个消费方都要记得同时判两处——正是 issue #1060 收口掉的第二口径病。
- **只跳过不标记**：货基会永久被判「首刷」（每天重新入队）、走势永久停在「补全中」、收益率里带它的持仓整对消失——不落行不等于不需要价。
- **让批量面覆盖货基（改取数面参数）**：货基排行在数据源是另一条榜；即便覆盖，也只是花请求拿同一个常量。
- **为货基引入万份收益 / 七日年化曲线**：第二价格口径。
- **一次性清洗存量平坦行、或一次性存量回填**：读侧已不消费那些行，清洗纯属美观；回填没有可用的离线事实（判定信号只存在于数据源响应里）。

## 后果

- 用户可见：货基走势从「一摞 1.0000 行拼出的水平线」改为直出的常量线 + 一句解释；净值日期列空；价格过期提示不再因货基常驻。
- 同步统计：「批量面缺口」不再含货基，缺口数重新可信。
- 词汇表修订：价格通道五值闭集与判定单点输入；新增「价格恒定标的」；PriceHistory 覆盖面排除恒定标的；InstrumentInfoSync 的收集面与进度分母、价格历史后台补全的队列判据、价格过期提示的检查面各自排除恒定标的；Instrument 的货基口径条目改写。
- 投递纪律：本裁决引入「所有入口都必须遵循」的豁免约束，采集三入口（首刷队列收集、每日逐只刷新的降级路径、当周采样点直落）须逐一核对并附核对清单；新增守门判据：删除豁免 → 货基重新入队 / 重新发请求的测试变红。
- 与 ADR-0038 的关系：决策 3「单位净值即价格」与决策 6「净值日期兼任水位」对**非恒定**场外基金不变；恒定标的按本裁决退出这两条语义。
