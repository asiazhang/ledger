# ADR-0137: 每日变异测试——「测试有效性」的自动化判据与观测工作流

- 状态：已接受（CI 载体已撤下改本地按需运行，前端 Stryker 面已随 Web 参照前端退役；正文收束为现行态，沿革见演进脉络）
- 日期：2026-09-25（现行态收束：2026-11-20）
- 作者：Ledger 项目
- 关联：ADR-0087（测试三层权威与「断言强度」——本 ADR 是其判据的自动化投影，不新增标准）、ADR-0062 / ADR-0068（先观察后立阈、判定下沉工具内的先例路径）、ADR-0112（crate 分层——in-diff 按 crate 内改动取范围的边界背景）、ADR-0148（Web 前端退役——Stryker 面随宿主退役）；#1816（spec）、#1817/#1818（试点）、#1827（落地）、#1832（前端工具链诊断与补丁，已退役）、#1935（观测面缺陷修复）；词汇表：测试基础设施域「零击杀测试」「存活变异体」「等价变异体」

## 背景

清理「无效测试」的原始诉求经 grilling 收敛为两个判定问题：一条断言是否仍有可能变红（ADR-0087 断言强度的人工判据），以及一套测试整体上抓住了多少行为变异。前者靠人读断言，成本高且随代码演化漂移；后者有成熟工具——cargo-mutants 对源码注入受控变异、跑测试观察是否变红，用「零击杀」把断言强度判据变成可执行检查。

工具成本与「全量」强相关（试点实测单变异体约 14–50 秒，全 workspace 数千变异体即数小时），进 PR 门禁与 `check.sh` 均不可行；且测试有效性随每次改动漂移，一次性清理后新代码仍会产生零击杀断言。定案为**常驻观测 + 看报告优化**。试点（#1817 currencies、#1818 physical-asset）验证了判定口径可执行、击杀矩阵可提取、单域耗时可预算。

## 决策（现行）

1. **载体 = 本地按需运行**（CI workflow 已撤下，见演进脉络）：Rust 侧 cargo-mutants 按需安装，在 Rust 根按白名单批次运行（全 workspace + 测试集同 workspace；in-diff 基线按需给定）；报告经本地报告脚本阅读（`scripts/mutation-summary.sh`，只做计数与清单展示、只格式化不判定）。观测面存在「无人定期跑」的显式缺口，由本地纪律承接。
2. **范围 = `--in-diff` + workspace 白名单渐进扩面**：只变异基线以来改动的 Rust 代码（diff 在 `src-app/` 内以 `git diff --relative` 生成，自动排除非 Rust 改动），历史欠账不每日重放、由报告驱动专项清理票承担。白名单是工具默认「只变异当前包」缺陷的修复面——批次 1 = 核心交易域 + 根包命令出口接缝；工具与测试支撑面长期排除；每批补当批清单与成本预估，扩面前先看上批报告存活分布。
3. **观测期不判定**：退出码 2（存在存活变异体）与 3（超时）不视为失败，4（基线红）/5/6（diff 错）/70（内部错）才是故障。尚无稳定的变异分数基线，阈值从何谈起没有依据——先积累分布，基线稳定后另立判据票（同 ADR-0062→0068 的兑现顺序）。
4. **判定口径**（ADR-0087 断言强度的自动化投影）：**零击杀测试**（该 crate 全部变异体上杀不死任何变异体）= 无效测试、删除候选；**击杀集被完全包含**的冗余测试只列清单报人工裁决、不自动删（保留回归定位粒度）；**存活变异体**不作为删除依据——逐域分类：该补的补、等价/不可测的进 `mutants.toml` 豁免（内联注释理由），补强规模失控另立 issue。
5. **豁免单点收口**：workspace 根 `.cargo/mutants.toml`，每条豁免附类别（等价 / 不可测）与理由注释；空清单起步、按需追加。

## 否决方案与代价

**否决方案（防重提）**：进 `check.sh` / PR 门禁（热回路违背「体验取舍」标尺，成本由观测承担）；一次性逐域清理（新代码持续产生零击杀，无常驻观测即回潮——清理手段保留、形态改常驻）；全量每日跑（单日数小时且随仓库线性恶化）；前端带病接入标注不可信（报告不可信则「看报告优化」前提坍塌——最终以前端退役收场）；降 Vitest 至 4.x 换 Stryker 兼容（为一个工具反向降级）；按 CONTEXT 上下文切分跑（与 crate 边界不符）；每日自动开 tracking issue（跳过日空 issue 噪音）。

**代价与已知边界**：观测期缺口——合入代码的测试有效性缺口不被拦截，只在报告暴露，门禁升级是基线稳定后的判据票；in-diff 盲区（历史欠账）由专项票承担；本地运行成本随「白名单 ∩ 当日改动」浮动，基线缺失回退 `HEAD~1` 有界。
