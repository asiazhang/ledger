# ADR 0132: 完整年度收益——按年表加「未实现变动」与「年度收益」两列，现金流式计算、缺料显式不可算

- 状态：已接受
- 日期：2026-09-21
- 作者：Ledger 项目
- 关联：#1535（本票）；#1534（前置——基金价格历史回填深度覆盖持仓期，已合并）；ADR-0129（已实现收益列，本票在其上加列，其替代方案的否决前提已消失）；ADR-0107（盈亏页组成与按币种分组）；ADR-0109（分红第三腿）；ADR-0019 / ADR-0122（价格历史与周采样）；ADR-0115（边界市值 = 时点存量 × ≤ 该日最新周线 × 同期汇率的既有纪律）；ADR-0114（期初存量的口径先例）；词汇表：投资域「年度收益（AnnualReturn）」（新）、「已实现收益（RealizedGain）」修订

## 背景

#1533 给盈亏页按年 / 按账户两表并入了现金分红，得到现金口径的「已实现收益」（已实现盈亏 + 现金分红），但「这一年赚了多少」还缺未实现变动一腿——当时价格历史采集窗口钉在近两年，早期年份的期初 / 期末市值不可得，完整年度收益被判为不可算（ADR-0129 替代方案明确否决并要求先立价格历史回填票）。#1534 已把基金的价格历史覆盖到首笔持仓流水日所在周（单请求全量通道，深度只是本地裁剪语义），前置条件消失，本票补上未实现变动腿。

## 决策

1. **按年表只加两列、行集不变**：在「已实现收益」列之后加「未实现变动」与「年度收益」两列；年度收益 = 已实现收益 + 未实现变动（域内相加，前端零算术）。#1533 的行集纪律（只有卖出或分红的年份成行）与既有三列读数逐位不变——只加列不加行。按账户表不加列（见代价与替代方案）。issue 所述「切换合计口径」由此裁决为：按年表回答「这一年赚了多少」的结果列（合计读数）自本票起由「已实现收益」切换为「年度收益」，既有列的读数与定义均不改动；`total` / 按账户表的合计口径不在本票范围（ADR-0129 决策 4 对 `total` 的专义裁决维持）。
2. **现金流式计算，不需要时点成本**：
   ```text
   年度收益 = (期末持仓市值 − 期初持仓市值) + 年内卖出净收入 + 年内现金分红 − 年内买入支出
   未实现变动 = 年度收益 − 已实现盈亏 − 现金分红
   ```
   与三腿定义式（已实现 + 分红 + Δ未实现）在估值齐全时逐位相等：FIFO 已实现盈亏与批次成本共用同一锚点，两式代数可互导。未实现变动由恒等式导出而非逐标的重算批次成本，恒等式由构造保证，展示层三列永远相加吻合。边界市值 = 时点持仓 × ≤ 该日最近周采样价 × 同期汇率（周键正反向兜底，与资金加权收益率边界市值共用同一装载器口径，ADR-0115）。
3. **边界时点**：期初 = 上一年 12-31、期末 = 当年 12-31；当年未完即取到最新（未来日期对「≤ 该日」查询自然夹到今天）。年内新开仓 / 清仓按期初或期末市值为 0 自然处理；convert 无现金腿、市值连续，split 不产生现金、份额与价格共同维持市值连续——两者不入现金流，公式天然覆盖。
4. **买入支出 = 该年 buy 行金额合计（含费用，含期初存量补记行）**；卖出净收入 = sell 行金额合计（已扣费）。补记行（origin = opening，ADR-0114）是 buy 行，按字面计入支出——若排除，补记年会把整笔存量市值虚计为年度收益；未实现变动因此取「自补记日起算」的语义，与资金加权收益率对期初存量的处理同源不同形（后者折市值、本口径计成本）。
5. **缺料显式不可算**：年初或年末仍有持仓而市值缺料（缺价或缺同期汇率）→ 该年未实现变动与年度收益为空值（契约 `Option`，前端标「无法计算」），不按 0 计、不静默跳过该标的继续合计；期初或期末持仓为零则无需估值、无价也可算（年内全平仓年份不依赖任何价格）。已实现与分红两腿不受行情影响，不可算年份照常出数。
6. **按币种分组沿用 ADR-0107 决策 6，筛选同源同过滤**：沿用其「按币种分组、不跨币种折算」口径，本腿组币种 = 账户币种（与匹配行 / 分红行币种同源，流水原生币恒为账户币），边界市值折到账户币后入组；账户 / 标的筛选对市值腿与既有两腿各用一次（筛到缺价标的即不可算，筛掉则不受影响）。
7. **年度收益列挂口径说明**：三腿构成、与且慢等平台年度收益可对照、不可算语义在场（ConceptLabel，文案唯一源在 i18n）。

## 理由

- **现金流式比三腿直算更稳**：逐标的算「年末未实现盈亏 − 年初未实现盈亏」需要边界时点的批次成本快照，多一份成本口径表达式；现金流式只吃行金额与边界市值，未实现变动作为残差导出，三列恒等式由构造成立。
- **行集纪律优先**：#1533 定下的「只有卖出或分红的年份成行」是既有表格语义；只加列让老用户读数零漂移。只有买入 / 转换的年份同样有损益，扩行集是真实后续议题，但不与加列混做。
- **含补记行是把「不可比」变「可比」的最短路径**：期初存量没有真实建仓时点，按补记日成本计支出后，该年损益自动收敛为「自补记日起算」——与资金加权收益率对存量的处理哲学一致（ADR-0115：折算是输入假设、不改账务）。
- **缺料显式化是既有空值语义的年度化**：Holding / 累计收益对缺价持仓跳过不计，是「某一时点合计」的正确语义；年度收益是「区间两端比较」，缺一端即不可比，跳过会把不可比伪装成 0——显式标注是唯一诚实形态。
- **口径归域**：三腿相加、缺料判定、边界市值装载全部在后端读投影内完成（与 ADR-0129 决策 4 同一纪律），前端只做格式化与三态渲染。

## 代价

- 按年表出现「无法计算」单元格：股票 / 场内标的早期年份（日 K 源只有近两年，要更深须换源另立票）、或任何缺周采样价 / 缺同期汇率的持仓年。
- 打开盈亏页多装载各年边界市值（每边界日一次价格历史扫描 + 一次全库腿流装载）；年份数 × 价格行数量级在个人账本下可接受，慢了再谈缓存。
- 域内近邻词再加一个（已实现盈亏 / 已实现收益 / 年度收益 / 累计收益），分工靠词汇表与各列口径说明撑住。
- 未实现变动由恒等式导出，不能独立于已实现腿单独展示（那是逐标的口径的事，本列不做）。

## 替代方案（防重提）

- **逐标的直算 Δ未实现再三腿相加**：与现金流式估值齐全时逐位相等，但要装载边界批次成本、多一份成本表达式，且残差导出天然保证展示恒等式。否决。
- **年度收益列由前端相加**：违反「金额口径归域、前端只格式化」（ADR-0129 决策 4 同款否决）。否决。
- **行集扩为「有持仓变动的年份都成行」**：会改动 #1533 既有行集（买入年新行），与「只加列」冲突；另票裁决。否决（记为后续议题）。
- **按账户表同步加两列**：需要（账户 × 标的 × 年）粒度的边界市值装配，增量逻辑独立成票更稳；本票不做。否决（记为后续议题）。
- **缺价年份按 0 计 / 跳过缺价标的继续合计**：前者把不可比伪装成零收益，后者让年度收益随数据完整度静默漂移。否决。
- **等价格历史覆盖全部标的持仓期再做**：股票深度受数据源限制，无限期阻塞用户可算的基金年份。否决。

## 影响

- 契约：`realized_pnl_summary` 按年行只增不改地加 `unrealized_change_cents` / `annual_return_cents`（`Option`，None = 不可算）；命令名与结果类型名不变。
- 前端：按年表两列 + 年度收益口径说明；i18n 两个列名 + 一条概念文案（中英双份，概念键入投资域闭集）。
- 词汇表：投资域新增「年度收益（AnnualReturn）」；「已实现收益（RealizedGain）」修订（不含浮动盈亏的理由从外部约束改口径本身，指针指向年度收益列）；CONTEXT-MAP.md 分域一览同步。
- ADR-0129 替代方案「本页升级为含未实现变动的完整年度收益」自本票起翻案落地；其决策 1–7（已实现收益列的形态与两腿口径）不变，见其修订记录。
