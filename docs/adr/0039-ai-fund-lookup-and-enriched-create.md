# ADR-0039: AI 基金导入——fund-lookup 只读端点与创建端点基金增强

- 状态：已接受（正文已按 ADR-0081 / #1204 / #1212 / ADR-0130 现行态收敛）
- 日期：2026-08-30（现行态收敛：2026-09-19）
- 作者：Ledger 项目
- 关联：顺应 ADR-0037（独立标的端点，不做 batch 内联即建）；消费 ADR-0038（场外基金一等标的）；ADR-0081（股票/ETF 创建同样走行情增强）；ADR-0130（场外基金换源新浪 + 证监会基金电子披露，东财退役）；#1204 / #1212；词汇表：AI 导入域 AI API / 投资域 Instrument

## 背景

场外基金成为一等标的（ADR-0038）后，AI 迁移基金账单必带 6 位基金代码。相比新增 batch 内联即建（与 ADR-0037 否决内联冲突，且引入双轨标的引用形状），更干净的做法是顺应 ADR-0037：保持 batch 只收 `instrument_id`，在只读查询与标的创建两个独立端点上做基金增强。

## 决策

1. **batch 输入保持只收 `instrument_id`**，不引入代码自然键内联即建，维持全应用统一的标的引用形状（ADR-0037）。
2. **新增只读基金查询端点（按 6 位代码查询）**：返回权威名称、最新单位净值与净值日期，供 AI 校验「代码 → 名称」映射与核对净值。
   - **数据源与存在性判据（#1212 / ADR-0130）**：由新浪净值/全历史面与证监会基金电子披露权威兜底（原东财搜索索引与档案通道已随 ADR-0130 退役），两段任一命中即判存在——**覆盖已终止（清盘）基金**，不再误报查无此码。
   - **刻意不做终止状态标注（#1212）**：不抓基金页面 HTML、不新增终止状态/日期字段，查询返回体字段保持稳定。
   - **`fund_class` 字段弃用保留（ADR-0130）**：原东财分类串无替代，按已发布契约只增不改原则保留字段、恒返回空串并标注弃用。
3. **创建端点对 `type = fund` 增强**：提交 6 位真实代码时尽力经外部源校验并回填权威名称与最新净值（落现价缓存并按价格失效信号语义广播）。
   - **确定查无此码 → 显式拒绝**（`sync.fund-not-found` 报错，不落入降级建行，#1204 已收口）；
   - **外部源网络不可达 → 降级建行**（使用 AI 提供的名称 + 真实代码建档，不阻塞导入，后续净值通道照常按代码服务）。
   - 注：同类按代码行情增强已于 ADR-0081 扩展至股票/ETF 标的。
4. **AI 基金导入三步流与导入知识**：按代码查询校验 → 创建/复用标的（带增强）→ batch 提交 `buy`/`sell`（持 `instrument_id`）；名称充代码仅限确实无代码的来源（不进净值通道）。导入知识补充基金申赎拆解与三步解析指引。

## 理由

- 延续 ADR-0037 的单一标的引用形状，三步流只多一次本机 HTTP 往返，对 AI 编排无感，且查询端点具备独立校验价值。
- 区分「确定查无此码（拒建防脏数据）」与「源不可达（降级保可用性）」，兼顾字典质量与导入韧性。
- 存在性判据覆盖已清盘基金，确保历史账单中的老基金可正常建档并进入净值管线。

## 备选与否决

- **batch 内联自然键即建**：推翻 ADR-0037、引入双轨引用与孤儿行复杂度，否决。
- **创建不做增强（照存 AI 所报名称）**：抄错名直接污染字典，否决。
- **网络故障一律硬拒绝**：将临时外网故障放大为整批导入阻塞，否决。
- **抓取网页 HTML 解析并标注基金终止状态**：维护面与新字段成本远超收益，否决。

## 后果

- 全应用标的创建与 batch 引用保持唯一形状；查询端点 `fund_class` 作为弃用空串字段长期兼容。
- 外部源不可达时允许名称质量降级建行，留待人工修订或后续名称刷新兜底。
