# ADR-0113: 业务域 crate 内部组织——四区、单向层序与声明投影守门

- 状态：已接受（`ledger-transaction` 首个落地；正文已按 #1591/#1597 目录约定与声明投影、ADR-0145 注记住址废止现行态收敛）
- 日期：2026-09-12（现行态收敛：2026-11-21）
- 作者：Ledger 项目
- 关联：ADR-0111（infra crate 内部组织——复用粒度、层序断言与投影范式，定位口径按业务域重写）；ADR-0112 决策 1（「不做域内模块重排」限缩为拆 crate 阶段纪律）；ADR-0056 / ADR-0059（守门与域模型）；ADR-0105（交易写入协议 Local/Replay 同址约束）；ADR-0145（代码注释禁令——废止本 ADR 原文件头/`//!` 注记住址）；#1181 / #1182 / #1591 / #1597 / #2203

## 背景

`ledger-transaction` 拆出 crate 时遵循 ADR-0112 的机械迁移纪律，沿用了扁平的 14 个顶层模块布局，导致写/读/接缝边界混乱、双入口面并存、模块名与词汇表脱节、存在三处跨区反向依赖，且缺少 crate 内部层序守门。需建立业务域 crate 的内部组织范式，并以 `ledger-transaction` 作为首个样板。

## 决策

### 1. 管辖边界

ADR-0112 决策 1 的「不做域内模块重排」仅限缩为拆 crate 阶段的迁移纪律（保行为等价可机械核对）；拆出后的域内组织由本 ADR 管辖。

### 2. 四区定位口径与目录约定（#1591 / #1597）

业务域 crate 内部按**消费面**（「谁消费它」，而非「像不像底层」）分四区：

| 区 | 定位 | 典型成员 |
|---|---|---|
| **共享语义** | 本域自有、被本域多条路径或其他域共同消费的语义与口径 | 金额口径、域模型、同步命令载荷、统一模糊搜索语义 |
| **跨域接缝** | 本域与外域之间的注册点与契约类型（ADR-0112 决策 5 反转面） | 仅持契约与注册点，不含消费逻辑 |
| **写路径** | 本域的写入编排与落库 | 写入协议、删除编排、行写入、批量、准入 |
| **读路径** | 本域的读取与检索 | 列表与单笔、搜索、读时投影 |

- **区归属登记面 = 目录约定（#1591）**：zone 由 crate 顶层区目录直接决定；**crate 根顶层单文件必须进区目录（fail loud）**，不允许根级单文件默认归共享语义（防无跨区依赖的写路径文件静默错分类）。区归属变更即目录移动；`layer` 统一收口于 ADR-0112 的 `CRATES` 政策核。

### 3. 单向层序与反边消除

允许依赖方向唯一：**写路径 / 读路径 → 跨域接缝 → 共享语义**；写路径与读路径不得互相依赖，任一路径必须仅凭「接缝 + 共享语义」即可编译。重排 `ledger-transaction` 时同步消除三处既有反边（本位币接缝契约归共享语义、模型→行写入转换归写路径、同步命令载荷契约归共享语义）。

### 4. 命名、兼容面、文件粒度与注记住址

- **命名与兼容面**：模块名与词汇表术语对齐（如「写入协议」）；不保留旧模块路径的别名转发；crate 根扁平再导出保留为存量壳层兼容面，新代码走区路径。
- **文件粒度与物理约束**：顶层单文件 = 单一模块子系统，超出即升目录、`mod.rs` 只声明与再导出；拆分不得破坏既有物理约束（如 ADR-0105 要求交易写入协议 Local/Replay 同址）。
- **测试布局**：测试随生产模块外挂（`<模块>/tests/`），自动命中既有测试守门豁免；共享测试脚手架收敛于 crate 根测试目录一份。
- **注记住址（ADR-0145 / #2203 修订）**：模块职责、不变量、ADR 指针与陷阱注记归 **ADR 本体与守门脚本数据面**。本 ADR 原先确立的「文件头 / crate `//!` 作为注记唯一作者位」（及 #1591/#1864 的行数/内容形态规则）随代码注释零容忍禁令整体废止。

### 5. 守门（声明投影 + 区级反向依赖）

- **模块声明投影（#1591）**：expected 由 `lib.rs` 的 `mod` 声明投影，磁盘孤儿文件/目录即红；`#[cfg(test)] mod tests;` 豁免；`#[path]` / `include!` / 未识别属性链 fail loud。
- **区级反向依赖断言**：禁止共享语义依赖接缝/路径区、禁止接缝依赖路径区、禁止写路径与读路径互依。
- **模型目录守门**：域模型禁止 glob 聚合的判据覆盖目录形态。

### 6. `ledger-transaction` 落地形状

```
src/
├── lib.rs         # 稳定再导出兼容面
├── amount/        # 共享语义：TransactionKind / kind→度量矩阵 / 本位币折算与接缝契约
├── model/         # 共享语义：交易实体与请求/响应/投影类型
├── command/       # 共享语义：同步命令载荷契约
├── shared/        # 共享语义（#1597 目录约定）：search_text 统一模糊搜索语义纯函数
├── seams/         # 跨域接缝：商户 / 投资 / 余额刷新 / 出资账户视图 / 来源与投影接缝
├── write/         # 写路径：写入协议 / 删除编排 / 计划装配 / 守卫 / 行写入 / 批量 / 出资准入 / op 产出
└── read/          # 读路径：列表与单笔 / 来源列投影 / 搜索
```

## 备选与否决

- **只改名不分区 / 只禁环不排全序**：无法一眼看清写/读/接缝边界，也缺少可守门的确定方向，否决。
- **照搬 ADR-0111 的 infra 区名**：业务域无引导层与 DB 机制，区名不可迁移，否决。
- **接缝随消费概念分散存放**：跨域边界被切碎，ADR-0112 挂载点无法集中核对，否决。
- **保留旧模块路径别名转发 / 把 zone 写进 `Cargo.toml [package.metadata]`**：前者制造双入口面，后者手抄第二遍且 Cargo 不校验，否决。

## 后果

- `ledger-transaction` 的区边界与单向层序由结构守门持续锁定；其他业务域 crate 按需逐域跟进，不强行批量重排。
- 零用户可见行为变化，迁移过程以既有三层测试断言零改全绿为等价判据。
