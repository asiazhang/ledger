# ADR-0113: 业务域 crate 内部组织——四区、单向层序与清单全等守门（transaction 首个落地）

- 状态：已接受（grilling 定稿 2026-09-12；实施按「后续票」段拆票，本文不直接改代码）
- 日期：2026-09-12
- 作者：Ledger 项目
- 关联：ADR-0111（infra crate 内部组织——本文复用其文件粒度规则、crate 内分层断言与清单双向全等三类机制，定位口径按业务域重写，两文并列不互相复述）；ADR-0112 决策 1（「不做域内模块重排」限缩为拆 crate 阶段纪律，见本文决策 1 与该 ADR 修订注记）；ADR-0056（白名单即规格）；ADR-0059（域模型逐类型再导出——模型目录化须同步扩守门判据）；ADR-0105（交易写入协议单正文双形态——拆分的物理约束）；#1092（ledger-transaction crate 拆分票，本文对象的来源）

## 背景

按 spec #1086 / #1092 拆出 `ledger-transaction` 时，迁移纪律是「只改引用形态、不做域内模块重排」（ADR-0112 决策 1），crate 内部因此沿用了根包域目录时期的扁平形状。落地后的实测形状与代价：

- **14 个顶层模块平铺在一个命名空间**：写路径 6 个（行为编排 / 行写入 / 批量 / 出资准入 / 同步命令 / 余额刷新接缝）、读路径 3 个（列表读取 / 搜索 / 搜索语义纯函数）、共享语义 2 个（金额口径 / 域模型）、跨域接缝 3 个（本位币 / 商户 / 投资）；另有 5 个来源与投影接缝内嵌在读路径模块里。
- **双入口面并存**：十几行 `pub mod` 与约 45 项 crate 根扁平再导出并列，读者无法判断哪一面是权威入口。
- **命名与词汇表脱节**：词汇表的正式术语是「写入协议（Write Protocol）」，代码里叫「行为层」；行为编排与行写入两个近义词并排；读取模块同时是读取权威与 5 个接缝的家。
- **接缝散落**：同类注册点在三种住址（独立接缝模块、读路径模块内部、出资模块一半准入一半接缝），跨域边界无法一处核对。
- **测试两处且脚手架重复**：域级测试目录按旧的扁平模块名组织（查询测试对应读取模块），生产模块旁另有外挂测试目录；两个测试脚手架文件各有一份近似的输入构造器。测试体量约为生产代码的 1.8 倍，导航成本主要落在测试侧。
- **crate 内部无分区守门**：与 `ledger-infra`（ADR-0111：四区 + 文件粒度 + 子目录反向依赖断言 + 清单双向全等）形成对照，本 crate 的模块清单仍是单向存在性登记。

## 决策

### 1. 与 ADR-0112 的边界：域内重排的管辖从「迁移期纪律」归还给本 ADR

ADR-0112 决策 1 的「不做域内模块重排」服务于拆 crate 阶段的机械迁移与行为等价证明（同 ADR-0112 决策 3），只约束「拆出时的布局」，不是对域内布局的长期禁令。拆出后是否重排、按什么轴分区，由本 ADR 管辖；ADR-0112 决策 1 加限定注记（见该 ADR 文末修订注记），其拆分轴、正交判据与门禁保底判定不变。

### 2. 业务域 crate 四区与定位口径

业务域 crate 内部按**消费面**分四区，每区一句话定位：

| 区 | 定位 | 谁进得来 |
| --- | --- | --- |
| 共享语义 | 本域自有、被本域多条路径与其他域共同消费的语义与口径 | 金额口径、域模型、同步命令载荷契约、统一模糊搜索语义 |
| 跨域接缝 | 本域与外域之间的注册点与契约类型（ADR-0112 决策 5 的反转面） | 只持契约与注册点，不含消费逻辑 |
| 写路径 | 本域的写入编排与落库 | 写入协议、删除编排、行写入、批量、准入 |
| 读路径 | 本域的读取与检索 | 列表与单笔、搜索、读时投影 |

判据是「谁消费它」，不是「它像不像底层」：被多域消费的纯语义归共享语义区，不因它的调用者住读路径而归读路径（先例：统一模糊搜索语义被投资域下拉消费，故属共享语义，不属交易搜索）。

### 3. 层序与三处反边

允许依赖方向唯一：**写路径 / 读路径 → 跨域接缝 → 共享语义**（箭头读作「可以依赖」）。据此，重排时同步消除三处现有反边：

1. 本位币基准读取接缝当前被金额口径（共享语义）依赖——接缝契约随其消费概念归共享语义区；
2. 域模型当前持有到行写入类型的转换实现（共享语义依赖写路径）——转换实现搬进写路径；
3. 同步命令载荷当前住写路径，而跨域接缝需要消费它——载荷契约归共享语义区，op 产出点留写路径。

写路径与读路径之间不得互相依赖；两条路径都必须能只凭「接缝 + 共享语义」编译。

### 4. 命名与兼容面

- 模块名与词汇表术语对齐：写入协议的承载模块按「写入协议」命名；「Writer 接缝」「金额口径」等词汇表已有的专名保留，不因重排改名。
- 模块路径允许重排，消费方 import 随重排机械同步；**不保留旧路径的别名转发模块**——那等于承认双入口面，与目标相反。
- **crate 根扁平再导出保留为壳层兼容面**：存量调用点零改动，但它只是兼容面；crate 根文档与守门纪律均声明「新代码一律走区路径」。

### 5. 文件粒度与文件头口径（复用 ADR-0111 决策 3，按业务域重写）

- 顶层单文件 = 只有一个模块的子系统；出现第二类职责或超出单屏可读量级即升目录，目录内 `mod.rs` 只做声明与逐项再导出。
- 文件头统一为「职责 + 不变量 + ADR 指针 + 陷阱」≤8 行；历史沿革（哪票改的、旧实现如何）归 ADR，不进生产文件头。
- 拆分不得破坏既有设计决策的物理约束：交易写入协议的 Local / Replay 两形态必须同址（ADR-0105），不因拆分分离。

### 6. 测试布局

- 测试随生产模块外挂（`<模块>/tests/`），路径段含 `tests` 即自动落在既有守门豁免内（ADR-0056 决策 5）。
- 共享测试脚手架收敛到 crate 根测试目录一份，重复构造器合并；脚手架不得命名为绕过豁免的形态。

### 7. 守门（P0 前置，先红后动）

- 模块清单从单向存在性登记升级为**双向全等**：磁盘上出现未登记模块即红（对偶方向，ADR-0111 决策 5 / #1134 同款）。
- 新增区级反向依赖断言：共享语义不得依赖接缝与路径区；接缝不得依赖路径区；写路径与读路径不得互相依赖。
- 模型守门判据扩到目录形态——现行判据只认文件名，模型目录化后「域模型禁止 glob 聚合」会静默失靶。
- 「删除断言即变红」负向夹具随守门同批落地（ADR-0087）。
- 守门补强先于重排合入：补强本身在旧形状上全绿，重排后同一套断言继续守新形状。

### 8. transaction 的首个落地形状

`ledger-transaction` 是首个样板，目标树：

```
src/
├── lib.rs         # 唯一地图：四区说明 + 稳定再导出（兼容面）
├── amount/        # 共享语义：交易类型闭集真源 / kind→度量矩阵 / 本位币折算
├── model/         # 共享语义：交易实体与各请求 / 响应 / 投影类型
├── command/       # 共享语义：同步命令载荷契约
├── search_text.rs # 共享语义：统一模糊搜索语义纯函数（ADR-0027 全库唯一定义点）
├── seams/         # 跨域接缝：本位币 / 商户 / 投资 / 余额刷新 / 出资账户视图
├── write/         # 写路径：写入协议 / 删除编排 / 计划装配 / 守卫 / 行写入 / 批量 / 出资准入 / op 产出
└── read/          # 读路径：列表与单笔 / 来源列投影 / 搜索与拼音修复
```

关键改名：行为编排模块改为写入协议模块；余额刷新接缝迁入跨域接缝区；读取模块拆为列表与来源投影两件；出资准入与出资账户视图接缝分家（前者写路径、后者接缝区）；读路径内嵌的五个来源与投影接缝外迁接缝区，消费逻辑留读路径。

## 备选与否决

- **只改名不分区**：命名对齐解决一半问题，但「写路径有哪几件、跨域边界在哪」仍需逐文件读；且没有分区就没有可断言的层序。
- **照搬 ADR-0111 的 infra 四区**（原语 / db / boot / shell_support）：业务域 crate 没有引导层与数据库机制，四区名不可迁移；可迁移的是粒度规则、层序断言与清单全等三类机制，本 ADR 按业务域重写定位口径。
- **接缝随消费概念住**（局部性优先）：投资接缝横跨写读两侧、出资模块一半准入一半接缝，按消费概念切会把跨域边界切碎，ADR-0112 挂载点清单无法一处核对。
- **只禁环不排全序**：读者与 agent 拿不到「谁能依赖谁」的确定答案，而本仓的分层守门哲学（ADR-0056 / 0111 / 0112）正是把方向变成规格。
- **保留旧模块路径的别名转发**：等于承认双入口面，且旧名与词汇表术语继续脱节。

## 后果

- 导航收益：一处目录回答「写在哪、读在哪、跨域边界在哪」，文件头不再需要先付长篇叙事成本。
- 旧模块路径消失，消费方 import 机械改一次（改动力度已核对：金额口径与域模型模块路径不变，其余集中在行为编排、读路径接缝、余额刷新与出资准入）。
- `ledger-transaction` 成为业务域 crate 内部组织的首个样板；其余域 crate 是否跟改逐域另票，本文不强制、不批量重排。
- 零用户可见行为变化：schema、迁移、IPC/HTTP 契约不变；行为等价证据是三层测试原样跑绿、断言零改（ADR-0112 决策 3 同款纪律）。
