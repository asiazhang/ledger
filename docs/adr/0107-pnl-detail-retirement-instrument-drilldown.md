# ADR-0107: 盈亏页收敛为两表折本位币单值，逐匹配明细退役，持仓下钻落投资明细页签

- 状态：已接受（正文已按 2026-09-13 两表收敛、ADR-0129 已实现收益列、ADR-0135 下钻迁址与 #1845 单值翻案现行态收敛）
- 日期：2026-09-11（现行态收敛：2026-09-27）
- 作者：Ledger 项目
- 关联：ADR-0011（交易日汇率序列）；ADR-0030 / ADR-0094（URL 下钻纪律与会话内保留）；ADR-0129（盈亏页「已实现收益」主列与副行拆分）；ADR-0131（投资概览单值口径先例）；ADR-0135（投资交易迁入投资页明细页签）；#1843 / #1845（两表翻案为折本位币单值）；词汇表：投资域「已实现盈亏」「已实现收益」「盈亏展示口径」、界面交互域「持仓下钻」

## 背景

早期盈亏页包含五块内容：筛选、总盈亏卡、按年/按账户/按标的三张汇总表、以及逐匹配「卖出明细」卡。评审中「卖出明细」多次被误读为交易流水冗余；随后产品进一步裁决「总盈亏卡」与「按标的汇总」与持仓页/明细页重复、多币种分组拼接在报表表里可读性差。经四轮产品裁决，盈亏页与持仓下钻收敛为以下现行形态。

## 决策

1. **盈亏页收敛为「筛选 + 按年 / 按账户两表」**
   - 退役「卖出明细」逐匹配卡（接受失去逐批次成本/盈亏的 UI 粒度，交易页 sell 行不补盈亏列）、退役「总盈亏概览」卡（总口径由持仓合计承接）与「按标的汇总」表。
   - 保留账户/标的筛选，按年与按账户两张汇总表随筛选收窄，各以「已实现收益」为主列并在单元格副行拆出「已实现盈亏 / 现金分红」（ADR-0129），不展示未实现腿。
   - `realized_pnl_summary` IPC 返回形状删除 `details`、`total` 与 `by_instrument` 零消费字段（前后端同仓同发布）。

2. **两表金额口径：折本位币单值，币种分组在本页退役（#1845）**
   - 按年与按账户两表行键收敛为年度 / 账户（币种维退役），每行折全局默认币种（DefaultCurrency）呈单值：逐腿按自身事件周汇率折算（卖出匹配按卖出周、现金分红按到账周），事件周缺失在 **±8 周**窗口内就近兜底（唯一引入就近周语义的读面）。
   - 窗口内仍无汇率则所在行显式标注「无法计算」（不以零计入、不给半截数字）；币对零历史报 `fx.rate-missing`；表头文案披露按事件周/就近周折算口径。
   - 资金加权收益率卡（比率口径，ADR-0115）及其他读/写路径既有折算纪律不受影响。

3. **持仓下钻落点：投资页明细页签（ADR-0135）**
   - 持仓页签行的标的/代码列点击跳转至投资页明细页签 `/investments?tab=detail&account=&instrument=`（不带 `kinds`，完整呈现该标的交易历史；URL 只读不写回、一次性消费）。
   - 已清仓标的的投资流水在明细页签按标的筛选（不带账户）即可直达，无落空跳转。
   - 主交易列表不再含投资 kind 后，原交易页 `?instrument=` URL 下钻维度退役；`TransactionListFilter.instrument_id` 与 HTTP 同名参数按已发布契约冻结并存（前端不再消费）。

## 理由

- 逐匹配明细与交易流水高度同构、多次造成认知混淆，且产品确认汇总粒度已足够；进一步撤除总卡与按标的汇总消除跨页信息重复。
- 多币种账户下按币种拆行拼接可读性差；ADR-0011 落地历史汇率序列、ADR-0131 建立单值合计先例后，两表统一折本位币单值显著提升复盘可读性。
- 投资 kind 整体迁入投资明细页签（ADR-0135）使持仓下钻与清仓标的查询在同一域内闭环，不再跨主交易列表维护孤立维度。

## 否决与演进摘要

- **交易页 sell 行补「已实现盈亏」列 / 保留明细卡并存**：前者拖慢核心列表读路径、后者不消冗余，否决。
- **中间过渡态（均已随后续裁决演进）**：
  - 初版保留总卡 + 三表 + 主交易页 `?instrument=` 维度；
  - 2026-09-13 裁决撤总卡与按标的汇总（清仓标的流水曾短暂无 UI 入口，后随 ADR-0135 投资明细页签恢复）；
  - 初版为修复跨币种裸数字混算曾改按币种分组，后在历史汇率就位（ADR-0011）与单值先例（ADR-0131）基础上于 #1845 翻案为折本位币单值并清理死字段。

## 后果

- 逐批次匹配明细永久失去 UI 入口，恢复需新 ADR 翻案；明细页签提供的是交易口径而非逐匹配盈亏口径。
- 盈亏页仅呈按年/按账户两张本位币单值汇总表，表头显式披露就近周折算近似边界。
- 交易过滤契约中的 `instrument_id` 作为遗留字段冻结并存，直到 BREAKING 窗口再评估清理。
