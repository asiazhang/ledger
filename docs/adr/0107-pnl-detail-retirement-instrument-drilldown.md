# ADR 0107: 盈亏页退役逐匹配卖出明细——两表折本位币单值，持仓下钻迁投资明细页签

- 状态：已接受并已实施（历经两次产品翻案：总盈亏卡/按标的汇总退役、币种分组翻案为单值；正文收束为终局态，沿革见演进脉络）
- 日期：2026-09-11（终局态收束：2026-11-20）
- 作者：Ledger 项目
- 关联：ADR-0011（FxRateHistory 事件周折算）、ADR-0030（TransactionFilter 深模块与 URL 下钻参数表）、ADR-0038 / ADR-0099（convert 两腿同记录）、ADR-0129（已实现收益列与三层阶梯）、ADR-0131（概览页签单值先例）、ADR-0135（投资交易迁明细页签——下钻落点迁移）；词汇表：投资域「已实现盈亏」「已实现收益」「盈亏展示口径」、界面状态与交互域「TransactionFilter」「持仓下钻」；来源：grill-with-docs 产品裁决（2026-09-11）

## 背景

盈亏页（已实现盈亏概览）原有五块：账户/标的筛选、总盈亏卡、按年/按账户/按标的三张汇总表、「卖出明细」卡。明细卡的数据本体是卖出匹配记录（security_lot_sales）的逐匹配行（卖出所得 − FIFO 对应批次成本），与交易页 sell 流水行高度同构，但数字语义是盈亏口径（成本单价、逐匹配盈亏）而非交易口径（成交单价、卖出所得）；产品评审中两次被误读为交易流水冗余——卡名与内容物错位本身即是问题证据。另一缺陷：原「各币种裸数字直接 SUM」的汇总混算口径在多币种账户下合计是错的。

## 决策（终局）

1. **盈亏页 = 筛选 + 按年/按账户 两张汇总表**：逐匹配「卖出明细」卡退役（后端 details 查询与投影、前端明细表一并删除）；总盈亏卡与「按标的汇总」表亦退役（总口径在持仓页签合计的累计收益可得，按标的信息在交易筛选下钻可得）；两表各含「已实现收益」主列（ADR-0129：已实现盈亏 + 现金分红两腿副行拆出）。
2. **逐匹配盈亏接受降级**：交易/明细页 sell 行不补「已实现盈亏」列；逐匹配的成本批次与盈亏不再有逐笔可见处，由两表兜底，将来真需要再立票翻案。
3. **标的维度落在投资明细页签**：交易页 `?instrument=` 标的维度随投资 kind 迁出主交易列表而退役（ADR-0135），`TransactionListFilter` 的 `instrument_id` 与 HTTP 同名参数按 ADR-0057 遗留参数先例冻结并存（前端停止消费、契约字段不删）；命中口径 = 该标的全部证券流水（buy/sell 行、convert 行任一腿命中即算、份额调整与现金分红行同样命中），URL-only 下钻无手动控件、按 id 形状校验未命中视为参数不在场。
4. **持仓下钻落点 = 投资页明细页签** `/investments?tab=detail&account=&instrument=`：持仓页签行的标的/代码列可点击，URL 只读不写回、一次性消费；不带 kinds——「该标的的交易历史」语义完整；按标的不带账户即达**已清仓标的**的全部交易历史（持仓页签只显示在持标的，明细页签是清仓标的流水的唯一 UI 入口）。
5. **两表折本位币单值**：按年 / 按账户每行呈一个折全局默认币种（DefaultCurrency）的已实现收益单值——逐腿按自身事件周汇率折算（卖出匹配按卖出周、现金分红按到账周），事件周缺失在 ±8 周窗口内就近兜底（唯一引入就近周语义的读面），窗口内仍无点则该腿缺料、所在行显式「无法计算」（不以零计入）；币对零历史沿用 `fx.rate-missing` 码化错误指路行情同步。表头口径说明句注明按实现时点所在周汇率、就近周折算（近似披露）。行集键为 年度 / 账户，`total` 与 `by_instrument` 死字段已从 IPC 契约删除。
6. **布局收敛**：冗余单统计网格清理随首版实施完成。

## 理由

- 明细卡与交易页的信息重叠是产品事实；不可替代的只有逐匹配成本/盈亏，产品裁决该粒度不需要——页面简化收益大于逐笔粒度损失。
- 标的维度走 URL-only 与分类维度同规：列表过滤控件面保持简洁；URL 永远赢、会话内保留、复位守卫由参数表同规则继承，零新增语义。
- 单值翻案承 ADR-0131 的折本位币先例：多币种分组拼接不可读，可读性优先；事件周汇率折算在 ADR-0011 修订后已是既有能力（流水折算按交易日取汇率历史序列）。
- 多入口共享同一下钻机制（同一 URL 参数纪律、新落点），边际成本极低；与来源列「不提供落空的跳转」原则一致。

## 否决方案与代价

**否决方案（防重提）**：交易页 sell 行补「已实现盈亏」聚合列（动核心读路径，且逐笔粒度已裁决不需要）；保留明细卡与持仓跳转并存（冗余不消除）；标的维度给手动下拉控件（与「仅 URL 下钻」先例不符）；汇总按币种分组（已翻案为单值——在本账本内退役）；交易时点汇率复杂度高曾作为不做折算的理由，随 ADR-0011 修订失效。

**代价与已知边界**：逐匹配明细（成本批次粒度）永久失去 UI 可见处，恢复须翻案本 ADR；±8 周就近兜底是折算近似（已显式披露），与写路径折算、组合走势、资金加权收益率、跨账本汇总的既有折算纪律互不适用；URL 参数面遗留冻结字段待 BREAKING 窗口清理。
