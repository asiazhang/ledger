# ADR 0136: 交易页「隐藏投资相关流水」设备级视图偏好——偏好与筛选分家

- 状态：已接受（决策入档；实现随实施票落地）
- 日期：2026-09-25
- 作者：Ledger 项目
- 关联：ADR-0135（主列表收窄为四通用 kind，本决策是其「日常收支动线」定位的下一层）、ADR-0096（出资账户与 InvolvingAccount 三端口径）、ADR-0094（筛选会话内保留与 ESC 复位边界）、ADR-0061（会话内保留）、ADR-0116（功能开关——设备级持久化 UI 状态的先例形态）、ADR-0008（服务端分页）；词汇表：界面状态与交互域「视图偏好」（新）、TransactionFilter 划界注记
- 来源：grill-with-docs 产品裁决（2026-09-25）

## 背景

ADR-0135 把五种投资 kind 迁出主列表后，交易页仍会被投资相关行刷屏：充值/提现转账（ADR-0096 决策 3：充值提现经既有 transfer 承载，投资账户余额 = 子弹）与投资账户直接支付的费用支出都是通用 kind，按「账户维度正交」留在主列表。用户动线里投资现金流占比高时，页面打开仍不像「日常收支动线」——ADR-0135 只迁投资 kind，这些行是银行账户视角的真实资金流，本就不该迁。

用户诉求：给一个「隐藏投资相关流水」的开关，且开关状态**跨启动记住**（本地持久化、不跨设备）。这与「筛选不持久化」（ADR-0094：筛选全维会话内保留、冷启动回默认、零写盘）正面相撞——做成筛选维度再持久化，即打破该边界，且「为什么这个筛选可以持久化」的口子再关不上。

## 决策

1. **新增设备级视图偏好，不新增筛选维度**：交易页筛选栏新增「隐藏投资相关流水」开关，状态是**视图偏好**（界面域新词条）而非 TransactionFilter 维度——跨启动本地持久化（具名 Pinia store 唯一读写方），不入账本 SQLite、不进备份、不参与多端同步；默认关。清除筛选与 ESC 复位不触达偏好，偏好也不参与「清除筛选」禁用态与 ESC 激活判定。ADR-0094 的「筛选不持久化」边界原样保留。
2. **命中口径 = 三端任一命中**：行的转出 / 转入 / 出资账户（InvolvingAccount 同口径，ADR-0096 决策 5）中任一端是投资类型账户（`investment`）即「投资相关流水」——充值转账（主账户为银行卡）一并隐藏；**按账户不按分类**（银行卡支付的「投资费用」分类支出不受影响）。
3. **偏好是行集先决收窄，无入口例外**：主列表行集 = 偏好收窄 ∩ 既有筛选；账户下钻不使偏好让位——下钻列表同样隐藏投资相关行，想看全量关掉开关（ADR-0135 对「行集随入口漂移」的否决理由同样适用）。
4. **只改交易页主列表呈现**：搜索页（全域检索，ADR-0135 决策 7）、投资页明细页签、报表 / 预算 / 余额 / 净资产库级口径全部不动。
5. **实现面（随实施票）**：`list_transactions` IPC 与 HTTP 加可选参数（只增、非 BREAKING，OpenAPI 与 AI 契约自描述面同步），隐藏判定在交易域读路径执行——服务端分页（ADR-0008）要求行集与 total 同口径，前端后滤不可行；域单测 + API 集成测试覆盖；开关文案经 i18n。

## 理由

- 偏好与筛选分家是唯一两全形态：既满足「记住我的选择」（持久化），又不破「筛选是会话瞬态」（ADR-0094 / ADR-0061「不做过度记忆」边界）；功能开关（ADR-0116）已确立「设备级持久化 UI 状态」先例，视图偏好是该家族的自然新成员。
- 三端口径对准痛点：刷屏的恰是充值转账；仅主账户口径治不了（充值主账户是银行卡，行会留下）。
- 下钻不让位保住「行为可预期」：偏好是用户对默认口径的一次性裁决，不随入口漂移；代价是下钻期间银行视角不完整，开关可见可关。

## 代价

- 偏好开启期间，账户下钻的银行视角流水不完整（缺投资相关行）——显式接受，开关一关即回全量。
- 偏好口径与分类语义可能错位：银行卡支付的「投资费用」分类支出照显，投资账户支付的非投资分类支出被隐藏——按账户不按分类是本决策口径，与分类维度语义互不改写。
- `list_transactions` 契约自 ADR-0135 的「零改动」转为「只增」：新增可选参数属发布边界内增量，旧调用方（含既有 HTTP 消费方）不受影响。

## 替代方案

- **改默认（主列表默认排除投资相关行）**：交易页不再「全部资金流水」完整视图，银行流水静默断链且无入口找回——否决。
- **做成 TransactionFilter 维度并持久化**：破 ADR-0094 边界，为其余筛选维度开坏先例——否决。
- **做成筛选维度、维持会话内保留**：每次冷启动需重新打开，不满足「记住」诉求——否决。
- **下钻时偏好自动让位**：行集随入口漂移，ADR-0135 同款否决——否决。

## 影响

- 契约：`list_transactions` IPC/HTTP 只增可选参数，零 BREAKING；无 schema 与迁移改动。
- 词汇表同步（随本 ADR 入档）：界面域新增「视图偏好」词条、TransactionFilter 补划界注记；CONTEXT-MAP 界面域条目主题追加。
- 实施拆票建议：① 交易域读路径可选参数与隐藏判定 + 域单测；② 前端偏好 store + 开关 UI + 契约接线 + API 集成测试。
