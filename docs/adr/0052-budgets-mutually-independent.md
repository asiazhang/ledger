# ADR-0052: 预算彼此独立——父子并存不扣减、不互斥

- 状态：已接受
- 日期：2026-09-01
- 作者：Ledger 项目
- 关联：issue #354（spec）、issue #355（分类删除守卫）、issue #356（子分类预算与路径名呈现）、issue #357（文档沉淀）；ADR-0029（永久滚动预算）、ADR-0005（两级分类）

## 背景

预算此前只能设置在顶级支出分类上：创建预算的分类下拉只列顶级分类，想要「父分类管总量、子分类管细分」的预算夹层时只能二选一——要么在父分类上设一个笼统上限，要么把预算拆到子分类而放弃分支总量视角。同一 spec 还补齐了分类删除守卫（分类自身名下存在未删除预算时拒绝删除并引导先删预算，issue #355）——该约束词汇表早已声称、代码却未实现，属于文档-代码冲突的纠正，与本口径决策同批落地但相互独立。

放开「预算可挂子分类」后，核心口径问题随之而来：父子预算并存时，一笔子分类支出应如何计入两条预算？本 ADR 沉淀该决策——**每条预算是彼此独立的独立上限**，并记录两个被放弃的替代方案。

## 决策

1. **预算可挂任意层级的支出分类**：创建预算的分类选项从仅顶级支出分类放开到全部支出分类（顶级 + 子分类），收入分类依旧不可选（无论层级）。既有边界全部不动：同「分类 + 周期」唯一（子分类同适用）、编辑仅允许改金额、金额为正、周期闭集按月/按年。
2. **预算彼此独立（Mutually Independent）**：每条预算是一个独立上限，父子预算可并存于同一支出分支，不扣减、不互斥——
   - 父分类预算的消耗统计**自身 + 全部子分类**，该口径自二级分类支持起即如此，非本次新增；
   - 子分类预算的消耗**只统计自身**——统计规则统一为「自身分类 + 全部子分类」，分类两级封顶、无孙级，子分类预算是同一规则落在叶子分类上的自然结果，无需按层级特判；
   - 父子并存时**同一笔支出有意计入两条预算**——父管总量、子管细分的「预算夹层」语义，两条上限各自独立判断超支。
3. **进度口径零改动**：本决策不改变任何进度计算——「父含子」与「子只算自身」是同一条统计规则在不同层级上的投影；本批唯一的后端行为新增是上述分类删除守卫（issue #355），与本口径决策无关。
4. **被放弃的替代方案**：
   - **父预算扣除已单独设预算的子分类**（父预算进度 = 自身 + 未设预算的子分类）。放弃理由见下「理由」；其本质缺陷是父预算的数字随「哪个子分类恰好有预算」漂移，并引入跨周期纠缠。
   - **父子互斥**（同一分支上父、子预算不允许并存，设其一须先删另一）。放弃理由见下「理由」；其本质缺陷是限制过强，把「父管总量、子管细分」这一正当需求直接堵死。

## 理由

- **为什么独立而不是扣减**：父预算与子预算回答的是两个不同的问题——「这个分支的总量不超 X」与「这个细分不超 Y」。两个约束同时有意义、逻辑上不冲突：一笔支出可以同时违反两条、只违反一条、或都不违反。扣减方案下，同一笔支出算不算进父预算取决于一个与本笔支出无关的配置（某子分类是否恰好设了预算），父预算的数字随子预算的增删漂移，用户无法稳定解释；扣减还必须按周期配对纠缠——子分类设了年预算未设月预算时，父的月进度扣不扣？跨周期纠缠没有自洽答案。
- **为什么独立而不是互斥**：互斥把选择成本压给用户（二选一），且不变量要在创建与删除两侧反复维护——报错文案必须解释「先删哪一条、按什么顺序」，删除顺序与错误提示纠缠；删掉子预算后分支又回到「无细分约束」状态，用户须重建父预算才能恢复总量视角。独立口径下没有任何顺序约束需要解释。
- **为什么「双计」是有意的**：预算进度不是一张全局报表，而是每条预算各自的透镜——不存在一个「预算总消耗」被重复计算的问题；同一笔支出同时出现在父、子两条预算的消耗里，正是「父管总量、子管细分」的字面含义。界面以「父 > 子」路径名呈现子分类预算（issue #356），避免把两条预算误读为重复记账。
- **为什么统计规则统一为「自身 + 全部子分类」**：这是「进度口径零改动」的根据——父预算的含子统计早已存在，子分类预算只是同一规则落在叶子分类上（无子分类可并入）；不引入「按层级特判」的第二条规则，就没有第二个口径要维护。

## 代价

1. 预算进度不再是互斥切片的和：父、子两条预算的消耗数字存在重叠，未来任何跨预算聚合都不得把父子数字直接相加；现有消费方（首页预算卡、预算执行列表）逐条独立呈现，不受影响。
2. 用户可能对「同一笔支出出现在两条预算里」感到意外；缓解手段是路径名呈现（issue #356），不做扣减补偿。
3. 父预算超支不蕴含任何子预算超支（反之亦然），两条上限需分别解读——这是「彼此独立」的直接推论而非缺陷。
