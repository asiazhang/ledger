# ADR-0019: 价格历史化——周粒度采样承载线，MarketPrice 收缩为现价缓存

- 状态：已接受（余额缓存前提已被 ADR-0067 证伪；采集通道、覆盖面、汇率源与走势入口已按 ADR-0038/0122/0126/0130 及 #1534/#1539/#1759/#1906/#1907 收敛为现行态）
- 日期：2026-08-27（现行态收敛：2026-10-07）
- 作者：Ledger 项目
- 关联：ADR-0011（流水按交易日消费汇率历史序列）；ADR-0015（同步职责切分）；ADR-0036（手动报价）；ADR-0038（场外基金净值与万分位刻度）；ADR-0067（余额/净资产持久化缓存）；ADR-0081（场内与美股行情通道）；ADR-0121 / ADR-0122（现价刷新与历史后台补全解耦）；ADR-0126（恒定价格标的不落历史行）；ADR-0130（腾讯/新浪/证监会/ECB 分工选源）；ADR-0131（投资概览页签承载组合走势）；#1534 / #1539 / #1759 / #1906 / #1907

## 背景

`market_prices` 已随 v0.3.0 发布冻结为「每标的仅保留一条现价」，无法原地扩展历史序列；仅靠用户手动刷新报价留痕又无法得到连续走势，且跨币种组合市值与历史流水折算都需要同期历史汇率。

## 决策

1. **双承载线分离，`market_prices` 收缩为现价缓存**
   - 新增周粒度历史表 `price_history`（标的价格序列）与 `fx_rate_history`（汇率序列）；`market_prices` 收缩定义为「现价缓存」（后随 ADR-0038 就地增 `nav_date` 并统一万分位刻度）。
   - 周粒度幂等存储：每标的一周至多一条（取该周最后一个有报价交易日），整周无报价不落点，同周重复写入整周覆盖。

2. **标的覆盖面与历史回填深度（ADR-0122 / 0126 / 0130 / #1534 / #1906）**
   - **覆盖面**：库内全部有价格写入通道的标的（股票、ETF、美股、场外基金与手动报价标的，含已清仓标的 #827，清仓不删历史）；**价格恒定标的**（如货币基金，ADR-0126）不落历史行，由读侧按常量合成。
   - **采集与现价解耦（ADR-0122）**：当周采样点由日常现价刷新的批量取数面落库；历史回填由后台自动补全以单请求整段拉取（股票/场内走腾讯不复权周 K 单请求 #1906，场外基金走新浪单只全历史 ADR-0130；原「单通道 K 线兼刷现价」与场内日 K 逐只车道均已退役）。
   - **回填深度**：股票/场内与场外基金统一覆盖至**该标的首笔持仓流水日所在周**（`buy`/`sell`/`convert`/`split` 任一腿命中；无持仓流水维持近两年）。

3. **汇率历史 `fx_rate_history` 独立采集（ECB 整份灌库，#1539 / #1759）**
   - 同时服务跨币种组合市值与核心交易域流水按交易日折算（ADR-0011），两表统一「1 base = ? quote」方向口径，查询层负责正反向兜底。
   - 来源为 **ECB 参考汇率**（同日两腿交叉推导，官方契约、回溯至 2005-04，替代原东财 FX 通道）；同时填充当期汇率表 `exchange_rates`（保护人工录入行不被覆盖）；按**可重建缓存**对待，不进同步日志。
   - **整份灌库，取消窗口裁剪（#1759）**：全量腿直接灌入整份 `eurofxref-hist.xml`（约 3 MB），深度判据为逐币种对覆盖 CNY 腿起点周（`2005-03-28`）；保留零非本位币痕迹跳过与 90 天每日增量腿，设置页另设手动同步入口。原「按最早非本位币日期裁窗口」会导致历史导入死锁（写入缺汇率 → 全量腿因无更早痕迹不触发），已退役。

4. **组合市值查询时推算，组合走势并入概览页签（#1907 / ADR-0131）**
   - 历史时点持仓数量由交易流水推算，不物化持仓快照表。
   - 独立走势页签与单标的走势查询（`instrument_price_trend` 等）已于 #1907 退役；组合市值曲线并入投资页**概览页签**走势卡，预设区间闭集为 `1月 / 3月 / 1年 / 3年 / 5年 / 全部`（默认近一年），按实际数据起点绘制。

## 理由

- 独立历史表与周粒度存储兼顾发布边界、数据量（~50 点/年/标的）与图表可读性，直接拉周 K / 全历史省去高频翻页与降采样成本。
- 汇率与标的 K 线解耦避免共用出口额度与 WAF 冲突，整份 ECB 灌库根治历史补记的先鸡先蛋死锁。
- 组合走势归并入概览页签消除独立页签碎片，单标的现价查看收敛到标的列表。

## 否决与已退役方案

- **仅实时报价顺带留痕 / 存日线粒度 / 用当期汇率近似历史**：分别导致曲线空洞、数据量 ×5 噪点重、历史市值永久失真，否决。
- **物化持仓快照表**：引入快照失效与重建负担；查询时推算配合增量优化即可达标，否决。
- **「个人账本规模下余额缓存收益趋零」前提**：已被 50 万笔 88s 实测证伪，账户余额与净资产改走持久化缓存（ADR-0067）。
- **东财日 K 兼刷现价、东财 FX 通道、独立走势页签与单标的走势、汇率按最早痕迹裁窗口**：均已在后续实证中退役并由上文现行方案取代。

## 后果

- `price_history` 与 `fx_rate_history` 属已发布只增不改表，周粒度与整周覆盖幂等契约长期稳定。
- 组合走势在长区间（3 年/5 年）上随标的持仓期回填深度自动补全；清仓后历史曲线完整保留。
