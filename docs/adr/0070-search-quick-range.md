# ADR-0070: 搜索页时间范围快捷选择上位——任意区间退路退役与遗留参数冻结并存

- 状态：已接受
- 日期：2026-09-04
- 作者：Ledger 项目
- 关联：spec #517（实施票 #526）；词汇表：界面状态与交互域「时间范围快捷选择」（消费形态三随实施落地）「数据期间边界」、核心交易域 TransactionSearch；决策先例 ADR-0057（报表页上位与年份下拉退役，遗留参数冻结先例）；ADR-0061（会话内保留——搜索页本票明确不做）；ADR-0047（命令注册单一来源，命令面只增不改的机制依托）

## 背景

搜索页的时间筛选自立项起是两个独立日期选择器（任意起止、可单边、可清空），而时间范围快捷选择已先后在交易页（#381–#392：预设芯片＋期间步进器＋期间直达面板）与报表页（ADR-0057）落地为共享交互。同为洞察组成员，两页时间过滤体验割裂：常用期间（当月/当季/当年/去年）在搜索页要分步挑日期才能表达，长尾期间更是无从下手；全仓时间交互学两套。

快捷选择上位的唯一牵绊是：搜索页是词汇表记载的「任意起止区间」全仓唯一退路——各消费页均不提供任意区间，唯搜索页以日期选择器保留该能力。移除日期选择器即宣告任意区间 UI 能力全仓退役，这是货真价实的能力取舍，须立案记录；后端单边可选参数的处置（收缩还是冻结）亦需裁决。本 ADR 记录 spec #517 拷问确认的五项裁定。

## 决策

### 1. 范围仅搜索页，完整平移交易页全闭集形态（消费形态三）

搜索页接入共享时间范围快捷选择，采用交易页全闭集五枚芯片（全部 | 当月 | 当季 | 当年 | 去年）＋期间步进器＋期间直达面板；「全部」＝无日期条件＝默认态，与既有默认搜索行为一致，升级不悄悄收窄搜索结果。交易页形态即组件缺省预设，接入零配置。交易页与报表页的快捷选择行为一字不动——三页（交易/报表/搜索）同构，学一次处处可用。

### 2. 任意起止/单边区间 UI 全仓退役

两个日期选择器移除，快捷选择行是搜索页唯一时间控件；「清除筛选」把日期条件一并清回「全部」（双空 → 「全部」芯片点亮）。搜索页曾是词汇表记载的任意区间唯一退路，随本决策该退路退役——任意区间 UI 能力自此全仓不存在。

**已知能力损失记录在案**：任意起止区间（如「3月5日–3月12日」）与单边日期条件（如「某日以来」）在 UI 不可达。这是刻意取舍而非疏漏：两类条件使用频率低，芯片闭集覆盖高频回顾口径，长尾期间经步进器与直达面板一击可达；为长尾保留第二套时间控件，代价是同维度双控件并存（「选择器填了区间、芯片不知该亮哪枚」的矛盾态，同 ADR-0057 否决年份下拉并存的理由）与全仓交互学两套。若未来确有强需求，按闭集扩展纪律另议，本 ADR 不预示。

### 3. 状态源维持搜索页本地，会话内保留明确不做

日期条件仍归搜索视图本地（视图内 computed 双向桥接接组件，与交易页桥接同构）；不引入 store，不动 TransactionFilter（其消费方边界维持交易列表专属，ADR-0030）。搜索词与筛选不持久化的边界（与 ViewState 一致）不变——会话内保留明确不做，另立 issue；ADR-0061 的原则适用于报表页期间等已裁定场景，不自动外推到搜索页。

### 4. 搜索过滤单边可选参数冻结并存

搜索过滤契约两侧原样保留：后端 `search_transactions` 的 `date_from`/`date_to` 与前端 TransactionSearchFilter 类型的可选日期字段均维持独立可选——单边语义仍是合法载荷，只是 UI 不再使用；比照 ADR-0057 遗留参数处理（只增不改约定的直接后果），成为冻结可选参数，新代码不使用单边语义。否决后端收缩参数形状（把两参合并或强制成对）：违「API 只增不改」发布约定；搜索语义上单边区间本就是双空区间的合法退化态，收缩不换取任何简化。命令面与 SQL 过滤逻辑一字不动。

### 5. 零新机制，全部随共享组件继承

快照语义（写入精确期间边界后不随时间漂移，仅高亮自然熄灭）、游标派生（「全部」无区间可反推 → 步进器置灰，期间标签仍可打开直达面板）、数据期间边界钳制（边界外步进置灰、面板期间不可选）、面板归弹层注册表（Overlay Suppression）、300ms 防抖自动搜索链路——全部随组件与既有接缝继承，本次不新增任何机制。

## 后果

- **词汇表暂态随实施收口**：本 ADR 立案时词汇表「时间范围快捷选择」边界句仍记载「搜索页保留任意区间作为唯一退路」；词汇表描述行为、随行为落地，反转（新增消费形态三、退路退役注记、「数据期间边界」消费方追加搜索页、核心交易域 TransactionSearch 的 UI 消费入口改指）由实施票 #526 承载，本票不动词汇表。
- **能力损失长期存在**：任意区间与单边条件在 UI 无入口是本决策的直接代价，未来读者不应把它当缺口修补——恢复入口即翻案，须新 ADR。
- **`date_from`/`date_to` 成为冻结可选参数**：未来读者会困惑命令为何保留 UI 不用的单边语义——这是「API 只增不改」的代价（同 ADR-0057 的 `year`/`month`），遗留侧已冻结。
- **闭集跨页差异定式**：交易页五枚（含「全部」＝默认态）、报表页四枚（期间必有界、默认「当年」）、搜索页五枚（同交易页）——「无日期过滤」对搜索有语义（全时间搜索）、对报表无语义，默认态不对称是刻意设计。
