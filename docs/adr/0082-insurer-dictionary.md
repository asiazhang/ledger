# ADR 0082: 保司独立字典——保险公司与商户分家、保费流水不挂商户、seed 常用国内保司

- 状态：已接受
- 日期：2026-09-06
- 作者：Ledger 项目

## 背景

ADR-0051 决策 7 为 MVP 效率将保险公司复用核心交易域商户（Merchant）字典：保险公司即保费流水的付款对象（商户 =「花给谁」），不建第二份保司字典。实践反馈：新建/编辑保单选择保险公司时，选择器列出的是全量商户（京东、红旗连锁等消费商户混在其中），「保司混在商户里」与用户对保司字段的精确预期冲突；两类语义同池也让商户排行、商户管理承载无关成员。更深一层：商户是个人消费轨迹（强个人属性，V001 明确不 seed），保司是公共机构名（客观事实数据）——两者本不同构。经设计评审决定推翻 ADR-0051 决策 7，保险公司升格为独立概念。

## 决策

### 1. 保险公司升格为保险域自有独立字典（Insurer）

- 新增保司字典表，保单以 `insurer_id` 引用（保持必填），字典归保险域（单消费方 Policy，不进参考数据域与核心交易域）。
- 字典语义照抄商户先例：名字全库唯一、软删除（已删不再进新建选择列表、存量保单引用保留照常显示）、改名即时生效（引用指向 id，不回刷历史）。
- **备选与否决**：商户加类型标记（`kind` / `is_insurer`）+ 选择器按类型过滤——保费口径虽不受损、无双份维护，但保司仍混在商户字典/商户排行/商户管理页里，语义不精确（正是本次要修的世界观），且稀释 ADR-0028 统一商户的动机；「不建第二份字典」的原理由「保险公司即保费流水的付款对象」随决策 2 一并解除。

### 2. 保费流水不挂商户

- 保费 `expense` 流水不携带商户引用；归属唯一事实仍是流水直挂保单（PolicyReference，ADR-0051 决策 3 不变），付款对象语义由保单的保司字段承担。
- 缴费协议（订阅形态）的计划行不再存 `merchant_id`：保单协议建档不再写商户，存量保单协议计划行随迁移置空——计划是模板非历史，可改；已生成流水的历史商户引用原样保留（历史忠实）。
- 口径后果（有意接受）：商户排行回归纯消费口径（不含保费支出）；商户名搜索搜不到保费流水（备注仍可搜）；保单列表保司列由商户下钻链接（MerchantLink）改为纯文本——保司不是商户，无商户排行可下钻。保单视角统计（累计已缴/现金流入/下期扣款日）不受影响。
- **备选与否决**：镜像商户（保司建档时同步建/绑同名商户，协议照旧复制商户）——商户排行/搜索口径不动，但两份字典要同步（改名漂移、删除联动），等于把 ADR-0051 反对的「第二份字典」换个方向建回来。

### 3. 管理面照商户管理页形态

- 保司管理为独立视图进侧栏「更多」组：改名/软删/「显示已删」只读切换/统一模糊搜索过滤，交互与商户管理一致（用户心智统一）。
- 保单表单选择器保留拼音可搜 + 即席创建（未命中按输入名建保司）。
- **备选与否决**：无管理页（即建后无改名/软删入口，建错名永远脏）；轻量弹层管理（新形态，无先例收益）。

### 4. seed 内置常用国内保司

- 迁移幂等预置约 30 家常用国内保司：人身险头部（国寿、平安人寿、太保寿险、泰康、新华、人保寿险、太平人寿、友邦等）+ 财产险头部（人保财险、平安财险、太保财险、国寿财险、大地、阳光、众安等）——车险（交强险/商业险）是高频保单场景，财产险公司必须覆盖。
- 命名用常用简称（「平安人寿」非「中国平安人寿保险股份有限公司」）：用户怎么叫、字典怎么存，拼音搜索直达。
- 机制照 V004 种子先例：确定性 UUID、`INSERT OR IGNORE` 按名幂等；后续版本可在新迁移继续幂等补种新成立保司；种子行为普通字典行（可软删，无特殊标记）。
- 与 V001「商户不 seed（强个人属性）」的差异化理由：保司是公共机构名、客观事实数据，开箱即用价值成立。
- **备选与否决**：中保协口径全量预置（150+ 家）——选择器臃肿、绝大多数行成死重（软删只读不可恢复）；法定全称——没人按全称打字，拼音首字母序列冗长。

### 5. 存量迁移走预 1.0 就地修改协议

- 1.0 未发布：按 AGENTS.md 发布约定**就地修改历史迁移**（保单建表迁移等），migration 文件头部注明对应 CHANGELOG 条目，并在 `CHANGELOG.md` 的 `Unreleased` 下增加 BREAKING 条目（就地修改先例：V003 头部注记）。
- 迁移顺序：先 seed 保司字典，再将存量保单按原商户名精确匹配迁移到保司（同名复用种子行，未命中即建），保单协议计划行置空商户；存量商户行与历史流水商户引用不动。
- AI 导入不识别保单/保司的边界不变（ADR-0051 决策 7 后半），保司字典同在 AI 契约之外。

## 后果

- schema：保单表 `merchant_id` → `insurer_id`、新增保司字典表与种子、订阅扩展表保单协议行商户置空（预 1.0 就地修改 + BREAKING 记录）。
- 词汇表：保险域新增 Insurer、修订 Policy / Premium 边界；CONTEXT-MAP 保险域关系改「核心交易 + 定时计划」、商户消费表述加保单协议例外；定时计划域 Counterparty 现状加例外。
- 实施面（另起 issue）：后端 policy model/crud/validation；前端保单表单/协议区/列表列/引用 store；保司管理视图（路由 + 收纳词表项）；i18n（含 en-US 保司文案）；BDD 步骤与 feature 文案；seed 名单定稿；migration 头注记与 CHANGELOG BREAKING 条目。
- 发布说明需提示口径变化：商户排行不再含保费支出。
