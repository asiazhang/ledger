# ADR-0130: 投资页「概览」页签——全页折本位币单值口径与两腿拆分

- 状态：已接受
- 日期：2026-09-19
- 作者：Ledger 项目
- 关联：#1536（本票一）、#1537（本票二）、spec #1532；ADR-0048（可投资资产与财务自由度）；ADR-0094（会话内保留与 ESC 复位通道）；ADR-0031（价格失效信号）；ADR-0114（跨账本投资汇总）；ADR-0129（同一标签在不同表位的 scope 变体句先例）；词汇表：投资域「投资概览」（新）、「可投资资产（InvestableAssets）」、「跨账本投资汇总（CrossBookInvestmentSummary）」

## 背景

不设预算的用户看不到自己的可投资资产：仪表盘财务自由度卡在零分母（未设任何预算）时按 ADR-0048 决策 4 给「设置预算后解锁」占位引导，把分子（可投资资产）一并藏起。但可投资资产 = 投资账户现金 + 持仓市值，本身不依赖预算——被自由度卡挡住是展示面归属问题。同时投资合计数字散落在仪表盘投资概览卡、持仓页签合计三卡与跨账本汇总页，投资页内缺一个回答「我的投资整体什么状态」的落点。

## 决策

1. **投资页新增「概览」页签并作为默认落点**（原默认「盈亏」）：一进投资页就看到可投资资产一个本位币数字，以及它由「投资账户现金」与「持仓市值」两腿构成。ESC 复位目标随默认态一并改址；会话内保留语义沿用（切走再回来回到离开时的页签，ADR-0094）。
2. **全页折全局默认币种（DefaultCurrency）单值**：本页所有金额折算到同一币种后相加呈现，币种随结果透出供页面标注。折算在域内单点执行，缺汇率按既有码化错误上抛，不静默混币种、不给半截数字。
3. **与持仓视图的分工是本 ADR 的核心口径决策**：同一标签（总市值 / 持仓收益）在两处的数不同**不是计算错误**，而是两条口径各回答一个问题——概览页答「我的投资整体有多少」（全账本、折本位币、单值），持仓页签答「每个账户各自持有什么」（按账户币种分组、不跨币种合并、随搜索与账户过滤收窄）。两处口径不互相折算，也不合并成一条；差异由本页概念说明的 scope 变体句承担（先例 ADR-0129：同一标签在不同表位的口径差异必须可解释）。
4. **口径单点重构、表达式不复制**：既有可投资资产单点拆成「投资账户现金腿」与「持仓市值腿」两个函数，原函数改为两者之和；财务自由度分子与跨账本汇总的「可投资资产」行为不变（两腿只服务拆分展示与合计）。
5. **单一后端只读命令作为本页唯一取数接缝**：一次返回本位币、可投资资产合计、两条腿、未计入合计的持仓数与账本内有无投资账户；前端只做装配与格式化，不出现第二份口径表达式、不做任何分组或折算。
6. **缺料状态显式可见，且不隐藏功能**：缺现价（或缺价格币→账户币汇率）的持仓按既有空值语义跳过、不以零计入，同时给出未计入的持仓数（既不虚增也不静默低估）；没有投资账户时照常出 0 并给一句引导；缺折算汇率时整卡警告 + 重试。
7. **订阅价格失效信号**：同步标的信息、录入报价或后台补全实际写价后（ADR-0031）本页自动重拉，与持仓概览、标的页列表、组合走势、价格过期提示同批消费方。
8. **纯只读**：页内不含同步、录价、设置预算等写入口或动作入口；唯一交互是口径说明与错误重试（重试即重发同一条读命令）。
9. **页面边界收窄**：内容只到「可投资资产两腿 + 投资合计四项」；不含账户级与标的级明细（归账户页与持仓页签）、不含资金加权收益率与组合走势（各有正主页面）。
10. **既有展示面全部保留、ADR-0048 不修订**：仪表盘投资概览卡、财务自由度卡、跨账本汇总页、持仓页签合计三卡均不改动；自由度仍需预算（ADR-0048 决策 4 讲的是零分母时命令照常返回、展示层负责引导），本页只是另给资产一个可见落点。

## 理由

- **资产的可见性不该被预算挡住**：可投资资产与预算无关，把它藏在自由度卡（零分母即占位）之后，等于让用户为看一个数先建一条预算——本页把资产的可读性还给资产本身。
- **全账本单值 vs 分组展示是两条问题**：跨币种账户各自的「总市值」无法合并成有精确语义的单一数字（ADR-0107 决策 6 的既有口径），但用户问「我的投资整体有多少」时必须有一个数。两条口径并存、各自标注，比强行统一成一条更诚实。
- **口径归域、前端零算术**：仓库纪律是金额口径归域（折算、相加、缺价跳过都在后端读投影内完成），前端只格式化——本页因此只有一个取数接缝，页面数字与口径说明不会各说各话。
- **缺料显式而不是静默**：缺价持仓跳过会低估、以零计入会虚增，两种都不说明就是错误信息；给数量说明让用户知道「少算了几只」，与净资产 / 可投资资产的空值语义一致。
- **默认落点改址的代价可控**：页签选中本已随会话保留、冷启动回默认（ADR-0094），默认值改址只动默认态一处，ESC 复位与冷启动自动跟随。

## 代价

- 投资页默认落点从「盈亏」变为「概览」，既有用户的第一眼内容改变（习惯按盈亏进入的人多一次点击）；页签顺序与默认选中值的一处常量改动会牵动前端落点测试。
- 同一标签两处不同数成为常态，必须靠页面上的口径说明承担解释成本；说明缺失即被读成计算错误。
- 投资域多一个读命令与一个页签组件，页面数增加一处（可关功能清单与本决策无关：投资页可关，本页随域入口进出）。
- 缺价持仓的存在会让合计与「所有持仓之和」不等——这是有意为之，但页面必须始终带说明。

## 替代方案（防重提）

- **在自由度卡内解锁分子**：要把「资产可见性」塞进一个以预算为分母的指标卡，零分母时必须同时表达「没有分母」与「分子是多少」，卡的语义被拆成两件事。否决。
- **本页也按账户币种分组展示**：与持仓页签合计重复，且回答不了「投资整体有多少」。否决。
- **把持仓页签合计三卡迁移到本页**：三卡是持仓页签的主体（随过滤收窄的账户视角），迁走会让持仓页失去自己的合计。否决（既有展示面保留）。
- **前端做折算与两腿相加**：把金额口径留在展示层，与「金额口径归域、前端只格式化」的纪律相悖，且与其他页的同一数字必然漂移。否决。
- **把本页做成投资页首页并退役仪表盘投资卡**：仪表盘回答的是「全部家当」，本页回答「投资部分」，两者并存不冲突；退役属后续迭代。否决。
- **缺价持仓按零计入**：会给出偏小的假数字（虚增/虚减价值），与既有空值语义冲突。否决。

## 影响

- 词汇表：投资域新增「投资概览」词条；「可投资资产（InvestableAssets）」补消费面（两腿拆分与合计的展示落点）；CONTEXT-MAP.md 投资域清单一并同步。
- 交互文档：界面状态与交互域「会话内保留」落地清单中的投资页复位目标同步为「概览」。
- 契约：新增一条只读命令与对应前端类型 / API 调用面 / i18n（中英双份）；命令注册一致性检查与结构守门清单同步。无 schema 改动、无迁移、无已发布契约变更。
- 验收：投资页默认落在概览、ESC 复位回概览、切走再回来保留离开时的页签；两腿之和等于既有可投资资产单点；多币种折本位币；隐藏账户排除；缺价计数可见；无投资账户 0 + 引导；缺汇率整卡警告 + 重试；写价后自动重拉；页内无写入口。

## 后续（本票边界外）

- 投资合计其余三项（总市值、持仓收益即未实现盈亏、累计收益）由 #1537 补齐，与本页同一接缝、同一折本位币单值口径。
- 概念说明的 scope 变体句（同一标签在概览与持仓两处的口径差异，中英同步）随 #1537 落地；本 ADR 决策 3 是其规格来源。
