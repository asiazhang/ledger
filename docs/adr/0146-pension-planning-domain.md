# ADR-0146: 养老规划独立成域——基本养老与多源个人储蓄口径、资产组主栏归位与只读草稿试算

- 状态：已接受（grilling 定稿，spec #2215）
- 日期：2026-11-22
- 作者：Ledger 项目
- 关联：修订 ADR-0133 决策 5（原「储蓄目标二期养老测算」独立升级为单列小域）；遵循 ADR-0063（侧栏每组 ≤3 主项硬上限与组内收纳）；遵循 ADR-0112（后端 workspace crate 分层）；遵循 ADR-0116（功能开关）；遵循 ADR-0091 / ADR-0101（多端同步 OpLog 与重放注册表）；词汇表：养老规划域（`CONTEXT-pension.md`，新）、储蓄目标域（`CONTEXT-savings-goal.md`）、界面状态与交互域（`CONTEXT-ui-interaction.md`）

## 背景

ADR-0133 决策 5 曾将养老预留为储蓄目标域的二期辅助测算器（仅城镇职工基本养老、唯一出口是回填目标额）。当产品形态明确为独立的「养老规划」页面（参考有知有行「过去积累 → 未来预估 → 养老生活」叙事与替代率对比）后，原有窄定位面临四处结构性不匹配：

1. **职责越界**：养老规划需同时盘点基本养老金与个人多渠道养老储蓄、评估退休后月领与生活水平替代率，已远超单个储蓄目标的蓄水进度，强挂储蓄目标域会扭曲两域边界。
2. **多渠道自有储备与账本数据的衔接**：用户的自有养老资金常分散在个人养老金账户、基金/美股投资账户、专项储蓄目标等多处（且含外币），需要安全地只读引用账本数据、防止重复计数，又绝不能把不可自由支取的社保余额混入净资产。
3. **退休领取折算与高龄断崖**：个人储备没有社保统筹终身兜底，若直接除以国家计发月数（如 60 岁 = 139 个月）再与基本养老金相加，会在 72 岁前后出现月领断崖，误导长期规划。
4. **交互实时性与同步日志清洁的张力**：桌面工作台需要调参即看结果，但每次微调若直接落库写 OpLog 会迅速污染多端同步流。

## 决策

### 1. 独立单列小域与资产组主栏落位（修订 ADR-0133 决策 5）

- 撤销 ADR-0133 决策 5「养老测算隶属储蓄目标域二期」的归属，新设单列小域 **养老规划**（后端域 crate `ledger-pension`，独立路由与页面，纳入功能开关闭集可关闭）。原储蓄目标域词条迁出，两域仅保留单向轻触点：养老规划可只读引用储蓄目标，存在缺口时单向引导跳转新建储蓄目标。
- 侧栏归位恪守 ADR-0063 每组主项 ≤3 硬上限：将**养老规划**放入 `assets`（资产）组默认主栏，原资产组主栏的**物品**迁入资产组默认收纳（「更多」页签），资产组出厂主栏收敛为「投资 / 攒钱 / 养老规划」，出厂收纳为「物品 / 保单 / 实物资产 / 保司管理」。

### 2. 测算范围闭集（A + D）与地域口径

- 聚焦**中国内地城镇职工养老体系、固定 CNY 展示**，仅包含两块：
  - **基本养老金（城镇职工）**：标准两腿公式（基础养老金 + 个人账户养老金）；内置 2025 渐进式延迟法定退休年龄、最低缴费年限（15–20 年）与国家标准计发月数规则作为默认推导，并允许用户手动覆盖退休年龄（覆盖弹性提前 / 延迟）；主输入收口为社保渠道可直接查得的参保项与是否续缴开关，宏观假设折叠带默认值。
  - **个人养老储蓄**：通用的个人自有养老储备（既有存量 + 退休前持续存入 + 预期年化收益率），不设国家第三支柱 12,000 元/年上限、不扣 3% 领取个税、不算缴存期抵税。
- **显式排除（v1 边界）**：不做企业年金 / 职业年金、不做独立的国家第三支柱专户政策模块、不做城乡居民养老、不做 1997 年前视同缴费过渡性养老金、不做蒙特卡洛 90% 概率区间预测、不内置易过时的城市社平工资静态表。

### 3. 账本数据边界与防重算三互斥模式

- **基本养老金与净资产彻底隔离**：纯手工档案，不建账本账户，不参与净资产与可投资资产口径。
- **个人养老储蓄采用三互斥来源模式**，消除同一笔资金被重复计数的可能：
  1. **手工模式**：手填既有储蓄与未来持续存入。
  2. **组合绑定模式（多选）**：支持同时勾选多个任意币种的账本账户与/或多个储蓄目标求和；账户候选项排除储蓄目标专属账户（延续 ADR-0133 绑定派生过滤先例）；未来持续存入默认带入所选储蓄目标的关联月存节奏之和并允许手填覆盖。
  3. **全账可投资资产模式**：只读引用投资域 `InvestableAssets`，与组合绑定互斥防重算；未来持续存入手填。
- **投资账户与多币种取数口径**：绑定投资类型账户（如美股券商户）时取「账户现金余额 + 该账户持仓市值」（与 `InvestableAssets` 两腿同源，缺价持仓跳过并显式提示未计入数），非投资账户取账户余额；所有外币金额统一按当期汇率折算 CNY，缺到 CNY 的汇率时按码化错误提示、不静默以零计入。
- **目标退休月开支**：默认手填，提供从预算域 `AnnualBudgetTotal ÷ 12` 一键抄入作为初始参考（单次填充、不反向绑定）。

### 4. 退休折算口径、评估输出与四类边界不变式

- **个人侧统一采用预期寿命等额摊领**：按设定预期寿命（默认 85 岁）与退休后保守年化收益率（默认 2%）计算等额年金月领（PMT），确保与终身发放的基本养老金相加时口径平滑覆盖全退休期。
- **评估输出**：完整呈现「过去积累 → 退休时预估积累 → 退休后月领」三段叙事，同时给出名义月领与按通胀率（默认 2.5%）折现的现值购买力、来源拆分、三柱参考对比（退休前收入 / 退休后月领 / 退休时社平）、以及「仅基本养老金 vs 加上个人养老储蓄」的替代率三档对比（55% / 70% / 100%）与现值月度缺口。
- **四类边界不变式**：
  1. 预计退休时累计缴费年限不足当年法定最低年限时，主结果基本养老金计为 0 并显式警示缺少年限，同时附「延缴至满最低年限时」的参考月领，不静默产出不可领的假数字。
  2. 当前已达或超过设定退休年龄时，跳过未来续缴与通胀折现（名义值等于现值）；设定退休年龄不小于预期寿命时提示调高预期寿命。
  3. 绑定账户或储蓄目标归档态照常读取并轻提示；软删态该项贡献回退为 0 并在对应位置显式标红警告，不阻塞整页估算。
  4. 新账本未建档时展示准备清单空态引导，不预填虚假样例数据。

### 5. 单人单例持久化、后端单点计算与草稿/同步分离

- **每账本单人单例**：输入档案落账本单例表 `pension_profile`（金额整数分），估算结果纯实时派生、永不落库；多成员与多方案留待后续演进。
- **计算权威唯一收口后端域**：延迟退休查表、计发月数、复利与 PMT 摊领、通胀折现、替代率与缺口反推全部位于 `ledger-pension` 域，前端零重复公式；跨表只读聚合（账户余额 + 持仓市值 + 当期汇率 / 可投资资产）收进同一读事务（`ensure_transaction` 纪律）。
- **草稿实时预览与显式保存入同步分离**：暴露纯只读草稿试算命令承接桌面双栏实时联动（不写库、不产 OpLog）；仅显式保存时写入 `pension_profile` 并产出一条整档语义命令接入 `sync-engine` 重放注册表（全账本 LWW 语义）。

## 否决的备选方案

- **留在储蓄目标域作附属测算器**：将养老压窄为目标额回填入口，无法承载多渠道养老储备盘点与退休现金流评估，已由决策 1 正式翻案。
- **拆分独立的「国家个人养老金专户（1.2 万上限 + 3% 领取税）」与「补充养老储蓄」两模块**：两套表单结构高度同构，且与用户将美股、基金等多渠道统一纳入个人养老储备的习惯冲突；收口为单一通用「个人养老储蓄」并支持多账户/多目标组合绑定更简洁且无政策包袱。
- **将社保或企业年金建模为账本账户并计入净资产**：社保余额退休前不可自由支取，混入净资产会系统性高估当前可支配财富。
- **个人储蓄按计发月数（如 139 个月）或 3% 永续提取率折算月领**：前者在 72 岁后断崖归零、高估高龄收入，后者默认永不消耗本金、显著压低小额养老储蓄的可用月领。
- **放 `insights` 组主栏或突破每组 3 主项硬上限**：养老规划与投资、攒钱同属资产与长期财富规划心智，放资产组并把低频的「物品」移入资产组默认收纳，既守住 ADR-0063 键位封闭不变量，又给养老规划提供直达主入口。
- **编辑即自动防抖写库并产 OpLog**：拖参探索会产生大量无意义同步操作并吞掉「还原已保存档案」的试算体验；改为纯只读草稿试算 + 显式保存落库同步。
