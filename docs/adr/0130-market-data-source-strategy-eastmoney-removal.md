# ADR-0130: 行情与净值源策略——移除东方财富，按链路分工选源

- 状态：已接受（grilling 定稿，2026-09-19；实现随实施票落地）
- 日期：2026-09-19
- 作者：Ledger 项目
- 关联：ADR-0121（取数面形状、降级契约、自适应限速保留；决策 6「不做多源」被本裁决取代）；ADR-0081（决策 1 的按代码查询主干道保留、其中的美股三市场候选遍历退役；决策 2 的市场闭集与精确交易所归属保留）；ADR-0039（基金查询与创建增强——数据源替换，判据形状不变）；ADR-0038 决策 6（场外基金净值通道形态保留、数据源替换）；ADR-0126 决策 3（货基判定的信号换源，单向打标语义不变）；ADR-0103（行情接入接缝形状不变）；词汇表：投资域 价格通道 / 行情批量取数 / 行情接入 / InstrumentInfoSync / 价格恒定标的 / MarketPrice / 手动报价

## 背景

**数据源的可用性已经跌破「可以继续押注」的线。** 2026-09-19 实测：历史 K 线端点 `push2his` 在所有已知主机（含 `21`/`40`/`70` 子域与 `push2`）返回连接层空响应（0/6），实时主机 `push2` 的批量报价 0/5 全失败；仅 `push2delay` 报价（5/5）、搜索与基金净值面（必须带 Referer）可用。历史 K 线是唯一没有降级通道的链路——它一断，价格历史后台补全整体停摆，而这正是使用者最先撞到的症状。

**原以为「只有东方财富能做」的独家能力，实测都有替代（同日实测）。**

- **场内类型识别**（stock / etf）：腾讯报价自报类型码 `GP-A` / `ETF` / `LOF` / `ZQ-KZZ`（按市场分三套字段布局）。
- **美股精确交易所归属**：腾讯报价自报后缀 `.OQ`（纳斯达克）/ `.N`（纽交所）/ `.AM`（美交所），与既有市场闭集一一对应。
- **基金存在性判定（含已终止）**：证监会基金电子披露网站对 #1212 记录的 5 只清盘基金 5/5 命中，名称、最后一期单位净值与净值日期与既有证据逐值一致。
- **货币基金判定**：同一官方站点的货基记录自报「单位净值为空 + 万份收益与七日年化有值」，与 ADR-0126 决策 3 依赖的第三类信号同形。

**替代通道的实测画像（2026-09-19，本机出口，非中国大陆家宽）。**

| 通道 | 覆盖 | 批量 | 今日观测量级 |
|---|---|---|---|
| 腾讯行情报价 | 沪深港美股票与场内基金，带类型、币种、交易所后缀 | ~900 只/次 | TTFB 0.15s（100 只 39KB） |
| 腾讯 K 线 | 沪深港美（**新浪 K 线对港美返回空**） | 单只 | 近两年 800 根 / 49KB / 0.24s |
| 新浪行情报价 | 同腾讯（含场外基金净值 `f_` 前缀） | ~850 只/次 | TTFB 0.15s（100 只 21KB） |
| 新浪场外基金净值 | `f_` 批量最新净值 + `getNav` 单只全历史（含已终止） | 批量 + 单只 | 219 只 1 次 0.20s；单只全历史 0.26s |
| 证监会基金电子披露 | 场外基金官方净值与名称（含已终止、含货基口径） | 单只区间或全市场单日分页 | 单只 0.13s；全市场单日 35,193 行可分页 |
| ECB 汇率 | 汇率序列 | — | 已另行定案（不在本裁决范围） |

**需求方的决定：不再使用东方财富。**

## 决策

1. **移除东方财富**：运行期不再调用任何东方财富端点；东财通道、常量与其测试随实施票一并删除，不留「停用但可启用」的死代码（先例：删除东财 FX 采集通道）。
2. **按链路分工选源**，不做「一个源整体替换另一个源」：
   - **场内标的（沪深港美股票与场内基金）**：腾讯行情为主源——批量报价、类型、币种与 K 线一个源解决；新浪报价为备用链路。
   - **场外基金净值**：新浪（批量最新净值 + 单只全历史，含已终止基金）；证监会基金电子披露为权威兜底与判定来源。
   - **汇率**：ECB（另行定案，本条不重开）。
   - ADR-0121 的整体形状保留：批量面为主、逐只通道为 fail-closed 降级、同步内熔断、跨同步记忆、降级对用户可见、自适应限速——**只换成员，不换形状**。
3. **自动判定与识别保留**：类型识别、精确市场、权威名称回填、存在性判定与货基判定都不改为用户手选。代价是腾讯的类型码按市场分三套字段布局，收口在一个探测单点（与既有未公开字段的隔离方式同款）；换来的是录入与 AI 导入链路零退步。
4. **美股市场闭集不动**：保留 `nasdaq` / `nyse` / `amex` 三值，不新增 `us`、不把三值合并。理由三条：腾讯自报交易所后缀，填三值零成本；界面早已把三值折叠显示为「美股」，精确交易所在用户侧本来就不暴露；而新增取值需要改写 `instruments.market` 的 CHECK，按本仓先例只会让存量库写入被拒，是唯一会把「已保存数据」拖进 breaking 的动作。存量行与新行语义一致，无迁移。
5. **行情日期取交易所当地交易日**：数据源给出的是交易所当地时间，交易日取其日期部分，不做时区换算。既有「unix 秒 + 北京时间换算」的日期口径随东财通道一并退役——若沿用北京时间切分，美股收盘会落到北京次日，把周五的行情记成周六。
6. **货基判定换源、语义不变**：判定信号改为官方披露的自报口径（单位净值为空 + 万份收益与七日年化有值）；ADR-0126 决策 3 的**单向打标**（未标记 → 标记、缺信号不清空、一次确认长期成立）不变。本项不可省：新浪批量面把货基的万份收益放在单位净值位（实测 `f_000198` 的单位净值位是 `0.2229`），不做判定改写即复现「货基市值少计约七成」的错误。批量面覆盖同步收窄——新浪批量面含货基，排行面无货币型那种结构性缺口随之消失。
7. **来源标记**：价格侧 `source` 写入新来源值（无 CHECK，闭集由写入通道收口），存量 `eastmoney` 行保留为历史事实，不重写、不迁移。字典侧标的行的存量 `eastmoney` 同样保留——它仍是删除准入的输入（仅手动行可删），本次**不**放开存量行为可删。
8. **契约面**：基金分类展示串无替代，已发布契约只增不改，故 `fund_class` 字段保留但返回空串并标注弃用（刻意不用名称关键词推导——推导错的分类比空值更糟）；股票查询返回体的精确市场描述去掉「精确交易所」措辞（取值闭集不变）；导入知识节里「东方财富不可达降级建行」一类表述改写为数据源中立的说法。
9. **不做可插拔数据源抽象**：延续 ADR-0103 / ADR-0121 的口味——没有「遍历一组数据源统一处理」的多态消费点，多源由统一形状与命名承载，不付 trait 与注册表税。
10. **合规口径**：接受非官方接口取数（腾讯、新浪无公开契约；证监会基金电子披露是官方数据但为站点内部接口，无公开契约），发布面如实记录再分发风险；不引入付费源（个人档许可普遍禁止再分发，与公开发布冲突）。

## 否决

- **保留东方财富兜底或双源并存**：需求是整体移除；且东财的问题不是「偶发失败」而是「独家链路整段失效」，兜底只能兜住它不起作用的那部分。
- **合并美股三市场为 `us` 或新增 `us`**：需求方不需要精确交易所，但数据源免费给了后缀；删除它反而要动 CHECK 与存量库，是唯一会把已保存数据拖进 breaking 的方向（见决策 4）。
- **取消自动识别、改由用户手选类型与市场**：曾作为移除东财的备选手段提出；替代源能自动给出类型与交易所后，这个代价不必付，且会把录入与 AI 导入链路一起降级。
- **整体换成一个源**：没有任何单一源同时覆盖场内报价、场内 K 线（含港美）、场外基金净值与基金存在性判定——新浪 K 线对港美返回空，腾讯没有场外基金净值前缀，官方站没有场内行情。
- **可插拔数据源抽象**：与 ADR-0103 / ADR-0121 同一口味，没有多态消费点。
- **付费源（Tushare Pro 等）**：个人档许可禁止再分发，与公开发布冲突；且不解决场内 K 线之外的任何问题。
- **基金分类用名称关键词推导**：错误分类比空值更糟（见决策 8）。
- **沿用北京时间切分行情日期**：会把美股收盘记到北京次日（见决策 5）。

## 后果

- **用户可见**：行情与净值刷新不再依赖单一非官方接口；基金新增成功提示里的「分类」一项变为空（字段保留）；其余交互零变化。
- **词汇表（随实施票落地，不在本裁决内提前改写）**：价格通道的来源标记取值、「行情批量取数」的单一数据源边界、「行情接入」查询半边的判定来源、「InstrumentInfoSync」的取数面成员、「价格恒定标的」的判定信号来源、以及字典来源条目的「东财」措辞——逐条改写到与新源一致。**这些条目在实施落地前仍描述现状，不提前改写**（代码是唯一事实来源）。
- **数据与迁移**：零 schema 变更、零存量重写。新增来源值不需要迁移（价格侧无 CHECK）；市场闭集不动；字典侧存量来源标记保留。
- **守门判据**：①删除东财通道后，任一东财端点的引用与常量不得残留（源码扫描）；②删除货基判定改写 → 货基被写成万份收益的测试变红；③删除「取当地交易日」→ 美股采样日错位的测试变红；④删除批量面降级接线 → 逐标的回退与降级标注无用武之地，接线型断言变红（继承 ADR-0121 既有判据）。
- **可逆性**：换源本身可逆（接缝形状未变，改回或改第三源是同一形状的替换）；但删掉的东财通道代码与其测试不保留副本，回退需重新实现。这是刻意的：保留死代码的维护成本高于重写成本（先例：东财 FX 通道删除）。
- **风险（无契约字段）**：替代源的关键信息同样是未公开字段（腾讯的类型码与交易所后缀、官方站的记录形态），换源不降低「字段语义无声变更」这一类风险，只是把风险从失效的通道移开；探测与解析须继续收口在单点，漂移时改一处。
