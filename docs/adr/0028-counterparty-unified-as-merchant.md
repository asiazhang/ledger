# ADR-0028: 交易对手方统一为商户（Merchant）

- 状态：已接受（推翻 ADR-0024 决策点「交易对手（Counterparty）」中的「不在核心 Transaction 表新增通用字段」）
- 日期：2026-08-29
- 作者：Ledger 项目
- 关联：issue #186（spec）、issue #187（文档先行）

## 背景

用户日常消费发生在具体商户上（京东、红旗连锁、万科物业……），但交易流水里没有「商户」维度——想知道「这个月在京东花了多少」只能翻备注或搜关键词，口径脏、统计不可靠。定时计划域已有自由文本的 `counterparty`（交易对手方，ADR-0024），但它只落在计划扩展表、与流水无关，且与「商户」语义重叠：两个词指同一物，各自演化迟早分叉。spec #186 决定统一语言与数据模型，本 ADR 先立语言，使后续实施票用词有据。

## 决策

1. **术语统一**：全库统一「商户（Merchant）」，`Counterparty`（交易对手）术语废弃；词汇表不再使用「交易对手」「商家」「收款方」指称该概念（定时计划域 Counterparty 词条改为指向核心交易域 Merchant 的指针）。
2. **Merchant 成为核心交易域共享概念**：新建 `merchants` 参考数据字典表（软删除 `is_deleted`、`name` 全库唯一、空表启动不 seed——商户是强个人属性，seed 通用商户是字典噪音）。它被三个域消费：核心交易（`expense` / `refund` / `income` 流水携带 `merchant_id`）、定时计划（installment / subscription 挂商户，每期生成交易时复制到流水）、AI 导入（自动识别商户、精确匹配复用或即建）。词条定义归核心交易域词汇表（CONTEXT-MAP 归属规则：跨域共享术语归核心交易域）。决策点原文中的「可选 `icon` / `color` 供报表与图表视觉辨识」已被实施现状推翻并退役（issue #223）：商户是高频自动增长的名字字典，视觉辨识字段只会复活低填充率噪音，与分类（数量少、用户手动维护、图标有辨识价值）对称的设计不适用于商户。
3. **推翻 ADR-0024 的一个决策点**：ADR-0024「不在 `Transaction` 表中新增通用 `counterparty` 字段」被推翻——`transactions` 直接增加 `merchant_id` 外键（字典行硬删时 `ON DELETE SET NULL`）；`scheduled_transactions` 扩展表的 `counterparty` 文本列改为 `merchant_id` 引用。ADR-0024 其余决策（计划生命周期、分期金额、周期规则、失败策略）维持不变；`ScheduledTransfer` 不使用商户（用 `to_account_id` 表示本方账户间转账）的边界维持。
4. **Schema 原地改，breaking change 无升级路径**：`merchants` 表并入既有初始迁移、`transactions` 直接加列，不写前向兼容迁移、不写数据搬迁脚本；发布时标注 breaking change，旧库无升级路径。

## 理由

- **为什么统一而不是并存**：商户与 Counterparty 是同一物（付款对象/收款来源），保留两套词与两处落点必然口径分叉；统一后报表排行、交易搜索、AI 导入匹配共享一个字典与一个名字空间。
- **为什么归核心交易域**：商户被三域消费，按 CONTEXT-MAP 归属规则，跨域共享概念只在核心交易域定义，其他域以指针引用。
- **为什么推翻 ADR-0024 决策点**：原决策防的是「为免改动核心表而保守」，当时商户需求尚不存在；如今商户是被流水、计划、导入三处消费的真实维度，自由文本无法去重统计，`merchant_id` 引用是唯一能支撑「按商户聚合净额、改名即时生效」的落点。
- **为什么原地改而不写升级路径**：单机桌面应用，没有服务端多版本共存问题；应用未公开发布（最新 tag 之后 schema 可自由修改），前向兼容迁移与数据搬迁脚本是一次性重成本、却永久留下双 schema 复杂度。代价明示（见下）好过永久负重。

## 代价

1. 旧库无升级路径：已有数据库需重建或重新导入，升级说明须显著标注 breaking change。
2. 既有定时计划扩展表中的 `counterparty` 自由文本不自动迁移为商户条目，重新录入或导入时自然重建。
3. 商户名全库唯一是精确匹配 upsert 的前提，也意味着同名的不同实体（如两家同名便利店）无法区分——同义词归一与自动合并留待后续，改名即时生效已够用。
