# ADR-0115: 投资收益率采用资金加权（XIRR）口径

- 状态：已接受（grilling 定稿，2026-09-12）
- 日期：2026-09-12
- 作者：Ledger 项目
- 关联：ADR-0107（盈亏按币种分组、不跨币种折算）；ADR-0099（基金转换结转成本）；ADR-0106（份额调整零现金流）；ADR-0109（现金分红为累计收益第三腿）；词汇表：投资域资金加权收益率（MoneyWeightedReturn）、Holding、累计收益（CumulativePnl）、已实现盈亏（RealizedPnl）、时点持仓（AsOfHolding）

## 背景

投资报表此前只有金额口径（持仓收益、累计收益、已实现盈亏），没有任何比例口径——用户无法回答「我赚了百分之几」，也无法与第三方基金平台的收益率对照。金额随投入规模变化，跨标的、跨账户、跨期间都不可比。三种主流比例口径各有取舍：简单累计（收益 ÷ 投入）、资金加权（IRR/XIRR）、时间加权（TWR）。

## 决策

1. **收益率口径 = 资金加权（XIRR）**：以实际现金流与期末市值解年化内部收益率（实际天数 / 365）。回答的是「我的钱实际赚了多少」，而不是「我选的标的涨了多少」。
2. **现金流定义**：买入为负（确认金额，含手续费）；卖出为正（净额，已扣手续费）；现金分红为正；份额调整为现金流零贡献（零现金腿、份额重述）；基金转换在**单标的粒度**按转出批次的结转成本拆成正负两条现金流（转出腿为正、转入腿为负），在账户级与全账级不额外引入（零现金腿天然无影响）。
3. **期间与期初价值**：默认自该粒度首笔流水起算；支持区间选择，区间开始时的存量持仓按**区间首日市值**折为一笔期初投入（负现金流）。期初市值是收益率的输入假设，不改任何账务数据，也不构成第二套持仓口径。
4. **空值与币种**：缺价（无现价或缺账户币→本位币汇率）的标的跳过、不计入该标的收益率，也不计入其所属账户与全账合计——沿用持仓与净资产既有的空值语义；收益率按币种分组，不跨币种折算（与 ADR-0107 同口径）。
5. **展示粒度**：持仓页每行给单标的收益率，盈亏页给账户级与全账级；同一算法两个消费面，不新开页面。

## 理由

- 资金加权把「什么时候投了多少钱」计入结果，与「我赚了多少」的日常直觉一致，是本项目选定并落文档的唯一比例口径。
- 简单累计收益率忽略资金占用时间，定期投入的账户会被系统性低估，长期与短期之间不可比。
- 时间加权（TWR）剔除现金流影响、可与指数比较，但回答的是选品能力，且要求逐笔现金流时点的组合市值快照——本期不做，保留为后续议题。
- 基金转换两腿按结转成本补现金流：结转成本是 ADR-0099 已定的转换锚点，复用它即不引入第二套口径；否则转换进来的份额零成本入账，单标的收益率失真。

## 替代方案（防重提）

- **简单累计收益率（第三方平台常见口径）**：与平台同名口径可比、计算最简，但忽略资金时间价值。否决为**主口径**；若日后要并列展示，须另立口径并说明两者不可互算。
- **时间加权收益率（TWR）**：可与指数、与其他标的比较，但要求逐笔现金流时点的组合市值快照，且回答的不是用户问的问题。本期不做，保留为后续议题。
- **以「持仓收益 ÷ 持仓成本」当收益率**：只覆盖未平仓部分、忽略已实现与分红，与累计收益口径打架；ADR-0107 已裁决不采用摊薄成本法，本票不重开。否决。
- **把收益率折成本位币再跨币种合并**：需要交易时点汇率口径，与 ADR-0107 既定边界冲突。否决（沿用按币种分组）。

## 代价

1. XIRR 是数值解：现金流符号多次变号时可能无解或多解。产品行为定为**不给数、显式标注无法计算**，绝不猜一个解。
2. 单标的粒度依赖基金转换的结转成本，因此该粒度只在成本审计完整时可信；存量幽灵数据（指向已软删卖出的匹配）按既有排除口径处理。
3. 区间选择引入「期初市值」这一非账务输入：文档与文案必须写明它是收益率的输入假设，避免被读成第二套持仓口径。

## 后果

- 新增收益率读投影与前端展示；账务数据零改动、schema 零改动。
- 收益率与累计收益并列为两种口径：金额回答「赚了多少」，比例回答「赚了百分之几」，两者不互为换算。
- 相关词汇表条目：投资域资金加权收益率（MoneyWeightedReturn）、Holding、累计收益（CumulativePnl）、已实现盈亏（RealizedPnl）。
