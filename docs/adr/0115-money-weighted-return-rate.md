# ADR-0115: 投资收益率采用资金加权（XIRR）口径

- 状态：已接受（grilling 定稿，2026-09-12；期初存量语义三票补全与否决注记已并入正文，沿革见演进脉络）
- 日期：2026-09-12（现行态收束：2026-11-20）
- 作者：Ledger 项目
- 关联：ADR-0011（FxRateHistory 事件周折算）、ADR-0099（基金转换结转成本）、ADR-0106（份额调整零现金流）、ADR-0107 / ADR-0129（盈亏呈现与币种边界）、ADR-0109（现金分红为累计收益第三腿）；词汇表：投资域资金加权收益率（MoneyWeightedReturn）、期初存量（OpeningBalance）、Holding、累计收益（CumulativePnl）、已实现盈亏（RealizedPnl）、时点持仓（AsOfHolding）

## 背景

投资报表此前只有金额口径（持仓收益、累计收益、已实现盈亏），没有任何比例口径——用户无法回答「我赚了百分之几」，也无法与第三方基金平台的收益率对照。金额随投入规模变化，跨标的、跨账户、跨期间都不可比。三种主流比例口径各有取舍：简单累计（收益 ÷ 投入）、资金加权（IRR/XIRR）、时间加权（TWR）。

## 决策（现行）

1. **收益率口径 = 资金加权（XIRR），唯一主口径带一个显式口子**：以实际现金流与期末市值解年化内部收益率（实际天数 / 365），回答「我的钱实际赚了多少」。**未年化口子**：建仓时点未知（含期初存量）的标的年化没有输入，改给**未年化口径 = 累计收益 ÷ 累计投入**（分子 = ADR-0109 三腿累计收益，分母 = 期初存量买入额 + 全部真实成本流含转换转入腿），与年化并列展示且**不可互算**（年化回答「我的钱一年赚了多少」，未年化回答「这笔投入一共赚了多少」）；该口子不得扩展为全账唯一口径。
2. **现金流定义**：买入为负（确认金额，含手续费）；卖出为正（净额，已扣手续费）；现金分红为正（仓位外现金，恒入集）；份额调整为现金流零贡献；基金转换在**单标的粒度**按转出批次的结转成本拆成正负两条现金流（转出腿为正、转入腿为负），账户级与全账级不额外引入。**期初存量行（`origin = opening`，V027 闭集列，仅 buy 可携带）不入现金流集**——它不是外部投入，只是「某时刻起就存在的存量」；排除仅辖现金流集，金额口径读数逐位不变。
3. **期间与期初价值**：默认自该粒度首笔流水起算；支持区间选择，区间开始时的存量持仓按**区间首日市值**折为一笔期初投入（负现金流）。**期初存量 + 真实流水的标的，年化恢复**：起算点顺延到**首笔真实流水**，期前存量按该日市值（时点持仓 × 周线价格 × 同期汇率）折为一笔期初投入；t0 当日的持仓变动流水由折算承载（含当日持仓）、分红不在折算内恒入集（含 t0 日）；**折算是年化帧的市值锚，不进未年化口径的成本帧**。区间边界对未年化标的一律不施加（生命周期度量——把存量折成「区间首日市值」会与它自己的买入额重复计入），选不选区间同解。
4. **空值与币种**：缺价（无现价或缺账户币→本位币汇率）的标的跳过、不给数就不入合计（该标的与其所属账户/全账合计均不计入），沿用持仓与净资产既有空值语义；**含期初存量且无真实流水的标的**给未年化口径；**合集（账户级 / 全账级）含此类标的时整项降级为未年化**——分子分母对全合集各自汇总后相除、随行标口径，混合场景不按口径拆两行（年化与未年化不可互算，两行会出现两个不可比的答案）；降级判定是生命周期标记，不随清仓消失；若合集内存量 + 真实流水共存且年化恢复，则随普通对入年化合集、不再触发降级。收益率按币种分组，不跨币种折算。
5. **展示粒度**：持仓页每行给单标的收益率（标口径随行标注），盈亏页给账户级与全账级；同一算法两个消费面，不新开页面。

## 理由

- 资金加权把「什么时候投了多少钱」计入结果，与「我赚了多少」的日常直觉一致，是本项目选定并落文档的唯一比例口径。
- 简单累计收益率忽略资金占用时间，定期投入的账户会被系统性低估；时间加权（TWR）回答的是选品能力且要求逐笔现金流时点的组合市值快照，本期不做、保留为后续议题。
- 基金转换两腿按结转成本补现金流：结转成本是 ADR-0099 已定的转换锚点，复用它即不引入第二套口径。
- 期初存量的年化不是算法缺陷而是输入不成立：建仓时点补不出来，「成本 → 现值」的累计涨幅被摊到 1 天年化会产生天文数字（实测 `003156`：+3.16% 年化成 8,594,733.89%）——不给数、显式标注，比猜一个解正确。

## 否决方案与代价

**否决方案（防重提）**：简单累计收益率作主口径（忽略资金时间价值）；TWR 本期不做（要求组合市值快照）；以「持仓收益 ÷ 持仓成本」当收益率——否决的是拿它当唯一口径（只覆盖未平仓、忽略已实现与分红），未年化口径以累计收益三腿作分子已补上该缺口，但它仍不得作为全账唯一口径；把收益率折成本位币再跨币种合并——原文以「需交易时点汇率」为障碍，ADR-0011 修订后取数已是既有能力，**否决本身未重新裁决**，按币种分组的呈现边界沿用，是否解禁须另起裁决。

**代价与已知边界**：XIRR 是数值解，现金流符号多次变号时可能无解或多解——不给数、显式标注无法计算，绝不猜一个解；单标的粒度依赖基金转换结转成本，只在成本审计完整时可信（存量幽灵数据按既有排除口径处理）；区间选择引入「期初市值」非账务输入，文档与文案写明它是收益率的输入假设、不是第二套持仓口径。

## 后果

- 新增收益率读投影与前端展示；账务数据零改动（V027 origin 闭集列除外，只增不改）；schema 其余零改动。
- 收益率与累计收益并列为两种口径：金额回答「赚了多少」，比例回答「赚了百分之几」，两者不互为换算。
