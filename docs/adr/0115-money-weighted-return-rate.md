# ADR-0115: 投资收益率采用资金加权（XIRR）口径，期初存量降级未年化

- 状态：已接受（grilling 定稿，2026-09-12；正文已按 #1343 / #1345 / #1346 与 #1539 现行态收敛）
- 日期：2026-09-12（现行态收敛：2026-09-19）
- 作者：Ledger 项目
- 关联：ADR-0011（交易日汇率折算）；ADR-0099（基金转换结转成本）；ADR-0106（份额调整零现金流）；ADR-0107（盈亏页呈现边界）；ADR-0109（现金分红与累计收益三腿）；#1343 / #1345 / #1346（期初存量、顺延年化与合集降级）；词汇表：投资域资金加权收益率（MoneyWeightedReturn）、期初存量（OpeningBalance）、累计收益（CumulativePnl）

## 背景

投资报表此前只有金额口径（持仓收益、累计收益、已实现盈亏），缺少跨规模与跨期间可比的比例口径。选用年化资金加权收益率（XIRR）后，补记持仓（期初存量，无真实建仓日期）若被当成补记当日入金，会把累计涨幅摊到 1 天年化成天文数字（实测 +3.16% 年化为 8,594,733%），需要为「建仓时点未知」建立精确的未年化降级与恢复规则。

## 决策

### 1. 主口径：资金加权年化收益率（XIRR）

- 以实际现金流与期末市值解年化内部收益率（实际天数 / 365），回答「我的钱实际赚了多少」。
- **现金流定义**：买入为负（含手续费）；卖出为正（扣手续费）；现金分红为正（仓位外现金，**含区间起始日当天的分红**，#1345）；份额调整现金流恒为 0；基金转换在**单标的粒度**按转出批次结转成本拆成转出正/转入负两条现金流，在账户级与全账级净影响为 0；期初存量行（`origin = opening`）不入 XIRR 现金流集。
- **区间与期初市值**：默认自首笔流水起算；选择区间时，区间起始日的存量持仓按**该日市值**折为一笔期初负现金流（起始日当天买卖由该折算承载，分红不进折算、照常入集）。期初市值仅作收益率输入假设，不改账务数据，不构成第二套持仓口径。
- **展示粒度**：持仓页给单标的收益率，盈亏页给账户级与全账级；XIRR 无解或多解时显式标注「无法计算」，绝不猜解。

### 2. 空值与币种口径

- 缺现价或缺所需汇率的标的整行跳过（不给数、不计入所属账户与全账合计），年化与未年化两口径同守此纪律。
- 收益率按**币种分组**，不跨币种折算。（注：初版否决跨币种折算时以「缺少交易时点汇率」为依据，该取数障碍已随 ADR-0011 修订消除，但按币种分组的口径未重新裁决、继续沿用，#1539。）

### 3. 期初存量（OpeningBalance）与未年化降级规则（#1343 / #1345 / #1346）

通过 `security_transactions.origin`（V027，`trade` | `opening`，默认 `trade`，仅 `buy` 可携带）标识补记存量（不影响任何金额口径）：

| 粒度 / 形态 | 口径与规则 |
|---|---|
| **单标的：仅期初存量（无后续真实流水）** | 建仓时点未知，给**未年化收益率（`cumulative`）= 累计收益（ADR-0109 三腿）÷ 累计投入（含存量买入与转换转入腿）**；属生命周期度量，不施加区间边界；与年化不可互算。 |
| **单标的：期初存量 + 后续真实流水（#1345）** | **年化恢复**：以首笔真实流水日 `t0` 为起算点，期前存量按 `t0` 日市值折为期初投入（同决策 1 区间机制；`t0` 日分红恒入集）；该折算锚仅属年化帧，不混入未年化成本帧；区间边界仍不施加；现金流重新纳入所属账户与全账年化合计。 |
| **合集（账户级 / 全账级，#1346）** | 合集内**存在「仅存量、无真实流水」的标的（含已清仓者，生命周期标记不随清仓消失）**时，整项降级为未年化（按成本帧汇总全合集分子分母，含存量+真实流水标的），**不拆年化/未年化两行**；否则正常按全部标的现金流解年化。 |

## 理由

- XIRR 计入资金占用时间，克服简单累计收益率对定投和长短期不可比的失真；复用 ADR-0099 结转成本避免转换份额零成本扭曲单标的收益。
- 期初存量没有真实建仓日期，年化输入本身不成立；用「累计收益三腿 ÷ 累计投入」作显式未年化口子既保住信息可读性，又补全了「持仓收益 ÷ 持仓成本」遗漏已实现与分红的缺口。
- 合集混合场景整项降级而不拆两行，避免同一账户出现两个不可互算的答案或把极小真实成交残余误读为整户表现。

## 备选与否决

- **简单累计收益率作全账唯一主口径**：忽略资金时间价值，否决。
- **时间加权收益率（TWR）**：回答的是选品能力而非资金实际收益，且需逐笔现金流时点的组合市值快照，暂不做、保留为后续议题。
- **「持仓收益 ÷ 持仓成本」作唯一收益率口径**：遗漏已实现盈亏与分红，否决为唯一口径（其合理诉求由期初存量未年化三腿口径承接）。
- **把收益率折本位币跨币种合并**：维持按币种分组边界（取数障碍已消除，是否解禁留待后续单独裁决）。

## 后果

- 金额口径（累计收益）与比例口径（年化 / 未年化）并列展示、互不换算；单标的粒度依赖基金转换成本审计完整。
- 区间期初市值与 `t0` 存量折算作为输入假设在文档与文案中显式说明，避免与账务成本混淆。
