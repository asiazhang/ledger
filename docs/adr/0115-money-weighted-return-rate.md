# ADR-0115: 投资收益率采用资金加权（XIRR）口径

- 状态：已接受（grilling 定稿，2026-09-12）
- 日期：2026-09-12
- 作者：Ledger 项目
- 关联：ADR-0107（盈亏按币种分组、不跨币种折算）；ADR-0099（基金转换结转成本）；ADR-0106（份额调整零现金流）；ADR-0109（现金分红为累计收益第三腿）；词汇表：投资域资金加权收益率（MoneyWeightedReturn）、Holding、累计收益（CumulativePnl）、已实现盈亏（RealizedPnl）、时点持仓（AsOfHolding）

## 背景

投资报表此前只有金额口径（持仓收益、累计收益、已实现盈亏），没有任何比例口径——用户无法回答「我赚了百分之几」，也无法与第三方基金平台的收益率对照。金额随投入规模变化，跨标的、跨账户、跨期间都不可比。三种主流比例口径各有取舍：简单累计（收益 ÷ 投入）、资金加权（IRR/XIRR）、时间加权（TWR）。

## 决策

1. **收益率口径 = 资金加权（XIRR）**：以实际现金流与期末市值解年化内部收益率（实际天数 / 365）。回答的是「我的钱实际赚了多少」，而不是「我选的标的涨了多少」。
2. **现金流定义**：买入为负（确认金额，含手续费）；卖出为正（净额，已扣手续费）；现金分红为正；份额调整为现金流零贡献（零现金腿、份额重述）；基金转换在**单标的粒度**按转出批次的结转成本拆成正负两条现金流（转出腿为正、转入腿为负），在账户级与全账级不额外引入（零现金腿天然无影响）。期初存量行（`origin = opening`）不入本集合，见「修订记录」2026-09-15。
3. **期间与期初价值**：默认自该粒度首笔流水起算；支持区间选择，区间开始时的存量持仓按**区间首日市值**折为一笔期初投入（负现金流）。期初市值是收益率的输入假设，不改任何账务数据，也不构成第二套持仓口径。
4. **空值与币种**：缺价（无现价或缺账户币→本位币汇率）的标的跳过、不计入该标的收益率，也不计入其所属账户与全账合计——沿用持仓与净资产既有的空值语义；收益率按币种分组，不跨币种折算（与 ADR-0107 同口径）。
5. **展示粒度**：持仓页每行给单标的收益率，盈亏页给账户级与全账级；同一算法两个消费面，不新开页面。

## 理由

- 资金加权把「什么时候投了多少钱」计入结果，与「我赚了多少」的日常直觉一致，是本项目选定并落文档的唯一比例口径。
- 简单累计收益率忽略资金占用时间，定期投入的账户会被系统性低估，长期与短期之间不可比。
- 时间加权（TWR）剔除现金流影响、可与指数比较，但回答的是选品能力，且要求逐笔现金流时点的组合市值快照——本期不做，保留为后续议题。
- 基金转换两腿按结转成本补现金流：结转成本是 ADR-0099 已定的转换锚点，复用它即不引入第二套口径；否则转换进来的份额零成本入账，单标的收益率失真。

## 替代方案（防重提）

- **简单累计收益率（第三方平台常见口径）**：与平台同名口径可比、计算最简，但忽略资金时间价值。否决为**主口径**；若日后要并列展示，须另立口径并说明两者不可互算。
- **时间加权收益率（TWR）**：可与指数、与其他标的比较，但要求逐笔现金流时点的组合市值快照，且回答的不是用户问的问题。本期不做，保留为后续议题。
- **以「持仓收益 ÷ 持仓成本」当收益率**：只覆盖未平仓部分、忽略已实现与分红，与累计收益口径打架；ADR-0107 已裁决不采用摊薄成本法，本票不重开。否决为**唯一口径**；2026-09-15 修订（issue #1343）为「无时点持仓」另立了以累计收益 ÷ 累计投入定义的未年化口径，缺口即在此，见「修订记录」。
- **把收益率折成本位币再跨币种合并**：需要交易时点汇率口径，与 ADR-0107 既定边界冲突。否决（沿用按币种分组）。

## 代价

1. XIRR 是数值解：现金流符号多次变号时可能无解或多解。产品行为定为**不给数、显式标注无法计算**，绝不猜一个解。
2. 单标的粒度依赖基金转换的结转成本，因此该粒度只在成本审计完整时可信；存量幽灵数据（指向已软删卖出的匹配）按既有排除口径处理。
3. 区间选择引入「期初市值」这一非账务输入：文档与文案必须写明它是收益率的输入假设，避免被读成第二套持仓口径。

## 后果

- 新增收益率读投影与前端展示；账务数据零改动、schema 零改动。
- 收益率与累计收益并列为两种口径：金额回答「赚了多少」，比例回答「赚了百分之几」，两者不互为换算。
- 相关词汇表条目：投资域资金加权收益率（MoneyWeightedReturn）、Holding、累计收益（CumulativePnl）、已实现盈亏（RealizedPnl）。

## 修订记录

- **2026-09-15（issue #1343）：期初存量标的改给未年化口径——建仓时点未知时 XIRR 没有输入。**
  补记（持仓初始化）进来的存量持仓只有平台的「份额 + 持仓成本单价」快照，真实建仓时点
  补不出来；这些行此前以普通 `buy`、日期 = 补记日落账，决策 2 把它当当日真实入金，于是
  「成本 → 现值」的累计涨幅被摊到 1 天年化（实测 `003156`：成本 1.1533 → 现值 1.1898 的
  +3.16% 年化成 8,594,733.89%）。持有的钱不是那天进的，年化没有输入——不是算法缺陷，
  是输入不成立。修订内容：

  - **新增「期初存量（OpeningBalance）」语义**：`security_transactions.origin` 闭集列
    （V027，`trade` | `opening`，默认 `trade`），写入契约 `TransactionInput.origin` 随行
    （只增不改，仅 buy 可携带，行为层准入守卫拒绝其余 kind）。
  - **决策 2 的现金流集排除期初存量行**：它不是外部投入，只是「某时刻起就存在的存量」。
    排除仅针对现金流集——CumulativePnl / Holding / 已实现盈亏等金额口径的读数逐位不变。
  - **决策 4 的空值语义扩展到含期初存量的标的**：该标的的年化输出 `None` 并整行改标
    「未年化」（新口径 `cumulative`），其现金流也不计入所属账户与全账合计——与
    「缺价跳过即不入合计」同一「不给数就不入合计」纪律。
  - **决策 1 的排他性开一个显式口子：未年化收益率 = 累计收益 ÷ 累计投入**，只在建仓
    时点未知（含期初存量）的标的上启用，与年化并列展示且**不可互算**（年化回答「我的钱
    一年赚了多少」，未年化回答「这笔投入一共赚了多少」）。这条口子同时收窄「替代方案」
    里对「以持仓收益 ÷ 持仓成本当收益率」的否决：当时否决的是**拿它当唯一收益率口径**，
    且原口径确有「只覆盖未平仓部分、忽略已实现与分红」的缺口——本票的口径以
    累计收益（ADR-0109 三腿：未实现 + 已实现 + 分红）作分子、累计投入（含期初存量买入与
    转换转入腿）作分母，正好补上该缺口。否决其余部分不变：它仍不得作为全账唯一口径。
  - **区间选择不改变期初存量标的的口径**：未年化是**生命周期**度量，区间边界一律不施加
    （把存量折成「区间首日市值」会与它自己的买入额重复计入）。
  - **范围外（后续 ticket）**：期初存量 + 之后真实流水时，年化起算点顺延到首笔真实流水
    （期前存量按期初市值折为期初投入，复用决策 3 机制）；本票先按「含期初存量即不给年化」
    落，账户级 / 全账级的未年化口径同样留待后续。
- **2026-09-15（issue #1345）：存量 + 真实流水的持仓年化恢复——起算点顺延到首笔真实流水。**
  上一条「范围外」的落实：期初存量标的之后有了真实流水（再买 / 卖 / 分红）后，年化口径
  重新成立——以**首笔真实流水**为起算点，期前存量按该日市值（时点持仓 × ≤ 该日最新
  周线价格 × 同期汇率，复用决策 3 机制）折为一笔期初投入（负现金流），此后的年化与真实
  持有期一致。细则：
  - **t0 当日的持仓变动流水由折算承载**（与区间起始日 `(start, …]` 同款约定——折算含
    当日持仓）；**分红是仓位外现金、不在折算内，恒入集**（含 t0 日）。
  - **折算是年化帧的市值锚，不进未年化口径的成本帧**：未年化的分子分母仍按
    期初存量买入额 + 全部真实成本流计，折算值不得混入（否则把市值锚错当现金流）。
  - **仅存量、无真实流水的对行为不变**：仍给未年化口径；存量 + 真实流水的对现金流
    重新计入所属账户与全账合计；折算缺价 / 缺历史汇率按决策 4 空值语义整行跳过
    （不给数就不入合计）。
  - **区间边界对含期初存量的对仍不施加**（上一条纪律延续）：起算点恒为首笔真实流水、
    期末恒取现值，选不选区间同解。
  - **范围外同票修复**：区间起始日（含）的分红照常入集——分红不在期初市值折算内，原
    `(start, …]` 过滤把它连同买卖一起排除，起始日分红被整体丢弃、区间年化被低估；修正
    后分红仅受窗口外侧约束，买卖 / 转换腿口径不变。

- **2026-09-15（issue #1346）：账户级与全账级的未年化口径——合集含期初存量时整项降级。**
  #1343 落地后，含期初存量的标的会退出账户级与全账级的年化合计，整户补记场景（如
  「雪球基金」）在盈亏页看不到任何收益率——比显示天文数字正确，但信息缺失。修订内容：

  - **合集（账户级 / 全账级）含期初存量标的时整项改给未年化口径**：分子（累计收益）
    与分母（累计投入）对全合集各自汇总后相除，随行标口径（复用 #1343 的口径闭集）；
    不含期初存量时行为逐位不变。合集里整户只有期初存量的账户 / 币种组自此有行
    （#1343 下整项缺席）。
  - **混合场景定案：整项降级，不按口径拆两行**。同账户既有期初存量又有真实成交标的
    时，整项给未年化（分子分母覆盖全部标的），不给「真实成交标的的年化」第二行。
    理由：年化与未年化不可互算（决策 1 排他口子），并列两行会让「该账户赚了百分之几」
    出现两个不可比的答案；且年化行只覆盖真实成交残余——整户补记场景残余为零（年化行
    缺席）或极小（年化率被误读为整个账户的表现）。与单标的行规则同构：含期初存量 →
    未年化，粒度从标的升到合集、规则不变。
  - **期初存量对清仓后仍算含**：合集含的判定是对的生命周期标记，不随该标的清仓消失——
    存量买入额本就无时点，其历史得失并入未年化合集口径仍成立；判定不引入「是否仍
    持仓」的第二时点条件。
  - **空值语义不变**：缺价 / 缺汇率的标的仍整项跳过，不入年化与未年化任何口径的合计。
  - **区间选择**：期初存量腿不施加边界（生命周期度量，#1343 已定）；真实成交腿按区间
    入集；含期初存量的合集口径不因区间改变。
  - **修订注记（2026-09-15，#1345 合并后）**：降级触发收窄为「仅存量、无真实流水的对」
    ——存量 + 真实流水的对年化恢复后现金流完整，随普通对入年化合集、不再触发降级；
    降级合集的 Σ 分子分母按成本帧计（#1345 的 t0 折算不进），覆盖包括存量 + 真实流水
    对在内的全部标的。
