# ADR-0057: 报表页时间范围快捷选择上位——期间化报表口径与年份下拉退役

- 状态：已接受
- 日期：2026-09-03
- 作者：Ledger 项目
- 关联：spec issue #409；词汇表：界面状态与交互域「时间范围快捷选择」（消费形态二）「报表年份筛选」（退役）「数据期间边界」「分类下钻」；决策先例 ADR-0049（模块级 i18n）、发布约定（API 只增不改）

## 背景

报表页的时间筛选自立项起是年粒度单选下拉（报表年份筛选，#265/#266/#389 三阶段演进为数据期间边界年档），而交易页已有完整的快捷时间选择（#381/#382/#383/#388/#392：预设芯片 + 期间步进器 + 期间直达面板，快照语义 + 数据期间边界钳制）。两页时间交互不一致：交易页月/季/年皆可一键直达，报表页只能整年看——「上个月分类花在哪」「本季度商户排行」在报表页无解，用户被迫去交易页自己筛流水。需求将交易页快捷时间选择迁移至报表页；本 ADR 记录迁移幅度与三个牵连裁决（「全部」闭集差异、年份下拉退役、后端参数形状）。

## 决策

### 1. 完整平移，报表页为「日期闭集」消费形态

报表页获得与交易页同构的快捷时间选择（四枚日期芯片 + 期间步进器 + 期间直达面板），三张报表卡（月度收支/分类构成/商户排行）随所选期间重算。**报表闭集不含「全部」**——期间必有界：报表本就是「看一段期间的结构」，无界聚合没有自然形态（月度收支卡在全时段下会退化为无限柱，隐藏/切年聚合/空态各有硬伤）；交易页闭集（含「全部」五枚）不动。快照语义、游标派生、数据期间边界钳制随共享交互整体继承。

### 2. 年份下拉退役

年份下拉移除，快捷选择行是报表页唯一时间控件；「任意年份一击直达」由期间步进器与期间直达面板继承（数据期间边界钳制下体验不劣于直选下拉）；进入默认「当年」（继承原下拉默认行为）。同维度双控件并存必然产生「下拉选 2023、芯片亮当年」的矛盾态，且违反单一事实源直觉。「报表年份筛选」词条退役，词汇表留历史注记。

  > 注（2026-09-03 修订，见「修订记录」）：「进入默认当年」原口径为每次进入报表页即回当年（含下钻往返）；随 ADR-0061「会话内保留」落地，细化为冷启动回默认「当年」、同一会话内离开再回来保留离开时的期间与下钻位置。本句按修订前原文保留。

### 3. 月度收支卡统一「期间内按月分布」口径

年 = 12 柱、季 = 3 柱、月 = 单组柱（该月收入/支出/退款三柱 + 净额 tooltip）如实展示。统一语义让后端零特判（from/to 分组按月，月期间自然回 1 行）；月期间切日粒度是有真实价值的新报表，另立 issue 不混入本轮。

### 4. 后端参数形状：from/to 单机制，遗留参数冻结并存

三张报表命令统一新增可选 `from`/`to`（YYYY-MM-DD 含边界），SQL 退化为日期字典序区间比较（与交易列表日期过滤、下钻跳转载荷、快捷选择快照语义全部同构）；缺省回退旧口径。**已发布遗留参数原样保留**（月度汇总/商户排行的 `year`、分类份额的 `month`+`year`——只增不改约定的直接后果），前端此后一律传 from/to，遗留参数成为不再使用的冻结可选参数。否决 month/quarter/year 组合方案：一个命令两套过滤机制并存于「现役」侧，且季度谓词需新写月区间数学。

### 5. 前端复用：共享受控组件（唯一新缝）

时间选择行（芯片+步进器+面板）抽为共享受控组件，快照区间 v-model 进出、不持状态源——交易页唯一事实源仍是 TransactionFilter 日期维度，报表页自持期间状态（不进 TransactionFilter，其消费方边界维持交易列表专属）。组件只是交互载体，与「不引入第二状态源」纪律一致；消灭两份必然漂移的内联实现。

## 后果

- **闭集跨页差异是刻意设计**：交易页五枚（含「全部」= 默认态），报表页四枚（期间必有界、默认「当年」）——「无日期过滤」对报表无语义，两页默认态本不对称。
- **`from`/`to` 与遗留参数长期并存**：未来读者会困惑 category_shares 为何有两套过滤参数——这是发布约定「API 只增不改」的代价，遗留侧已冻结，不得在新代码中使用。
- **下钻联动随期间化外推**（词汇表既有原则的自动延伸，不另立决策）：跳转载荷带所选期间首尾日期；期间切换复位下钻回基础态。
- **为任意区间报表预埋**：from/to 单机制使搜索页形态的任意区间报表未来接入零后端改动。
- 词汇表修订随本决策落地（界面状态与交互域）：「时间范围快捷选择」去交易页锚定升为共享交互（新增消费形态二）、「报表年份筛选」退役、「数据期间边界」消费方更新、「分类下钻」期间化（载荷/复位/配色）。

## 修订记录

- **2026-09-03（issue #428，ADR-0061）：消费形态二默认语义细化——「每次进入回当年」改「冷启动回当年、会话内保留」。** 报表页会话状态已先行落地（#427 会话级 store）：同一应用会话内离开报表页再回来（下钻跳转往返、侧栏切换、回退）= 回到离开时的样子，期间与图内下钻位置恢复、三卡按恢复的期间照常现拉（不是缓存数据）；仅冷启动回默认「当年」。「不做过度记忆」的 ViewState 边界与本决策的闭集差异、快照语义、年份下拉退役、from/to 参数形状均不变——细化的只是「进入」一词的保留粒度（原则与备选取舍见 ADR-0061）。
