# ADR-0056: 后端域目录化——域/壳/基础设施三层定义与依赖方向守门

- 状态：已接受（**现行约束仅存决策 4/5**——白名单即规格的结构守门与测试豁免约定；三层定义与依赖方向的载体已由 ADR-0112 升级为 workspace crate，模型定性由 ADR-0059 修订，基础设施「无域语义」由 ADR-0111 细化为可守门两条；决策 4 的守门数据分界由 #1591 定案扩充为「事实投影 / 政策显式 / cargo 退役」，见文末修订注记。目录搬迁史不再维护，历史见 git）
- 日期：2026-09-02
- 作者：Ledger 项目
- 关联：spec #394 / issue #396（本文档票）；守门先例 ADR-0047；分层载体与拆分轴 ADR-0112；crate 内部组织 ADR-0111

## 背景

（历史背景）后端约 73% 的非测试实现逻辑住在 `commands/`，域行为核心要到「命令层」找，三种目录形状并存；域 import 壳的反向依赖没有机器信号。本 ADR 把三层定义与依赖方向落成可守门的结构；载体演进见 ADR-0112。

## 决策

### 1–2. 三层定义与依赖方向（现行定义见 ADR-0112）

壳 → 域 → 基础设施的单向依赖、域不依赖壳、域间横向消费允许但须显式——现行定义由 ADR-0112 决策 1/2 以 workspace crate 承载并编译期强制，本文不复述；本文与决策 4/5 相关的原判定见 ADR-0112 修订注记。

### 3. 迁移路线图（已全部执行，不构成现行约束）

前置口径修缮 + 五阶段 + 两检查点的路线图已执行完毕；逐阶段模块划分与迁移记录见 git 历史与实施票（#395–#408），终态见「迁移状态」节。

### 4. 结构守门：白名单式脚本

- 守门对象：白名单 = 已验证对壳层零依赖的目录 / crate；白名单内出现对壳层的依赖即红。挂入 `scripts/check.sh` 与 CI。白名单本身即规格——它是质量门槛而非测试（先例：命令注册双向全等检查、i18n key 全等检查）。载体升级为 crate 边界核对后（ADR-0112 决策 4），机制与哲学不变。
- 数据分界（#1591 定案扩充）：**事实有权威源就投影，政策无源就显式**。事实类数据（模块清单 ← crate `lib.rs` 的 `mod` 声明；crate 成员 ← workspace 成员 glob）从权威机器可读源派生与核对，不手抄第二遍；政策类数据（layer 分派、允许依赖方向、方向禁令、认许边）永远显式声明，**禁止**从注释散文生成（第二真理源）。命令注册表（ADR-0047）合法的理由同源：`#[tauri::command]` 是编译器契约，不是散文。cargo 编译期已拒绝的越界方向退役给 cargo，分类与载体见 ADR-0112 决策 4 修订注记。
- 扫描边界：文本级扫描，注释与字符串字面量掩码后匹配壳层模块路径引用（`commands::` 路径与 `use … as` 别名引入）。**评审兜底面随退役收窄到 cargo 看不见的形态**——同 crate 内引用与字符串字面量内容；跨 crate 方向由 cargo 依赖图与 `Cargo.toml` 声明面核对承担（`use … as` 别名改写对文本不可达，但编译期逃不掉，不属兜底面）。
- fail loud：白名单路径缺失、条目内扫不到非测试 Rust 文件、发现反向依赖，均非零退出并列出 `文件:行`。

### 5. 测试豁免约定

- **豁免** = 外挂测试模块与测试目录（`tests.rs` 文件、`tests/` 目录；先例：写入接缝的外挂测试目录）：BDD/单元 fixture 合法引用壳层入口（既有先例：BDD 直调命令层内部函数），不制造虚假违规。
- **不豁免** = 普通文件内的内联 `#[cfg(test)]` 模块：白名单内当前零壳层引用；内联测试若需引用壳层，应外挂为测试目录——豁免不以放宽主文件约束为代价。

## 备选方案与否决理由

- **维持现状 + 注释自律**：目录形状三态并存、反向依赖无机器信号；否决。
- **黑名单式守门**：默认放行新代码，把「已验证零依赖」变成「未拉黑」；白名单默认约束、每加一域追加一行，把事实固化为规格；否决黑名单。
- **编译期/依赖图工具（cargo-deny 类）**：当时模块级方向不是 crate 依赖图上的边，引入重依赖的成本高于文本扫描；crate 化后依赖方向已由 cargo 图编译期强制（ADR-0112）。

## 现状

- 各域已归位、壳层压平为单文件 `commands/<域>.rs`；基础设施白名单与两条模型禁令（ADR-0059 决策 6）随结构守门生效。逐域迁移见 git 历史与实施票（#395–#408），载体升级见 ADR-0112。
- 零影响面：schema、迁移文件、IPC/HTTP 对外契约、命令注册清单不变。

## 修订注记（#1591 定案，2026-09-20）：守门数据分界——事实投影、政策显式、cargo 退役

决策 4 增加一条机制级判据「**事实有权威源就投影，政策无源就显式**」，并据此收缩守门承载面：

- **事实投影**：手写模块清单整体退役——expected 改由各 crate `lib.rs` 的 `mod` 声明投影（磁盘上的孤儿模块文件/目录仍照红）；清单条目注记迁居 crate `lib.rs` 的 `//!` 与模块文件头（ADR-0113 决策 5，升为注记唯一作者位），守门报错文案从插值注记改为**规则级** ADR/issue 指针（指针住规则里，不随条目数增长）。`WHITELIST` 不投影——它是「已验证对壳层零依赖」的政策条目表，不是模块全册登记。
- **政策显式**：layer、允许依赖方向、方向禁令、infra→域认许边继续显式声明，只换载体（layer 收口到 ADR-0112 的 `CRATES` 政策核）。
- **cargo 退役**：违规必然成环或必然编不过的源码文本扫描退役给编译期拒绝；「可声明但禁止」的方向按 `Cargo.toml` 声明面判定。
- **不改**：白名单即规格的机制哲学、测试豁免约定（决策 5）、fail loud 纪律（非零退出 + `文件:行`）全部不变；决策 1–3 按原文保留作历史。

实施拆票与逐族退役清单见 #1591 定案评论与 #1593–#1597；`mod` 扫描的形状判定表（`#[cfg(test)]` 豁免、feature 门与非 pub `mod` 计入、`#[path]` / `include!` / 认不出的形状 fail loud）随实施同址留痕。
