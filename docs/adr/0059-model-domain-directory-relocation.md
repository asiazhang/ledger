# ADR-0059: 模型域化——全局模型目录随域归位（修订 ADR-0056 模型定性）

- 状态：已接受
- 日期：2026-09-03
- 作者：Ledger 项目
- 关联：spec #417；逐域系列 #418（T1 样板）→ #419/#420/#421/#422/#423（T2–T6）→ #424（T7 守门收口）；修订对象 ADR-0056（其决策 1 将 `models/` 列为基础设施）；现役先例行情同步域 `sync::model`（#407/#417 归属裁决）；检查点纪律沿用 ADR-0056 阶段 1

## 背景

ADR-0056 完成后，13 个域目录已全部归位，但全局模型目录仍以基础设施名义挂在天花板上：`pub use *` 扁平再导出让全项目随手以 `crate::models::*` 引用任何域的类型，「这个类型归哪个域拥有」在目录上完全不可见，类型所有权靠记忆与试错。且该目录已不满足基础设施「无域语义」的定义——交易模型文件今天就在消费交易域的金额矩阵与写入接缝。每新增一处跨域引用，边界就模糊一分，没有人能说出「这样引用是否越界」。本 ADR 修订 ADR-0056 对模型目录的定性，记录动机、归属原则、目标形状、逐域路线与守门计划；spec 见 #417。

## 决策

### 1. 定性修订与文档同步

推翻 ADR-0056 将模型目录列为基础设施的判定：模型类型不是无域语义的基础设施，归各自拥有它的域。ADR-0056 正文不重写，状态区加修订注记；仓库级指导（AGENTS.md）基础设施清单删去「模型」；本文是模型域化的唯一决策来源。

### 2. 归属原则

类型归拥有它的域，消费方走域路径显式 import（域间横向消费允许且是既有事实，与 ADR-0056 依赖方向一致）；**实体归属优先于当前消费方分布**。第一个先例：汇率实体（ExchangeRate/ExchangeRateInput）随币种参考数据域走——`exchange_rates` 以 base/quote 双外键挂在 `currencies` 上，是币种参考数据的从属实体；投资域是汇率的消费方与录入入口，改走域路径消费。不建共享模型残留模块：使用矩阵证实无公共抽象——同步字段为字段级重复、无公共分页信封、金额即裸整数分。

### 3. 目标形状

每域一个 `model.rs`（现役先例：行情同步域 `sync::model`）；域内主题模块不散放类型定义；域 model 只允许**逐类型 re-export，禁止 glob**——所有权必须逐类型可见。财务自由度类型并入投资域模型、经投资域接缝再导出（既有裁决：自由度归投资域）。基金行情 DTO 归属投资域、迁入投资域集中模型 `investment::model`（修订注记，#422：初版本文随行情同步域迁入 `sync::model`（#407）；Q11 事实修正——DTO 虽有一个录入入口在行情同步壳，但被投资域引擎自身消费，经用户确认域归属投资，行情同步域转为消费方，同步控制三类型仍留驻 `sync::model`）。

### 4. 逐域路线（迷你系列，一域一提交）

币种（+汇率）#418（T1 样板）→ 商户/分类/账户 #419（T2，含 `db::balance` 读模型改消费账户域类型、「基础设施→域类型消费」允许边落地）→ 保单/预算/物品 #420（T3）→ 报表/仪表盘读模型 #421（T4）→ 投资域全量（财务自由度并入）#422（T5）→ 核心交易收尾 #423（T6）→ 守门收口 #424（T7：全局模型目录消亡、残留/glob 禁令生效、契约终局 diff 复验、ADR-0056/0059 状态对账注记）。T1 完成即**检查点**：以真实成本对照预期复盘，放行 T2–T6（复用 ADR-0056 检查点纪律，真实收益证据先行、不放大沉没成本）；词汇表地图的结构句子待全系列迁完后同步。

### 5. 基础设施边：「基础设施→域类型消费」认许为允许边

余额计算引擎留驻基础设施单点（#404 既定裁决不翻案），改消费账户域类型。基础设施消费域类型认许为允许边——先例：余额计算已消费核心交易域金额矩阵；域语义随类型属主走，基础设施只消费不定义。结构守门维持只禁「依赖壳」一个方向，其余方向仍靠评审。

### 6. 守门计划（T7 收口提交落地）

结构守门新增两条文本级扫描，沿用既有「文本级扫描 + fail loud」形态（先例：命令注册双向全等检查、i18n key 全等检查、0056 白名单守门）：① **全局模型模块路径残留禁令**——已迁类型不得再经全局命名空间引用，防扁平命名空间以新形式复活；② **域内模型文件 glob 再导出禁令**——域 model 只许逐类型 re-export。全局模型目录白名单行随目录消亡删除（此后目录缺失即红，清单漂移 fail loud）。外挂测试（`tests.rs` 文件、`tests/` 目录）继续 ADR-0056 决策 5 豁免：跨域类型消费在测试中合法，不因守门扩展假阳性。

**T7 收口对账（#424 落地）**：全局模型目录与统一入口已删除、白名单行已删；两条禁令生效并对全树绿——① `crate::models` / `tauri_app_lib::models` 路径残留即红（全树扫描，外挂测试同样豁免）；② 域接缝 `pub use …model(s)::*`、跨域拍平及域模型文件（model.rs / models.rs）内 `pub use …::*` 聚合即红；域内私有 `use …model::*` 引入属消费非再导出，不在禁内。定时计划域既有 `pub use models::*` 为全树唯一违例，随禁令逐类型化（纯再导出形态改写，消费面零变化）。OpenAPI 契约终局 diff 为空（13 paths / 22 schemas，逐字节一致），目录消亡对外零影响。

### 7. 契约验收与迁移纪律

迁移前抓取 OpenAPI 机器可读契约端点 JSON 存基线，收口后 diff 必须为空——serde 属性与 utoipa 组件名随类型走、不依赖模块路径，diff 把「理论不变」变成「验证不变」。每域纪律：整文件移动优先（历史可跟随）、纯移动 + 引用改写零语义变化、每步一键质量门槛（含结构守门）全绿 + 既有测试面（BDD/API 集成/单测）全绿。零行为变化的纯移动**不新增行为测试**——搬家的正确性由机器核对承载（编译器 + clippy、质量门槛、契约 diff、既有测试面），行为测试只会复制实现细节。

## 后果

- **类型所有权回到目录上**：「这个域拥有什么类型」一次命中；跨域耦合在 import 与 diff 里可见、可评审；修改某域时上下文只装该域文件。
- **历史可追溯分工**：ADR-0056 正文保持原样（当时的决策与记录），其状态注记与本文（及 T7 对账注记）共同承载修订脉络——不重写历史，只注记修订。
- **零影响面**：schema、迁移、IPC/HTTP 对外契约、命令注册清单全部不变；前端手写镜像类型零改动；「已发布 API 只增不改」约定不受影响，无需 CHANGELOG 条目。
- **过渡期双轨**：T1–T6 期间全局目录仍承载未迁域类型，全局命名空间逐域缩窄；T7 后目录消亡、两条禁令生效，模型路径只剩域路径一种形态。
