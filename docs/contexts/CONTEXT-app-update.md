# 领域词汇表：应用更新

> Ledger 领域词汇表的应用更新分域。全部分域与彼此关系见 `CONTEXT-MAP.md`；决策记录见 `docs/adr/`（ADR-0124）。
> 跨域术语不复制定义：更新前备份见备份与数据文件域 `CONTEXT-backup-datafiles.md`；轻量设置项见参考数据与设置域 `CONTEXT-reference-settings.md`；桌面专属管理动作与弹层编排见界面状态与交互域 `CONTEXT-ui-interaction.md`。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## 自动更新（Auto Update）

- **定义**：客户端发现新版本并完成下载、安装的应用自身升级机制（ADR-0124）。更新单元是应用整体，一次更新同时带上前端与后端的全部变更。
- **边界**：
  - 平台范围：桌面三平台（macOS、Windows、Linux AppImage）；deb 与 Android 无更新工件，更新入口降级为打开发布页引导，不冒充可自更新。
  - 交互为全询问式：提示 → 用户确认 → 下载（带进度）→ 确认后安装重启；永不静默下载、永不静默安装。
  - 无强制升级门槛：不阻止旧版本继续使用，兼容性警告经更新清单的发布说明告知（ADR-0124 决策 5）。
  - 单 stable 通道，无多通道。
  - 归壳层机制：不持账本语义，不进基础设施、不立业务域 crate 与壳内域目录（ADR-0111 归位判据）；检查入口按桌面专属管理动作对待（界面状态与交互域）。
  - 与备份域相邻：安装前自动创建更新前备份（见备份与数据文件域）；与多端同步域无交叉——更新分发应用本体，不分发账本数据。
- **别名**：不使用「自动升级」（定名裁决见 ADR-0124，易与付费升级混淆）、「OTA」（偏移动/固件语境）、「在线更新」。

## 更新检查（Update Check）

- **定义**：客户端向更新源查询是否有更新版本的动作；触发分两种——启动后延迟静默检查与设置页手动检查（ADR-0124）。
- **边界**：
  - 后台（启动延迟）检查失败静默，不打扰；手动检查失败就地报错（用户可见错误经码化错误与本地化，见核心交易域错误码）。
  - 每个新版本至多自动提醒一次：发现新版本的提醒弹层展示后记录「已提醒版本」，同版本后续启动不再自动弹层；设置页手动检查不受该记忆限制。
  - 自动检查开关与「已提醒版本」记忆都是设备本机偏好（轻量设置项，见参考数据与设置域），不随 Backup/Restore 迁移、不进账本数据、不经同步分发。
- **别名**：不使用「检查升级」「检查版本」。

## 更新清单（Update Manifest）

- **定义**：更新源上的机器可读清单文件（latest.json），声明最新版本号、发布说明与各平台更新工件的下载地址及更新签名（ADR-0124）。
- **边界**：
  - 托管于 GitHub Releases，发布流程在 publish 阶段生成并上传；静态清单，无动态服务。
  - 兼容性警告写入发布说明字段，随提醒弹层展示。
  - 端点以数组配置、按序尝试，为镜像 fallback 预留扩展位。
- **别名**：不使用「版本清单」「更新配置」。

## 更新工件（Updater Artifact）

- **定义**：更新器可消费、随更新清单分发的各平台产物——macOS 的 .app.tar.gz、Windows 的 NSIS 安装器、Linux 的 AppImage（ADR-0124）。
- **边界**：
  - 与发布页安装包的关系按平台而异：NSIS 安装器与 AppImage 既是安装包也是更新工件；macOS 更新工件（.app.tar.gz）不等于 DMG 安装包，DMG 仅用于首次安装。
  - 每个更新工件附更新签名；无签名的工件不被更新器接受。
  - deb 与 Android 无更新工件。
- **别名**：不使用「增量包」（更新为整包替换，非增量 diff）、「补丁」。

## 更新签名（Update Signature）

- **定义**：对更新工件离线签名的 minisign 式签名；更新器凭烧入客户端的公钥验签通过才会安装（ADR-0124）。
- **边界**：
  - 与平台代码签名（macOS 签名与公证、Android APK 签名）正交：更新签名证明「更新来自发布者」，平台签名证明「二进制可在平台安全运行」；更新器只验前者。
  - 公钥随应用发行，已发行客户端无法更换公钥——私钥保管（CI secrets ＋ 离线备份）是长期承诺，泄漏即需重建信任链。
- **别名**：不使用「代码签名」（那是平台签名的语义）、「校验和」（验签不是哈希比对）。
