# 领域词汇表：预算

> Ledger 领域词汇表的预算分域（单列小域）。全部分域与彼此关系见 `CONTEXT-MAP.md`；决策记录见 `docs/adr/`（ADR-0029 永久滚动预算）。
> 跨域共享术语（Transaction、Amount Model、Transaction Kind Mapping、Category 等）见核心交易域 `CONTEXT-core.md`，本文不复制定义；spent 口径引用核心交易域 Amount Model，不在此重复。

## Budget（预算）

- **定义**：用户对某一**支出分类**设定的周期性支出上限，一经设置**永久滚动**生效（ADR-0029）——不设起止日期、不逐期排程，进度窗口永远是「当前自然周期」（见 BudgetPeriod 与 BudgetProgress）。表 `budgets`。
- **边界**：
  - **「分类 + 周期」唯一**：同分类同周期仅允许一条未删除预算；重复创建明确拒绝并引导编辑已有预算，**不静默覆盖**（写入行为细节见 ADR-0029 决策 4）；软删后可重新创建。
  - **只能挂支出分类**：收入分类与不存在的分类均被拒绝（注意：`categories.kind` 闭集仅 `income | expense`，与 BudgetPeriod 是两个无关概念）。
  - **金额为正数**：整数分存储，0 或负数拒绝。
  - **编辑仅允许改金额**：分类/周期不可改，改法为删旧建新；金额与支出分类校验复用创建侧逻辑，沿用与软删除一致的通用更新机制。
  - **`start_date` 为冻结残留**：已发布 schema 只增不改（该列自 v0.1.0 初始 schema 即存在），列保留但不参与任何计算，仅创建时记录用途；UI 无日期选择器、列表无「开始日期」列（ADR-0029）。
  - 分类删除受限：分类自身名下存在**未删除预算**时拒绝删除，中文文案引导先删对应预算；仅剩已删除预算不阻拦；只查分类自身名下，删父分类不检查其子分类名下预算（与「删除只影响该分类自身」边界一致，见核心交易域 Category）。
- **别名**：不使用「限额」「月度计划」（「计划」与定时计划域 ScheduledTransaction 混淆）。

## BudgetPeriod（预算周期）

- **定义**：预算的周期粒度，**闭集二值**：`monthly`（按月）/ `yearly`（按年），未知值拒绝。
- **边界**：
  - 周期**决定进度窗口**：`monthly` = 今天所在自然月，`yearly` = 今天所在自然年（见 BudgetProgress）；窗口随时间自动滚动，无需任何用户操作（永久滚动，ADR-0029）。
  - 周期参与「分类 + 周期」唯一性约束：同一分类可同时各设一条月预算与年预算。
  - **不可编辑**：创建后周期不可改，改法为删旧建新（见 Budget）。
- **别名**：不使用「频率」（与定时计划域 Recurrence Rule 的周期语义划清边界——预算周期只是窗口粒度，不驱动任何事件触发）。

## BudgetProgress（预算进度）

- **定义**：某 Budget 在**当前自然周期窗口**内的消耗情况，输出预算行（附分类名）+ 消耗金额 + 超支判断；由预算进度命令实时计算，不持久化。
- **边界**：
  - **spent 口径 = 核心交易域 Amount Model 的 `ExpenseNet` 度量**（见 Transaction Kind Mapping）：与报表分类净值同口径，不另造第二个口径；投资类 kind（buy/sell 等）不参与。
  - **统计范围含子分类**：子分类支出并入父分类预算统计。
  - **窗口与 `start_date` 无关**：窗口由命令层注入的本地「今天」推导——`monthly` = 今天所在自然月，`yearly` = 今天所在自然年；随时间自动滚动，存量旧日期预算行零迁移生效（ADR-0029）。
  - **退款冲减消耗**：窗口内退款使消耗回落，甚至可为负（当期退款多于当期支出，如原支出发生在上期）。
  - **超支判断**：窗口内消耗金额超过预算上限即超支。
  - 首页预算进度卡与预算页复用同一命令，零改动自动跟随滚动窗口。
- **别名**：不使用「使用率」「消耗率」（本域只输出金额差值判断，不输出百分比口径）。

## AnnualBudgetTotal（年度预算总额）

- **定义**：全部未删除预算按当前节奏年化的支出水平（默认币种单币种口径）= Σ 月度预算 × 12 + Σ 年度预算——投资域财务自由度（FinancialFreedom）的分母（ADR-0048）。
- **边界**：
  - **无窗口、不滚动**：与 BudgetProgress 的「当前自然周期」滚动窗口显式划界——本口径不看任何时间窗，预算一存在即按周期粒度年化为持续的支出水平；`start_date` 冻结残留同样不参与。
  - **月度 × 12 是节奏年化而非实际统计**：只设月度预算也能得到完整的年度支出水平。
  - **不回退实际支出**：未设预算分类的实际开销不进分母——指标反映「计划中的开销节奏」，不受单月挥霍冲击；未设任何预算时总额为零，占位引导归展示层。
  - 预算金额本身即默认币种单币种口径，与折算后的分子同币种可直接相除；本词条是新增的跨域派生聚合，非 BudgetProgress 输出，不破坏预算域「只输出金额差值」既有边界。
- **别名**：不使用「年度预算支出」（易读成实际支出口径，与指标语义冲突）、「年化预算」。
