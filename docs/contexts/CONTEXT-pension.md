## 养老档案（PensionProfile）

- **定义**：单本账本内唯一的个人养老规划配置档案——记录参保现状、退休预期、基本养老金参数、个人养老储蓄配置、测算假设与目标开支基准，持久化于账本单例表 `pension_profile`（ADR-0146）。
- **边界**：
  - **每账本单人单例**：一账本至多一份养老档案，随账本备份与多端同步流转；多成员家庭与单人多方案对比不在当前范围内。
  - **只存原始输入与引用标识**：金额按核心域整数分落库；一切估算结果均为只读实时派生，不落库存储。
  - **草稿试算与显式保存分家**：页面调参经纯只读试算实时联动预览，不写库、不产同步日志；仅显式保存时落库并追加一条整档语义命令进多端同步重放注册表，避免拖参探索刷爆 OpLog。
  - **未建档空态**：新账本无档案记录时呈现引导空态（列明社保可查数据清单并明示仅为估算），不预填虚假样例数据冒充真实档案。
  - **界面称谓**：zh-CN 界面（侧栏主项与页面标题）统一称「养老规划」，落位资产组主栏、支持功能开关关闭。
- **别名**：不使用「养老管理」（暗示可操作缴费或赎回）、「退休方案」（易与多方案对比混淆）。

## 养老估算（PensionEstimate）

- **定义**：基于养老档案（或前端未保存草稿）与账本实时只读数据派生出的退休现金流评估结果——回答「退休后每个月预估能领多少钱、相当于现在多少购买力、够不够花」，由养老规划域单点实时计算、不落库（ADR-0146）。
- **边界**：
  - **仅覆盖中国内地城镇职工养老体系，固定 CNY 展示**：不作跨国社保抽象；个人侧绑定外币账本实体时按参考数据与设置域当期汇率折算 CNY 汇总。
  - **明示估算**：输出强依赖政策演进与宏观假设（社平增长率、记账利率、收益率、通胀率），文案始终明示估算性质，不伪装精确承诺；不做蒙特卡洛概率区间。
  - **三段叙事与双口径并列**：呈现「过去积累 → 退休时预估积累 → 退休后月领」三段全貌；退休后月领同时给出**名义月领**与按预期通胀率折现的**现值购买力**，并附来源拆解与参考对比（退休前预估月收入、退休时预计社平工资）。
  - **已达或已过退休年龄**：距退休年限不大于零时跳过未来续缴与通胀折现（名义值等于现值），按当前存量与累计年限直接估算即领水平；若设定退休年龄不小于预期寿命，提示调高预期寿命而非报错。
- **别名**：不使用「退休金计算器」「养老金计算器」（「计算器」暗示精确数值而非基于假设的估算）。

## 基本养老金（BasicPension）

- **定义**：中国内地城镇职工基本养老保险的预计月领取额——由基础养老金与个人账户养老金两腿构成，纯手工维护参保现状、绝不计入账本净资产（ADR-0146）。
- **边界**：
  - **仅支持城镇职工基本养老，通用两腿口径**：明确不支持城乡居民养老、企业年金 / 职业年金，亦不纳入 1997 年前视同缴费的过渡性养老金。
  - **2025 渐进式延迟退休与弹性覆盖**：内置 2025 渐进式延迟法定退休年龄、最低缴费年限（15–20 年）与国家标准计发月数规则作为默认推导，同时允许用户手动覆盖退休年龄（覆盖弹性提前 / 延迟场景）。
  - **输入分层**：主输入仅收社保渠道可直接查得的参保项（出生年月、性别 / 身份类别、累计缴费年限、个人账户当前余额、当前月缴费基数、当地当前社平工资与是否续缴开关），不内置易过时的城市社平死表；社平增长率、缴费基数增长率、记账利率与历史平均缴费指数等假设项折叠带默认值。
  - **未达法定最低缴费年限**：预计退休时累计缴费年限不足当年法定最低年限时，不静默产出可领假数——主结果中基本养老金计为 0 并显式警示缺少年限，同时附「延缴至满最低年限时」的参考月领。
  - **与净资产彻底隔离**：基本养老金储存额受退休锁定、不可自由支取，不建模为账本账户，不进入净资产与可投资资产口径。
- **别名**：不使用「社保余额」（个人账户余额仅是输入之一，不是月领口径）、「统筹养老金」（仅指基础养老金一腿）。

## 个人养老储蓄（PersonalPensionSavings）

- **定义**：除基本养老金外，用户为养老自主准备的个人储备及其退休后按月摊领测算——可涵盖个人养老金账户、养老基金、股票定投、专项储蓄等任意自有养老渠道，以既有存量、退休前持续存入与预期年化收益率推演退休时规模，并按预期寿命等额摊领为月领现金流（ADR-0146）。
- **边界**：
  - **通用自有口径、无政策特例包袱**：不设国家第三支柱 12,000 元/年缴存硬上限，不扣 3% 领取个税，不测算缴存期个税抵扣；用户若纳入个人养老金专户资金，按实际余额直接计入即可。
  - **三互斥来源模式（杜绝重复计数）**：
    - **手工模式**：手填既有储蓄与退休前持续存入。
    - **组合绑定模式（多选）**：自由勾选多个任意币种的账本账户与/或多个储蓄目标累加作为既有储蓄；账户候选自动排除储蓄目标专属账户，防止同一目标资金被双计；未来持续存入默认汇总所选储蓄目标的关联月存节奏（见储蓄目标域蓄水进度），亦允许手填覆盖。
    - **全账可投资资产模式**：只读引用投资域可投资资产（InvestableAssets）作为既有储蓄，因已涵盖全部投资账户而与组合绑定互斥；未来持续存入手填。
  - **多币种与投资账户取数口径**：非投资账户取账户余额；投资类型账户取「账户现金余额 + 该账户持仓市值」（与投资域可投资资产两腿口径同源，缺价持仓跳过并显式标注未计入数）；全部外币金额按当期汇率折算为 CNY，缺到 CNY 的汇率时按码化错误提示、不静默以零计入。
  - **预期寿命等额摊领**：按设定预期寿命与退休后保守年化收益率做等额年金月领（确保资金平滑覆盖整个退休期，避免直除计发月数导致高龄断崖）。
  - **绑定实体退化**：关联账户或储蓄目标处于归档态时照常读取并附轻提示；已被软删时该项贡献回退为 0 并在界面显式标红警告，不阻塞整页估算。
- **别名**：不使用「第三支柱」「个人养老金专户」（后者特指受 1.2 万上限与 3% 领取税约束的国家制度账户，范围窄于本词条）、「企业年金」。

## 退休替代率（ReplacementRate）

- **定义**：退休后预估月养老金占退休前预估月收入的比率——用于衡量退休后生活水平相对退休前的维持程度，并同时对比「仅基本养老金」与「加上个人养老储蓄后」两档变化（ADR-0146）。
- **边界**：
  - **三档生活水平刻度**：以 55% 与 70% 为界面刻度分界（低于 55% 为开支缩减、55% 至 70% 为基本平衡、70% 及以上为开支宽裕）；分档标签归展示层，后端仅输出比率口径。
  - **缺分母不虚构**：未填写退休前月收入基准时，替代率与生活水平刻度缺席，不回退为社平工资或零分母。
  - **同口径相除**：分子与分母均在同一时点（退休时名义口径或同等折现后的现值口径）相比，避免跨通胀时点错位失真。
- **别名**：不使用「财务自由度」（后者以可投资资产 3% 提取率对年度预算为口径，属投资域 FinancialFreedom，与本词条分属不同问题）。

## 养老缺口（PensionGap）

- **定义**：按现值口径衡量，用户设定的目标退休月开支与退休后预估月养老金（现值购买力）之间的差额——正值表示月度缺口，负值或零表示覆盖充裕（ADR-0146）。
- **边界**：
  - **可选增强**：仅当用户填写了目标退休月开支（现值）时派生；开支基准可手填，亦可从预算域年度预算总额折月（年预算 ÷ 12）一键抄入作为初始参考（单次填充，不强绑定）。
  - **与储蓄目标的单向衔接**：存在月度缺口时，推算对应的退休储备缺口提示，并提供一键跳转储蓄目标域新建目标的引导；引导是单向入口，不反向改写既有储蓄目标。
- **别名**：不使用「必存金额」（缺口反映假设下的参考差额，非强制义务）。
