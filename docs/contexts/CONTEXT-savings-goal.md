# 领域词汇表：储蓄目标

> Ledger 领域词汇表的储蓄目标分域（单列小域）。全部分域与彼此关系见 `CONTEXT-MAP.md`；决策记录见 `docs/adr/`（ADR-0133 虚拟账户本体与类型落位）。
> 跨域共享术语（Transaction、Amount Model、BalanceAdjustment 等）见核心交易域 `CONTEXT-core.md`，ScheduledTransfer / Occurrence 见定时计划域 `CONTEXT-scheduled-plans.md`，本文不复制定义。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## 储蓄目标（SavingsGoal）

- **定义**：用户为特定用途（购车、教育金、养老等）设定的资金蓄水目标——目标金额 + 可选截止日 + 状态。蓄水动作是真实流水、进度是真实余额（ADR-0133）。
- **边界**：
  - **1 目标 : 1 专属账户**：创建目标即自动创建其专属账户，不可手造无主目标账户；目标经绑定持有账户身份（见目标账户）。
  - **与预算划界**：预算管「花」（支出上限），储蓄目标管「攒」（蓄水），两域独立、互不扣减（见预算域 Budget）。
  - **与定时计划划界**：定时转账计划是流水模板，储蓄目标是资金口径——目标域零新写入路径，存取全部落核心交易域既有 kind（见目标账户）。
  - **目标金额为正数**：整数分存储；币种即专属账户币种，单币种、目标域不消费汇率。
  - **截止日可选**：无截止日正推预计达成时间，有截止日反推所需月存。
- **别名**：不使用「心愿」「心愿单」（购物清单语义，非本域本体）、「理财目标」（偏金融产品）、「存钱计划」（「计划」与定时计划域混淆）。

## 目标账户

- **定义**：承载储蓄目标资金的专属账户——参考数据层的 `other` 类型账户，目标域经绑定持有其身份；特殊性不靠账户类型值表达，与黑洞账户同款先例（ADR-0133）。
- **边界**：
  - **蓄水 = 转入、取出 = 支出**：全部是真实 `transfer` / `expense` 流水，天然参与余额缓存、涉及账户过滤、交易搜索等既有口径，无任何特殊路径；月存节奏可由定时转账计划（ScheduledTransfer）驱动，也可手动零星存入。
  - **计入净资产**：transfer 零和，蓄水不改变净资产；取出花掉如实下降（与借贷域「净资产守恒」同一哲学）。
  - **余额即进度**：期初已有存款经余额调整（BalanceAdjustment）校正，不造「初始蓄水」新概念。
  - **删除受限**：名下目标在用即禁删（守卫经壳层编排，账户域不反向依赖目标域）；删目标且余额为零时级联软删专属账户，流水保留可查。
  - **出资准入**：不作为 buy/sell 结算账户候选——前端候选下拉按绑定过滤；v1 后端准入不拦（钱出池、进度如实回落，语义自洽），硬守卫立票观察（ADR-0133）。
  - **借贷对端不特判**：借入资金直存目标池自然成立——transfer、进度上涨、净资产零和全正确。
- **别名**：不使用「心理账户」「虚拟账户」（口语可延，术语表不收）、「信封」（envelope 预算术语，本域非信封模型）。

## 蓄水进度

- **定义**：储蓄目标在当前时点的积累情况——专属账户余额对目标金额的表达，由目标域读命令实时计算、不持久化（比照预算域 BudgetProgress 形态）。
- **边界**：
  - **进度 = 余额**：取出使进度自动回落，无「扣回进度」特殊语义；利息等真实流入自然计入。
  - **只输出金额与月数**：差值、剩余月数、落后 / 超前的差值判断；不输出百分比口径（比照预算域「只输出金额差值判断」边界）。
  - **节奏来源闭集二值**：关联定时转账计划的每期金额，或目标上手填的「计划月存」；实际流入的滚动平均可作页面参考值，不作推算依据（被漏记与一次大额存入扭曲）。
  - **关联计划查找读口径单点**（#1753）：「某目标的关联计划」= 指向目标专属账户的在用定时转账计划（`scheduled_transfer_plans.to_account_id` = 专属账户、`status='active'`、未软删），按周期折算月存（月 ×1 / 年 ÷12 / 周 ×52÷12 / 日 ×30、间隔均摊，订阅花费先例同款系数与舍入）逐计划折算求和；读口径单点住储蓄目标域 `pace` 模块，后续消费关联计划的读面同源复用。
- **别名**：不使用「完成度」「百分比进度」。

## 预计达成时间（ETA）

- **定义**：无截止日目标按当前节奏正推的达成时点——「还差 N 个月 / 预计某年月」，蓄水进度的推算方向之一。
- **边界**：纯目标参数算术（已存、目标额、节奏、今天），不做利率与复利假设；节奏为零（无计划且未手填）时不推算，给引导而非虚构时点。
- **别名**：不使用「预测完成日期」（「预测」暗示统计模型，实为纯参数算术）。

## 所需月存

- **定义**：有截止日目标反推的「每月需存金额」，与当前节奏比较输出落后 / 超前差值；蓄水进度的另一推算方向。
- **边界**：与预计达成时间共享同一组输入（已存、目标额、截止日、今天），两方向是同一算术的正反两面，不分两套口径。
- **别名**：不使用「每月应存」（「应」含义务语义）。

## 达成与归档

- **定义**：目标生命周期的展示态与收纳态——余额达到目标金额即为达成（纯展示态），用户可归档（达成后或放弃后）使其退出默认列表。
- **边界**：
  - **达成不触发任何自动动作**：不自动暂停关联计划、不自动记支出；关联计划仍在执行时目标页给提示、由用户处理（两域边界：目标域不改定时计划域状态）。
  - **归档不删任何东西**：账户、流水、历史进度原样保留，归档目标可查；删除目标是独立动作，受目标账户删除守卫约束（见目标账户）。
- **别名**：不使用「关闭」「完结」（暗示连带清算）。

## 养老测算

- **定义**：养老目标的辅助测算器（第二期交付）：输入当前社保参保情况，按城镇职工基本养老保险公式估算预计月养老金；与蓄水进度正交，唯一接触面是「目标金额的来源」可升级为缺口回填。
- **边界**：
  - **仅支持城镇职工基本养老**：城乡居民养老是另一套体系，明示不支持；企业年金 / 个人养老金不计入基本养老金口径。
  - **输入分层**：默认只问参保可查项（出生日期、性别 / 身份类别、累计缴费年限、个人账户储存额、当前缴费基数）；假设项（计发基数增长率、记账利率、弹性退休）折叠带默认值。
  - **明示估算**：输出随政策与假设浮动，文案不伪装精确；敏感性分析不在范围内。
  - **按缺口设目标是可选增强**：补期望退休后月开支，差额折算目标额一键回填、随时可手改——回填是引导不是权威。
- **别名**：不使用「退休金计算器」（「计算器」暗示精确）。
