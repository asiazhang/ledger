# 领域词汇表：界面状态与交互

> Ledger 领域词汇表的界面状态与交互分域。全部分域与彼此关系见 `CONTEXT-MAP.md`；决策记录见 `docs/adr/`（ADR-0035 等）。
> 本域是纯界面层概念：不持业务数据，只读消费各域（交易搜索复用核心交易域列表信息，但搜索词不持久化；下拉拼音过滤复用统一模糊搜索语义规格，见核心交易域 TransactionSearch）。
> 跨域共享术语见核心交易域 `CONTEXT-core.md`，本文不复制定义。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## TransactionFilter（交易列表过滤模块）

- **定义**：交易列表视图的过滤状态机——「用户意图进、列表状态出」的深模块（工厂形态 composable，ADR-0030）：接收过滤意图，内化 URL 下钻解析、参考数据就绪补判、首刷时序、复位规则与统一出口，产出可观察的过滤状态与刷新版本号，驱动列表请求。
- **边界**：
  - **过滤意图**：调用方声明的语义请求，四个入口（页码回退入口另列于下，全模块共五入口）——部分修改过滤维度（立即生效：翻页归零 + 刷新）、回默认态、外部数据变化（重拉 + 翻回第一页，不动筛选）、转发最新路由查询（URL 下钻只读入口，视图只监听路由并转发，不持解析逻辑与时序标志）。四者共用同一内部出口，「翻页归零 + 刷新」全仓仅此一处。
  - **页码回退入口（ADR-0045）**：删除当前页最后一条后的页码回退——调用方声明「本页删后剩 N 条」，`N 为 0 且当前页非第一页`时减一页，然后一律版本 bump（保持当前页、不翻回第一页）；「翻页归零」仍是唯一出口，「回退不归零」是新增显式入口，删除路径不再直写页码。
  - **补判（URL 参数延迟应用）**：URL 下钻参数（账户/商户/分类/日期边界，收成一张参数表）在参考数据未就绪时挂起（不先行误清维度，不像旧实现先误判回退再重应用），就绪后一次性校验应用；参数至多消费一次（无论应用还是让位），后续参考数据重拉不重放。
  - **让位（字段级手动改动优先）**：补判遇用户已手动改动**同一维度**则让位，其他维度不受牵连。
  - URL **只读不写回**（组件状态是唯一事实源，延续 #96 决策 3/4）；下钻进入且所有下钻维度均无有效参数时复位日期/类型，query 变化（含导航清除）时对应维度同步清空。
  - **分类维度（issue #377）**：URL 分类参数携带合法分类 id → 按该分类**精确过滤**（不含子分类）；携带保留值 → 「仅无分类」（哨兵态，三态过滤：不过滤/精确/仅无分类）；非法/未知值回退不过滤（参数视为不在场，不误清其他维度）。校验映射含**软删分类**（历史交易口径，先例商户）；分类维度仅作 URL 下钻只读入口，列表页不设手动分类筛选控件。
  - **日期边界维度（issue #380）**：URL 日期参数成对携带起止日，按日历形状校验（月/日限定在可能范围；非法视为不在场，回退不过滤）——无参考数据映射、不涉保留值，挂起补判/让位/复位守卫同规。消费方是报表分类下钻跳转：以此携带所选期间首尾日期（见「分类下钻」跳转段）。
  - 筛选与分页不持久化（与 ViewState 边界一致）；分页参数归模块所有，请求发起与列表数据仍归视图（分页契约见 ADR-0008）；模块内部消费 Reference Data store 的就绪状态（见参考数据与设置域 Reference Data），不向调用方暴露就绪通知接口。
  - 消费方目前仅交易列表视图；搜索页（核心域 TransactionSearch）维度不相交，等第二个消费者出现再谈共用。
- **别名**：不使用「筛选状态机」（实现描述非术语）、「过滤器组件」（它是逻辑模块，不是 UI 组件）。

## 数据期间边界（Data Period Boundary）

- **定义**：交易数据可供期间筛选共同消费的闭区间口径；按月、季、年分别派生，统一回答「哪些自然期间应当可选」而不持有界面选择状态。
- **边界**：
  - **唯一公式**：`[min(最早交易期间, 当前期间), max(当前期间, 最新交易期间)]`；空库回退为仅当前期间。当前期间保证用户始终能回到今天，未来交易则把上界推迟到最新交易所在期间。
  - **输入专名**：日期极值接口 `report_date_range` 提供交易日期对；日期对本身不携带月、季、年粒度，三档期间边界均由本口径派生。
  - **消费方**：时间范围快捷选择消费各粒度边界，约束期间步进器与期间直达面板（交易页与报表页同规；报表页月/季/年三档粒度各消费对应档边界）。
  - **历史注记（由报表年份筛选上移）**：早期报表年份筛选曾使用围绕已选年份 ±2 的滑动窗口；窗口随选中值移动，跳到远处年份需连点多年。现改为数据期间边界的年档全量闭区间，历史年份可一击直达。
- **别名**：不使用「数据范围」（可能指任意查询区间）；正式术语为数据期间边界。

## 时间范围快捷选择（Quick Time Range）

- **定义**：时间维度快捷过滤的共享交互——单选分段日期芯片＋尾部常驻期间步进器（< 期间标签 >）＋点击期间标签打开的期间直达面板；各消费页以它为自身时间筛选状态的触发方式集合，选择交互受控不持状态源，不引入第二状态源（交易页唯一事实源仍是 TransactionFilter 日期维度，报表页唯一事实源是其会话状态 store 的期间快照，issue #427）。
- **消费形态二**：
  - **交易页（全闭集）**：芯片（全部 | 当月 | 当季 | 当年 | 去年）五枚，「全部」= 无日期过滤 = 默认态。
  - **报表页（日期闭集）**：仅当月/当季/当年/去年四枚日期芯片，无「全部」——期间必有界，报表不存在「无期间的结构图」；三张报表卡（月度收支/分类构成/商户排行）随所选期间重算，月度收支卡统一「期间内按月分布」口径（年 = 12 柱、季 = 3 柱、月 = 单组柱如实展示）；冷启动默认「当年」，会话内离开再回来保留离开时的期间（会话内保留，ADR-0061）。原年份下拉（报表年份筛选，已退役）的任意年份一击直达能力由期间步进器与期间直达面板继承。
- **语义**：
  - **闭集**：芯片只收「关账回顾」单位——当月/当季/当年/去年四枚日期芯片为基础，交易页形态另含「全部」（无日期过滤 = 默认态），报表页形态期间必有界、不含「全部」；上月/上季等长尾经期间步进器或期间直达面板到达，不设芯片。未来扩预设只往闭集加枚举。
  - **快照语义**：芯片、步进器与期间直达面板只把精确的自然周期边界（YYYY-MM-DD、含边界）写入日期维度，写入后即为快照——跨月/季/年后区间不漂移，仅芯片高亮（当前区间恰为某预设定义、相对「今天」的自然周期时点亮）随时间推移自然熄灭，列表永不被静默换数据。
  - **游标派生**：期间步进器不落任何状态——步进前从当前日期区间唯一反推（单位，期间），±1 步进后换算回区间写回快照；自然月/季/年跨度互不相同保证反推唯一。「全部」无区间可反推 → 步进器置灰，但期间标签仍可打开直达面板，默认按月选择。
  - **钳制于数据期间边界**：期间步进器与期间直达面板统一受数据期间边界约束；边界外的步进方向置灰，面板中的期间不可选。边界在途或失败时暂退化为不钳制，不阻塞快捷选择。
  - **不持久化**：快捷选择、步进位置与面板选择不持久化（与 ViewState 边界一致）；交易页 URL 下钻复位日期后自然回「全部」，报表页冷启动回默认「当年」、会话内离开再回来保留离开时的期间（会话内保留，ADR-0061）。
- **边界**：各消费页均不提供任意起止区间（搜索页保留该能力作为唯一退路）；周期边界按本地时区日历（自然月 / 自然季度 / 自然年，「去年」= 当前年减一的完整自然年）；芯片文案与期间标签随界面语言，标签格式（如「2026年2月」/「Feb 2026」）本地化；期间直达面板是非模态弹层，点外部或 ESC 即关闭；其打开与关闭归弹层注册表，打开期间纳入 Overlay Suppression；芯片与步进器本身不是弹层。
- **历史注记**：#383 原先规定期间步进器不钳制未来——可步进到无数据的未来期间，空列表是诚实行为；随着期间直达面板与数据期间边界落地，该语义已修订为统一钳制于数据期间边界，历史表述不再代表当前行为。词条立项时锚定交易页；报表页接入后去页锚定升为共享交互，年份下拉退役见「报表年份筛选」历史注记。
- **别名**：不使用「日期快捷筛选」「时间游标」（游标不落状态，非可持久化对象）、「月份跳转」（面板随当前浏览单位在月/季/年间切换，月份不是其唯一形态）。

## TransactionModalState（交易弹窗编排）

- **定义**：交易列表视图四个弹窗（记一笔、退款、编辑、加入物品）共享的开启/目标/关闭编排深模块（工厂形态 composable，ADR-0045）——意图闭集四，显示开关由「意图非空」派生（无独立显示开关），目标行与回调序号随开启递增内化，关闭清回空终态；「编辑需先取买卖明细再开窗、失败不开窗」的异步时序与慢取竞态守卫内化其中。产出可观察的意图终态，供视图判别渲染。
- **边界**：
  - **意图闭集四**：记一笔（无目标行，携带可创建类型子类型）、退款/编辑/加入物品（携带目标交易行，编辑另携带买卖明细）；显示开关由意图非空派生，关闭清回空终态，不存在「目标非空但已关闭」的中间态。
  - **异步时序内化**：编辑意图先取买卖明细再开窗，失败走错误提示不开窗；慢取竞态以「最后一次开启胜出」守卫，迟到的前次结果丢弃。
  - **只内化开启/目标/关闭编排，不内化关闭后的列表刷新**（翻回第一页或保持当前页仍归视图）：弹窗编排与交易列表过滤两个深模块正交，视图只做接线。
  - **不持任何业务数据**：目标行只是开启时传入的引用，非持久状态。
- **别名**：不使用「行操作弹窗」（记一笔非行操作，顶栏按钮与快捷键同入口）、「弹窗状态机」（实现描述非术语）。

## 字段错误态（Field Error State）

- **定义**：弹窗表单自由输入字段对**格式错误输入**的统一反馈态——非法输入不拦截、原样保留并即时红显，提交动作随之禁用；判定口径全仓单点（轻量共享模块收口，ADR-0058），各弹窗一致。
- **边界**：
  - 只覆盖**格式类错误**：解析失败（如金额 `4.30发`）、超出表示精度（如 `4.305`，金额以整数分表达）、必填为空；纯业务规则不成立（如金额纯零）不在其列，走既有提交时校验通道。
  - **即时判定**：输入中即判定即红；初始为空不红（不惩罚尚未输入），空值红在失焦或保存尝试时出现。
  - **不拦截、不静默丢弃**：允许自由键入与粘贴，非法性只由红态表达，不做字符过滤或吞键；非法输入原样保留显示，红态持续到用户修正（取代非法文本失焦即被静默清空的旧行为）。
  - 反馈形态为红框＋提交禁用，两件同发；字段错误文案按需后补（经既有 i18n 资源），不是本态的必要组成。
  - **两类红**：本态用交互反馈红（组件库内置错误色），与语义色（支出红等业务含义色，见参考数据与设置域 Appearance）是两类红，不混同。
  - **范围边界**：下拉类字段无输入面、日期选择由组件自身钳制键入，均不在本态范围；必填未选的统一红显留推广期裁决。
  - 首批落地交易弹窗族，逐步推广到全部含自由输入的弹窗表单。
- **别名**：不使用「输入过滤」（被否决的竞争方案：拦截键入与粘贴）、「表单校验」（含义过宽，本词条只锚格式错误的反馈态）。

## Loadable（异步任务）

- **定义**：前端异步任务的统一生命周期模块（工厂形态 composable，ADR-0040）——「发起动作进、终态出」：调用方以发起闭包声明任务，模块内化 loading 置收、错误捕获与文案归一、竞态裁决与错误展示，产出可观察的 loading/error 状态；「刷新」即再次发起。
- **边界**：
  - **错误展示策略单点**：默认策略为统一 toast 提示（文案经全仓统一归一转中文文本）；策略是模块内一处私有单点，全局改策略只碰一处，不设注入机制。toast 函数经模块级单点 sink 由应用入口在消息提供器内注册（测试注入假 sink），sink 与策略正交。
  - **error 状态与 toast 双通道共存**：error 是可观察状态（视图可自选渲染，如警告位/空态），toast 是默认动作，互不排斥；「既弹又入警示位」的双通道消费即此形态。
  - **不持任务结果**：发起返回值只承载成败——成功回结果、失败回空且 error 置位，error 是唯一成败判据；数据存取归调用方，发起永不向调用方抛错。
  - **不区分任务形态**：数据拉取与提交动作同一接口，差异全在调用方 UI 决策（失败后是空态还是表单留存）。
  - **首跑时序归调用方**：模块无生命周期钩子，只管单次任务生命周期；等参考数据就绪再首刷等时序语义属调用方（见参考数据与设置域 Reference Data）。
  - **竞态语义**：终态 = 最后一次发起的结果；迟到的前发结果一律丢弃，连其 loading 收尾一起作废。「进行中禁用按钮」是调用方 UI 决策。
  - **刻意静默不收编**：显式吞错的 fire-and-forget 刷新是合法形态，不迁入本模块。
- **别名**：不使用「异步任务模块/AsyncTask」（泛称动作本体，术语锚定状态本质）、不使用「useAsyncState」（VueUse 同名物，仓库未引入）。

## ScheduledPlanList（计划清单）

- **定义**：定时计划三业务形态（分期/订阅/定时转账，域概念见定时计划域 ScheduledTransaction）共享的清单编排深模块（工厂形态 composable，ADR-0041）——以计划形态为参数，内化清单加载与刷新、状态过滤、Plan Lifecycle 操作（暂停/恢复/取消）、行操作描述符与周期选项/周期标签，产出可观察的清单状态与动作；「定时」页三个页签是它的薄适配器，只留各自形态真差异（分期的期数预览与进度、转账的同币种约束与币种跟随、订阅的商户挂靠与花费面板）。
- **边界**：
  - **是 ScheduledTransaction 的清单视图概念，不是其别名**：计划清单指清单编排这一界面层模块；ScheduledTransaction 是定时计划域的协议/模板本体（其别名禁用「定时计划」），两者是「视图编排 ⟷ 域概念」的关系，不得互称。
  - **双接缝拓扑**：与计划表单接缝（ScheduledPlanForm，计划域私有——公共草稿、商户解析含重名兜底竞态、公共 payload 组装，契约详见 ADR-0041）构成计划域前端双接缝——清单持持久可观察状态、表单草稿是瞬态，生命周期不同，不合为一体。
  - **纪律门槛（防上帝模块）**：模块内形态分支只表达「能力有无」（如无商户能力的形态不暴露商户面）；形态特化计算体（期数预览、币种跟随、转入账户过滤）一律留适配器。
  - **弹层纯度**：模块不引用任何组件、不接弹层注册表（见 Overlay Suppression）；行操作描述符由适配器渲染，确认弹层按弹层封装纪律留在适配器。
  - **状态文案不另造**：定时计划状态标签沿用全仓单源的既有状态文案工具（订阅花费面板同为其消费方），模块直接复用。
  - **接缝拓扑边界**：跨域表单共享接缝（决策时 7 个消费方）一字不动；计划详情弹窗不动；Plan Lifecycle 语义以后端为唯一事实（ADR-0024），模块只消费不重定义。
- **别名**：不使用「定时计划」（ScheduledTransaction 被禁用的含糊别名，见定时计划域 ScheduledTransaction）、「计划列表」（视图泛称，不锚定模块本质）。

## WindowState（窗口状态）

- **定义**：应用窗口的几何形态——大小、位置、最大化/还原——跨启动保持的界面状态。
- **边界**：
  - 属于**界面状态**（UI State），不是业务概念；与业务"状态"（定时计划域 Occurrence 状态、Plan 生命周期）是两类东西，术语上必须区分。
  - 由官方窗口状态插件持久化，应用启动时自动恢复；dev 与 release 行为一致。
- **别名**：不使用"窗口大小"（只是几何的一部分）。

## ViewState（视图状态）

- **定义**：用户在界面中的位置与外观选择——当前所在视图、侧边栏折叠、侧栏组内顺序——跨启动保持。
- **边界**：
  - 与 WindowState 同属界面状态，与业务"状态"（定时计划域 Occurrence 状态、Plan 生命周期）区分。
  - 覆盖四样：上次视图（路由）、侧边栏折叠、侧栏组内顺序（右键排序菜单自定义，点选即重排并立即持久化，「恢复默认排序」清除记录；无记录或脏数据时回默认序；持久化对象为**组内**顺序——旧平铺序数据经解析防御整体回退默认序，见侧栏分组）、**组内收纳清单**（每组一个有序视图名清单，页签序 = 清单序、成员资格与顺序同源，见组内收纳）；不做"过度记忆"（不持久化筛选条件、滚动位置、列宽等；此类瞬态的保留粒度见「会话内保留」——会话内回到离开时的样子、冷启动回默认，依旧不写盘）。
  - **上次视图的持久化粒度是视图名**：路由上的页签等下级参数不持久化——组内「更多」页的页签选择跨启动不保留，重启回到该组默认页签（ADR-0062；属「不做过度记忆」既有边界的自然延伸）。历史持久化的全局「更多」视图名经重定向链映射到记账·更多，存量「上次视图 = 保单」相应落到资产组「更多」保单页签（旧视图名保留路由解析，issue #202 先例的延伸）。
  - **分域存储**：界面状态（含 WindowState、ViewState、偏好）不进入 SQLite，与业务数据分库/分域；业务数据仍独占 `ledger.db`。
- **别名**：不使用"会话"（偏网络会话）、"记忆"（含糊）。

## 会话内保留（In-Session Retention）

- **定义**：界面瞬态选择的保留粒度原则——同一应用会话内，离开一个视图再回来 = 回到离开时的样子（所见即所离）；应用冷启动（跨启动）不保留，回到默认口径。保留全程不写盘、不写回 URL（ADR-0061）。
- **边界**：
  - **会话的边界 = 应用进程的一次运行**：会话内的任何导航（侧栏切换、下钻跳转往返、回退）都算「离开再回来」；应用退出再打开是冷启动。
  - **与 ViewState 的关系是细化不是推翻**（ADR-0061）：ViewState 持久化的「位置与外观」跨启动保持不变；「不做过度记忆」禁止的是跨启动记忆——本原则补上会话内的保留粒度：瞬态选择从「每次进入即回默认」细化为「会话内回到离开时的样子、冷启动回默认」，依旧零写盘。
  - **保留的是选择，不是数据**：回来时数据照常按恢复的选择现拉，离开期间新记的账进入即反映；保留的不是离开时的数据快照。
  - **按领域语义逐状态归位**：原则不自动升级所有瞬态——未纳入保留的瞬态（如交易页筛选）仍每次进入回默认（URL 下钻参数在场时按参数装配）。
  - 首个落地：报表页期间选择与图内下钻位置（见「时间范围快捷选择」「分类下钻」）。
- **别名**：不使用「会话保持」（偏服务端会话）、KeepAlive（组件实例缓存，被否决的备选，见 ADR-0061）、「记忆」（含糊，ViewState 别名禁用理由同理）。

## 侧栏分组（Sidebar Groups）

- **定义**：侧边栏菜单按域职责分组的组织形态（已落地形态）：分组标题不占键位、不参与排序与计数；主项在线性序中的连续位置仍是键位依据。分组：固定「概览」；「记账」= 交易、账户、预算；「资产」= 投资、物品；「洞察」= 报表、搜索；固定「AI」「设置」——全局「更多」固定项已随组内收纳移除（ADR-0062），各组低频成员由组标题行的「更多」链接承载（见组内收纳）。
- **边界**：
  - 组与组序固定，不允许跨组移动；右键排序收窄为**组内**排序（上移/下移/移顶/移底语义不变，边界与「恢复默认」均按组内序判定），持久化对象随之收窄为组内序（见 ViewState）。
  - 动机：视图数已顶满数字键位与认知舒适区，保险域视图加入时按域职责归位，而不是让单一新视图插队平铺。
  - **主项与收纳成员**：组内视图分「主项」（入组内序与键位带，每组至多三项、运行时硬上限）与「收纳成员」（入该组「更多」聚合页，脱离组内序与键位带；见组内收纳）；「更多」链接仅当组内存在收纳成员时渲染，固定项与链接本身不可排序、不可收纳。
  - 历史注记：本词条立项时为过渡态（保险域 MVP 落地前侧栏维持平铺），issue #359 随侧栏分组先行落地、保单空位待保单建档票接入，过渡态注记同票作废；保单随后随 issue #360 接入「资产」组内末位（投资 = 金融资产、物品 = 实物资产、保单 = 合同权益）；issue #371/#372 将低频的保单迁入「更多」聚合视图，「资产」组二项化、「更多」以第四固定项落位洞察组之后、AI 之前——此为对 issue #360 放置决策的**演进而非否定**（取舍与清单见 ADR-0055），历史照录不删；issue #444 将商户管理自设置页 Tab 迁入「更多」为第二个页签（保单在前且默认不变、商户追加在后，ADR-0055 决策 2 清单追加成员），「更多」收纳器自此跨域承载第二成员；ADR-0062 以组内收纳取代全局单一收容器——定时自「记账」组迁入该组「更多」（主项三项化）、全局「更多」固定项移除、各组主项 ≤3 成为键位带封闭的硬上限，此为对 ADR-0055 决策 1 的演进而非否定，历史照录不删。
- **别名**：不使用“导航分组”（含系统导航歧义）、“菜单折叠”（分组是常驻形态，不是折叠交互）。

## 组内收纳（In-Group Containment）

- **定义**：低频视图的收纳机制——收纳单位是**侧栏分组**而非全局单点：每组拥有自己的「更多」页签式聚合页（被收视图整体迁入、功能零损失），「更多」链接渲染在组标题行右侧、仅当组内存在收纳成员时显示（ADR-0062；取代 ADR-0055 的全局单一收容器）。
- **边界**：
  - **≤3 硬上限**：每组主项至多三项是运行时不变量，非出厂建议——3 组 × 3 主项 = 9 恰好铺满数字键位带，键位封闭由上限保证；组满时「移回侧栏」置灰并提示，不自动换出、不强制腾位。
  - **开发者清单裁定出厂，用户配置作个性化层**：出厂收纳成员由开发者清单随决策记录（记账 = 定时、商户；资产 = 保单；洞察 = 无）；用户经右键菜单移入/移回——移入无限制（任一主项可入本组「更多」），移回受上限约束：记账组出厂满员，定时与商户移回须先移出一个主项。
  - **不跨组**：收纳只在组内进行，域归位原则不因用户配置打破（保单在资产组、商户在记账组）；固定项与「更多」链接本身不可收纳。
  - **持久化**：每组一个有序收纳清单入 ViewState（跨启动），清单序 = 页签序，成员资格与顺序同源；「恢复默认排序」同时复位组内序与收纳清单，是一键回出厂布局的唯一通道。
  - 页签不跨启动持久化（ViewState 粒度，重启回该组默认页签）；折叠态不渲染「更多」链接；路由镜像侧栏层级，存量全局「更多」路由与旧保单路由经重定向链迁移，历史持久化的「更多」视图名映射到记账·更多。
- **别名**：不使用「低频收纳」（全局收容器时代的旧机制名）、「收藏」（语义是收纳非收藏）。

## ViewShortcut（视图快捷键）

- **定义**：在应用窗口内用主修饰键（macOS 为 Cmd，Windows/Linux 为 Ctrl）+ 主键直接切换到对应视图的快捷方式。主键分配：概览=1，可排区**主项**按组序与组内线性序连续取 2 起，AI=0；设置为唯一例外，用 Cmd/Ctrl+,（macOS 平台「设置」惯例键位）——刻意不用 Cmd+S，避免与通用「保存」肌肉记忆冲突。组内收纳使主项至多 3×3=9，**键位带永不溢出由 ≤3 硬上限保证**（ADR-0062）；出厂态主项七项，⌘2–⌘8 占用、⌘9 空置，三组填满后自然回填——ADR-0055「十键十视图全占、无空转位」与「可排区末位无键位 wart 已消除」的表述不再恒真；收纳成员与「更多」链接无键位、不出键位提示、不可经键盘触发跳转，也不占用键位带。
- **边界**：
  - 仅窗口聚焦时生效，属应用内导航，不是全局快捷键（不劫持系统级按键）。
  - 输入框聚焦时同样生效（Cmd/Ctrl+数字与文本编辑键不冲突）。
  - 弹窗 / 确认框（如分类编辑、删除确认）打开时抑制（判定机制见 Overlay Suppression），避免在编辑或确认中途跳走丢失上下文。
  - 数字键跟随菜单位置：重排侧栏即重排键位（位置记忆一次学全）。
  - **键位随用户自定义排序（issue #270，#359 收窄为组内）**：右键可排区项**组内**排序即重排键位与提示，实时一致、重启保持；移入/移出收纳使主项集变化时，其后主项键位随线性规则重排（ADR-0062）；**固定项例外**——概览恒 ⌘1、AI 恒 ⌘0、设置恒 ⌘,，各「更多」链接恒无键位，均不参与自定义（同生同灭：自定义解禁只及组内可排项）。「恢复默认排序」后回出厂键位与出厂收纳状态（见组内收纳）。
- **别名**：不使用“全局快捷键”（那是系统级、应用失焦也生效的概念）。

## CreateShortcut（记一笔快捷键）

- **定义**：交易页裸键 `a`/`z`/`i`/`b`/`s` 直达对应类型的记一笔弹窗（支出/转账/收入/买入/卖出），随视图装卸仅交易页生效。
- **边界**：
  - **仅裸键，不用 Cmd/Ctrl 组合**（2025-08 决策）：组合键让给系统与视图快捷键（如 Cmd+Z 撤销、Cmd+A 全选的肌肉记忆）；裸键失效属于弹层误判 bug，修弹层判定而非加组合键双轨。
  - 退款（refund）不占键位，入口由交易条目右键菜单承接。
  - 焦点在可编辑元素或弹层打开时抑制（见 Overlay Suppression）。
- **别名**：不使用“组合键快捷键”、“记一笔快捷键入口”（口语沿用无妨，正式术语为记一笔快捷键）。

## Overlay Suppression（弹层抑制）

- **定义**：弹层（弹窗、命令式确认框、气泡确认、下拉菜单、筛选下拉、日历面板）打开期间抑制全局快捷键的机制，视图快捷键与记一笔快捷键共用同一判定。
- **边界**：
  - **「弹层是否打开」是显式声明的应用状态，不做 DOM 推断**：各弹层封装组件随自身显隐状态向弹层注册表上报开/关，快捷键闸门只读注册表（见 ADR-0035）。
  - 历史教训（两代 DOM 嗅探均因此翻车）：弹层库的弹层 DOM 与「打开状态」之间不存在稳定契约——容器关闭后空壳永久残留（懒传送门语义，第一次关弹窗即全灭），下拉菜单首次打开后仅隐藏、节点永不卸载（用过任一筛选下拉即全灭）。以任何 class 名存在性为信号都会把「已关闭」误判为「打开」，导致快捷键永久失效（见 ADR-0035）。
  - **应用内弹层一律经封装组件使用**：绕过封装直接用裸组件会脱离抑制；失效模式为「弹层开着时快捷键误触发」（当场可见可修），而非静默永久失效。
  - 弹层关闭动画期间（离场动画未完）仍视为打开，属预期。
- **别名**：不使用“弹窗检测”、“覆盖层探测”、“遮罩嗅探”（均已废弃的机制描述）。

## 弹层关闭语义

- **定义**：模态弹层（弹窗、确认框）只能经**显式动作**关闭——提交/保存、标题栏 ✕、ESC；点击弹窗外遮罩一律不构成关闭意图，误触零代价（填一半的表单不因点外面丢失，issue #249）。实现收口两处（统一弹窗薄封装默认遮罩点击不关 + 确认框调用点显式声明），具体做法见 AGENTS.md 编码约定，此处只锚语义。
- **边界**：
  - 显式关闭通道齐备，无需新增机制：ESC 关最上层弹层是弹层库既有行为（键位职责见「ESC 键语义」），✕ 走弹窗默认渲染，提交成功自动关闭路径不变。
  - **非模态弹层不受约束**：下拉菜单、气泡确认、日历面板等点外部关闭是其交互本体。
  - 弹层的**打开**判定走弹层注册表（Overlay Suppression，ADR-0035）：关闭语义收紧与打开判定正交，弹层打开期间快捷键照常被抑制。
  - 全量统一零特例：只读浏览弹窗与表单弹窗同一语义；不做脏检查与「放弃编辑？」确认（遮罩点击不关闭，无需脏状态追踪）。
  - 抽屉类弹层尚未引入；将来引入时按本词汇表另行考虑其关闭语义。
- **别名**：不使用「真模态」（弹窗本就是模态，问题在关闭语义）、「防误触关闭」（只描述动机，不是语义术语）。

## ESC 键语义

- **定义**：ESC 是应用内部职责的按键——有弹层时由弹层库默认行为关闭最上层弹层，无弹层时无操作；**永不作用于窗口层**（不退出全屏）。窗口行为守卫（issue #154）在最外层捕获阶段无条件拦截其默认行为。
- **边界**：
  - 拦截无条件，不区分全屏状态：JS 层检测不到 macOS 原生全屏（WebView 中全屏 DOM API 恒空），且按语义 ESC 本来就不归窗口层管。
  - 只拦截默认行为、不阻断传播：弹层库的 ESC 关闭依赖事件继续传播。
  - 退出全屏只走系统手势（顶部指针 / Ctrl+Cmd+F）；全屏状态重启后由 window-state 插件恢复（见 WindowState）。
- **别名**：不使用“ESC 退出全屏”（那是被禁止的默认行为）。

## 原生右键菜单

- **定义**：WebView 自带的默认上下文菜单（Back/Reload 等），与记账应用无关。窗口行为守卫（issue #154）默认拦截之。
- **边界**：
  - 唯一例外：可编辑元素（输入框、文本域、下拉、可编辑区）内放行，保留系统编辑菜单（剪切/拷贝/粘贴），判定与记一笔快捷键的可编辑判定同源。
  - 自定义右键菜单消费者均不受影响——拦截只阻止默认菜单、不阻断传播，自定义菜单组件均能读取事件坐标弹出：交易行菜单（issue #151）、账户行菜单、**侧栏排序菜单（issue #270，第三个消费者）**（右键组内可排项弹出排序菜单，概览/更多/AI/设置四固定项与分组标题右键无任何菜单）。
  - macOS 无原生禁用 API（Windows 有），前端拦截是唯一跨平台手段。
- **别名**：不使用“浏览器右键菜单”、“WebView 菜单”（正式术语为原生右键菜单）。

## 界面文本不可选（Non-Selectable Interface）

- **定义**：整个界面（主内容区、侧边栏、全部弹层）的文本一律不可选中——拖拽、双击与 Cmd/Ctrl+A 均不产生选区高亮，唯一例外是可编辑元素（input、textarea、contenteditable）内照常选择与编辑。动机与「原生右键菜单」同族：右键菜单禁用后（仅可编辑元素放行），内容区可选择性名存实亡——选中后连右键复制都没有，只剩 Cmd+C 一条独路；骚扰全留、能力近乎为零，故全局禁选，复制需求改走显式通道。
- **边界**：
  - **全局单一收口**：规则挂文档根（html）层 `user-select: none`（含 `-webkit-` 前缀，WKWebView 需要）。user-select 非继承属性，但 `auto` 取值沿父级 used value 解析，根层一条规则全窗口生效——主内容区、侧边栏、传送门到 body 的弹层（模态弹窗、下拉、日历面板）一体纳入；将来新增视图、弹层零声明自动覆盖，无需逐个声明、也不出现漏网的可选区域。
  - **唯一例外是可编辑元素**：input、textarea、contenteditable 显式恢复 `user-select: text`（含前缀）；弹层内表单控件天然适用同一例外，录入、搜索框选词等编辑场景毫发无损。
  - **复制走显式通道**：复制按钮 + clipboard API（CSS 不影响 clipboard），现有两处继续工作——AI 提示词页一键复制、关于设置里点击复制完整版本号；新复制需求按此模式补，不再借道文本选择通道。
  - **不拦截 Cmd/Ctrl+A**：无可选文本时全选自然无效果，窗口行为守卫（issue #154）不加新逻辑。
  - **反转历史**：立「导航铬层不可选」词条时明确「内容区维持可选；同类骚扰出现再议」。本词条即那次预留的「再议」：触发事实是右键菜单禁用后内容区可选择性名存实亡 + 整页选区刷蓝骚扰；旧裁决废除，取代本词条，侧边栏原有内联禁选样式已收编进全局规则（一处语义一处声明）。
- **别名**：不使用「禁用选择」「文本不可复制」「导航铬层不可选」（旧名，范围仅侧边栏，已反转）；正式术语为界面文本不可选。

## 拼音可搜下拉

- **定义**：实体类下拉的统一过滤交互——输入按统一模糊搜索语义规格过滤选项 label，匹配语义全库唯一定义点为核心交易域 TransactionSearch（ADR-0027），此处不复述。
- **边界**：
  - **只覆盖实体类下拉**（账户、分类、标的、关联交易）；选项已在前端内存的（参考数据全量、趋势面板标的字典一次拉全、关联交易滑动窗口）由**薄封装选择器组件**本地过滤（包一层通用下拉，收口过滤与透传，并向弹层注册表上报开/关，见 Overlay Suppression），匹配纯函数全仓单点；范围决策编码在调用点的组件选择上。
  - **标的远程搜索例外**（issue #199）：投资表单/实盘面板的标的下拉搜索全标的字典，字典经全市场同步后不可前端全量驻留，故维持远程搜索——拼音过滤由后端标的列表命令按同一语义规格匹配（判定目标「代码 · 名称」等价文本），远程模式下本地过滤不生效，薄封装组件仅收口过滤入口保持载体一致。
  - **枚举类下拉与币种下拉保持通用下拉不加过滤**（issue #195 范围决策）：账户类型、交易类型、订阅周期、市场等选项极少且固定；年份（原报表年份筛选，现经期间直达面板年档选择）选项虽随使用年限数据驱动增长，但纯为数字——拼音过滤对两者均无意义；币种选项本身含拉丁代码可直接搜，避免「什么都能拼音搜」的心智噪音。
  - 与交易搜索（核心交易域 TransactionSearch）共用同一份语义规格、实现各自独立，学一次两处通用。
  - **只过滤不重排**：不命中项隐藏、剩余项顺序不变（保护位置记忆）；清空搜索词恢复完整列表。汉字输入照常过滤，拼音不是唯一入口。
  - 已全量落地（issue #199，试点见 #198），覆盖转账、记账/退款/投资/订阅表单、预算与分类父选择、列表与实盘筛选、标的下拉等全部实体类下拉。
- **别名**：不使用“下拉搜索”、“模糊下拉”（含糊）；正式术语为拼音可搜下拉。

## 分类下钻（Category Drilldown）

- **定义**：报表支出分类构成图的两段式层级导航——第一段**图内下钻**：点一级分类柱，同一张图内切换为该分类的二级构成，行集合 = 二级子分类行 + 该一级自身直挂行，卡片头部面包屑「全部分类 › 分类名」点根返回基础态；第二段**跳转下钻**：点二级分类柱、父直挂行或未分类柱，直达按该分类过滤的交易列表明细（分类精确过滤与「仅无分类」语义见 TransactionFilter 的分类维度）。
- **边界**：
  - **直挂行补齐口径**：交易表单不限定叶子分类，直挂一级分类的交易行若缺位，下钻合计便对不上父柱——直挂行与二级行并存，各柱合计恒等于父柱金额。
  - **占比悬停可见、分母随层级**：柱尾只标金额，占比收进 tooltip（柱尾常驻占比与金额、柱宽三重冗余，退到悬停可查）；基础态以全部一级柱合计为分母；下钻态改以父分类总额为分母，看清单个分类内部的相对构成。
  - **未分类是柱不是层级**：未分类无子结构，不进图内下钻，只作跳转入口（跳转语义同二级柱跳转的「仅无分类」）。
  - **瞬时视图状态**：下钻位置不持久化（与 ViewState 边界一致），跨启动不恢复；会话内离开报表页再回来回到离开时的下钻位置（会话内保留，ADR-0061）；切换期间复位回基础态——悬停在无数据的下钻态只会迷惑。
  - **配色跨态恒定**：下钻态沿用同一分类稳定映射，同分类同色（直挂行即父分类色），跨期间、跨层级不变；未分类固定灰。
  - **跳转载荷与图所见同口径**：跳转带所选期间日期边界（报表页接入时间范围快捷选择后，口径从年份泛化为期间——年 = 年界、季 = 季界、月 = 月界）、刻意不带交易类型过滤——退款继承原分类，列表净值与柱值一致。
- **别名**：不使用「分类钻取」（生造词）；「层级切换」是已退役的汇总层级切换器表述，不再指本词条。
