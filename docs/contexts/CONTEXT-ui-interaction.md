# 领域词汇表：界面状态与交互

> Ledger 领域词汇表的界面状态与交互分域。全部分域与彼此关系见 `CONTEXT-MAP.md`；决策记录见 `docs/adr/`（ADR-0021 等）。
> 本域是纯界面层概念：不持业务数据，只读消费各域（交易搜索复用核心交易域列表信息，但搜索词不持久化；下拉拼音过滤复用统一模糊搜索语义规格，见 ADR-0027）。
> 跨域共享术语见核心交易域 `CONTEXT-core.md`，本文不复制定义。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## TransactionFilter（交易列表过滤模块）

- **定义**：交易列表视图的过滤状态机——「用户意图进、列表状态出」的深模块（工厂形态 composable，ADR-0030）：接收过滤意图，内化 URL 下钻解析、参考数据就绪补判、首刷时序、复位规则与统一出口，产出可观察的过滤状态与刷新版本号，驱动列表请求。
- **边界**：
  - **过滤意图**：调用方声明的语义请求，四个入口——部分修改过滤维度（立即生效：翻页归零 + 刷新）、回默认态、外部数据变化（重拉 + 翻回第一页，不动筛选）、转发最新路由查询（URL 下钻只读入口，视图只监听路由并转发，不持解析逻辑与时序标志）。四者共用同一内部出口，「翻页归零 + 刷新」全仓仅此一处。
  - **补判（URL 参数延迟应用）**：URL 下钻参数（账户/商户，收成一张参数表）在参考数据未就绪时挂起（不先行误清维度，不像旧实现先误判回退再重应用），就绪后一次性校验应用；参数至多消费一次（无论应用还是让位），后续参考数据重拉不重放。
  - **让位（字段级手动改动优先）**：补判遇用户已手动改动**同一维度**则让位，其他维度不受牵连。
  - URL **只读不写回**（组件状态是唯一事实源，延续 #96 决策 3/4）；下钻进入且两个维度均无有效参数时复位日期/类型，query 变化（含导航清除）时对应维度同步清空。
  - 筛选与分页不持久化（与 ViewState 边界一致）；分页参数归模块所有，请求发起与列表数据仍归视图（分页契约见 ADR-0008）；模块内部消费 Reference Data store 的就绪状态（见参考数据与设置域 Reference Data），不向调用方暴露就绪通知接口。
  - 消费方目前仅交易列表视图；搜索页（核心域 TransactionSearch）维度不相交，等第二个消费者出现再谈共用。
- **别名**：不使用「筛选状态机」（实现描述非术语）、「过滤器组件」（它是逻辑模块，不是 UI 组件）。

## WindowState（窗口状态）

- **定义**：应用窗口的几何形态——大小、位置、最大化/还原——跨启动保持的界面状态。
- **边界**：
  - 属于**界面状态**（UI State），不是业务概念；与业务"状态"（定时计划域 Occurrence 状态、Plan 生命周期）是两类东西，术语上必须区分。
  - 由官方窗口状态插件持久化，应用启动时自动恢复；dev 与 release 行为一致。
- **别名**：不使用"窗口大小"（只是几何的一部分）。

## ViewState（视图状态）

- **定义**：用户在界面中的位置与外观选择——当前所在视图、侧边栏折叠、报表汇总层级、侧栏可排区顺序——跨启动保持。
- **边界**：
  - 与 WindowState 同属界面状态，与业务"状态"（定时计划域 Occurrence 状态、Plan 生命周期）区分。
  - 覆盖四样：上次视图（路由）、侧边栏折叠、报表层级切换、侧栏可排区顺序（右键排序菜单自定义，点选即重排并立即持久化，「恢复默认排序」清除记录；无记录或脏数据时回默认序）；不做"过度记忆"（不持久化筛选条件、滚动位置、列宽等）。
  - **分域存储**：界面状态（含 WindowState、ViewState、偏好）不进入 SQLite，与业务数据分库/分域；业务数据仍独占 `ledger.db`。
- **别名**：不使用"会话"（偏网络会话）、"记忆"（含糊）。

## ViewShortcut（视图快捷键）

- **定义**：在应用窗口内用主修饰键（macOS 为 Cmd，Windows/Linux 为 Ctrl）+ 主键直接切换到对应视图的快捷方式。主键分配：数字键 1–0 按侧边栏菜单顺序依次对应前 10 个视图（概览=1 … AI=0）；设置为唯一例外，用 Cmd/Ctrl+,（macOS 平台「设置」惯例键位）——刻意不用 Cmd+S，避免与通用「保存」肌肉记忆冲突。每个侧栏视图恰好一个快捷键。
- **边界**：
  - 仅窗口聚焦时生效，属应用内导航，不是全局快捷键（不劫持系统级按键）。
  - 输入框聚焦时同样生效（Cmd/Ctrl+数字与文本编辑键不冲突）。
  - 弹窗 / 确认框（如分类编辑、删除确认）打开时抑制（判定机制见 Overlay Suppression），避免在编辑或确认中途跳走丢失上下文。
  - 数字键跟随菜单位置：重排侧栏即重排键位（位置记忆一次学全）。
  - **键位随用户自定义排序（issue #270）**：右键可排区项（第 2–9 位）排序即重排键位与提示，实时一致、重启保持；**固定项例外**——概览恒 ⌘1、AI 恒 ⌘0、设置恒 ⌘,，三固定项不参与自定义（同生同灭：自定义解禁只及可排区）。「恢复默认排序」后回出厂键位。
- **别名**：不使用“全局快捷键”（那是系统级、应用失焦也生效的概念）。

## CreateShortcut（记一笔快捷键）

- **定义**：交易页裸键 `a`/`z`/`i`/`b`/`s` 直达对应类型的记一笔弹窗（支出/转账/收入/买入/卖出），随视图装卸仅交易页生效。
- **边界**：
  - **仅裸键，不用 Cmd/Ctrl 组合**（2025-08 决策）：组合键让给系统与视图快捷键（如 Cmd+Z 撤销、Cmd+A 全选的肌肉记忆）；裸键失效属于弹层误判 bug，修弹层判定而非加组合键双轨。
  - 退款（refund）不占键位，入口由交易条目右键菜单承接。
  - 焦点在可编辑元素或弹层打开时抑制（见 Overlay Suppression）。
- **别名**：不使用“组合键快捷键”、“记一笔快捷键入口”（口语沿用无妨，正式术语为记一笔快捷键）。

## Overlay Suppression（弹层抑制）

- **定义**：弹层（弹窗、命令式确认框、气泡确认、下拉菜单、筛选下拉、日历面板）打开期间抑制全局快捷键的机制，视图快捷键与记一笔快捷键共用同一判定。
- **边界**：
  - **「弹层是否打开」是显式声明的应用状态，不做 DOM 推断**：各弹层封装组件随自身显隐状态向弹层注册表上报开/关，快捷键闸门只读注册表（见 ADR-0035）。
  - 历史教训（两代 DOM 嗅探均因此翻车）：弹层库的弹层 DOM 与「打开状态」之间不存在稳定契约——容器关闭后空壳永久残留（懒传送门语义，第一次关弹窗即全灭），下拉菜单首次打开后仅隐藏、节点永不卸载（用过任一筛选下拉即全灭）。以任何 class 名存在性为信号都会把「已关闭」误判为「打开」，导致快捷键永久失效（见 ADR-0021、ADR-0035）。
  - **应用内弹层一律经封装组件使用**：绕过封装直接用裸组件会脱离抑制；失效模式为「弹层开着时快捷键误触发」（当场可见可修），而非静默永久失效。
  - 弹层关闭动画期间（离场动画未完）仍视为打开，属预期。
- **别名**：不使用“弹窗检测”、“覆盖层探测”、“遮罩嗅探”（均已废弃的机制描述）。

## 弹层关闭语义

- **定义**：模态弹层（弹窗、确认框）只能经**显式动作**关闭——提交/保存、标题栏 ✕、ESC；点击弹窗外遮罩一律不构成关闭意图，误触零代价（填一半的表单不因点外面丢失，issue #249）。实现收口两处（统一弹窗薄封装默认遮罩点击不关 + 确认框调用点显式声明），具体做法见 AGENTS.md 编码约定，此处只锚语义。
- **边界**：
  - 显式关闭通道齐备，无需新增机制：ESC 关最上层弹层是弹层库既有行为（键位职责见「ESC 键语义」），✕ 走弹窗默认渲染，提交成功自动关闭路径不变。
  - **非模态弹层不受约束**：下拉菜单、气泡确认、日历面板等点外部关闭是其交互本体。
  - 弹层的**打开**判定走弹层注册表（Overlay Suppression，ADR-0035）：关闭语义收紧与打开判定正交，弹层打开期间快捷键照常被抑制。
  - 全量统一零特例：只读浏览弹窗与表单弹窗同一语义；不做脏检查与「放弃编辑？」确认（遮罩点击不关闭，无需脏状态追踪）。
  - 抽屉类弹层尚未引入；将来引入时按本词汇表另行考虑其关闭语义。
- **别名**：不使用「真模态」（弹窗本就是模态，问题在关闭语义）、「防误触关闭」（只描述动机，不是语义术语）。

## ESC 键语义

- **定义**：ESC 是应用内部职责的按键——有弹层时由弹层库默认行为关闭最上层弹层，无弹层时无操作；**永不作用于窗口层**（不退出全屏）。窗口行为守卫（issue #154）在最外层捕获阶段无条件拦截其默认行为。
- **边界**：
  - 拦截无条件，不区分全屏状态：JS 层检测不到 macOS 原生全屏（WebView 中全屏 DOM API 恒空），且按语义 ESC 本来就不归窗口层管。
  - 只拦截默认行为、不阻断传播：弹层库的 ESC 关闭依赖事件继续传播。
  - 退出全屏只走系统手势（顶部指针 / Ctrl+Cmd+F）；全屏状态重启后由 window-state 插件恢复（见 WindowState）。
- **别名**：不使用“ESC 退出全屏”（那是被禁止的默认行为）。

## 原生右键菜单

- **定义**：WebView 自带的默认上下文菜单（Back/Reload 等），与记账应用无关。窗口行为守卫（issue #154）默认拦截之。
- **边界**：
  - 唯一例外：可编辑元素（输入框、文本域、下拉、可编辑区）内放行，保留系统编辑菜单（剪切/拷贝/粘贴），判定与记一笔快捷键的可编辑判定同源。
  - 自定义右键菜单消费者均不受影响——拦截只阻止默认菜单、不阻断传播，自定义菜单组件均能读取事件坐标弹出：交易行菜单（issue #151）、账户行菜单、**侧栏排序菜单（issue #270，第三个消费者）**（右键可排区项弹出排序菜单，三固定项右键无任何菜单）。
  - macOS 无原生禁用 API（Windows 有），前端拦截是唯一跨平台手段。
- **别名**：不使用“浏览器右键菜单”、“WebView 菜单”（正式术语为原生右键菜单）。

## 界面文本不可选（Non-Selectable Interface）

- **定义**：整个界面（主内容区、侧边栏、全部弹层）的文本一律不可选中——拖拽、双击与 Cmd/Ctrl+A 均不产生选区高亮，唯一例外是可编辑元素（input、textarea、contenteditable）内照常选择与编辑。动机与「原生右键菜单」同族：右键菜单禁用后（仅可编辑元素放行），内容区可选择性名存实亡——选中后连右键复制都没有，只剩 Cmd+C 一条独路；骚扰全留、能力近乎为零，故全局禁选，复制需求改走显式通道。
- **边界**：
  - **全局单一收口**：规则挂文档根（html）层 `user-select: none`（含 `-webkit-` 前缀，WKWebView 需要）。user-select 非继承属性，但 `auto` 取值沿父级 used value 解析，根层一条规则全窗口生效——主内容区、侧边栏、传送门到 body 的弹层（模态弹窗、下拉、日历面板）一体纳入；将来新增视图、弹层零声明自动覆盖，无需逐个声明、也不出现漏网的可选区域。
  - **唯一例外是可编辑元素**：input、textarea、contenteditable 显式恢复 `user-select: text`（含前缀）；弹层内表单控件天然适用同一例外，录入、搜索框选词等编辑场景毫发无损。
  - **复制走显式通道**：复制按钮 + clipboard API（CSS 不影响 clipboard），现有两处继续工作——AI 提示词页一键复制、关于设置里点击复制完整版本号；新复制需求按此模式补，不再借道文本选择通道。
  - **不拦截 Cmd/Ctrl+A**：无可选文本时全选自然无效果，窗口行为守卫（issue #154）不加新逻辑。
  - **反转历史**：立「导航铬层不可选」词条时明确「内容区维持可选；同类骚扰出现再议」。本词条即那次预留的「再议」：触发事实是右键菜单禁用后内容区可选择性名存实亡 + 整页选区刷蓝骚扰；旧裁决废除，取代本词条，侧边栏原有内联禁选样式已收编进全局规则（一处语义一处声明）。
- **别名**：不使用「禁用选择」「文本不可复制」「导航铬层不可选」（旧名，范围仅侧边栏，已反转）；正式术语为界面文本不可选。

## 拼音可搜下拉

- **定义**：实体类下拉的统一过滤交互——输入按统一模糊搜索语义规格（ADR-0027）过滤选项 label，语义细节以 ADR-0027 及其附件词汇表为准；效果上即支持汉字子串与拼音首字母（如 `zsyh` 命中「招商银行」）两种命中方式，词条之间 AND。
- **边界**：
  - **只覆盖实体类下拉**（账户、分类、标的、关联交易）；选项已在前端内存的（参考数据全量、趋势面板标的字典一次拉全、关联交易滑动窗口）由**薄封装选择器组件**本地过滤（包一层通用下拉，收口过滤与透传，并向弹层注册表上报开/关，见 Overlay Suppression），匹配纯函数全仓单点；范围决策编码在调用点的组件选择上。
  - **标的远程搜索例外**（issue #199）：投资表单/实盘面板的标的下拉搜索全标的字典，字典经全市场同步后不可前端全量驻留，故维持远程搜索——拼音过滤由后端标的列表命令按同一语义规格匹配（判定目标「代码 · 名称」等价文本，与全局搜索同一匹配实现），远程模式下本地过滤不生效，薄封装组件仅收口过滤入口保持载体一致。
  - **枚举类下拉与币种下拉保持通用下拉不加过滤**（issue #195 范围决策）：账户类型、交易类型、订阅周期、市场等选项极少且固定；年份（见「报表年份筛选」）选项虽随使用年限数据驱动增长，但纯为数字——拼音过滤对两者均无意义；币种选项本身含拉丁代码可直接搜，避免「什么都能拼音搜」的心智噪音。
  - 与全局搜索（核心交易域 TransactionSearch）共用同一份语义规格、实现各自独立（前端与后端各有拼音库，词组多音字消歧如「银行」→ yh，接受生僻多音字的字库级分歧），学一次两处通用。
  - **只过滤不重排**：不命中项隐藏、剩余项顺序不变（保护位置记忆）；清空搜索词恢复完整列表。汉字输入照常过滤，拼音不是唯一入口。
  - 已全量落地（issue #199，试点见 #198），覆盖转账、记账/退款/投资/订阅表单、预算与分类父选择、列表与实盘筛选、标的下拉等全部实体类下拉。
- **别名**：不使用“下拉搜索”、“模糊下拉”（含糊）；正式术语为拼音可搜下拉。

## 报表年份筛选（Report Year Filter）

- **定义**：报表视图的年份选择下拉——可选范围为数据驱动的闭区间 `[最早交易年份, max(当前年, 最新交易年份)]`，空库回退 `[当前年, 当前年]`；范围由报表域一次性给出，前端以无过滤下拉升序平铺直选，任何年份一击可达。
- **边界**：
  - 范围语义 =「有数据的年份全可选」：起点是最早流水年份；终点取「数据与今天更晚者」，未来日期的流水也可筛到；当前年天然在范围内（终点 ≥ 当前年），默认选中当前年无需钳制。
  - 不做拼音过滤（延续拼音可搜下拉的枚举类范围决策：选项纯为数字）；不设年份面板翻页（选项数 = 使用年限，几十项内平铺即够）。
  - 取代早期「围绕已选年份 ±2 的滑动窗口」——窗口随选中值移动，跳到远处年份需连点多年，是本词条确立的动因。
- **别名**：不使用「年份范围选择器」（它是单值筛选下拉，不是范围选择控件）。
