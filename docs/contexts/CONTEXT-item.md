# 领域词汇表：物品

> Ledger 领域词汇表的物品分域（单列小域）。全部分域与彼此关系见 `CONTEXT-MAP.md`；决策记录见 `docs/adr/`（ADR-0014）。
> 跨域共享术语（Transaction、Instrument、Subscription 等）见核心交易域 `CONTEXT-core.md`、投资域 `CONTEXT-investment.md`、定时计划域 `CONTEXT-scheduled-plans.md`，本文不复制定义。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## Item（物品）

- **定义**：用户拥有并使用的耐用实物（如手机、电脑、家具、车、家电），用于跟踪它"从购买到今天平均每天花多少钱"（使用成本摊薄）。是账本中与参考数据（账户/分类/币种，见参考数据与设置域 Reference Data）、核心交易域交易流水（Transaction）、投资域投资标的（Instrument）并列的独立领域概念，不是字典也不是一次性交易。
- **边界**：
  - 仅覆盖耐用实物，不含服务/订阅（那些是定时计划域 ScheduledTransaction / Subscription 的语义，见 Subscription）。
  - 每个物品**自包含总成本**（`total_cost_cents`）：基础成本在有关联购买交易时自动带出，后续花费（维修/配件/运费）由用户编辑总数累加；**不**由系统对多笔交易求和（避免与账本产生双向纠缠，见 Item↔Transaction 关联）。
  - 可选关联一笔核心交易域购买交易，仅为自动带出成本/日期与溯源；不建立"交易→物品"的反向引用，也不要求有对应交易（赠品/旧物允许只记录物品、不产生交易）。
  - 生命周期：`in_use`（在用）/ `disposed`（已处置，记录处置日期 + 可选残值）。
  - 币种/金额复用核心交易域 Amount 接缝（整数分 + raw/native 折算到默认币种）。
  - 属独立领域（独立 store），不属于参考数据（那不是"可选值字典"）；写入后发 `ledger:changed`（粗粒度失效）。
- **别名**：不使用 "Asset / 资产"（偏会计/金融，且与投资域混淆）、"Good"、"Instrument"（那是金融标的，见 Instrument）。

## DailyUsageCost（每天使用成本）

- **定义**：一件 Item 的平均使用成本，= 该物品分摊的总成本 ÷ 拥有天数（从购买日期到今天，或用户自选参考日；已处置物品到处置日，可选扣残值）。展示为本位币（核心交易域默认币种 DefaultCurrency）。
- **边界**：
  - 分子 = 物品总成本（基础 + 追加）；已处置且填残值时分子 = 总成本 − 残值；分子下限 0（残值 ≥ 成本或总成本异常为负时不输出负成本）。
  - 分母 = 自购买日期到"目前"的日历天数，默认取今天实时，支持用户自选参考日。
  - **参考日语义**：缺省目标日按状态取（在用 → 今天；已处置 → 处置日）；用户自选参考日时**覆盖目标日**（两种状态均生效，未来日期合法——预览「如果用满 N 天」）；参考日只改分母，**分子口径不变**（已处置物品仍扣残值，成本基准不随参考日变化）。单件重算命令为只读计算，不发失效信号。
  - 只输出“每天”一个口径（月/年由用户心理换算，避免口径发散）。
  - **跨物品合计口径**（issue #122 dashboard 汇总卡）：全部在用物品每天成本合计 = Σ 各在用物品分子（折本位币，Amount 接缝当前汇率）÷ 各自天数，收敛在 `commands::item::item_daily_total_internal`（不是 Σ分子 ÷ Σ天数 的加权均值）；缺汇率错误上抛，不以零计入。
- **别名**：不使用"摊销成本"（偏会计）、"折旧"（会计上特指固定资产折旧，此处是主观使用成本）。
