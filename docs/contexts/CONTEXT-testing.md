# 领域词汇表：测试基础设施

> Ledger 领域词汇表的测试基础设施分域（前端测试替身的布线与清理语义、BDD e2e 步骤共享层的工厂与分组语义）。全部分域与彼此关系见 `CONTEXT-MAP.md`；决策记录见 ADR-0085（前端 invoke 测试接缝唯一化）与 ADR-0086（BDD e2e 步骤共享层加深）。
> 本域只定义测试层的布线、清理、构造、写入与分组语义，不复述任何业务域术语；被测命令的语义归各业务分域，参考数据夹具的语义归参考数据与设置域。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## invoke 测试接缝

- **定义**：前端测试中命令替身布线的**唯一定义点**。组装与接线一体：一次调用即把应答表挂上全局替身并注册每测清理，返回分发器供一次性覆盖与调用事实断言。
- **求值序**：overrides 表 → defaults 表 → 参考数据预热兜底 → 未命中报错。求值序与两表分工是接口语义的一部分，既有使用者语义零迁移成本。
- **边界**：只管替身如何应答命令与替身生命周期；被测组件的渲染方式、业务断言的写法不归本域。全局替身统一替换（命令/事件/消息三类）是本域的不动基础，接缝只改变「替身如何被布线」。
- **别名**：不使用「mock 布线」「桩子」「测试脚手架」等泛称指代本接缝。

## defaults 表（命令契约快照）

- **定义**：测试场景下命令应答的静态快照，只收静态值，表达「本场景下命令契约长什么样」。
- **边界**：动态行为（调用计数、按参分支、一次性失败）不进 defaults 表，归 overrides 表；参考字典命令不在此表枚举——参考数据预热兜底负责，重复枚举属回潮（守门目标形态）。

## overrides 表（用例级覆盖）

- **定义**：用例特定的应答覆盖，可含函数，表达本用例独有的动态行为；优先级高于 defaults 表。
- **边界**：只承载「本用例关心的差异」，不是第二张默认值表；与 defaults 表同现时不得重复定义同一命令的静态应答。

## 未命中报错

- **定义**：求值序全层未命中时，替身以**含命令名**的错误拒绝该次调用。
- **双语义**：拼错或漏布线的命令立即让测试变红；同时也是「本测试关心的命令面」的显式声明——接线表即命令面清单。
- **全局基座**：未走接缝的测试同样得到含命令名的拒绝（而非返回未定义值后在产品代码中以类型错误崩溃），由全局壳层每测复位后重挂；走接缝的测试覆盖之。
- **别名**：不使用「兜底报错」「未捕获命令」等变体称呼。

## 参考数据预热

- **桩层（默认行为）**：参考字典的五个列表命令（币种/账户/分类/商户/保司）由接缝内建规范夹具兜底应答，夹具含正常行与软删行各一，使软删过滤路径天然可测；测试无需逐字复制预热布线。
- **store 层（opt-in）**：接线时可选择由接缝代做参考 store 的预载刷新；默认关闭——刷新时序与断言时机耦合，默认开启会破坏「迁移纯机械替换」判据。
- **边界**：夹具是参考数据域 Reference Data 的测试投影，字段语义归参考数据与设置域；预热只保证「替身能答、store 可载」，不改变参考数据就绪状态的产品语义。

## 清理四件套

- **定义**：每测自动执行的四个清理动作——桩复位（复位后重挂未命中报错基座）、本地存储清空、状态容器重置、消息接口清零；随同自动执行的还有文档体清空与组件卸载。
- **归属**：由全局壳层统一保证，对全部测试文件生效；测试文件内出现同类样板即回潮。
- **边界**：清理语义是「用例间零交叉污染」，不承载任何前置 seeding——前置数据一律走接线表或工厂，不靠「上一个用例的残留」。

## 消息替身稳定实例

- **定义**：消息接口的全局替身每测发放**同一稳定实例**并自动清零；需要断言消息的测试经测试辅助层出口读取该实例。
- **边界**：机制仍是全局替身统一替换，稳定实例只是发放策略，不是第二套消息系统；测试不得自建并行实例（历史样板已随迁移删除）。

## 目录级测试薄壳

- **定义**：测试目录的共享文件只承载**本目录特有**的夹具与编排组合（如目录专有路由替身、可变数据源、域内夹具族），通用能力一律上收测试辅助层。
- **判断标准**：能被测试辅助层出口替代的部分必须上收；薄壳内出现可通用化的布线/清理/查找能力即违规。
- **别名**：不使用「目录 helpers」泛称；「薄壳」强调其只做域特有组合、不自持实现。

## 行为等价判据

- **定义**：迁移类改动的验收标准——全量既有测试保持绿；迁移本身是纯机械替换，不引入断言语义变化。接缝自身的正确性由该判据整体验证，另以少量直接断言覆盖清理与未命中报错语义。
- **唯一例外通道**：隐式依赖显式化——依赖「替身返回未定义值」的用例被未命中报错基座变红后，按用例语义补布线；这属把隐式依赖写明，不是行为变更。
- **边界**：判据适用于布线迁移，不适用于接缝深化本身（深化票以「既有使用者不改一字仍绿」为附加判据）。

## 测试世界（World）

- **定义**：BDD e2e 的共享上下文——步骤函数间传递状态的唯一载体，持有数据库连接、实体名称注册表、跨域错误断言状态与各域快照分组。
- **边界**：本体只保留跨域共享的基础设施（连接、名称注册表、错误状态、冻结时钟）；域内快照一律入快照分组，本体不随 issue 线性生长。连接的并发借用以既有宏单点约束。
- **别名**：不使用「共享上下文」「测试上下文」泛称。

## 步骤输入工厂

- **定义**：BDD 步骤层构造领域输入结构体的纯函数——热点字段作位置参数、其余取默认值，冷字段经结构体更新语法覆盖。交易输入按 kind 各设构造函数，计划输入按三形态各设构造函数。
- **边界**：与产品侧装配器严格区分——TransactionInput 装配器（见核心交易域）是前端进程内的产品装配接缝，服务用户表单形态；步骤输入工厂是测试 arrange 助手，服务场景语义。二者构造同一结构体但互不替代、互不调用。默认值合法且语义中性，场景关心的字段必须显式给出。
- **别名**：不使用裸称「输入工厂」（易与装配器混淆）、「构造器」。

## 步骤动词

- **定义**：BDD 共享层中代表一个场景前置或动作的命名函数——名称注册表解析、输入工厂构造、经公开写入口写入、结果注册回测试世界。前置动词（Given 侧）与动作动词（When 侧）是其两种使用形态。
- **边界**：动词是测试层唯一允许触发写入的形态，步骤函数不直接构造输入、不直写数据库（显式例外除外）；写入失败即场景失败或进入错误断言路径，不静默吞错。
- **别名**：不使用「前置动词」指代全类（其仅指 Given 侧子集）、「辅助函数」泛称。

## 快照分组

- **定义**：测试世界快照按域聚合的分组结构——交易、计划、资产（投资+实物资产）、物品、保单、报表、引导（备份/数据位置/加密/启动失败）七组，各自持有快照与断言辅助。
- **边界**：找某域的状态只看其分组一处；新快照必须归入既有分组，回退本体平铺即回潮。跨域设施（错误断言状态、冻结时钟）不入组。分组内读取辅助做成分组方法，纯连接查询为共享自由函数。

## 公开写入口（测试侧）

- **定义**：测试层造数与动作的写入纪律——凡公开入口存在的实体创建与状态变更，前置与动词必须经域层/行为层公开函数完成，业务不变量（含余额缓存行等派生数据维护）由产品代码而非测试 SQL 保证。
- **边界**：裸 SQL 仅限「公开入口不存在、且场景本身依赖库内状态直置」的显式例外，逐个登记动机（与壳层写仪式的例外白名单纪律同构，ADR-0073）。与统一测试数据库工厂（ADR-0084）分层互斥：那是域内与 API 集成层的建库/种子工厂、账户种子由调用方指定标识；BDD 层经公开写入口取得生成标识、经名称注册表解析，不消费种子工厂。测试无应用运行时，不经壳层命令，直接消费域层公开函数。
- **别名**：不使用「测试种子」「数据工厂」指代本纪律。
