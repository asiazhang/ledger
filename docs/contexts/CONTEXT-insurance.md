# 领域词汇表：保险

> Ledger 领域词汇表的保险分域（单列小域）。全部分域与彼此关系见 `CONTEXT-MAP.md`；域 MVP 决策（建档、缴费复用订阅、流水直挂、现金流入口径、生命周期、侧栏分组与键位上限）见 ADR-0051。
> 跨域共享术语（Transaction、Amount Model、Transaction Kind Mapping、Merchant、Subscription、Occurrence 等）见核心交易域 `CONTEXT-core.md`、定时计划域 `CONTEXT-scheduled-plans.md`、AI 导入域 `CONTEXT-ai-import.md`，本文不复制定义。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## Policy（保单）

- **定义**：一张消费型保险合同在账本中的静态档案，回答「我有哪几张保单、保什么、保到什么时候」。与物品域 Item 同为独立领域概念：不是参考数据字典行，不是交易流水，也不是生成流水的协议。
- **边界**：
  - **静态合同档案**：只持合同静态要素（保险公司、保单号、险种、保障期间、保额等）；一切缴费动态参数（每期保费金额、缴费频率、扣款账户）**不进保单**，由缴费协议单点持有——保单重复存即第二口径。
  - **建档不强制缴费协议**：趸交/缴清保单（无周期扣缴）可纯档案存在，保费手动补记后经保单引用归属；缴费协议持保单引用（方向：协议 → 保单），1 张保单可对应历史多段协议（费率变更 = 取消旧协议 + 重建，继承订阅既有语义）。
  - **三分界**：保单 = 静态合同档案；缴费协议 = 复用定时计划域订阅形态（Subscription），不另造缴费引擎；保费流水 = 实际资金历史（核心交易域 Transaction）。
  - **独立视图入口**：保单以独立视图进侧栏「资产」组（见界面状态与交互域 侧栏分组），不挂靠其他视图作页签；新建/编辑为弹窗，缴费协议区可折叠可选（对应建档不强制缴费协议）。
  - **生命周期**：无手动状态字段——到期由保障期间推导（止日期非空且早于今天 → 已到期），可推导的状态不持久化（先例：预算永久滚动）；删除为软删除，已删保单不进列表，其上历史流水引用**保留不置空**（保单是档案非字典，置空会毁掉已缴/已赔历史）。
  - 仅覆盖**消费型**语义（保障型费用支出 + 收入侧资金流）；储蓄/返还型保单的现金价值资产化（进净资产）明确不在本域范围，缓行。
  - 保险公司复用核心交易域商户（Merchant）字典——保险公司即保费流水的付款对象，不建第二份保司字典。
  - AI 导入（见 AI 导入域 AI API）不识别、不建档保单（MVP 边界）：建档不涉及账户余额变动，在 AI 读回验证契约之外。
- **别名**：不使用"保单管理"（指功能而非实体）、"合同"（偏法律文本）；"保险"指险种领域而非单张合同，不作为实体名。

## Premium（保费）

- **定义**：保单的周期性资金流出，记账语义为核心交易域 `expense` 流水（通常挂「金融保险」分类），经定时计划域订阅形态（Subscription）按周期生成。
- **边界**：
  - 扣缴协议继承订阅形态全部既有语义：周期规则（含按年）、每期内金额固定、价格变更 = 取消旧计划 + 按新金额重建、经暂停/取消停止（见定时计划域 Plan Lifecycle）。
  - 手动补记的保费是普通 `expense` 流水，与自动生成流水无差别，均可经保单引用归属到保单（见 PolicyReference）。
- **别名**：不使用"缴费"（动词化、含混）、"年费/月费"（预设了频率）。

## PolicyInflow（保单现金流入）

- **定义**：保单发生的收入侧资金流，记账语义为核心交易域 `income` 流水（**非** `refund`）。场景包括理赔款、退保款、满期返还——三者记账语义无差别（都是收入 + 挂单），不为各场景造专名。
- **边界**：
  - 口径动机：`refund` 在支出净额度量中是冲减项（见核心交易域 Transaction Kind Mapping），若记退款，「保费支出」统计会被冲小、口径失真；现金流入与原保费不是同一笔经济往来，故记收入。
  - 现金流入与原保费交易之间无引用关系，仅经保单引用同挂一张保单（见 PolicyReference）。
- **别名**：不使用"退款"（refund 已有专门语义）；"理赔款""退保款""满期金"为场景词可用，落库术语统一"保单现金流入"。

## PolicyReference（保单引用）

- **定义**：核心交易域流水对保单的可选归属指针——保费（`expense`）与保单现金流入（`income`）流水可挂一张保单，使「这张单累计缴了多少、赔了多少」可查。
- **边界**：
  - 引用可选：不挂保单的流水行为与现状完全一致；手动补记与自动生成的流水归属能力相同。
  - 保单视角统计以该引用为归属依据，**不经**「缴费协议 → 期次 → 流水」推导链——推导链在手动补记场景断裂，流水直挂是归属的唯一事实。
  - 保单软删除后引用保留不置空（见 Policy 生命周期）；引用随保单视角统计继续可对账，已删保单不在列表中但历史不丢。
- **别名**：不使用"关联交易"（物品域溯源指针语义，见物品域 source_transaction_id）。

## 保单视角统计（单保单口径）

- **定义**：单张保单的实时推导统计：累计已缴保费、累计现金流入、下期扣款日。
- **边界**：
  - 按流水忠实统计、不摊销、不落库（与定时计划域 SubscriptionSpend 的「实际花费」口径同纪律）；下期扣款日来自其缴费协议（订阅形态）的期次（Occurrence）。
  - MVP 不做全局口径（年度保费总额等）：无下游消费方的派生聚合不建（对照预算域 AnnualBudgetTotal 有财务自由度消费方）。
- **别名**：不使用"保单报表"（暗示独立报表模块）。
