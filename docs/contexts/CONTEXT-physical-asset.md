# 领域词汇表：实物资产

> Ledger 领域词汇表的实物资产分域（单列小域）。全部分域与彼此关系见 `CONTEXT-MAP.md`；域 MVP 决策（估值档案定位、只追加估值历史、处置与软删、净资产第三腿、入口收纳）见 ADR-0063。
> 跨域共享术语（Amount Model、DefaultCurrency、Transaction 等）见核心交易域 `CONTEXT-core.md`，本文不复制定义。
> 若与代码行为冲突，以代码为准并同步修正本文件。

## PhysicalAsset（实物资产）

- **定义**：用户登记的大件实物（如房子、车子、贵重收藏）的**估值档案**，回答「我有哪几件大件、各值多少钱、家底合计多少」。与物品域 Item 同为独立领域概念：不是参考数据字典行，不是交易流水，也不是生成流水的协议。
- **边界**：
  - **与物品域按「要不要跟踪市值」互斥分家**：Item 回答使用成本摊薄（分母天数、分子成本），实物资产维护市值档案（估值）；同一件东西不应两边都建。黄金等贵金属不在范围（ADR-0063 决策 1）。
  - 建档必填仅名称与当前估值（估值 = 第一条估值历史行），购买日期、购买价 + 币种可选；可选金额与币种成对（保额同款先例）。
  - 编辑只改名称 / 购买信息；**估值不走编辑**，走 Valuation 更新（追加历史行）。
  - 币种复用核心交易域币种字典（种子权威）；金额一律整数分；估值折本位币走 Amount 接缝（当期汇率，缺汇率错误上抛）。
  - 删除为软删除：软删后不进列表与合计，数据与估值历史保留。
  - 入口收纳在「更多」聚合页页签（见界面状态与交互域 侧栏分组，ADR-0055）；本域纯 IPC，无 HTTP 面；AI 导入不识别建档实物资产。
- **别名**：不使用"Asset / 资产"（与投资域金融资产混淆）、"固定资产"（会计折旧语义，本域估值全手动）、"收藏品"（范围过窄）。

## Valuation（估值）

- **定义**：对一件实物资产在某个日期的价值判断（日期 + 币种金额），全手动录入。当前估值 = 最新一条估值历史行（估值日期最新，同日按插入序）；系统不做自动折旧或增值。
- **边界**：
  - 每次估值**追加一条新历史行**（见 ValuationHistory），旧值保留不覆盖；更新估值即追加。
  - 估值日期缺省今天、允许补录过去日期（事后整理），**未来日期显式拒绝**（估值是已发生的判断）。
  - 建档估值必填（= 第一条历史行）；列表 / 详情消费当前估值与估值日期——「这个数是多久前估的」由估值日期回答。
  - 在持资产的当前估值经当期汇率折本位币后计入在持合计与净资产（Amount 接缝）；缺汇率报错上抛，不以零或缺项静默通过。
- **别名**：不使用"市价"（MarketPrice 是投资域行情语义）、"评估值"（暗示第三方评估）、"现值"（含会计折现歧义）。

## ValuationHistory（估值历史）

- **定义**：一件实物资产的估值序列（只追加不改写的历史行），当前估值即其中最新一条。
- **边界**：
  - 只追加：估值更新永远是插入新行，任何路径不改写既有行；行级无更新语义（无 version / 软删标志），依附资产存续（资产硬删时级联消失，软删不触及）。
  - 当前值 = 估值日期最新一条，同日按插入序（UUID v7 主键时间有序）。
  - MVP 界面只消费当前估值；历史行是估值走势等未来诉求的原料，无独立展示界面。
- **别名**：不使用"估值记录"（动词化）、"价格历史"（那是投资域 PriceHistory）。

## Disposal（处置）

- **定义**：实物资产退出在持视角的状态标记——状态转已处置，处置日期必填、处置价 + 币种可选纯记录（「这车卖了 8 万」）。
- **边界**：
  - **处置 = 状态标记，不是删除**：已处置资产保留完整档案（含估值历史），经「已处置」筛选可回看；处置价是纯记录，不进任何金额口径。
  - 已处置不进默认列表（默认只看在持）、不进在持合计、不进净资产。
  - 与删除（软删）是界面上分离的两个动作：处置改变状态、删除移出列表；两者都使资产退出在持口径。
- **别名**：不使用"出售"（暗示交易挂钩，本域无资金流）、"报废"（处置可以是卖出/赠与等多种情形）、"清仓"（投资域卖出语义）。
