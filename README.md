# 开源记账（OpenLedger）

开源、本地优先的个人记账应用：把收入、支出、转账、投资和预算全部收进一个私密的本地账本。所有数据保存在你自己的设备上，不上传云端；可选整库加密，也能在多台设备间通过你自有的对象存储保持同步。桌面（macOS / Windows / Linux）与 Android 手机共用同一套功能。

当前处于早期快速迭代阶段，功能持续更新中。

## 为什么用开源记账

- **数据私有**：账本以本地文件形式存储，离线可用，不依赖任何云端服务。
- **可选加密**：整库加密 + 主口令，支持 Touch ID 自动解锁与忘记口令重置；另有金额隐私模式一键掩码全应用金额。
- **多端同步**：自备 S3 兼容对象存储桶即可在多台设备间同步，打开应用即同步、记账后自动上传，新设备凭快照一键引导加入；同步包可选加密上云。
- **多账本**：个人、家庭等多本账独立记账，跨账本投资汇总合并只读总览。
- **多币种账户**：支持现金、银行卡、信用卡、电子钱包、投资账户、负债、借出款等多种账户，余额实时计算。
- **投资记账**：买卖股票自动匹配持仓、计算已实现盈亏与年化收益率，可一键同步 A 股、港股与美股行情。
- **AI 记账与数据迁移**：把日常账单或历史账单交给 AI 编程助手，通过本地接口逐行记入 / 批量导入，省去手工录入。

## 功能一览

### 概览
- 净资产总览（多币种折算合计）、本月收支与预算进度
- 投资概览、物品每日使用成本、财务自由度进度

### 交易
- 顶部「记一笔」按钮弹窗快速录入（支出 / 收入 / 转账 / 买入 / 卖出，借出 / 借入以转账变体落账，成功后列表即时刷新）
- 记录收入 / 支出 / 转账 / 退款 / 买入 / 卖出 / 基金转换 / 份额调整（拆股、送股）/ 现金分红等多种类型；退款由交易行菜单发起，基金转换、份额调整与分红由 AI 导入写入、界面只读呈现
- 按账户、商户、标的、交易类型（多选）、日期组合过滤，支持分页浏览；筛选与分页在会话内保留
- 转账双向展示「转出 → 转入」，账户名、商户名、标的代码可点击下钻

### 搜索
- 按关键字检索交易备注、账户名与商户名，支持拼音首字母
- 支持金额区间与日期范围组合筛选

### 账户
- 多类型账户管理，实时余额无需手工维护
- 信用卡可登记信用额度与账单日 / 还款日，列表显示已用额度百分比，编辑弹窗显示可用额度与下次账单日 / 还款日
- 支持初始余额设置

### 投资
- 持仓、盈亏、标的、走势四个页签
- 买入 / 卖出自动匹配（FIFO），自动计算已实现盈亏；买入 / 卖出可选「出资账户」，现金实际流出 / 流入的账户纳入余额归因
- 现金分红与份额调整（拆股 / 送股 / 份额折算）记录；基金转换自动分摊、余额不变
- 资金加权收益率（XIRR）：逐标的、逐账户与全账级年化内部收益率
- 累计收益 = 持仓收益 + 已实现盈亏 + 累计分红；盈亏汇总按币种分组展示
- 一键从东方财富同步沪市、深市、港股、美股的标的信息与最新价格（支持全量与增量，带逐标的进度）
- 场外基金按 6 位代码即拉添加：自动回填东财名称、类型与最新单位净值（含净值日期），fund 类型标的的唯一创建通道
- 净值 / 价格走势曲线；持仓与盈亏页标的代码可点击，跳交易页查看该标的完整交易历史（含已清仓标的）

### 预算
- 按分类设置预算，跟踪支出进度与超支状态

### 定时计划
- 订阅、分期、定时转账三种形态，按天 / 周 / 月 / 年周期自动执行
- 支持暂停、恢复、取消与期次明细

### 物品与实物资产
- 物品：记录购入价格，自动计算在用物品的每日使用成本
- 实物资产：建档、更新估值与处置，在持合计折本位币展示

### 保险
- 保单档案管理（保险公司从保司字典选择，内置 30 家常用国内保司）
- 保费流水归保单引用，商户排行保持纯消费口径

### 报表
- 月度收支柱状图
- 分类占比分析（可按一级 / 二级层级汇总，图内逐级下钻）
- 商户消费排行（Top 5 / Top 10，点商户名下钻交易）
- 时间范围快捷选择

### 多账本
- 新建、重命名、移除与切换账本，现有数据自动成为「默认账本」；入口在侧栏左下角
- 跨账本投资汇总：各本账本的持仓市值、持仓收益、累计收益与可投资资产合并成只读合计，币种不一致时按当期汇率折算，未解锁 / 未初始化的账本逐本标注不计入

### 多端同步
- 内置 S3 兼容对象存储同步通道：用户自备存储桶 + 显式凭据，支持自定义 HTTPS 端点与寻址方式，同步包可选加密上云，保存前可测试连接
- 打开应用即同步、桌面运行期低频轮询、记完账自动上传；同步时机无需惦记
- 双端并发改动按确定性规则合并，无法执行的操作进挂起清单逐条可查，不中断同步
- 新设备凭检查点快照引导加入，只重放增量即达一致；提供厂商预设下拉，选中即预填通道参数

### AI 导入
- 应用内一键复制 AI 入口提示词，交给 Cursor、Claude Code 等 AI 助手
- AI 通过本地 HTTP 接口幂等写入账户 / 分类 / 交易，自动去重
- 两种会话形态共用同一本地 HTTP 接口：AI 记账（日常账单增量记入）与数据迁移（历史账单全量导入 + 读回对账）；导入知识分级自足，投资交易、基金申赎 / 转换、份额调整与分红等进阶知识按需获取

### 设置

按领域分域为 6 个 Tab：

- 通用：深色 / 浅色主题、界面语言、展示币种
- 分类：分类管理（二级层级、图标、拖拽排序）；币种为内置字典，不再单独展示
- 数据：备份与恢复（一键备份、自动清理旧备份、从备份恢复）、数据存储位置、整库加密、多端同步、数据修复
- 定时：定时计划域设备偏好
- 功能：功能可见性开关（预算、报表、定时、商户、投资、物品、保单、实物资产、保司九项可按需关闭，收起不用的入口）
- 关于：版本信息与日志等级

> 注：股票行情同步入口在投资页「标的」子视图（同步持仓价格）；标的全量同步已退役，标的录入走「添加投资标的」按代码查询。设置页不提供同步入口。

## 桌面与移动

- 桌面窗口收窄到移动档宽度时自动切换为移动布局（顶栏 + 导航抽屉），交易、报表、投资、预算等页面均有窄屏适配
- Android 与桌面共享同一套功能与数据口径：触屏交互、系统返回手势、安全区适配，配置同一对象存储通道即可加入多端同步

## 安装

从 [GitHub Releases](https://github.com/asiazhang/ledger/releases) 下载对应平台的安装包：

- **macOS（Apple Silicon）**：`.dmg`，拖入「应用程序」即可。已用 Developer ID 证书签名并经 Apple 公证，Gatekeeper 正常放行。
- **Windows（x64）**：`.exe`（NSIS 安装器），双击按向导安装。未签名：SmartScreen 出现「已保护你的电脑」时点「更多信息 → 仍要运行」。
- **Linux（x64）**：`.deb`（Debian/Ubuntu 系，`sudo dpkg -i` 安装）或 `.AppImage`（`chmod +x` 后直接运行）。
- **Android（arm64 APK）**：`.apk` 下载到真机直接安装（覆盖 arm64-v8a，2016 年后的绝大多数 Android 手机）；系统提示未知来源时，在「设置 → 应用 → 特殊访问权限 → 安装未知应用」中放行对应浏览器/文件管理器即可，升级同样直装新版本覆盖。

> macOS 安装包已用 Developer ID 证书签名并经 Apple 公证（验证记录见 [docs/verification/658-ci-signing-notarization.md](docs/verification/658-ci-signing-notarization.md)）；Windows 安装包未签名，Android APK 已用发布密钥签名；Linux 生态无统一代码签名机制。Windows 与 Linux 版本发布初期未经真机验证，遇到问题请到 [Issues](https://github.com/asiazhang/ledger/issues) 反馈（决策记录见 [ADR-0066](docs/adr/0066-cross-platform-release.md) 与 [ADR-0074](docs/adr/0074-android-release.md)）。

## 从源码构建

```bash
git clone git@github.com:asiazhang/ledger.git
cd ledger
pnpm install
pnpm run tauri build
```

构建产物输出到 `src-tauri/target/release/bundle/`。

> 需要本机装有 Rust 工具链、Node.js 与 pnpm（版本由 `package.json` 的 `packageManager` 字段锁定，可用 corepack 或 pnpm 官方安装脚本安装对应版本）。更多技术细节、开发命令与架构约定，请见 [AGENTS.md](AGENTS.md) 与 [docs/](docs/) 开发文档。
