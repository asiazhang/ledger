# Ledger

一款本地优先的个人记账应用：把收入、支出、转账、投资和预算全部收进一个私密的本地账本。所有数据保存在你自己的设备上，不上传云端。

当前处于早期快速迭代阶段，功能持续更新中。

## 为什么用 Ledger

- **数据私有**：账本以本地文件形式存储，离线可用，不依赖任何云端服务。
- **多币种账户**：支持现金、银行卡、信用卡、电子钱包、投资账户、负债、借出款等多种账户，余额实时计算。
- **投资记账**：买卖股票自动匹配持仓、计算已实现盈亏，可一键同步 A 股与港股行情。
- **AI 辅助导入**：把历史账单交给 AI 编程助手，通过本地接口批量写入账本，省去手工录入。

## 功能一览

### 概览
- 各账户实时余额总览

### 交易
- 顶部「记一笔」按钮弹窗快速录入（选类型填金额即可落账，成功后列表即时刷新）
- 记录**收入 / 支出 / 转账 / 退款 / 买入 / 卖出**等多种类型
- 按账户、日期、交易类型组合过滤，支持分页浏览
- 转账双向展示「转出 → 转入」，账户名可点击下钻

### 搜索
- 按关键字检索交易备注与账户名
- 支持金额区间与日期范围组合筛选

### 账户
- 多类型账户管理，实时余额无需手工维护
- 支持初始余额设置

### 报表
- 月度收支柱状图
- 分类占比分析（可按一级 / 二级层级汇总）

### 投资
- 股票标的与持仓管理
- 买入 / 卖出自动匹配（FIFO），自动计算已实现盈亏
- 一键从东方财富同步沪市、深市、港股的标的信息与最新价格（支持全量与增量）
- 场外基金按 6 位代码即拉添加：自动回填东财名称、类型与最新单位净值（含净值日期），fund 类型标的的唯一创建通道

### 预算
- 按分类设置预算，跟踪支出进度与超支状态

### AI 导入
- 应用内一键复制 AI 入口提示词，交给 Cursor、Claude Code 等 AI 助手
- AI 通过本地 HTTP 接口幂等写入账户 / 分类 / 交易，自动去重

### 设置

按领域分域为 4 个 Tab（ADR-0022；ADR-0034 更名并移除币种展示）：通用 → 分类 → 数据 → 关于。

- 通用：深色 / 浅色主题、默认币种
- 分类：分类管理（二级层级、图标、拖拽排序）；币种为内置字典，不再单独展示
- 数据：备份与恢复（一键备份、自动清理旧备份、从备份恢复）、数据存储位置
- 关于：版本信息

> 注：股票行情同步入口已迁至投资页「标的」子视图（全量同步 / 同步持仓价格），设置页不再提供。

## 安装

从 [GitHub Releases](https://github.com/asiazhang/ledger/releases) 下载最新版 macOS 安装包（DMG），拖入「应用程序」即可。

> 目前仅提供 macOS 安装包；Windows / Linux 可从源码自行构建（见下）。

## 从源码构建

```bash
git clone git@github.com:asiazhang/ledger.git
cd ledger
pnpm install
pnpm run tauri build
```

构建产物输出到 `src-tauri/target/release/bundle/`。

> 需要本机装有 Rust 工具链、Node.js 与 pnpm（版本由 `package.json` 的 `packageManager` 字段锁定，可用 corepack 启用对应版本）。更多技术细节、开发命令与架构约定，请见 [AGENTS.md](AGENTS.md) 与 [docs/](docs/) 开发文档。
