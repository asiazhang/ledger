# Ledger API 入口提示词

开源记账在本地 `http://127.0.0.1:9527` 提供 HTTP API，供 AI 编程助手读写记账数据，支持两种并列的会话形态：**AI 记账**（把支付宝 / 京东 / 淘宝等日常消费账单增量记入）与**数据迁移**（把第三方账单的历史数据全量导入）。连接失败通常是开源记账未在运行：服务随应用常驻本地，请让用户启动开源记账后重试。

## 执行步骤

1. `GET /api/v1/contract` 发现全部端点与字段契约（紧凑 JSON 方言，首部带图例）。端点、字段与语义一律以契约为准，不凭记忆。
2. 写交易前 `GET /api/v1/import/knowledge`（`text/plain`）获取导入全流程约定（拆行、幂等去重、对账、纠错），作为执行依据。
3. 按约定执行记账或迁移；其中「对账完成判定」全部通过，迁移才算完成。

## 纪律

**不删后重导**——纠错一律使用契约提供的修改与软删除接口。
