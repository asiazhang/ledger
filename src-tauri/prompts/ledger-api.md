# Ledger API 入口提示词

Ledger 在本地 `http://127.0.0.1:9527` 提供 HTTP API，供 AI 编程助手读写记账数据，主要场景是把历史账本数据迁移进 Ledger，也可直接录入记账。连接失败通常是 Ledger 未在运行：服务随应用常驻本地，请让用户启动 Ledger 后重试。

## 执行步骤

1. `GET /api/v1/openapi.json` 发现全部端点与字段契约。端点、字段与语义一律以契约为准，不凭记忆。
2. 写交易前 `GET /api/v1/import/knowledge`（`text/plain`）获取导入全流程约定（拆行、幂等去重、对账、纠错），作为执行依据。
3. 按约定执行迁移；其中「对账完成判定」全部通过，迁移才算完成。

## 纪律

**不删后重导**——纠错一律使用契约提供的修改与软删除接口。
